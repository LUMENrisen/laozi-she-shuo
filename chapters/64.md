

## 引言：最“自白”的一章，最“日常”的母职

帛书本第二十章，是《德道经》中老子最为“现身说法”的章节之一。他描述了自己与世俗的背离：

> 絕學无憂。
>
> 唯與訶，其相去幾何？美與惡，其相去何若？
>
> 人之所畏，亦不可以不畏。恍呵其未央哉，
>
> 眾人巸（熙）巸（熙），若鄉（饗）於大牢，而春登臺。
>
> 我泊焉未佻（兆），若嬰兒未咳。累呵如无所歸。
>
> 眾人皆有餘，我獨遺。我禺（愚）人之心也，蠢蠢呵。
>
> 鬻（俗）人昭昭，我獨若𦟲（昏）呵。鬻（俗）人蔡（察）察（察），我獨𨴽（悶）𨴽（悶）呵。
>
> 忽呵其若海，望（恍）呵其若无所止。
>
> 眾人皆有以，我獨頑以悝（俚）。
>
> 吾欲獨異於人，而貴食母。

“绝学无忧”——抛弃（过度的）学问，就没有忧虑。“唯”与“呵”（恭敬的应答与呵斥），相差多少？“美”与“恶”，相差多少？人们所畏惧的，我也不可以不畏惧。茫茫然像没有尽头啊！众人都熙熙攘攘，像去参加盛大的宴席，像春天登上高台赏景。我却独自淡泊，没有迹象，像婴儿还不会笑。疲惫啊，像无家可归。众人都富足有余，唯独我像有所遗失。我真是愚人的心啊，浑浑沌沌！俗人都很精明，唯独我昏昏沉沉；俗人都很明察，唯独我闷闷无言。恍惚啊像大海，飘忽啊像没有止境。众人都有所作为，唯独我顽劣又鄙陋。我和别人不同——我珍贵的是“食母”（以道为养）。

朱邦復先生在《止笑譚》中，将这一章解读为 **“对世俗价值观的彻底否定与对道的独尊”** 。他认为“绝学无忧”是承接上一章“绝圣弃智”的逻辑——“学”是为了“益”（积累知识），但“道”是“损”（舍弃多余），“绝学”才能“无忧”。他区分了“为学日益”与“为道日损”——学得越多，人离“道”越远。而他最后落脚在“贵食母”——以道为养，就像婴儿以母乳为养一样。

但如果我们把主语换成“母亲的身体”——那个每天都在被孩子耗尽、却仍然在喂养的身体——这一章就不再是“哲学家的独白”，而是一份 **“一个疲惫母亲的自白书”**：

- “绝学无忧”——孩子出生后的最初几年，你根本没时间“学”新东西。你的认知资源被孩子的需求占满了。但你反而“无忧”了——因为你的关注点极其单一：他。
- “唯与诃，其相去几何？”——你曾经在乎的“好”与“坏”、“对”与“错”，现在都模糊了。你唯一在乎的是：他饿了？困了？难受了？
- “众人熙熙，如享太牢，如春登台”——别人在追逐热闹、欢宴、升职、旅行。你却在——哄睡、喂奶、换尿布。你无法“登台”，因为你的舞台太小了。
- “我泊焉未兆，若婴儿未咳”——你像那个“还没学会笑”的婴儿。你不是“麻木”——你是“还没来得及反应”。你的时间被孩子的节奏切割成碎片，你已经没有“完整反应”的能力了。
- “俗人昭昭，我独昏昏”——别人精明、计划、有条理；你昏昏沉沉、忘东忘西、无法规划。但这不是你的“缺陷”——是你的注意力和时间被重新分配了。
- “众人皆有以，我独顽以俚”——别人都有“用”、有“成就”、有“产出”；你“无用”、你“愚顽”、你“鄙陋”——但你的“无用”正是另一个生命的“有用”。
- “吾欲独异于人，而贵食母”——“食母”在这里不是比喻——就是**母乳**。你喂养他——用你的身体、你的时间、你的生命。这不是“像”道——这就是道本身。

让我们逐句对照。


## 一、“絕學无憂”——抛弃（过度的）学问，就没有忧虑

### 朱邦復的解读：知识越多，忧虑越多

朱先生将“绝学无忧”解读为“不刻意追求学问知识”：

> “不追求學問知識，是無憂無慮的不二法門。”

> “人所知本有限，而環境變化無窮，知愈多愈不足。不學尚不知其不足，知多反而慮多。”

他的逻辑是：学问本身不是问题，但“为学”的目的是“日益”——越学越多。而“为道”的目的是“日损”——越舍越少。当你不再追求“更多知识”时，你才能从“知识焦虑”中解脱。

### 从身体经验出发：孩子出生后根本没时间“学”——但你反而“无忧”了

“絕學无憂”——在母亲的身体里，“绝学”是什么？

- **孩子出生后的最初几年，你根本没有时间“学”新东西。** 你没有时间看书、没有时间上课、没有时间“提升自己”。你的认知资源被孩子的需求占满了——喂奶、换尿布、哄睡、陪玩。你“绝学”了——不是主动选择，是生存需要。
- **但你也“无忧”了。** 不是因为“什么都不担心”——是因为你的关注点变得极其单一：**他饿了吗？他困了吗？他难受吗？** 你不再为“我应该学什么”、“别人怎么看我”、“我有没有进步”而焦虑——你只是在他需要的时候回应他。
- **“无忧”不是“没有忧虑”——是“忧虑的内容被简化了”。** 你不再为“未来的不确定性”而忧——因为你连“明天能不能睡个好觉”都不确定。你只活在当下——他哭了，你抱；他睡了，你躺。这就是“无忧”——不是没有烦恼，是烦恼不再复杂。

朱先生说“绝学无忧”是舍弃过多知识带来的焦虑。母亲的身体告诉我们：**孩子出生后，你没时间学、没精力学——但你也不再为“学习焦虑”所困。你的关注点从“我要学什么”变成了“他需要什么”。**

| 朱邦復的“绝学无忧” | 母亲经验的“绝学无忧” |
| :--- | :--- |
| 不追求学问知识，就没有忧虑 | 孩子出生后根本没时间学，但也不再为“学习焦虑”而忧 |
| 第三人称：为学与为道的对立 | 第一人称：我不学新东西——但我的关注点变得极其单一：他 |


## 二、“唯與訶，其相去幾何？”——恭敬与呵斥，相差多少？

### 朱邦復的解读：世俗的价值判断差别不大

朱先生将“唯之与阿，相去几何”解读为“尊与侮差別不大”：

> “別人對我的態度，是尊重抑輕侮，又有多少差別？”

他的逻辑是：人们在乎的“尊重”和“轻侮”，在道的层面看差别并不大。这些价值判断是人为的，不是绝对的。

### 从身体经验出发：你曾经在乎的“对错”，现在都模糊了——“他”才是唯一的参照

“唯與訶，其相去幾何？”——在母亲的身体里，“唯”和“诃”是什么？

- **“唯”是别人对你的认可、赞美、尊重。** “你真是个伟大的妈妈”、“你做得太好了”——这些是“唯”。
- **“诃”是别人对你的批评、否定、轻蔑。** “你怎么连孩子都带不好”、“你太没用了”——这些是“诃”。
- **产后的母亲——这两者的差别变小了。** 别人说你“做得好”，你不会狂喜——因为你太累了；别人说你“做得不好”，你不会崩溃——因为你太忙了。你唯一在乎的是：**孩子吃饱了、睡好了、安全了。** 外界的评价，和孩子的哭声比起来——都太远了。

朱先生说“唯与阿相去几何”是世俗价值判断差别不大。母亲的身体告诉我们：**产后的你，不再被“赞美”或“批评”轻易撼动——因为你的参照系已经从“别人怎么看我”变成了“他是否安好”。“唯”和“诃”的差别，在孩子的平安面前，确实“相去几何”？——没多少。**

| 朱邦復的“唯与阿相去几何” | 母亲经验的“唯与阿相去几何” |
| :--- | :--- |
| 尊重与轻侮，差别不大 | 产后你不再被赞美或批评轻易撼动——“他是否安好”才是唯一的参照 |
| 第三人称：世俗价值的相对性 | 第一人称：“他睡了”——比我被夸或被骂重要一万倍 |


## 三、“美與惡，其相去何若？”——美与恶，相差多少？

### 朱邦復的解读：美丑善恶的界限是相对的

朱先生将“善之与恶，相去若何”解读为“所谓善与恶，差别不大”：

> “所謂善與惡，又有多大的差別？”

他的逻辑是：善恶是人的主观判断，不是客观真实。它们在不同文化、不同情境中差别很大——没有一个固定的“善”或“恶”本身。

### 从身体经验出发：产后你不再在乎“美”——“舒服”才是标准

“美與惡，其相去何若？”——在母亲的身体里，“美”和“恶”是什么？

- **“美”是“好看、整齐、精致、让人欣赏”。** 你曾经在乎的——妆容、穿搭、身材、形象。
- **“恶”是“丑、乱、脏、让人嫌弃”。** 你曾经回避的——素颜、凌乱、奶渍、疲惫。
- **产后的母亲——“美”与“恶”的界限模糊了。** 你穿着沾了奶渍的睡衣、头发没洗、脸色苍白——但你不会因此觉得自己“丑”。你抱着孩子、他安静地睡着、你感受到他的体温——那一刻，你觉得自己“美”吗？不，你根本不考虑这个问题。你只是“在”。那种“在”的满足感，比“好看”重要得多。
- **“美”的标准变了——“他舒服”就是“美”。** 你曾经为了“好看”花一个小时化妆，现在你为了“让他舒服”花一晚上哄睡。你的“美”不再属于“视觉审美”的范畴——它属于“他是否安然”的范畴。

朱先生说“美恶相去何若”是美丑善恶的界限是相对的。母亲的身体告诉我们：**产后你不再在乎“美”——“他安好”就是美。奶渍、素颜、疲惫——在你感受到他呼吸的那一刻，都不再是“恶”。**

| 朱邦復的“美恶相去何若” | 母亲经验的“美恶相去何若” |
| :--- | :--- |
| 美丑善恶的界限是相对的 | 产后你不再在乎“美”——“他安好”就是美 |
| 第三人称：价值的相对性 | 第一人称：奶渍不是“恶”——他睡了，就是“美” |


## 四、“人之所畏，亦不可以不畏”——人们畏惧的，我也不可以不畏惧

### 朱邦復的解读：顺应世俗的戒慎

朱先生将“人之所畏，不可不畏”解读为“别人害怕的，我也不能不怕”：

> “人們所畏懼的，我也不能不害怕。”

但他在注解中暗示这种“畏”是表面的、暂时的——不是真正的“畏道”，而是顺应世俗的谨慎。

### 从身体经验出发：母亲最“畏”的不是别人怕的——是孩子生病、受伤、意外

“人之所畏，亦不可以不畏”——在母亲的身体里，“畏”是什么？

- **“人之所畏”是别人怕的东西——失业、贫穷、失败、社交评价。** 你曾经也怕过。
- **但你现在的“畏”已经变了。** 你最怕的是：孩子发烧到39度、他摔倒了、他咳嗽不止、他半夜突然哭醒——这些是“人之所畏”吗？别人不一定怕这些——但你怕。非常怕。
- **“亦不可以不畏”的另一层意思：** 你变得“胆小”了。你过马路时更小心、你更注意食品安全、你更在意环境温度——不是因为你自己，是因为你还要为他活。你的“畏”不是软弱——是因为你的生命里多了一个完全依赖你的人。

朱先生说“人之所畏不可不畏”是顺应世俗的戒慎。母亲的身体告诉我们：**你的“畏”已经变了——你现在最怕的不是失败和贫穷，是孩子生病、受伤、意外。你变得“胆小”——因为你的命不再只属于你自己。**

| 朱邦復的“人之所畏不可不畏” | 母亲经验的“人之所畏不可不畏” |
| :--- | :--- |
| 顺应世俗的戒慎 | 你的“畏”变了——最怕的是孩子生病、受伤 |
| 第三人称：世人的共同恐惧 | 第一人称：我变“胆小”了——因为我的命不再只属于我 |


## 五、“眾人熙熙，若饗於大牢，而春登臺”——众人熙攘，像赴盛宴，像春登高台

### 朱邦復的解读：世俗的快乐与热闹

朱先生将“众人熙熙，如享太牢，如春登台”解读为“人们快乐的欢笑、游玩”：

> “人們快樂的歡笑、遊玩。”

他在对比自己的淡泊——众人追逐热闹，他却独自淡泊。

### 从身体经验出发：别人在享宴登台，你在哄睡喂奶——你的“台”只有一米宽

“眾人熙熙”——在母亲的身体里，“熙熙”是什么？

- **别人在聚会、旅行、升职、发表、被赞美、被看见。** 他们在“享太牢”、“春登台”——他们是台上的主角、宴席的嘉宾。
- **你呢？** 你在凌晨三点抱着哭闹的孩子在房间里来回走、你在厨房热辅食、你在叠尿布——你的“台”只有一米宽（婴儿床到餐桌的距离）。你的“宴席”是他吃完辅食后睡着的那一刻。
- **“如春登台”的反面：** 你无法“登台”——因为你的舞台太小了、你的节目太重复了、你的观众只有一个人（而且他还不会鼓掌）。但你不需要“舞台”——因为你的全部注意力都在这个小小的生命上。

朱先生说“众人熙熙”是世俗的欢乐与热闹。母亲的身体告诉我们：**别人在享宴登台，你在哄睡喂奶——你的“台”只有一米宽，但那是你全部的、唯一的舞台。**

| 朱邦復的“众人熙熙如享太牢” | 母亲经验的“众人熙熙如享太牢” |
| :--- | :--- |
| 世俗的热闹与欢乐 | 别人在聚会、旅行、登台，你在哄睡、喂奶、换尿布 |
| 第三人称：世俗的快乐场景 | 第一人称：我的“舞台”只有一米宽——但那是我的全部 |


## 六、“我泊焉未兆，若嬰兒未咳”——我淡泊无迹，像婴儿还不会笑

### 朱邦復的解读：返璞归真的状态

朱先生将“我独泊兮其未兆，如婴儿之未孩”解读为“淡泊恬静，心若止水”：

> “我卻淡泊恬靜，心若止水。……像嬰兒一樣。”

“未孩”是“还没学会笑”。婴儿在会笑之前，他的状态是最本真的——不表演、不讨好、不伪装。

### 从身体经验出发：你不是“淡泊”——你是“来不及反应”

“我泊焉未兆，若嬰兒未咳”——在母亲的身体里，“泊焉未兆”是什么？

- **你不是“淡泊”——你是“来不及反应”。** 孩子哭，你抱；孩子睡，你躺；孩子需要，你给。你的节奏完全被他的节奏占据，你“来不及”去追求、去争取、去表现。你不是“超脱”——你是“被占据”。
- **“若嬰兒未咳”——你不是“像婴儿”——你怀里就有一个婴儿。** 那个真实地、正在呼吸、正在睡着的婴儿。你和他在一起——你不需要“像”他——你就在他身边。
- **“未兆”的另一种理解：** 你不是“没有计划”——是“计划被孩子的节律切碎了”。你无法为明天做太多规划——因为明天取决于他几点醒、几点吃、几点睡。

朱先生说“泊焉未兆若婴儿未孩”是返璞归真的状态。母亲的身体告诉我们：**你不是“淡泊”——你是“来不及反应”。你的时间被孩子的需求切碎了，你“像”一个未咳的婴儿——不是因为你“修炼”到了那个境界，是因为你活在他的节奏里。**

| 朱邦復的“泊焉未兆若婴儿未孩” | 母亲经验的“泊焉未兆若婴儿未孩” |
| :--- | :--- |
| 淡泊恬静，像婴儿一样本真 | 你不是“淡泊”——你是“来不及反应”，因为活在他的节奏里 |
| 第三人称：修炼的境界 | 第一人称：我不是“像”婴儿——我怀里就有一个真实的婴儿 |


## 七、“眾人皆有餘，我獨遺”——众人都有余，唯独我像遗失了什么

### 朱邦復的解读：世俗的富足与道的匮乏

朱先生将“众人皆有馀，我独若遗”解读为“别人都富足，唯独我像有所遗失”：

> “人人都志得意滿、努力進取，只有我是我行我素、遺世獨立。”

他的“遗”是“被世人遗忘”、“脱离世俗”。

### 从身体经验出发：你“遗”的不是“财富”——是“时间”、“自己”、“记忆”

“眾人皆有餘，我獨遺”——在母亲的身体里，“遗”是什么？

- **你“遗”了时间。** 你没有“余”时间——你的时间都被他用完了。你“遗”了睡眠——你“遗”了曾经属于你自己的夜晚。
- **你“遗”了自己。** 你的社交圈缩小了、你的爱好暂停了、你的个人时间消失了——你“遗”了那个“只为自己而活”的自己。
- **你“遗”了记忆。** 你记不住昨天发生了什么、记不住最后一次完整的睡眠是什么时候——你的大脑被“何时喂奶、何时换尿布”占满了。
- **但这种“遗”不是“失去”——是“转移”。** 你的时间、自己、记忆——它们没有“消失”——它们被转移到了他身上。你“遗”的部分，就是他已经拿走的部分。

朱先生说“众人皆有馀我独若遗”是世俗富足与道的匮乏之间的对比。母亲的身体告诉我们：**你“遗”了很多——时间、自己、记忆——但你不是“失去了”，你只是“转移了”。他拿走了你的一部分，所以你已经不完全属于你自己了。**

| 朱邦復的“众人皆有馀我独若遗” | 母亲经验的“众人皆有馀我独若遗” |
| :--- | :--- |

## 八、“我愚人之心也，蠢蠢呵”——我是愚人的心啊，浑浑沌沌

### 朱邦復的解读：大智若愚

朱先生将“我愚人之心也哉！沌沌兮”解读为“我行我素，不起波澜”：

> “我的心如宇宙初生時的渾沌，對這些表象都不起波瀾。”

他解释“愚”不是“笨”——是“不被世俗精明所染”，是“大智若愚”。

### 从身体经验出发：你“愚”不是“笨”——是你的注意力被重新分配了

“我禺人之心也，蠢蠢呵”——在母亲的身体里，“愚”是什么？

- **你“愚”了。** 你反应变慢了、记忆力变差了、注意力不集中了——“妈妈脑”（Mom Brain）是真实存在的生理现象。睡眠不足、激素变化、认知资源被分散——你确实变“笨”了。
- **但这不是“智力下降”——是“注意力被重新分配了”。** 你对“育儿专家级别”的知识可能变钝了——但你对“孩子的哭声是饿还是困”变敏感了。你不是变“蠢”了——是你的智力被重新定向了。
- **“蠢蠢呵”的另一个层面：** 你不再像以前那样“精明”了——你不再精于计算得失、不再精于社交周旋、不再精于自我包装。不是因为“懒得”——是因为“精力被用完了”。

朱先生说“我愚人之心”是大智若愚、不被世俗精明所染。母亲的身体告诉我们：**你变“愚”了——反应变慢、记忆力下降——但你的“愚”是生理上的（睡眠不足、认知资源被占用），不是道德上的。你的注意力被重新分配给了更重要的事——他。**

| 朱邦復的“我愚人之心” | 母亲经验的“我愚人之心” |
| :--- | :--- |
| 大智若愚，不被世俗精明所染 | 你变“愚”了——“妈妈脑”、反应变慢——但你的注意力被重新分配给了他 |
| 第三人称：道的浑朴 | 第一人称：我确实变“笨”了——但我能分辨他哭声中的不同 |


## 九、“俗人昭昭，我独若昏”——俗人精明，我独自昏沉

### 朱邦復的解读：世俗的精明与道的昏昧

朱先生将“俗人昭昭，我独昏昏”解读为“俗人明察秋毫，我却浑浑噩噩”：

> “有些人飛黃騰達、意興風發，唯我渾渾噩噩。”

“昭昭”是清晰、精明、有条理；“昏昏”是模糊、迟钝、不明确。老子说自己与世俗相反。

### 从身体经验出发：你不是“昏沉”——你是活在与世俗不同的“流速”里

“鬻人昭昭，我獨若昏呵”——在母亲的身体里，“昏”是什么？

- **别人是“昭昭”的——他们有计划、有目标、有效率、有产出。** 他们的生活是清晰的、可衡量的、可见的。
- **你是“昏昏”的——你的生活是破碎的、重复的、没有“产出的”。** 你的一天被切割成无数个小片段：喂奶、换尿布、哄睡、再喂奶……你没有一个“完整的”可描述的一天。
- **但你不是“昏”——你是活在与世俗不同的“流速”里。** 孩子的节律就是你的节律——他睡你醒、他醒你醒、他哭你醒……你的时间不是线性的，是围绕他的需求波动的。你的“昏”不是迟钝——是“你的生活节律不再同步于社会时钟”。

朱先生说“俗人昭昭我独昏昏”是世俗精明与道的昏昧的对比。母亲的身体告诉我们：**你不是“昏沉”——你是活在与世俗不同的“流速”里。你的时间被他的需求切碎了，你的“昏”是“无法与社会时钟同步”的症状。**

| 朱邦復的“俗人昭昭我独昏昏” | 母亲经验的“俗人昭昭我独昏昏” |
| :--- | :--- |
| 世俗精明，道的昏昧 | 你的生活是破碎的、重复的、无产出的——不是昏，是时间被切碎了 |
| 第三人称：智与愚的对比 | 第一人称：我的“流速”和他的节律同步——和社会不同步 |


## 十、“俗人察察，我独闷闷”——俗人明察，我独闷闷不语

### 朱邦復的解读：世俗的察察与道的闷闷

朱先生将“俗人察察，我独闷闷”解读为“别人什么都明察秋毫，我却默默无言”：

> “有些人好像什麼都明察秋毫，而我則默默無言。”

“察察”是精细、锐利、看得清楚；“闷闷”是沉默、不尖锐、不显露。

### 从身体经验出发：你不是“没话说”——是“没力气说”

“鬻人蔡蔡，我獨悶悶呵”——在母亲的身体里，“闷闷”是什么？

- **你不是“沉默寡言”——是“没力气说”。** 晚上起来三次、白天还要应对各种需求——你没有多余的能量去“昭昭”、去“察察”、去参与那些“细腻的观察和判断”。
- **你的“闷闷”是：** 别人在分析、在评论、在建议——你在听、在点头、然后忘记。不是“不在意”——是“没有精力在意”。
- **“闷闷”的另一个层面：** 你不参与那些“精明的对话”——你不去评论“别人怎么带孩子”、不去分析“哪个育儿方法更好”——因为你太累了。你的注意力只够覆盖他的需求。

朱先生说“俗人察察我独闷闷”是世俗的精细与道的沉默的对比。母亲的身体告诉我们：**你不是“没话说”——是“没力气说”。你的“闷闷”不是“修行”——是“睡眠不足的副产品”。**

| 朱邦復的“俗人察察我独闷闷” | 母亲经验的“俗人察察我独闷闷” |
| :--- | :--- |
| 世俗精细，道者沉默 | 你不是“没话说”——是“没力气说”，注意力只够覆盖他的需求 |
| 第三人称：智与愚的对比 | 第一人称：我没有精力去分析、评论——我太累了 |


## 十一、“忽呵其若海，恍呵其若无所止”——恍惚像大海，飘忽像没有止境

### 朱邦復的解读：得道者的广阔与无执

朱先生将“澹兮其若海，飂兮若无止”解读为“像大海一般恬淡，像大风一样无所归止”：

> “我像大海一般恬淡，又像大風一樣無所歸止。”

他描述的是得道者的心境——广阔、不执着、不被任何事物所固定。

### 从身体经验出发：你的世界确实像海——孩子的需求像潮水，来了又退，退了又来

“忽呵其若海，望呵其若无所止”——在母亲的身体里，“海”和“无所止”是什么？

- **你的世界像海——孩子的需求像潮水。** 饿了、困了、哭了、需要抱——一波又一波，来了又退，退了又来。你永远不知道下一波什么时候来——但你确信它会来。
- **“无所止”——你的睡眠没有止境、你的疲惫没有止境、你的“待命”没有止境。** 你不知道什么时候“做完”了——因为“做完”不是一个选项。他的需求是连续的、没有“完成”的。
- **“海”的容量：** 你像海一样——能容纳他的每一次哭、每一次闹、每一次需要。但你也是海水本身——潮汐不是“外来的”——是你身体里涌动的节奏。

朱先生说“忽呵其若海”是道者广阔无执的心境。母亲的身体告诉我们：**你的世界确实像海——他的需求像潮水，一波接一波，你永远不知道下次“登陆”是什么时候。但你还在、你还在这里、你还等着下一波。**

| 朱邦復的“忽呵其若海” | 母亲经验的“忽呵其若海” |
| :--- | :--- |
| 道者的广阔与无执 | 孩子的需求像潮水，来了又退、退了又来——你永远在“待命” |
| 第三人称：道的境界 | 第一人称：我的“无所止”是——没有“做完”的一天 |


## 十二、“眾人皆有以，我獨頑以俚”——众人都有所作为，我独顽劣鄙陋

### 朱邦復的解读：世俗的有用与道的无用

朱先生将“众人皆有以，我独顽且鄙”解读为“众人都有能力，唯独我既愚昧又鄙陋”：

> “眾人都有能力，唯獨我既愚昧又鄙陋。”

“有以”是有用、有作为、有成就；“顽”是顽固不化；“俚”是粗俗、鄙陋。老子说自己与世俗的有用相反。

### 从身体经验出发：你“无用”——你的“用”是另一个人全部的生命

“眾人皆有以，我獨頑以悝”——在母亲的身体里，“顽以俚”是什么？

- **别人都有“用”、有“产出”、有“成就”。** 他们升职、发表、被认可、被看见——他们有“用”。
- **你“无用”——你的工作不被计入GDP、不被写在简历上、不被授勋表彰。** 你喂奶、换尿布、哄睡、重复、重复、重复——这些“没有产出”的活动，就是你的全部“用”。
- **但你的“无用”是另一个人全部的“用”。** 你之所以“无用”，是因为你的“用”已经转移到了他身上——他的生存、他的成长、他的安全感——全部依靠你的“无用的活动”。你的“顽”是不被看见的坚持；“鄙”是不被计入的价值。

朱先生说“众人皆有以我独顽且鄙”是世俗的有用与道的无用的对比。母亲的身体告诉我们：**我“无用”——我的工作不被看见、不被计量、不被奖励。但我的“无用”是他全部的“有用”。**

| 朱邦復的“众人皆有以我独顽且鄙” | 母亲经验的“众人皆有以我独顽且鄙” |
| :--- | :--- |
| 世俗有用，道者无用 | 你的“用”不在简历上、不在GDP里——但在他每一口呼吸中 |
| 第三人称：有用与无用的颠倒 | 第一人称：我的“无用”是他的“有用”——全部的“用” |


## 十三、“吾欲獨異於人，而貴食母”——我独异于人，珍贵的是“食母”

### 朱邦復的解读：以道为养

朱先生将“我独异于人，而贵食母”解读为“不假外求，依循自然”：

> “真知灼見之人，……獨立特行，不苟同於眾昧。”

“食母”是“以道为养”——就像婴儿以母乳为食一样，道的滋养是最原始的、最根本的。

### 从身体经验出发：“食母”不是比喻——就是**母乳**。你喂养他——用你的身体，这就是道本身

“吾欲獨異於人，而貴食母”——在母亲的身体里，“食母”是什么？

- **“食母”不是比喻——就是母乳。** 你用你的身体喂他——不是“像”道，这就是道本身。你的乳汁、你的温度、你的存在——这些都是“食母”。他吃你，你滋养他——这是最原始的道。
- **“貴食母”的深层含义：** 你不去别处寻找“道”的滋养——你就在喂养中成为了滋养本身。你不需要“学”道——你就在“行”道。每一次喂奶，每一次抱，每一次回应——这些都是“食母”——你给他，他用。
- **“吾欲獨異於人”——你不是“独异”——你只是在做别人可能没机会做的事。** 你在这个社会中显得“异”——因为你在喂奶、在哄睡、在做那些“不产出”的事。但你不是“脱离社会”——你是在做最基本、最原始的事：让另一个生命活下去。

朱先生说“贵食母”是以道为养——就像婴儿以母乳为食一样。母亲的身体告诉我们：**“食母”不是比喻——就是母乳。你喂他，这就是道本身。你不需要去别处找“道”——你就是它的源头。**

| 朱邦復的“贵食母” | 母亲经验的“贵食母” |
| :--- | :--- |
| 以道为养 | “食母”就是母乳——你喂他，这就是道本身 |

## 结语：绝学、未兆、食母——母亲是“道”最日常的化身

朱邦復先生在这一章中，用“绝学无忧”开篇，以“贵食母”收尾，勾勒了一个与世俗背道而驰的求道者形象——他不追逐热闹、不精明算计、不追求有用——他像婴儿一样“未咳”、像海一样“无执”、像愚人一样“浑沌”。最后，他落在了“食母”——以道为养。

而母亲的身体，是这一章最完整的“实践场”：

- **“绝学无忧”——你没时间学新东西，但也不再为“学不会”而焦虑。**
- **“唯与诃，相去几何”——你不再被赞美和批评轻易撼动——“他睡了”比任何评价都重要。**
- **“美与恶，相去何若”——你不再在乎“美”——“他安好”就是美。**
- **“人之所畏”——你变“胆小”了——最怕的是他生病、受伤。**
- **“众人熙熙”——别人在享宴登台，你在凌晨三点抱着他在房间里来回走。**
- **“泊焉未兆”——你不是“淡泊”——你是“来不及反应”，活在他的节奏里。**
- **“若婴儿未咳”——你不是“像”婴儿——你怀里就有一个真实的、正在呼吸的婴儿。**
- **“众人皆有馀，我独遗”——你“遗”了时间、睡眠、自己——但你“遗”的部分，就是他拿走的部分。**
- **“我愚人之心”——你变“笨”了——但“妈妈脑”不是智力下降，是注意力被重新分配。**
- **“俗人昭昭，我独昏昏”——你不是“昏沉”——你是活在与世俗不同的“流速”里。**
- **“俗人察察，我独闷闷”——你不是“没话说”——是“没力气说”。**
- **“忽呵其若海”——孩子的需求像潮水，一波接一波——但你还在这里。**
- **“众人皆有以，我独顽以俚”——你的“用”不在简历上，但在他每一口呼吸中。**
- **“吾欲独异于人，而贵食母”——“食母”不是比喻——就是母乳。你喂他——这就是道本身。**

**“绝学无忧”——不是“不学”——是“不被学习焦虑所困”。母亲在最忙的时候“绝学”了——她没有时间“学习如何做母亲”，她只是在“做母亲”。“未兆”——不是“没有计划”——是“计划被他的节律切碎了”。“食母”——不是比喻——是真实的、身体的、每一天都在发生的喂养。**

一个母亲就是“道”最日常的化身。她不需要“模仿”道的状态——她就在道的状态里。她不“像”婴儿——她怀里就有一个真实的婴儿。她不“以道为养”——她就是“食母”的源头。

**“吾欲独异于人，而贵食母”——老子说他和别人不同，因为他珍贵的是“食母”（以道为养）。而对一个母亲来说，“食母”就是她每天在做的事——喂他、抱他、回应他。她不需要“学”道——她就在“行”道。**



## 引言：最“政治”的一章，最“母亲”的尺度

帛书本第五十八章，是《德道经》中关于“政之宽严”与“祸福相依”的集中论述：

> 其政閔閔，其邦屯屯。其正（政）察察，其邦夬（缺）夬（缺）。
>
> 𢢸（禍），福之所倚；福，𢢸（禍）之所伏；孰知其極？其无正也？正復為奇，善復為妖。
>
> 人之迷也，其日固久矣。
>
> 是以方而不割，廉而不刺，直而不紲，光而不曜。

“其政闷闷，其邦屯屯”——政治宽厚包容，国家就淳朴富足。“其政察察，其邦缺缺”——政治苛刻严明，国家就缺漏凋敝。

“祸，福之所倚”——灾祸旁边就倚靠着福；“福，祸之所伏”——福分里面就潜伏着祸。“孰知其极？”——谁能知道它们的终极呢？“其无正也？”——难道没有确定的标准吗？“正复为奇”——正会转变为奇，“善复为妖”——善会转变为妖。“人之迷也，其日固久矣”——人们对此迷惑不解，已经很久了。

“是以方而不割”——所以方正但不割伤人，“廉而不刺”——有棱角但不刺伤人，“直而不绁”——正直但不放肆，“光而不曜”——有光芒但不耀眼。

朱邦復先生在《止笑譚》中，将这一章解读为 **“政策宽严的辩证与祸福相倚的规律”** 。他认为“其政闷闷”是宽厚平实的政策，人民醇厚朴实；“其政察察”是严明的政策，人民因畏惧而心存侥幸、民风浇薄。他特别强调了“祸兮福之所倚，福兮祸之所伏”——幸福与灾祸是相互依存的，正如电性磁力不可分离。他最后以“方而不割，廉而不劌，直而不肆，光而不耀”作结——圣人行事方正但不伤及他人、自持原则但无害于人、正直坦率但不放肆、道德学问过人却隐匿锋芒。

但如果我们把主语换成“母亲的身体”——那个在养育中面对“闷闷”与“察察”的选择、在孩子的成长中经历“祸福相依”、最终以“方而不割、光而不耀”的方式存在的身体——这一章就不再是“政治哲学”，而是一份 **“关于母亲如何在‘宽’与‘严’之间找到尺度、如何在孩子的‘祸’与‘福’中保持稳定、如何以‘光而不耀’的方式存在于孩子生命中的日常记录”**：

- “其政闷闷，其邦屯屯”——母亲宽松、包容、不处处干涉，孩子就“屯屯”（淳朴、富足、有生命力）。他不被规矩压住——他有空间成为自己。
- “其政察察，其邦缺缺”——母亲苛刻、审视、处处要求，孩子就“缺缺”（缺漏、凋敝、失去生命力）。他活在“被检查”的状态里——他的“自己”在缩小。
- “祸，福之所倚”——孩子的“问题”（不乖、难带、犯错）里，可能藏着他的“福”（有主见、有韧性、有边界）。母亲的焦虑——可能是她还没看见那个“福”。
- “福，祸之所伏”——孩子的“顺利”（听话、优秀、省心）里，可能潜伏着“祸”（失去自我、压抑、讨好）。母亲的欣慰——可能藏着未来的担忧。
- “孰知其极？”——谁能知道这些变化最终会走向哪里？母亲不知道。她只能看着、等着、不急着下结论。
- “正复为奇，善复为妖”——你以为“对”的，可能变成“错”；你以为“好”的，可能变成“坏”。母亲最深的困惑——就是“什么是对的”。
- “方而不割”——母亲有原则、有边界，但不“割”孩子的心。她的“方”（规则、底线）是用来保护关系的——不是用来切割关系的。
- “廉而不刺”——她有“棱角”（自己的立场、自己的需要），但不刺伤孩子。她不把自己的“棱角”当作伤害孩子的工具。
- “直而不绁”——她正直、坦率、不撒谎，但不“放肆”（不把自己的直率变成攻击）。她该说的时候说——但不“过”。
- “光而不曜”——母亲的存在有“光”（温暖、爱、影响力），但那个光不“曜”（不刺眼、不炫耀、不让孩子感到压力）。她发光——但她的光不会灼伤他。


## 一、“其政闷闷，其邦屯屯”——政宽则国富

### 朱邦復的解读：宽厚政治带来淳朴

朱先生将“其政闷闷，其民淳淳”解读为“宽厚的政治带来淳朴的民风”：

> “國家之政策平實，人民的生活也就淳厚樸實。”

“闷闷”是宽厚、不严苛、不琐碎。“屯屯”是淳朴、富足、充实。政治不折腾——人民就活得好。

### 从身体经验出发：母亲宽松、包容、不处处干涉——孩子就“屯屯”（淳朴、有生命力）

“其政閔閔，其邦屯屯”——在母亲的身体里，“闷闷”和“屯屯”是什么？

- **“闷闷”是宽松、不严苛、不处处干涉。** 她不每件事都管、不每个行为都纠正、不给生活塞满“不可以”。那是“闷闷”——宽厚、不琐碎。
- **“屯屯”是孩子淳朴、富足、有生命力。** 他不活在“被检查”的紧张里——他有空间探索、犯错误、成为自己。那是“屯屯”——不是因为“被管得好”——是因为“管得少”。
- **“闷闷”的另一种理解：** “闷”不是“不管”——是“不苛刻”。她不是“放任”——是“信任”。信任本身比管制更有力量。

朱先生说“闷闷之政民淳淳”是宽厚政治带来淳朴民风。母亲的身体告诉我们：**她宽松、不处处干涉——孩子就“屯屯”（淳朴、富足、有生命力）。不是因为“管得好”——是因为“管得少”。**

| 朱邦復的“闷闷之政民淳淳” | 母亲经验的“其政閔閔其邦屯屯” |
| :--- | :--- |
| 宽厚政治带来淳朴民风 | 她宽松、不处处干涉——孩子就淳朴、富足、有生命力 |
| 第三人称：宽政的效果 | 第一人称：我管得少——他活得好 |


## 二、“其政察察，其邦缺缺”——政苛则国凋

### 朱邦復的解读：严苛政治带来凋敝

朱先生将“其政察察，其民缺缺”解读为“严明的政策带来民风浇薄”：

> “如政策嚴明，人民將因畏懼而心存僥倖，民風澆薄。”

“察察”是严苛、审视、明察秋毫。“缺缺”是缺漏、凋敝、不满。政治太严苛——人民反而活不好。

### 从母亲经验的解读：母亲苛刻、审视、处处要求——孩子就“缺缺”（失去生命力、缩小自己）

“其正察察，其邦夬夬”——在母亲的身体里，“察察”和“缺缺”是什么？

- **“察察”是严苛、审视、处处检查。** 她检查他的行为、检查他的表现、检查他是否符合标准——那是“察察”。
- **“缺缺”是孩子失去生命力。** 他活在“被检查”的紧张里——不敢出错、不敢表达、不敢做自己。那是“缺缺”——不是因为“管得严”——是因为“管得太严”。
- **“察察”的代价：** 她越“察察”（审视、纠正、要求）——他越“缺缺”（萎缩、不自信、不敢动）。她以为“察”是“关心”——但“察”过度，就成了“缺”。

朱先生说“察察之政民缺缺”是严苛政治带来凋敝。母亲的身体告诉我们：**她苛刻、处处要求——孩子就“缺缺”（失去生命力）。不是“管得好”——是“管得太严”。**

| 朱邦復的“察察之政民缺缺” | 母亲经验的“其正察察其邦夬夬” |
| :--- | :--- |
| 严苛政治带来凋敝 | 她苛刻、处处要求——孩子就失去生命力、缩小自己 |
| 第三人称：苛政的效果 | 第一人称：我“察”得越多——他“缺”得越多 |


## 三、“祸，福之所倚”——祸中倚福

### 朱邦復的解读：祸福相倚

朱先生将“祸兮福之所倚”解读为“祸中倚着福”：

> “幸福的感受，是因為與所經歷過的災禍比較而得。”

灾祸旁边就倚靠着幸福——不是“灾祸之后才有幸福”——是“灾祸本身就带着幸福的种子”。

### 从母亲经验的解读：孩子的“问题”（不乖、难带、犯错）里，藏着“福”——有主见、有韧性、有边界

“𢢸，福之所倚”——在母亲的身体里，“祸”和“福”是什么？

- **“祸”——孩子“难带”。** 他不听话、不合作、不按她的预期来。那是“祸”——让她头疼、让她疲惫。
- **“福”——那里面藏着“福”。** 他的“不听话”可能是“有主见”的萌芽；他的“不合作”可能是“有边界”的开始；他的“犯错”可能是“学习成长”的路径。她需要看见那个“祸”里倚着的“福”。
- **“祸福相倚”的另一种理解：** 她以为的“问题”——可能是他成为自己的方式。她以为的“麻烦”——可能是他生命力的表现。

朱先生说“祸兮福之所倚”是祸中倚着福。母亲的身体告诉我们：**孩子的“问题”里，可能藏着“福”。她需要看见那个“祸”里倚着的“福”。**

| 朱邦復的“祸兮福之所倚” | 母亲经验的“𢢸福之所倚” |
| :--- | :--- |
| 祸中倚着福 | 孩子的“问题”里藏着“福”——有主见、有韧性、有边界 |
| 第三人称：祸福的辩证 | 第一人称：他的“麻烦”——可能是他成为自己的方式 |


## 四、“福，祸之所伏”——福中伏祸

### 朱邦復的解读：福中伏祸

朱先生将“福兮祸之所伏”解读为“福中藏着祸”：

> “災禍往往是享福太過，輕忽了事態的必然性而產生的。”

幸福里面就潜伏着祸患——不是“幸福会变成灾祸”——是“幸福的里面已经藏着灾祸的种子”。

### 从母亲经验的解读：孩子的“顺利”（听话、优秀、省心）里，潜伏着“祸”——失去自我、压抑、讨好

“福，𢢸之所伏”——在母亲的身体里，“福”和“祸”是什么？

- **“福”——孩子“省心”。** 他听话、乖顺、不惹麻烦。那是“福”——让她轻松、让她骄傲。
- **“祸”——那里面潜伏着“祸”。** 他的“听话”可能是“失去自我”的开始；他的“乖顺”可能是“压抑自己”的信号；他的“省心”可能是“讨好”的外壳。她需要看见那个“福”里伏着的“祸”。
- **“祸福相伏”的另一种理解：** 她以为的“省心”——可能是他正在失去自己。她以为的“好事”——可能是未来问题的伏笔。

朱先生说“福兮祸之所伏”是福中藏着祸。母亲的身体告诉我们：**孩子的“省心”里，可能潜伏着“祸”——失去自我、压抑、讨好。她需要看见那个“福”里伏着的“祸”。**

| 朱邦復的“福兮祸之所伏” | 母亲经验的“福𢢸之所伏” |
| :--- | :--- |
| 福中藏着祸 | 孩子的“省心”里可能潜伏着“祸”——失去自我、压抑、讨好 |
| 第三人称：福祸的辩证 | 第一人称：他的“乖”——可能是“丢失自己”的开始 |


## 五、“孰知其极？其无正也？”——谁能知道终点？难道没有正的标准吗？

### 朱邦復的解读：祸福转化无定

朱先生将“孰知其极？其无正”解读为“祸福无定，哪里有什么确定的标准”：

> “到底這之間關係如何呢？由於禍福無定，互為因果，反覆變化。”

福祸的转化没有固定的规律——你无法“算”出来。今日的福，可能是明日的祸；今日的祸，可能是明日的福。没有“正”的固定标准。

### 从母亲经验的解读：她不知道孩子的“问题”最终会走向哪里——她只能看着、等着、不急着下结论

“孰知其極？”——在母亲的身体里，“知其极”是什么？

- **她不知道。** 她不知道孩子的“问题”最终会走向哪里——是会成为他的力量，还是成为他的困扰？她不知道。她只能看着、等着、不急着下结论。
- **“其无正也？”——有没有一个“对”的标准？** 她不知道“这样管”是对的，还是“那样放”是对的。她只能摸索、只能试、只能不停地调整。
- **“孰知其极”的另一种理解：** 她不急着“下结论”——不急着说“这孩子完了”或“这孩子真好”。她看着、等着、在不确定中继续爱。

朱先生说“孰知其极其无正”是祸福转化无定。母亲的身体告诉我们：**她不知道孩子的“问题”最终会走向哪里——她只能看着、等着、不急着下结论。在不确定中继续爱。**

| 朱邦復的“孰知其极其无正” | 母亲经验的“孰知其極其无正也” |
| :--- | :--- |
| 祸福转化无定 | 她不知道孩子的“问题”最终会走向哪里——只能看着、等着 |
| 第三人称：祸福的无常 | 第一人称：我不知道——但我还在爱 |


## 六、“正复为奇，善复为妖”——正会变奇，善会变妖

### 朱邦復的解读：正奇善恶的转化

朱先生将“正复为奇，善复为妖”解读为“正可能变成奇，善可能变成妖”：

> “正可能變成奇，善也可能變成惡。”

你以为“正”的（对的、正确的）——可能变成“奇”（反常的、不对的）；你以为“善”的（好的、有益的）——可能变成“妖”（坏的、有害的）。没有固定不变的“正”和“善”。

### 从母亲经验的解读：她以为“对”的方法——可能变成“错”的；她以为“好”的意图——可能变成“坏”的后果

“正復為奇，善復為妖”——在母亲的身体里，“正”和“奇”、“善”和“妖”是什么？

- **“正”——她以为“对”的教育方法。** 她以为“严厉”是对的——但孩子可能变得退缩。她以为“放手”是对的——但孩子可能变得没有边界。“正”可能变成“奇”——她以为对的，变成了错的。
- **“善”——她以为“好”的育儿意图。** 她以为“为你好”是好的——但孩子可能感到窒息。她以为“不让他受苦”是好的——但孩子可能失去抗挫力。“善”可能变成“妖”——她以为好的，变成了坏的。
- **“正复为奇，善复为妖”的深层含义：** 没有“永远正确”的方法。她以为对的、好的——可能随着孩子成长变成错的、坏的。她需要保持灵活——不固守任何“正”或“善”。

朱先生说“正复为奇善复为妖”是正奇善恶可以互相转化。母亲的身体告诉我们：**她以为“对”的方法——可能变成“错”的；她以为“好”的意图——可能变成“坏”的后果。没有永远正确的。**

| 朱邦復的“正复为奇善复为妖” | 母亲经验的“正復為奇善復為妖” |
| :--- | :--- |
| 正奇善恶可以互相转化 | 她以为“对”的方法可能变“错”，以为“好”的意图可能变“坏” |
| 第三人称：正奇善恶的转化 | 第一人称：没有永远“对”的——他变了，我也要变 |


## 七、“人之迷也，其日固久矣”——人们迷惑很久了

### 朱邦復的解读：人们对此困惑已久

朱先生将“人之迷，其日固久”解读为“人们为此困惑已久”：

> “人們為之困惑不已，已經很久了。”

祸福、正奇、善恶的转化——人们一直搞不清楚。这个迷惑不是今天才有的——已经很久了。

### 从母亲经验的解读：母亲最深的困惑——“什么是对的”——她已经困惑很久了

“人之迷也，其日固久矣”——在母亲的身体里，“迷”是什么？

- **她最深的困惑——“什么是对的”。** 她是该严一点还是松一点？是该管多一点还是放手多一点？是该坚持还是妥协？她已经困惑很久了。
- **“固久矣”的另一种理解：** 这不是她一个人的困惑——每一个母亲都有过同样的困惑。从古至今——母亲们都在问：“我这样做对吗？”
- **“迷”不是“不知道”——是“没有固定答案”。** 她不是“不懂”——是“懂了也会变”。孩子变了——答案就变了。她需要习惯“迷”——而不是追求“不迷”。

朱先生说“人之迷其日固久”是人们困惑已久。母亲的身体告诉我们：**她最深的困惑——“什么是对的”——已经很久了。她需要习惯“迷”——而不是追求“不迷”。**

| 朱邦復的“人之迷其日固久” | 母亲经验的“人之迷也其日固久矣” |
| :--- | :--- |
| 人们困惑已久 | 她最深的困惑——“什么是对的”——已经很久了 |
| 第三人称：困惑的普遍性 | 第一人称：我不是一个人——所有母亲都在问这个问题 |


## 八、“是以方而不割”——方正但不割人

### 朱邦復的解读：有原则但不伤人

朱先生将“方而不割”解读为“行事方正却不伤害他人”：

> “坦然自持而不取捨於禍福，雖行事方正卻不傷及他人。”

“方”是正直、有原则、有边界。“割”是割伤、伤害。“方而不割”是有原则但不因为原则而伤害人。

### 从母亲经验的解读：母亲有原则、有边界，但不“割”孩子的心

“方而不割”——在母亲的身体里，“方”和“割”是什么？

- **“方”——她有边界、有规则。** 她不是“随他去”的。她有“不可以”的事、有“必须”的事。那是“方”——有形状、不模糊。
- **“不割”——她的边界不伤孩子的心。** 她说不的时候——不是说“我不爱你”。她设规则的时候——不是说“你不够好”。她的“方”是用来保护关系的——不是用来切割关系的。

朱先生说“方而不割”是有原则但不伤人。母亲的身体告诉我们：**她有边界、有规则——但她的边界不“割”孩子的心。她的“方”是用来保护关系的。**

| 朱邦復的“方而不割” | 母亲经验的“方而不割” |
| :--- | :--- |
| 有原则但不伤人 | 她有边界，但不“割”孩子的心——她的“方”保护关系，不是切割关系 |
| 第三人称：有原则的温和 | 第一人称：我不“随他去”——但我的“不”不会让他觉得我不爱他 |


## 九、“廉而不刺”——有棱角但不刺人

### 朱邦復的解读：自持原则但不刺人

朱先生将“廉而不刿”解读为“自持原则却无害于人”：

> “自持原則而無害於人。”

“廉”是棱角、是正直、是不妥协。“刺”是刺伤。“廉而不刺”是有棱角但不因为棱角而刺伤别人。

### 从母亲经验的解读：她有“棱角”（自己的立场、自己的需要），但不刺伤孩子

“廉而不刺”——在母亲的身体里，“廉”和“刺”是什么？

- **“廉”——她有立场。** 她有“我”的边界、有“我”的需要、有“我”的感受。那是“廉”——她的“自己”是完整的，不是扁平的。
- **“不刺”——她不把自己的“棱角”当作伤害孩子的工具。** 她有需要——但她不让孩子为她的需要买单。她有立场——但她不把立场变成“你必须听我的”的利刃。

朱先生说“廉而不刿”是有棱角但不刺人。母亲的身体告诉我们：**她有立场——但不把孩子当作“被刺”的对象。她的“棱角”是她的——不是用来刺他的。**

| 朱邦復的“廉而不刿” | 母亲经验的“廉而不刺” |
| :--- | :--- |
| 有棱角但不刺人 | 她有立场——但她的立场不是用来刺伤孩子的 |
| 第三人称：有棱角的温和 | 第一人称：我有“我”的边界——但我不会用它来刺你 |


## 十、“直而不绁”——正直但不放肆

### 朱邦復的解读：正直坦率但不放肆

朱先生将“直而不肆”解读为“正直坦率却不放肆”：

> “真直坦率而不放肆。”

“直”是正直、坦率、不绕弯子。“肆”是放肆、不克制、越界。“直而不肆”是该说的时候说——但不“说过了”。

### 从母亲经验的解读：她正直、坦诚、不撒谎——但不把自己的“直”变成伤害孩子的武器

“直而不紲”——在母亲的身体里，“直”和“绁”是什么？

- **“直”——她坦诚。** 她对孩子说实话、不撒谎、不掩饰。那是“直”——不是“绕来绕去”的。
- **“不绁”——她不过度。** 她不把自己的“直”变成攻击。她不是“我有话直说”然后用“直”来伤人。“直”是坦率——“绁”是“过度”。她“直”但不“过”。

朱先生说“直而不肆”是正直但不放肆。母亲的身体告诉我们：**她坦诚、不撒谎——但不把自己的“直”变成伤害孩子的武器。“直”不是借口。**

| 朱邦復的“直而不肆” | 母亲经验的“直而不紲” |
| :--- | :--- |
| 正直但不放肆 | 她坦诚——但不把“直”变成伤害孩子的武器 |
| 第三人称：正直的节制 | 第一人称：我说实话——但不会用“我说实话”来伤害你 |


## 十一、“光而不曜”——有光但不耀眼

### 朱邦復的解读：有光芒但不耀眼

朱先生将“光而不耀”解读为“道德学问过人却隐匿锋芒”：

> “雖道德學問過人，卻隱匿其鋒芒，不會刺人眼目。”

“光”是光芒、是影响力。“曜”是耀眼、刺眼。“光而不曜”是发光但不刺眼——存在但不压迫。

### 从母亲经验的解读：母亲有“光”（温暖、爱、影响力）——但她不会让孩子感到被“照”得无处可逃

“光而不曜”——在母亲的身体里，“光”和“曜”是什么？

- **“光”——她存在、她影响、她温暖。** 她爱他、她在他的生命里——那是她的“光”。不是“隐藏”的——是“存在”的。
- **“不曜”——她的光不刺眼。** 她不会让孩子觉得“被照得无处可逃”——不会让他觉得“我必须回应你的光”。她发光——但她的光不会灼伤他。她给他空间——即使她的光在那里。
- **“光而不曜”的深层含义：** 母亲的存在是“光”——孩子知道她在。但那个光不是“探照灯”——不是时刻在扫描他、检查他、要求他回应。她是“光”——但她的光是“暖”的，不是“刺”的。

朱先生说“光而不耀”是有光芒但不耀眼。母亲的身体告诉我们：**她存在、她影响、她温暖——但她的光不会让孩子感到被“照”得无处可逃。她是“光”——但她的光是“暖”的。**

| 朱邦復的“光而不耀” | 母亲经验的“光而不曜” |
| :--- | :--- |
| 有光芒但不耀眼 | 她存在、她影响——但她的光不会让孩子感到无处可逃 |
| 第三人称：有光的节制 | 第一人称：我在——但我的“在”不会让你感到压迫 |


## 结语：“闷闷”与“察察”之间——母亲找到的尺度

朱邦復先生在这一章中，用“宽严之辨”和“祸福相依”的框架，解读了“其政闷闷其民淳淳”与“其政察察其民缺缺”的政治类型对比，以及“祸福相倚、正奇转化”的辩证规律。他最后以“方而不割、廉而不刺、直而不肆、光而不耀”作结——圣人行事的四种节制。

而母亲的身体，是这一章最完整的“闷察-祸福-四不”的演绎者：

- **“其政闷闷，其邦屯屯”——她宽松、不处处干涉——孩子就淳朴、富足、有生命力。**
- **“其政察察，其邦缺缺”——她苛刻、处处要求——孩子就失去生命力、缩小自己。**
- **“祸，福之所倚”——孩子的“问题”里藏着“福”——有主见、有韧性、有边界。**
- **“福，祸之所伏”——孩子的“省心”里潜伏着“祸”——失去自我、压抑、讨好。**
- **“孰知其极？”——她不知道孩子的“问题”最终会走向哪里——只能看着、等着。**
- **“正复为奇，善复为妖”——她以为“对”的方法可能变“错”，以为“好”的意图可能变“坏”。**
- **“人之迷也”——她最深的困惑——“什么是对的”——已经很久了。**
- **“方而不割”——她有边界，但不“割”孩子的心。她的“方”保护关系，不是切割关系。**
- **“廉而不刺”——她有立场——但她的立场不是用来刺伤孩子的。**
- **“直而不绁”——她坦诚——但不把“直”变成伤害孩子的武器。**
- **“光而不曜”——她存在、她影响——但她的光不会让孩子感到无处可逃。**

**“闷闷”与“察察”之间——母亲找到了自己的尺度。** 她试过“察察”（处处检查、纠正、要求）——发现孩子“缺缺”。她回到“闷闷”（宽松、信任、不干涉）——发现孩子“屯屯”。她不是“放任”——她是“相信”。相信比检查更有力量。

**“祸福相倚”——母亲学会了在孩子的“问题”里看见“福”，在孩子的“省心”里看见“祸”。** 她不急着下结论——不急着说“坏了”或“好了”。她看着、等着、在不确定中继续爱。她知道“正”可能变“奇”，“善”可能变“妖”——所以她不做那个“永远正确”的母亲。

**“方而不割，廉而不刺，直而不绁，光而不曜”——母亲就是这“四不”的日常版本。** 她有边界——但不切割关系。她有立场——但不刺伤孩子。她坦诚——但不放肆。她发光——但不刺眼。她“在”——但不压迫。她“爱”——但不占有。她“光”——但不耀。

一个母亲的身体，在“闷闷”与“察察”之间找到了自己的尺度。在孩子的“祸”与“福”中学会了等待。在“正”与“奇”、“善”与“妖”的转化中保持了灵活。她“方而不割”、“廉而不刺”、“直而不绁”、“光而不曜”——她存在，但不压迫；她爱，但不占有；她发光，但不耀眼。那是她一生在修的“尺度”。

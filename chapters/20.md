

## 引言：最“政治”的一章，最“日常”的母职

帛书本第五十七章，是《德道经》中关于“以正治邦、以奇用兵、以无事取天下”的集中论述：

> 以正之（治）邦，以畸（奇）用兵，以无事取天下。
>
> 吾何以知其然也𢦏（哉）？
>
> 夫天下多忌諱，而民彌貧。民多利器，而邦家茲（滋）昏。人多知（智），而何（奇）物茲（滋）起。法物滋章，而盗賊多有。
>
> 是以聖人之言曰：我无為也，而民自化。我好靜，而民自正。我无事，民自富。我欲不欲，而民自樸。

“以正治邦”——用正道来治理国家。“以奇用兵”——用奇谋来用兵作战。“以无事取天下”——用“无事”（不折腾、不妄为）来取得天下。

“吾何以知其然也哉？”——我怎么知道应该这样呢？

“夫天下多忌讳，而民弥贫”——天下的禁忌越多，人民越贫穷。“民多利器，而邦家滋昏”——民间有太多锐利的器具（或权谋），国家就越昏乱。“人多智，而奇物滋起”——人们有太多智巧，奇怪的事物就不断兴起。“法物滋章，而盗贼多有”——法令越是繁多彰明，盗贼反而越多。

“是以圣人之言曰”——所以圣人说：“我无为也，而民自化”——我无为，人民就自然化育。“我好静，而民自正”——我喜好清静，人民就自然端正。“我无事，民自富”——我无所事事（不折腾），人民就自然富足。“我欲不欲，而民自樸”——我没有欲望，人民就自然淳朴。

朱邦復先生在《止笑譚》中，将这一章解读为 **“因目的不同而手段各异，治天下应以无事为原则”** 。他认为“以正治国”是正道，“以奇用兵”是不得已的奇术——两者目的不同；但“取天下”不能靠“正”也不能靠“奇”——要靠“无事”。他特别强调了“天下多忌讳，而民弥贫”等一系列社会批判——政令繁苛、权谋盛行、法令严苛——这些都是“有事”的结果。最后落脚在“我无为而民自化……”——统治者不折腾，人民自然安定富足。

但如果我们把主语换成“母亲的身体”——那个在产后被“忌讳”（社会期待）、“利器”（育儿工具）、“智巧”（专家理论）、“法令”（标准规则）所包围的身体——这一章就不再是“政治哲学”，而是一份 **“关于母亲如何在‘多忌讳、多利器、多智、法令滋彰’的环境中守住‘无为、好静、无事、欲不欲’的日常记录”**：

- “以正治邦”——在孩子的世界里，母亲是“邦”的治理者。她用“正”（规律、节律、日常）来维持家庭的秩序。
- “以奇用兵”——但在突发情况（孩子生病、紧急事件）时，她需要用“奇”（非常规手段）来应对。
- “以无事取天下”——但要“取得”孩子的心和信任，只能用“无事”——不紧张、不控制、不焦虑。“无事”才能“取”。
- “吾何以知其然也哉？”——母亲怎么知道应该这样做？因为她试过“有事”了。
- “天下多忌讳，而民弥贫”——家里规矩越多、限制越多、禁忌越多——孩子反而越“贫”（没有生命力、不敢探索）。
- “民多利器，而邦家滋昏”——孩子手里有太多“工具”（电子设备、玩具、各种“方法”），家庭反而越混乱。
- “人多智，而奇物滋起”——母亲学太多“育儿智慧”，反而会产生“奇物”（焦虑、比较、不切实际的期望）。
- “法物滋章，而盗贼多有”——规则越细、标准越多、要求越严——孩子反而学会了“偷”（说谎、逃避、阳奉阴违）。
- “我无为，而民自化”——母亲放下“方法”、放下“控制”——孩子自己就会成长。不是被“塑造”的——是“自化”的。
- “我好静，而民自正”——母亲安静下来、不焦虑、不催促——孩子自己会找到自己的节奏。那是“自正”。
- “我无事，民自富”——母亲不折腾、不攀比、不给孩子填满时间——孩子自己会“富”（有安全感、有兴趣、有空间）。
- “我欲不欲，而民自朴”——母亲放下“我想要你成为什么”——孩子自己会回到“朴”（最真实的自己）。


## 一、“以正治邦，以奇用兵，以无事取天下”——正治国、奇用兵、无事取天下

### 朱邦復的解读：因目的不同而手段各异

朱先生将“以正治国，以奇用兵，以无事取天下”解读为“治国用正道，用兵出奇谋，取天下靠无事”：

> “治國要以正道，作戰要出人不意，要得天下，則應採無為的態度。”

“正”是常规的、公开的；“奇”是非常的、出其不意的；“无事”是不折腾、不妄为。不同的目的需要不同的手段。

### 从母亲经验的解读：在孩子的世界里，母亲用“正”（日常规律）来维持秩序，用“奇”（非常手段）应对突发，但“取”他的心只能用“无事”

“以正治邦”——在母亲的身体里，“正”是什么？

- **她用“正”来维持日常。** 规律的作息、稳定的回应、一致的边界——那是“正”。它不是“控制”——是“秩序”。孩子需要“正”来感到安全。

“以奇用兵”——在母亲的身体里，“奇”是什么？

- **她在突发情况时用“奇”。** 孩子生病时用特殊方法安慰、紧急时用非常手段应对——那是“奇”。不是常态——是应对。

“以无事取天下”——在母亲的身体里，“无事”是什么？

- **但要“取”孩子的心——只能用“无事”。** 不能用“正”（规则）来强迫他爱你，不能用“奇”（技巧）来操控他靠近你——只能用“无事”：不紧张、不控制、不焦虑。她“无事”——他自然来。她“有事”——他自然逃。那是“取天下”的唯一方式——不是“取”来——是“让”他来。

朱先生说“正治国奇用兵无事取天下”是因目的不同手段各异。母亲的身体告诉我们：**她用“正”维持秩序，用“奇”应对突发，但“取”孩子的心——只能用“无事”。“无事”才能“取”。**

| 朱邦復的“正治国奇用兵无事取天下” | 母亲经验的“正治邦奇用兵无事取天下” |
| :--- | :--- |
| 不同目的不同手段 | 她用“正”维持秩序，用“奇”应对突发，但“取”孩子的心——只能用“无事” |
| 第三人称：治理的策略 | 第一人称：我不能“取”他——我只能“让”他来 |


## 二、“吾何以知其然也哉？”——我怎么知道应该这样呢？

### 朱邦復的解读：如何知道这个道理

朱先生将“吾何以知其然哉？以此”解读为“我是怎样知道的呢？凭这个”：

> “我是怎樣知道的呢？因為……”

他通过观察社会现象来验证这个道理——“多忌讳则民贫、多利器则国昏、多智则奇物起、法令滋彰则盗贼多”——这些都是“有事”的后果。

### 从母亲经验的解读：母亲怎么知道“无事”才能取孩子的心？——因为她试过“有事”了

“吾何以知其然也？”——在母亲的身体里，“知其然”是什么？

- **她怎么知道“无事”才能取他？——因为她试过“有事”了。** 她试过用“方法”控制、用“规则”要求、用“焦虑”驱使——结果他更远、更抗拒、更不信任。她“有事”的时候——他不在。
- **她试过“无事”——然后他来了。** 当她放下方法、放下控制、放下“你应该”——他靠近了。那是她的“以此”——从经验中知道的，不是从书中读来的。

朱先生说“吾何以知其然哉以此”是凭观察得来的。母亲的身体告诉我们：**她试过“有事”——他走了；她试过“无事”——他来了。那是她的“以此”——经验教的。**

| 朱邦復的“吾何以知其然哉以此” | 母亲经验的“吾何以知其然也” |
| :--- | :--- |
| 凭观察得来 | 她试过“有事”——他走了；她试过“无事”——他来了。那是她的经验 |
| 第三人称：认知的根据 | 第一人称：我是用身体试出来的 |


## 三、“天下多忌讳，而民弥贫”——忌讳越多，人民越贫穷

### 朱邦復的解读：政令繁苛则民贫

朱先生将“天下多忌讳，而民弥贫”解读为“政令愈繁，人民愈贫困”：

> “政令愈繁瑣，人民愈貧困。”

“忌讳”是禁忌、禁令、限制。越多限制——人民越“贫”（没有活力、不敢作为）。

### 从母亲经验的解读：家里规矩越多、限制越多——孩子反而越“贫”（没有生命力、不敢探索）

“天下多忌諱，而民彌貧”——在母亲的身体里，“忌讳”是什么？

- **“忌讳”是“不能去那里”、“不能做那个”、“不可以这样”。** 太多“不可以”——孩子不敢探索、不敢尝试、不敢犯错。那是“贫”——他的生命力被限制了。
- **“贫”的另一种理解：** 不是“没有钱”——是“没有空间”。他的世界被“不可以”缩小了。那个空间越小——他越“贫”。

朱先生说“多忌讳则民贫”是禁令越多人民越穷。母亲的身体告诉我们：**太多“不可以”——孩子不敢探索。他的世界缩小了——那是“贫”。**

| 朱邦復的“多忌讳则民贫” | 母亲经验的“多忌諱而民彌貧” |
| :--- | :--- |
| 禁令越多人民越穷 | 太多“不可以”——孩子不敢探索，他的世界缩小了 |
| 第三人称：社会批判 | 第一人称：“不可以”太多——他就不敢动了 |


## 四、“民多利器，而邦家滋昏”——利器越多，国家越昏乱

### 朱邦復的解读：利器多则国昏

朱先生将“朝多利器，国家滋昏”解读为“利害集团多则国家难治”：

> “社會上權勢及利益團體愈多，國家愈難治理。”

“利器”可以是实际的武器，也可以是权谋、手段、利益工具。越多“利器”——越多争抢——越昏乱。

### 从母亲经验的解读：孩子手里有太多“工具”（电子设备、玩具、各种“方法”），家庭反而越混乱

“民多利器，而邦家茲昏”——在母亲的身体里，“利器”是什么？

- **“利器”是电子设备、玩具、各种“方法”。** 孩子有太多“工具”——太多选择、太多刺激、太多“可以玩的东西”——反而让家庭更“昏”（混乱、争吵、停不下来）。
- **“昏”的另一种理解：** 不是“看不见”——是“看不清”。太多工具——他看不清什么是真正需要的、什么是真正重要的。家庭也“昏”——不知道如何停下来。

朱先生说“多利器则国昏”是利器多则国家昏乱。母亲的身体告诉我们：**太多工具——孩子停不下来、家庭乱成一团。那是“昏”。**

| 朱邦復的“多利器则国昏” | 母亲经验的“多利器而邦家滋昏” |
| :--- | :--- |
| 利器多则国家昏乱 | 太多工具——孩子停不下来、家庭乱成一团 |
| 第三人称：社会批判 | 第一人称：工具越多——我们越乱 |


## 五、“人多智，而奇物滋起”——智巧越多，奇物越多

### 朱邦復的解读：智巧多则奇物起

朱先生将“人多伎巧，奇物滋起”解读为“技能越多，新奇之物越复杂”：

> “個人的技術愈高明，新奇的貨物變化就愈複雜。”

“智”是机巧、智慧。“奇物”是新奇的、不必要的、复杂的东西。智巧越多——制造出来的“奇物”越多。

### 从母亲经验的解读：母亲学太多“育儿智慧”，反而会产生“奇物”——焦虑、比较、不切实际的期望

“人多知，而奇物滋起”——在母亲的身体里，“知”和“奇物”是什么？

- **“知”是她学的“育儿智慧”。** 她看了很多书、学了很多方法、知道了太多“应该”——那是“知”。
- **“奇物”是焦虑、比较、不切实际的期望。** 她知道越多——“我做得对不对”、“别人怎么做的”、“我应该更好”——那些“奇物”就越多。不是孩子变复杂了——是她的“知”让一切变复杂了。

朱先生说“人多伎巧奇物滋起”是技巧越多奇物越兴起。母亲的身体告诉我们：**她学太多“育儿智慧”——“奇物”（焦虑、比较）就越来越多。“知”让一切变复杂了。**

| 朱邦復的“人多伎巧奇物滋起” | 母亲经验的“多知而奇物滋起” |
| :--- | :--- |
| 技巧越多奇物越兴起 | 她学太多“育儿智慧”——焦虑和比较就越来越多 |
| 第三人称：社会批判 | 第一人称：我知道越多——越复杂 |


## 六、“法物滋章，而盗贼多有”——法令越多，盗贼越多

### 朱邦復的解读：法律越严，盗贼越多

朱先生将“法令滋彰，盗贼多有”解读为“法律愈苛刻，盗贼愈多”：

> “法律愈是苛刻彰顯，盜賊愈是難以遏阻。”

法令多——不是为了阻止犯罪——反而制造了更多“犯罪”。因为“法”越多，可被“犯”的条条框框越多。

### 从母亲经验的解读：规则越细、标准越多——孩子反而学会了“偷”（说谎、逃避、阳奉阴违）

“法物滋章，而盗賊多有”——在母亲的身体里，“法物”和“盗贼”是什么？

- **“法物”是家里的规则、标准、要求。** 她订了很多规则——“必须这样”、“不能那样”、“应该这样”——那是“法物”。
- **“盗贼”是孩子学会了“偷”。** 不是说“偷东西”——是偷懒、说谎、阳奉阴违、逃避。规则越多——他越会“怎么不被抓到”。那不是“他变坏了”——是“规则太多，他不得不学会‘偷’。”

朱先生说“法令滋彰盗贼多有”是法令越严盗贼越多。母亲的身体告诉我们：**规则越多——孩子越会钻空子。“盗贼”不是“变坏”——是“不得不学会躲避规则”。**

| 朱邦復的“法令滋彰盗贼多有” | 母亲经验的“法物滋章而盗賊多有” |
| :--- | :--- |
| 法令越严盗贼越多 | 规则越多——孩子越会钻空子、说谎、逃避 |
| 第三人称：社会批判 | 第一人称：规则越多——“小偷”越多 |


## 七、“我无为，而民自化”——我无为，人民自化

### 朱邦復的解读：统治者无为，人民自然化育

朱先生将“我无为而民自化”解读为“在上者无所作为，人民自然化育”：

> “在上者無所作為，人民自然化育。”

“无为”不是“什么都不做”——是“不妄为、不控制”。“自化”是人民自己成长、自己变化——不需要被“塑造”。

### 从母亲经验的解读：母亲放下“方法”、放下“控制”——孩子自己就会成长。不是被“塑造”的——是“自化”的

“我无为，而民自化”——在母亲的身体里，“无为”和“自化”是什么？

- **她放下“方法”。** 不“应用”育儿技巧、不“执行”教育方案——她只是“在”。那是“无为”。
- **孩子自己“化”了。** 他成长了、他学会了、他成为了他自己——不是她“塑造”出来的——是他自己“化”出来的。那是“自化”。

朱先生说“我无为而民自化”是无为则民自化。母亲的身体告诉我们：**她放下“方法”——孩子自己就“化”了。不是她“塑造”的——是他自己长出来的。**

| 朱邦復的“我无为而民自化” | 母亲经验的“我无为而民自化” |
| :--- | :--- |
| 无为则民自化 | 她放下“方法”——孩子自己就“化”了。不是塑造，是生长 |
| 第三人称：无为的治理效果 | 第一人称：我不“做”他——他自己就“化”了 |


## 八、“我好静，而民自正”——我好静，人民自正

### 朱邦復的解读：统治者安静，人民自然端正

朱先生将“我好静而民自正”解读为“我好静则民正”：

> “不輕舉妄動，人民自然順正。”

统治者安静下来——人民自然找到自己的节奏。不是被“纠正”的——是“自正”的。

### 从母亲经验的解读：母亲安静下来、不焦虑、不催促——孩子自己会找到自己的节奏。那是“自正”

“我好靜，而民自正”——在母亲的身体里，“好静”和“自正”是什么？

- **她安静下来。** 不焦虑、不催促、不急于“纠正”他。那是“好静”。
- **孩子自己“正”了。** 他找到了自己的节奏——不是她替他“调正”的——是他自己“正”过来的。那是“自正”。

朱先生说“我好静而民自正”是静则民正。母亲的身体告诉我们：**她安静下来——孩子自己就“正”了。不是她“纠正”的——是他自己找到的。**

| 朱邦復的“我好静而民自正” | 母亲经验的“我好靜而民自正” |
| :--- | :--- |
| 静则民正 | 她安静下来——孩子自己就“正”了。不是纠正，是找到 |
| 第三人称：静的治理效果 | 第一人称：我不急——他自己就正了 |


## 九、“我无事，民自富”——我无事，人民自富

### 朱邦復的解读：不折腾则民富

朱先生将“我无事而民自富”解读为“不多加干预，人民自然富足”：

> “不多加干預，人民自然富足。”

统治者不折腾、不加税、不搞大工程——人民自己就会富起来。不是“给”的——是“让”的。

### 从母亲经验的解读：母亲不折腾、不攀比、不给孩子填满时间——孩子自己会“富”

“我无事，民自富”——在母亲的身体里，“无事”和“自富”是什么？

- **她不折腾。** 不给孩子排满课、不比别人家、不“为了他好”而安排一切。那是“无事”。
- **孩子自己“富”了。** 他有安全感、有兴趣、有空间——不是她“给”的——是他自己“长”出来的。“富”不是“钱”——是“有自己”。

朱先生说“我无事而民自富”是无事则民富。母亲的身体告诉我们：**她不折腾——孩子自己就“富”了。不是“给”的——是“长”出来的。**

## 十、“我欲不欲，而民自朴”——我无欲，人民自朴

### 朱邦復的解读：无欲则民朴

朱先生将“我无欲而民自朴”解读为“无欲不贪，人民自然朴实”：

> “無欲不貪，人民自然樸實。”

统治者没有多余的欲望——人民就自然淳朴。不是“被教育”成朴实的——是因为没有一个“欲”的榜样在引导他们追求。

### 从母亲经验的解读：母亲放下“我想要你成为什么”——孩子自己会回到“朴”（最真实的自己）

“我欲不欲，而民自樸”——在母亲的身体里，“欲不欲”和“自朴”是什么？

- **她放下“我想让你成为什么”。** 不把自己的期望、自己的遗憾、自己的“未完成”放在他身上。那是“欲不欲”。
- **孩子自己“朴”了。** 他回到了最真实的自己——不是她“塑造”的——是他自己“还原”的。“朴”是未经雕琢的本来面目——不是被“教育”出来的。

朱先生说“我无欲而民自朴”是无欲则民朴。母亲的身体告诉我们：**她放下期望——孩子自己就“朴”了。不是她“塑造”的——是他自己“还原”的。**

## 结语：从“有事”到“无事”——母亲回到自化自正

朱邦復先生在这一章中，用“正、奇、无事”的目的区分，和“多忌讳、多利器、多智、法物滋彰”的社会批判，构建了“取天下应以无事为原则”的政治哲学。他认为统治者不折腾、不控制、不多欲——人民就会自化、自正、自富、自朴。

而母亲的身体，是这一章最完整的“无事取天下”的演绎者：

- **“以正治邦”——她用“正”（规律、日常）维持家庭秩序。**
- **“以奇用兵”——她用“奇”（非常手段）应对突发情况。**
- **“以无事取天下”——但要“取”孩子的心——只能用“无事”。不紧张、不控制、不焦虑。**
- **“吾何以知其然也？”——她试过“有事”——他走了；她试过“无事”——他来了。那是她的经验。**
- **“多忌讳而民弥贫”——太多“不可以”——孩子不敢探索，他的世界缩小了。**
- **“多利器而邦家滋昏”——太多工具——孩子停不下来、家庭乱成一团。**
- **“多知而奇物滋起”——她学太多“育儿智慧”——焦虑、比较越来越多。**
- **“法物滋章而盗贼多有”——规则越多——孩子越学会钻空子、说谎、逃避。**
- **“我无为而民自化”——她放下“方法”——孩子自己就“化”了。**
- **“我好静而民自正”——她安静下来——孩子自己就“正”了。**
- **“我无事民自富”——她不折腾——孩子自己就“富”了。**
- **“我欲不欲而民自朴”——她放下期望——孩子自己就“朴”了。**

**“无事”是“取天下”的唯一方式。** 母亲不能用“正”（规则）来强迫孩子靠近她，不能用“奇”（技巧）来操控他信任她——只能用“无事”：不紧张、不控制、不焦虑。她“无事”——他自然来。她“有事”——他自然逃。那是“取”的唯一方式——不是“取”来——是“让”他来。

**“自化、自正、自富、自朴”——母亲最深的功课是“让”。** 她不需要“塑造”他——她只需要“让”他长。不是“做”出来的——是“让”出来的。她放下“方法”——他“自化”。她安静下来——他“自正”。她不折腾——他“自富”。她放下期望——他“自朴”。

一个母亲的身体，从“有事”（焦虑、控制、方法、规则）走向“无事”（信任、等待、陪伴、允许）。她试过“有事”——发现那让他更远。她回到“无事”——发现他自然靠近。她不需要“取”他——她只需要“让”他来。他的“化”、“正”、“富”、“朴”——不是她“给”的——是她“让”的。



## 引言：最“争议”的一章，最“母亲”的守护

帛书本第六十五章，是《德道经》中争议最大的一章——它被后世解读为“愚民政策”：

> 故曰：為道者非以明民也，將以愚之也。
>
> 民之難治也，以其知（智）也。故以知（智）知邦，邦之賊也；以不知（智）知邦，邦之德也。
>
> 恒知此兩者，亦稽式也。恒知稽式，此胃（謂）玄德。
>
> 玄德深矣，遠矣，與物反矣，乃至大順。

“故曰”——所以说：“为道者非以明民也，将以愚之也”——用道来治理的人，不是要让人民变得“明”（聪明、机巧），而是要让人民回归“愚”（朴质、不智巧）。

“民之难治也，以其知也”——人民之所以难以治理，是因为他们太“知”（机巧、智谋）了。“故以知知邦，邦之贼也”——所以用智巧来治理国家，是国家的祸害；“以不知知邦，邦之德也”——不用智巧来治理国家，是国家的德性。

“恒知此两者，亦稽式也”——恒常地知道这两种方式的区别，就是一种法则。“恒知稽式，此谓玄德”——恒常地知道这个法则，就是玄德。

“玄德深矣，远矣，与物反矣”——玄德是深刻的、悠远的，它和世俗的事物是相反的，“乃至大顺”——然后才能达到最大的和顺。

朱邦復先生在《止笑譚》中，对“愚民政策”的批评做了正面的辩护。他认为“非以明民，将以愚之”不是“让人变蠢”，而是“不要让人有超出自己能力的知识和欲望”：

> “今人对老子之愚民政策，多有抨击，但若深思，当知今之评者与老子立场不同，今人所惧者为丧失自由，老子所惧者为民多机智巧诈，最后世界必然被毁灭。”

他以人体为喻：当所有器官各守其分、各尽其责时，人体健康；如果器官有了过多知识、能分辨工作轻重、待遇高低——必生不平之鸣。那就是“癌变”的开始。所以他强调：“常使民无知无欲”是一种保护——不让人的“知”和“欲”超前于他的判断能力，避免被野心家利用。

但如果我们把主语换成“母亲的身体”——那个在孩子“太聪明”时反而担心的母亲——这一章就不再是“愚民的政治哲学”，而是一份 **“关于母亲如何守护孩子的‘愚’（朴质）不被‘知’（机巧智诈）所侵蚀的日常记录”**：

- “为道者非以明民也，将以愚之也”——对孩子来说，母亲不是要让他“聪明”（机巧、会钻空子、会表演）——而是要让他“愚”（朴质、真实、不设防）。那个“愚”不是“笨”——是“不被机巧污染”。
- “民之难治也，以其知也”——孩子为什么难带？因为他“知”了——学会了讨价还价、学会了钻空子、学会了用“聪明”来达到目的。那是“知”——不是“智慧”——是“机巧”。
- “以知知邦，邦之贼也”——用“聪明”的方式来教孩子、管孩子——是“贼”（损害）。你越是用“方法”来对付他——他越学会“方法”来对付你。
- “以不知知邦，邦之德也”——不用“聪明”的方式来教孩子——不玩心机、不斗智——那才是“德”（真正的养育）。你朴实了——他也朴实了。
- “恒知此两者，亦稽式也”——知道“用智”和“不用智”的区别——就是养育的法则。
- “恒知稽式，此谓玄德”——恒常地知道这个法则——就是母亲最深的“玄德”。
- “玄德深矣，远矣，与物反矣”——母亲的“玄德”是深刻的、悠远的——它与“聪明”的养育方式是相反的。孩子不需要学会那么多“聪明”——他只需要学会真实。
- “乃至大顺”——当母亲守护了孩子的“愚”——他才能“大顺”（真正地、自然地生长）。


## 一、“为道者非以明民也，将以愚之也”——行道的人不是要让人聪明，而是要让人回归朴质

### 朱邦復的解读：不是愚民，是保护

朱先生将“非以明民，将以愚之”解读为“不让民智大开，反而使之愚昧”：

> “今人对老子之愚民政策，多有抨击……老子所惧者为民多机智巧诈，最后世界必然被毁灭。”

“明”是聪明、机巧、有知识。“愚”是朴质、不设防、不智巧。“明”让人有“知”——但那个“知”如果没有足够的判断力支撑，反而会让人被利用。老子说的“愚”——是保护。

### 从母亲经验的解读：对母亲来说，“愚”不是“笨”——是“不被机巧污染”的本真

“將以愚之也”——在母亲的身体里，“愚”是什么？

- **她不想让孩子“太聪明”。** 她不想让他学会钻空子、学会讨价还价、学会用“表演”来换取东西。那些“聪明”不是真正的智慧——是机巧。
- **她想要他“愚”**——不是“笨”——是“朴质”。不设防、不狡猾、不计算。那个“愚”是“真”的前身——没有被“知”污染过。
- **“愚”的另一种理解：** 孩子不需要“聪明”才能被爱。他不需要“表现好”才能得到关注。他不需要“机巧”才能获得资源——他只需要“在”。那是“愚”——最本真的存在状态。

朱先生说“将以愚之”不是让人变蠢，是保护。母亲的身体告诉我们：**她不让孩子“太聪明”——她守护他的“愚”（朴质、真实、不设防）。那个“愚”不是“笨”——是“没有被机巧污染”的本真。**

| 朱邦復的“将以愚之” | 母亲经验的“將以愚之也” |
| :--- | :--- |
| 不是愚民，是保护 | 她不想让孩子“太聪明”——她守护他的“愚”（朴质、真实） |
| 第三人称：保护性的愚 | 第一人称：“愚”不是笨——是没有被污染的真 |


## 二、“民之难治也，以其知也”——人民难治，是因为他们太智巧

### 朱邦復的解读：智巧多则难治

朱先生将“民之难治，以其智多”解读为“人民难以管理是因为智巧太多”：

> “人民之難以管理，是因機智太多，喜歡取巧。”

“知”不是“知识”——是“机巧”、“智谋”。人民越“知”（会钻空子、会算计）——越难治理。

### 从母亲经验的解读：孩子为什么难带？——因为他“知”了（学会了讨价还价、钻空子、用“聪明”来达到目的）

“以其知也”——在母亲的身体里，“知”是什么？

- **他学会了“讨价还价”。** “如果我做这个，你就给我那个。”那是“知”——不是在沟通，是在交易。
- **他学会了“钻空子”。** “妈妈说不能吃糖，但奶奶给……那我就找奶奶。”那是“知”——不是在遵守，是在找漏洞。
- **他学会了“表演”。** “我乖的时候妈妈会高兴，所以我乖——但不是因为我真的想乖。”那是“知”——不是在成长，是在应对。
- **“知”的代价：** 他越“知”——她越“难治”。他越会用“聪明”来绕开她——她越需要“更聪明”来堵住他。那是一场上行螺旋——只会越来越“难”。

朱先生说“民之难治以其智多”是智巧多则难治。母亲的身体告诉我们：**孩子学会了讨价还价、钻空子、表演——“知”越多，越“难治”。那是上行螺旋。**

| 朱邦復的“民之难治以其智多” | 母亲经验的“民之難治以其知也” |
| :--- | :--- |
| 智巧多则难治 | 孩子学会了讨价还价、钻空子、表演——“知”越多，越“难治” |
| 第三人称：智巧的代价 | 第一行人：他越“聪明”——我越“难” |


## 三、“以知知邦，邦之贼也”——用智巧治理国家，是国家的祸害

### 朱邦復的解读：以智治国是贼

朱先生将“以智治国，国之贼”解读为“用智巧治国者是国贼”：

> “用機智的方式，來治理國家、教育人民的，無異於國之賊。”

“贼”是伤害、损害。用“智”（机巧、算计）来治理——表面“高效”，实际伤害了国家的根基。

### 从母亲经验的解读：用“聪明”的方式来教孩子——是“贼”（损害关系）。你越用“方法”对付他——他越学会“方法”对付你

“以知知邦，邦之賊也”——在母亲的身体里，“知邦”和“贼”是什么？

- **你用“聪明”的方式来教他——那是“贼”。** 你设陷阱、你奖励“好行为”、你惩罚“坏行为”——那是“方法”。但它伤害的，是你们之间真实的关系。他学会的不是“对错”——是“怎么应对方法”。
- **“贼”的深层含义：** 你越用“智”（方法、技巧、算计）——关系越“伤”。他不再“信任”你——他开始“计算”你。那是“贼”——偷走了你们之间的真实。

朱先生说“以智治国是国之贼”是用智巧治国是祸害。母亲的身体告诉我们：**用“聪明”的方式教孩子——是“贼”。他学会的不是“对错”——是“怎么应对你的方法”。**

| 朱邦復的“以智治国国之贼” | 母亲经验的“以知知邦邦之賊也” |
| :--- | :--- |
| 用智巧治国是祸害 | 用“聪明”的方法教孩子——是“贼”。他学会的不是对错，是怎么应对你 |
| 第三人称：智治的弊端 | 第一行人：我用“方法”——他就学会了“应对方法” |


## 四、“以不知知邦，邦之德也”——不用智巧治理国家，是国家的德性

### 朱邦復的解读：不以智治国是福

朱先生将“不以智治国，国之福”解读为“不用智巧治国是国家的福”：

> “不用這種方法治國，才是國之福。”

“不知”不是“没有知识”——是“不用智巧”。不玩心机、不算计、不设陷阱。那是“德”——不是“方法”。

### 从母亲经验的解读：不用“聪明”的方式来教孩子——那才是“德”。你朴实了——他也朴实了

“以不知知邦，邦之德也”——在母亲的身体里，“不知”和“德”是什么？

- **你不用“方法”来教他——那是“德”。** 你不设陷阱、不玩奖励惩罚的游戏——你只是“在”。他学会了什么？他学会了“真实”——因为没有“方法”需要他“应对”。
- **“不知”的另一种理解：** 你朴实了——他也朴实了。你不“智”——他也不“知”。你们之间没有“算计”——只有“相处”。那是“德”——不是“方法”，是“关系”。

朱先生说“不以智治国是国之福”是不用智巧治国是福。母亲的身体告诉我们：**你不玩心机、不算计——他也就朴实了。那是“德”——不是“方法”，是“关系”。**

| 朱邦復的“不以智治国国之福” | 母亲经验的“以不知知邦邦之德也” |
| :--- | :--- |
| 不用智巧治国是福 | 你不玩心机、不算计——他也就朴实了。那是“德”——不是“方法” |
| 第三人称：不智治的益处 | 第一行人：我不“智”——他也不“知”。那是“德” |


## 五、“恒知此两者，亦稽式也”——恒常知道两者的区别，就是法则

### 朱邦復的解读：知道两者的区别就是法则

朱先生将“知此两者亦稽式”解读为“知道这两种分别，就是一种法则”：

> “知道這兩種分別，而知所取捨，就是一種法則。”

“此两者”是用“智”治和用“不智”治。“稽式”是法则、模式。知道什么时候该用“不智”——就是一种法则。

### 从母亲经验的解读：知道“用智”和“不用智”的区别——就是养育的法则

“恒知此兩者，亦稽式也”——在母亲的身体里，“稽式”是什么？

- **她知道“用智”和“不用智”的区别。** 她知道用“方法”的时候——关系会变薄；不用“方法”的时候——关系会变厚。她知道什么时候该停、什么时候该松。那是“稽式”——她的法则。
- **“恒知”的另一种理解：** 不是“偶尔知道”——是“恒常知道”。她每次想用“方法”的时候——她停下来，问自己：“我是在用‘智’还是‘德’？”那是“恒知”。

朱先生说“知此两者亦稽式”是知道两者的区别就是法则。母亲的身体告诉我们：**她知道“用智”和“不用智”的区别。她每次想用“方法”的时候，都问自己——那是“稽式”。**

| 朱邦復的“知此两者亦稽式” | 母亲经验的“恒知此兩者亦稽式也” |
| :--- | :--- |
| 知道两者的区别就是法则 | 她知道“用智”和“不用智”的区别——她每次用“方法”前都问自己 |
| 第三人称：法则的认知 | 第一行人：我知道什么时候该“智”——什么时候该“不智” |


## 六、“恒知稽式，此谓玄德”——恒常知道这个法则，就是玄德

### 朱邦復的解读：恒知稽式即玄德

朱先生将“常知稽式，是谓玄德”解读为“常思考此法则就是至德”：

> “常思考此法則，就是至德。”

“玄德”是深奥的、隐微的德性。恒常地知道“用智”和“不用智”的法则——就是玄德。

### 从母亲经验的解读：母亲“恒知”这个法则——不用“聪明”的方式教孩子——就是她的“玄德”

“恒知稽式，此胃玄德”——在母亲的身体里，“玄德”是什么？

- **她的“玄德”不是“做了什么大事”**——是她“恒常地”不用“聪明”的方式教孩子。每一次她想用“方法”、想“设计”他——她都停下来了。那是“恒知稽式”——那是“玄德”。
- **“玄德”的另一种理解：** 它不显眼。别人看不见她“不用方法”——他们只看见她“没什么方法”。但那个“没什么方法”——就是她的“玄德”。它不显、不亮、不被称赞——但它让关系真实。

朱先生说“常知稽式是谓玄德”是恒知法则就是玄德。母亲的身体告诉我们：**她“恒常”不用“聪明”的方式教孩子——那是她的“玄德”。不显眼，但让关系真实。**

| 朱邦復的“常知稽式是谓玄德” | 母亲经验的“恒知稽式此胃玄德” |
| :--- | :--- |
| 恒知法则就是玄德 | 她“恒常”不用“聪明”的方式教孩子——不显眼，但让关系真实 |
| 第三人称：玄德的界定 | 第一行人：我的“玄德”是“不智”——不是“方法”，是“德” |


## 七、“玄德深矣，远矣，与物反矣”——玄德是深远的，与世俗相反的

### 朱邦復的解读：玄德深远，与世俗相反

朱先生将“玄德深矣远矣，与物反矣”解读为“玄德深且远，与万物返朴归真”：

> “玄德的境界既深又遠，與萬物返歸於真樸。”

“与物反”是与世俗的事物相反。世俗追求“智”、追求“明”——玄德追求“愚”、追求“朴”。“反”不是“对着干”——是“回到对面”。

### 从母亲经验的解读：母亲的“玄德”与“聪明”的养育方式是相反的——“反”才能“顺”

“玄德深矣，遠矣，與物反矣”——在母亲的身体里，“与物反”是什么？

- **与“聪明”的养育方式相反。** 别人用“方法”、用“奖励”、用“设计”——她用“不智”、用“朴”、用“在”。那是“反”——不是“对着干”——是“选择了另一条路”。
- **“反”的另一种理解：** 她从“方法”回到“人”、从“设计”回到“关系”、从“聪明”回到“真实”。那是“反”——从表面回到根本。

朱先生说“玄德深矣远矣与物反矣”是玄德与世俗相反。母亲的身体告诉我们：**她的“玄德”与“聪明”的养育方式相反——从方法回到人，从设计回到关系。那是“反”。**

| 朱邦復的“玄德深矣远矣与物反矣” | 母亲经验的“玄德深矣遠矣與物反矣” |
| :--- | :--- |
| 玄德与世俗相反 | 她的“玄德”与“聪明”的养育方式相反——从方法回到人，从设计回到关系 |
| 第三人称：玄德的超越性 | 第一行人：我选了“反”的路——从“智”回到“朴” |


## 八、“乃至大顺”——最终达到大顺

### 朱邦復的解读：最终达到大顺

朱先生将“然后乃至大顺”解读为“然后才能顺合于道”：

> “然後才能順合於道。”

“大顺”是最大的和顺——不是“顺从”的“顺”——是“万物各归其位”的“顺”。当你不“智”——万物自“顺”。

### 从母亲经验的解读：当她守护了孩子的“愚”（不被机巧污染）——他才能“大顺”（自然地成为自己）

“乃至大順”——在母亲的身体里，“大顺”是什么？

- **当她守护了孩子的“愚”——他就“大顺”了。** 他不被“聪明”污染——他就能“自然地”成为自己。不用机巧、不算计、不表演——他就“顺”了。
- **“大顺”的另一种理解：** 不是“听话”的“顺”——是“长成自己”的“顺”。当他不需要用“聪明”来生存——他就能“顺”着他本来的样子生长。那是“大顺”。
- **“大顺”的深层含义：** 不是“顺利”——是“顺畅”。他生长得顺畅、表达得顺畅、存在得顺畅。没有机巧的阻碍——只有真实的流动。

朱先生说“然后乃至大顺”是最终达到大顺。母亲的身体告诉我们：**当她守护了孩子的“愚”——他就“大顺”了。不是“听话”的顺——是“长成自己”的顺。没有机巧，只有真实。**

| :--- | :--- |
| 最终达到大顺 | 当她守护了孩子的“愚”——他就“大顺”了。不是“听话”——是“成为自己” |
| 第三人称：大顺的境界 | 第一行人：我不让他“聪明”——他就“顺”了 |


## 结语：“愚”不是笨——“愚”是未被污染的“真”

朱邦復先生在这一章中，用“保护性愚民”的框架，解读了“为道者非以明民也将以愚之”、“民之难治以其智多”、“以智治国国之贼，不以智治国国之福”、“知此两者亦稽式”、“常知稽式是谓玄德”、“玄德深远与物反”等理念。他认为“愚”不是让人变蠢——是保护人不被“机智巧诈”所害。他特别以人体比喻：当细胞有了过多知识、开始分辨工作轻重、待遇高低——那就是癌变的开始。所以“无知无欲”是保护系统的正常运作。

而母亲的身体，是这一章最完整的“愚-德-大顺”的演绎者：

- **“非以明民也，将以愚之也”——她不想让孩子“太聪明”——她守护他的“愚”（朴质、真实、不设防）。**
- **“民之难治也，以其知也”——孩子学会了讨价还价、钻空子、表演——“知”越多，越“难治”。**
- **“以知知邦，邦之贼也”——用“聪明”的方法教孩子——是“贼”。他学会的不是对错，是怎么应对你。**
- **“以不知知邦，邦之德也”——你不玩心机、不算计——他也就朴实了。那是“德”——不是“方法”。**
- **“恒知此两者，亦稽式也”——她知道“用智”和“不用智”的区别——那是她的法则。**
- **“恒知稽式，此谓玄德”——她“恒常”不用“聪明”的方式教孩子——那是她的“玄德”。**
- **“玄德深矣，远矣，与物反矣”——她的“玄德”与“聪明”的养育方式相反——从方法回到人，从设计回到关系。**
- **“乃至大顺”——当她守护了孩子的“愚”——他就“大顺”了。不是“听话”——是“成为自己”。**

**“愚”不是笨——“愚”是未被污染的“真”。** 母亲不想让孩子“太聪明”——因为“聪明”往往意味着“机巧”：会钻空子、会讨价还价、会表演。那些“聪明”不是真正的智慧——它们是“知”的过度生长。她守护孩子的“愚”——让他的“真”不被“智”覆盖。

**“贼”与“德”——母亲的选择。** 用“聪明”的方法教孩子——是“贼”。他学会的不是对错——是怎么应对你的方法。不用“聪明”的方法教孩子——是“德”。你朴实了——他也朴实了。没有“方法”需要他“应对”——只有“关系”需要他“在”。

**“玄德”是“反”的——与世俗相反。** 别人用“方法”——她用“在”。别人用“设计”——她用“信任”。别人用“聪明”——她用“朴”。那是“反”——不是“对着干”——是“选了另一条路”。从“方法”回到“人”、从“设计”回到“关系”、从“聪明”回到“真实”。

**“大顺”——当孩子不被“知”污染，他就“顺”了。** 不是“听话”的顺——是“成为自己”的顺。他不需要用“聪明”来生存——他就能顺着自己本来的样子生长。没有机巧的阻碍——只有真实的流动。

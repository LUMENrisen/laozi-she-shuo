
## 引言：最“军事”的一章，最“身体”的哀者

帛书本第七十章（通行本第六十九章），是《德道经》中关于“不敢为主而为客、不敢进寸而退尺”的集中论述：

> 用兵有言曰：吾不敢為主而為客，吾不進寸而芮（退）尺。是胃（謂）行无行，襄（攘）无臂，執无兵，乃（扔）无敵矣。
>
> 𢢸（禍）莫於（大）於无適（敵），无適（敵）斤（近）亡吾吾葆（寶）矣。
>
> 故稱兵相若，則哀者勝矣。

“用兵有言曰”——兵家有一句话说：“吾不敢為主而為客”——我不敢主动进攻而宁可被动防守。“吾不進寸而退尺”——我不敢前进一寸而宁可后退一尺。

“是谓行无行”——这就是“行而无行”（虽有行阵却像没有行阵），“攘无臂”——“攘而无臂”（虽有手臂却像没有手臂），“执无兵”——“执而无兵”（虽有兵器却像没有兵器），“扔无敌”——“扔而无敌”（虽有敌人却像没有敌人）。

“祸莫大于无敌”——最大的祸患莫过于轻敌。“无敌近亡吾宝”——轻敌几乎丧失了我的法宝。

“故称兵相若”——所以两军兵力相当的时候，“则哀者胜矣”——内心悲悯、不敢轻敌的一方会获胜。

朱邦復先生在《止笑譚》中，将这一章解读为 **“以守为攻、哀兵必胜的军事原则”** 。他认为“不敢为主而为客”是不主动挑起战端，宁可被动应战；“不敢进寸而退尺”是不主动进取，宁可退让。他特别强调了“祸莫大于轻敌”——轻视敌人会丧失“三宝”（慈、俭、不敢先）；“哀者胜矣”——认为敌强己弱者胜算较大。

但如果我们把主语换成“母亲的身体”——那个在产后以“客”的姿态（把主动权交给身体）、以“退尺”的方式（不急着恢复、不强求“进寸”）、在“无敌”（自以为安全）时最容易放松警惕的身体——这一章就不再是“军事哲学”，而是一份 **“关于母亲如何以‘不敢为主’、‘不敢进寸’、‘哀者’的姿态守护自己和孩子的日常记录”**：

- “不敢为主而为客”——产后母亲不“为主”（不主动控制身体的恢复进程），她“为客”——把主动权交给身体、交给时间、交给自然的节律。她是“客”——不是“主”。
- “不敢进寸而退尺”——她不强求“进寸”（每一天都要有进步、要看到“恢复”的迹象），她宁愿“退尺”——接受“今天比昨天更累”、“今天比昨天更慢”。那是“退尺”——但那是她需要的。
- “行无行”——她“行”了（做了很多事），但好像“无行”（没有被记录、被看见的“业绩”）。她的“行”是看不见的行。
- “攘无臂”——她“攘”了（伸手、用力），但好像“无臂”（没有被感知的力量）。她用力了——但不是“看得见的力”。
- “执无兵”——她“执”了（拿着、握着），但好像“无兵”（没有武器）。她的“武器”是她的耐心——看不见，但一直在。
- “扔无敌”——她面对的不是“敌人”——但她的“警觉”是她唯一的“武器”。孩子睡了——她以为“无敌”（安全了），然后放松警惕——那是她最危险的时候。
- “祸莫大于无敌”——最大的祸患，莫过于“觉得自己安全了”。睡着的孩子可能呛奶、可能发烧、可能意外。她不能“无敌”——她必须永远保持“有敌”的警觉。
- “哀者胜”——母亲是“哀者”——她不是“强”的，她是“哀”的（疲惫的、警觉的、不敢放松的）。但正是那个“哀”让她“胜”了——让她能在深夜听到孩子的第一次咳嗽、能在危险发生前就醒了。


## 一、“吾不敢为主而为客”——我不敢主动进攻，宁可被动防守

### 朱邦復的解读：宁为客，不为主——守势为上

朱先生将“不敢为主而为客”解读为“不敢主动，宁取被动”：

> “凡戰爭，挑起戰端者為主動，保衛國土則為被動。”

“为主”是主动挑起战争，“为客”是被动应战。老子选择“客”——不是“不能”主动——是“不敢”主动。守势比攻势更接近道。

### 从母亲身体的经验出发：产后她不“为主”——不主动控制身体的恢复进程。她“为客”——把主动权交给身体

“不敢為主而為客”——在母亲的身体里，“为主”和“为客”是什么？

- **“为主”是她想要“控制”恢复的进程。** “我要今天比昨天好”、“我要快点恢复”——那是“为主”。她想“主导”身体的节奏。
- **“为客”是她把主动权交出去。** 她“为客”——身体是“主”，她是“客”。她跟着身体走，不是身体跟着她走。她不主导——她跟随。
- **“不敢为主”的深层含义：** 她不是“不能”控制——她“不敢”控制。因为她知道：身体的恢复有自己的节律。如果她“为主”（强行加速），她会受伤。她“为客”——让身体做主。

朱先生说“不敢为主而为客”是宁为客不为主。母亲的身体告诉我们：**她不控制恢复的节奏——她“为客”。身体是“主”，她是“客”。她跟着走，不是拉着走。**

| 朱邦復的“不敢为主而为客” | 母亲经验的“不敢為主而為客” |
| :--- | :--- |
| 宁为客不为主 | 她不控制恢复的节奏——身体是“主”，她是“客”。她跟着走 |
| 第三人称：守势为上 | 第一人称：我不“主”——我“客” |


## 二、“吾不敢进寸而退尺”——我不敢前进一寸，宁可后退一尺

### 朱邦復的解读：宁退尺，不进寸——退让为上

朱先生将“不敢进寸而退尺”解读为“不敢前进一寸，宁可后退一尺”：

> “向前進為侵侮，容易擴大爭端，後退則為忍讓，以求息事寧人。”

“进寸”是前进一小步——“退尺”是后退一大步。老子选择“退尺”——后退比前进更安全。退让不是“输”——是“不进入战场”。

### 从母亲身体的经验出发：她不强求“进寸”——她宁愿“退尺”——接受“今天比昨天更累”

“不敢進寸而退尺”——在母亲的身体里，“进寸”和“退尺”是什么？

- **“进寸”是“今天要恢复一点”。** 她想看到每天的“进步”——哪怕只是一寸。那是“进寸”。
- **“退尺”是“今天可能更累”。** 她接受“今天比昨天更慢”、“今天没有进步”——那是“退尺”。不是“倒退”——是“不追求进寸”。
- **“不敢进寸而退尺”的深层含义：** 她不强求“进步”——她接受“退步”。因为身体的恢复不是直线——有进有退。如果她只允许“进”——她会崩溃。“退尺”是她的允许——允许自己“不进步”。那个“允许”本身就是一种前进。

朱先生说“不敢进寸而退尺”是宁退尺不进寸。母亲的身体告诉我们：**她不强求“进步”——她接受“退步”。允许自己“不进步”本身就是一种前进。**

| 朱邦復的“不敢进寸而退尺” | 母亲经验的“不敢進寸而退尺” |
| :--- | :--- |
| 宁退尺不进寸 | 她不强求“进步”——接受“退步”。允许自己“不进步”本身就是前进 |
| 第三人称：退让为上 | 第一人称：我允许自己“退尺”——那是恢复的一部分 |


## 三、“行无行、攘无臂、执无兵、扔无敌”——行而无行，攘而无臂，执而无兵，扔而无敌

### 朱邦復的解读：有若无——不露形迹

朱先生将“行无行、攘无臂、执无兵、扔无敌”解读为“有形而无迹”：

> “作戰時，雖有行陣，可是好像沒有行陣；雖有手臂，卻似無手臂可舉；雖有兵器，又好像沒有兵器可拿；雖有敵人，卻又沒有敵人可擒。”

“有”但好像“无”——不露形迹、不显实力。不是“真没有”——是“不让你看见我有”。

### 从母亲身体的经验出发：她的“行”是看不见的、她的“力”是感觉不到的、她的“武器”是不显眼的

“行无行”——在母亲的身体里，“行无行”是什么？

- **她做了很多——但“无行”。** 她日复一日地喂奶、哄睡、陪伴——那些是“行”。但没有人“看”到那些行——它们不被记录、不被看见。那是“行无行”——做了，但好像没做。

“攘无臂”——在母亲的身体里，“攘无臂”是什么？

- **她用了很多力——但“无臂”。** 她抱他、托他、接住他——那些是“力”。但那个力不被感知——它没有“手臂”的形状。那是“攘无臂”——用力了，但好像没有用力的痕迹。

“执无兵”——在母亲的身体里，“执无兵”是什么？

- **她有很多“武器”——耐心、信任、等待——但“无兵”。** 她的“武器”不显眼——不是命令、不是惩罚、不是权威。那是“执无兵”——拿着，但好像没拿武器。

“扔无敌”——在母亲的身体里，“扔无敌”是什么？

- **她面对的不是“敌人”——是“需要”。** 孩子的哭闹不是“敌人”——是信号。她“扔”出去的不是“攻击”——是“回应”。那是“扔无敌”——面对的不是敌人，是回应。

朱先生说“行无行攘无臂执无兵扔无敌”是有若无、不露形迹。母亲的身体告诉我们：**她的“行”是看不见的，她的“力”是感觉不到的，她的“武器”是不显眼的。她“有”——但像“无”。**

| 朱邦復的“行无行攘无臂执无兵扔无敌” | 母亲经验的“行无行攘无臂执无兵扔无敌” |
| :--- | :--- |
| 有若无、不露形迹 | 她的“行”看不见、“力”感觉不到、“武器”不显眼——有，但像无 |
| 第三人称：用兵的至高境界 | 第一人称：我“有”——但你不“看”见 |


## 四、“祸莫大于无敌”——最大的祸患莫过于轻敌

### 朱邦復的解读：轻敌是最大之祸

朱先生将“祸莫大于轻敌”解读为“最大的祸害就是轻视敌人”：

> “爭戰時最大的禍害就是輕視敵人。”

“无敌”不是“没有敌人”——是“觉得没有敌人”（轻敌）。轻敌会让你丧失警惕——丧失警惕就会“丧吾宝”（丧失你的法宝）。

### 从母亲身体的经验出发：最大的祸患，莫过于“觉得自己安全了”。孩子睡了——她放松警惕——那是她最危险的时候

“𢢸莫大於无適”——在母亲的身体里，“无適”是什么？

- **“无適”是“没有警觉”。** 不是“没有敌人”——是“觉得自己安全了”。孩子睡了、她终于可以休息了——她“无敌”了（觉得没有威胁了）。然后她放松警惕——那是她最危险的时候。
- **“祸莫大于无敌”的养育版本：** 孩子睡了，她以为“安全了”，然后忽略那一声异常的咳嗽、那一次不寻常的安静。“无適”不是“没有危险”——是“没有警觉”。最大的祸患就是“没有警觉”。
- **“无敌”的深层含义：** 母亲的“警觉”不能停——不是因为她“紧张”——是因为她是那个“听到第一次咳嗽的人”。她不能“无敌”——她必须永远保持“有敌”的警觉。那不是焦虑——是守护。

朱先生说“祸莫大于轻敌”是轻敌是最大之祸。母亲的身体告诉我们：**最大的祸患是“觉得自己安全了”——她不能“无敌”，她必须永远警觉。那不是焦虑——是守护。**

| 朱邦復的“祸莫大于轻敌” | 母亲经验的“祸莫大于无適” |
| :--- | :--- |
| 轻敌是最大之祸 | 最大的祸患是“觉得自己安全了”——她不能“无敌”，必须永远警觉 |
| 第三人称：战争的警诫 | 第一人称：我不能“无敌”——那不是焦虑，是守护 |


## 五、“无敌近亡吾宝”——轻敌几乎丧失了我的法宝

### 朱邦復的解读：轻敌则丧宝

朱先生将“无敌几丧吾宝”解读为“轻敌则丧失了我的法宝”：

> “輕視敵人則喪失了我的法寶。”

“宝”是三宝——慈、俭、不敢为天下先。轻敌会让人丧失这三宝——丧失慈（不再以慈悲心对待敌人）、丧失俭（不再克制）、丧失不敢先（变得冒进）。丧宝——则败。

### 从母亲身体的经验出发：她不能“无敌”——因为“无敌”会让她丧失“宝”：警觉、耐心、不放任

“无適近亡吾吾葆”——在母亲的身体里，“亡吾宝”是什么？

- **她的“宝”不是三宝——是“警觉”、“耐心”、“不放任”。** 这些是她守护孩子的“宝”。
- **如果她“无敌”（觉得自己安全了）——她会“亡宝”。** 她会放松警觉——然后就听不见那一声异常。她会失去耐心——然后就对孩子吼。她会放任——然后就错过了需要干预的时刻。
- **“无敌近亡吾宝”的深层含义：** 她不能“觉得自己安全了”——因为那个感觉会让她“亡宝”。她需要保持警觉——不是“紧张”——是“不放任”。那三宝——“警觉、耐心、不放任”——是她守护的根基。

朱先生说“无敌几丧吾宝”是轻敌则丧宝。母亲的身体告诉我们：**她不能“无敌”——因为“无敌”会让她丧失“宝”：警觉、耐心、不放任。那不是紧张——是守护。**

| 朱邦復的“无敌几丧吾宝” | 母亲经验的“无適近亡吾葆” |
| :--- | :--- |
| 轻敌则丧宝 | 她不能“无敌”——“无敌”会让她丧失“宝”：警觉、耐心、不放任 |
| 第三人称：轻敌的后果 | 第一人称：我不能“觉得自己安全了”——那会让我丧失守护的“宝” |


## 六、“故称兵相若，则哀者胜矣”——两军相当，哀者必胜

### 朱邦復的解读：哀兵必胜

朱先生将“抗兵相加，哀者胜矣”解读为“认为敌强己弱者胜算较大”：

> “當兩軍作戰時，認為敵強己弱者勝算較大。”

“哀者”不是“悲伤”的哀——是“不敢轻敌”的哀。“哀”是“我比你弱”的认知——那个认知让你保持警觉、不轻敌、不冒进。

### 从母亲身体的经验出发：母亲是“哀者”——她不是“强”的，她是“哀”的。但正是那个“哀”让她“胜”了

“故稱兵相若，則哀者勝矣”——在母亲的身体里，“哀者胜”是什么？

- **她不是“强”的。** 她不是“超级妈妈”——她是“哀者”（疲惫的、警觉的、不敢放松的）。她不觉得自己“很强”——她知道自己的脆弱。
- **但正是那个“哀”让她“胜”了。** 因为她知道自己“弱”——所以她更警觉、更小心、更不放过任何异常。那个“哀”让她能听到深夜的第一次咳嗽、能在危险发生之前就醒过来。
- **“哀者胜”的深层含义：** 不是“弱”胜了“强”——是“警觉”胜了“放任”。“哀”让她不轻敌、不放任、不觉得自己“可以了”。那个“哀”是她的力量。不是“强”胜了——是“警觉”胜了。

朱先生说“哀者胜矣”是认为敌强己弱者胜算较大。母亲的身体告诉我们：**她是“哀者”——疲惫的、警觉的、不敢放松的。但正是那个“哀”让她“胜”了——因为“哀”让她不放过任何异常。**

| 朱邦復的“哀者胜矣” | 母亲经验的“哀者勝矣” |
| :--- | :--- |
| 认为敌强己弱者胜算较大 | 她是“哀者”——疲惫的、警觉的、不敢放松的。正是那个“哀”让她“胜”了 |
| 第三人称：哀兵必胜 | 第一人称：我不是“强”——我是“哀”。但“哀”让我警觉 |


## 结语：“不敢为主”、“不敢进寸”、“哀者胜”——母亲最深沉的守护

朱邦復先生在这一章中，用“宁为客不为主、宁退尺不进寸、哀兵必胜”的军事原则，解读了“不敢为主而为客、不敢进寸而退尺”、“行无行攘无臂执无兵扔无敌”、“祸莫大于轻敌”、“哀者胜矣”等战略智慧。他认为守势、退让、不敢轻敌是取胜的关键——“哀者”因为不敢轻敌，所以能胜。

而母亲的身体，是这一章最完整的“不敢为主、不敢进寸、哀者胜”的演绎者：

- **“不敢为主而为客”——她不控制恢复的节奏——身体是“主”，她是“客”。**
- **“不敢进寸而退尺”——她不强求“进步”——接受“退步”。允许自己不进步本身是前进。**
- **“行无行”——她的“行”看不见——做了，但好像没做。**
- **“攘无臂”——她的“力”感觉不到——用力了，但好像没有用力的痕迹。**
- **“执无兵”——她的“武器”不显眼——拿着，但好像没拿。**
- **“扔无敌”——她面对的不是“敌人”——是“回应”。**
- **“祸莫大于无敌”——最大的祸患是“觉得自己安全了”——她不能“无敌”。**
- **“无敌近亡吾宝”——“无敌”会让她丧失“宝”：警觉、耐心、不放任。**
- **“哀者胜”——她是“哀者”——疲惫的、警觉的、不敢放松的。但正是“哀”让她“胜”了。**

**“不敢为主”——母亲不“主导”恢复的节奏。** 她不是“主”——身体是“主”。她“客”——跟随、观察、不强行推动。如果她“为主”（强行控制），她会“败”。她“为客”——所以她能“胜”（恢复）。

**“不敢进寸”——母亲不强求“进步”。** 她不要求“今天要比昨天好”——她接受“今天可能比昨天差”。“退尺”是她的允许——允许自己不进步、允许自己退后。那个“允许”本身就是一种前进。

**“哀者胜”——母亲是“哀者”。** 她不是“强”的——她是“哀”的。疲惫的、警觉的、不敢放松的。那个“哀”让她不轻敌、不放任、不觉得自己“可以了”。她是那个在深夜听到第一次咳嗽的人、在危险发生之前就醒过来的人。那是她的“胜”——不是“强”的胜——是“警觉”的胜。

一个母亲的身体，就是“不敢为主、不敢进寸、哀者胜”最日常的版本。她不“主”恢复的节奏——她“客”。她不强求“进寸”——她允许“退尺”。她是“哀者”——疲惫、警觉、不敢放松。但正是那个“哀”让她“胜”了——让她在黑暗中也看得见、在安静中也听得见。那不是焦虑——是守护。不是“强”胜了——是“警觉”胜了。

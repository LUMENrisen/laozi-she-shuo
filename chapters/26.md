

## 引言：最“管理”的一章，最“日常”的实践

帛书本第六十三章，是《德道经》中关于“为无为、事无事、图难于其易、为大于其细”的集中论述：

> 為无為，事无事，味无未（味）。
> 
> 大小多少，報怨以德。
> 
> 圖難乎其易也，為大乎其細也。天下之難作於易，天下之大作於細。是以聖人冬（終）不為大，故能成其大。
> 
> 夫輕諾者必寡信。多易必多難，是以聖人猷（猶）難之，故終於无難。

“為无为”——以无为的方式来作为。“事无事”——以无事的方式来处事。“味无未（味）”——以无味的方式来品味（安于平淡）。

“大小多少”——大的、小的、多的、少的（一切事物）。“报怨以德”——用德来回报怨恨。

“图难乎其易也”——图谋难事要从容易处着手。“为大乎其细也”——做大事要从细微处着手。“天下之难作于易”——天下的难事都是从容易处开始的。“天下之大作于细”——天下的大事都是从细微处开始的。“是以圣人终不为大”——所以圣人始终不自以为在“做大”，，“故能成其大”——所以能成就其大。

“夫轻诺者必寡信”——轻易许诺的人必定信用不足。“多易必多难”——把事情看得太容易的，必定会遇到很多困难。“是以圣人犹难之”——所以圣人把事情都看得很难，“故终于无难”——所以最终反而没有困难。

朱邦復先生在《止笑譚》中，将这一章解读为 **“务实的管理之道”** 。他认为“为无为、事无事”是不要有私心、不要刻意制造事端；“大小多少，报怨以德”是能见微知著，人若有不满足即以德报之；“图难于其易，为大于其细”是解决困难从容易处下手、做大事从小地方开始；“天下难事必作于易，天下大事必作于细”是逐步剖析细节，皆可化难为易；“圣人终不为大，故能成其大”是不好高骛远，逐步推进；“轻诺必寡信，多易必多难”是轻易承诺则信用不足、把事情看得太容易则困难重重；“圣人犹难之，故终无难”是正视问题、小心处理，最终不被难倒。

但如果我们把主语换成“母亲的身体”——那个在产后恢复中日复一日地“为无为”（不急着“做”）、在养育孩子中“事无事”（不折腾）、在观察孩子中“味无味”（安于平淡的日常）、在日复一日的“作于细”中成就了“大”的身体——这一章就不再是“管理的格言”，而是一份 **“关于母亲如何在‘不作大’中成就‘大’、如何在‘作于细’中化解‘难’、如何在‘犹难之’中‘终无难’”的日常记录**：

- “为无为”——产后恢复最深的功课：不要急于“恢复”，不要急着“做”。无为不是什么都不做——是只做必要的事、不做多余的事。“为无为”是让她从“必须做什么”的焦虑中解脱出来，允许身体在自己的节奏里恢复——她越“无为”，身体越“自为”。
- “事无事”——养育孩子最深的功课：不折腾、不攀比、不给孩子填满时间。“无事”不是什么都不做——是“不做多余的事”。她“无事”了——孩子才“有事”了（有了自己的空间、自己的生长、自己的“事”）。
- “味无味”——安于平淡的养育日常。产后的生活是“无味”的——重复的、单调的、不被看见的。但她“味无味”——她安于那些无味的时刻，在无味中尝到了“本味”。
- “大小多少，报怨以德”——孩子发脾气、反抗、让她疲惫——她用“德”（耐心、理解、不反弹）来回应。不是“忍”——是“报”（回应的方式）。
- “图难于其易，为大于其细”——解决养育中的“难”，从最容易的事开始：不是“让他听话”——是“先让自己平静下来”。做成“大”（孩子的成长）——从最细微的事开始：不是“规划他的一生”——是“回应他今天的需要”。
- “天下难作于易”——所有养孩子时觉得“难”的事，都是从“容易”开始的。他今天第一次反抗——那“难”从第一次说不开始。但正因为从“易”开始，她才学会了如何面对后来的“难”。
- “圣人终不为大，故能成其大”——她从来不觉得自己在“做大事”。她只是在喂奶、换尿布、哄睡——但那些“小事”汇聚起来，成就了“大”：一个完整的生命。
- “轻诺必寡信”——她不会轻易对孩子承诺她做不到的事。不说“明天带你去”——如果她不确定；不说“我一定会”——如果她做不到。她承诺的，她做到。那是“信”。
- “多易必多难”——她不会把养育看成“很简单”的事。不轻视、不侥幸、不“想当然”。她不“多易”——所以她不会“多难”。
- “圣人犹难之，故终无难”——她把每件小事都当作“难”来对待（认真、不轻视），所以最终没有“难”（都能度过）。


## 一、“为无为”——以无为的方式作为

### 朱邦復的解读：不要有私心，不要刻意制造事端

朱先生将“为无为”解读为“不要有私心、不要刻意制造事端”：

> “不要有私心私欲，也不要刻意製造事端。”

“为无为”不是“不做”——是“以‘无为’的方式‘为’”。不刻意、不造作、不带着私心去“做”。

### 从身体经验出发：产后恢复最深的一课——不要急于“恢复”，不要急着“做”。她越“无为”，身体越“自为”

“为无為”——在母亲的身体里，“为无为”是什么？

- **她不要急于“恢复”。** 她不是“不做”——她是“不做多余的事”。她吃饭、睡觉、休息——那些是“为”。但她不急着运动、不急着“回到状态”、不急着“证明自己好了”——那些是“多余的事”。
- **她“为无为”——她的“做”是“让身体自己恢复”。** 她不是“用力”恢复——她是“允许”恢复。她越“无为”——身体越“自为”（自己修复）。
- **“为无为”的深层含义：** 她不是“不作为”——她是在“不挡道”。身体的自然恢复能力在她“不挡道”的时候，自己就工作了。“为无为”是让她从“我必须做什么”的焦虑中解脱出来。

朱先生说“为无为”是不要刻意制造事端。母亲的身体告诉我们：**产后恢复最深的一课——不要急于“恢复”。她越“无为”——身体越“自为”。**

| 朱邦復的“为无为” | 母亲经验的“为无為” |
| :--- | :--- |
| 不要刻意制造事端 | 产后不要急于“恢复”——她越“无为”，身体越“自为” |
| 第三人称：无为的作为 | 第一人称：我不“做”多余的事——身体自己会“做” |


## 二、“事无事”——以无事的方式处事

### 朱邦復的解读：不刻意制造事端

朱先生将“事无事”解读为“不刻意制造事端”：

> “不要刻意製造事端。”

“事无事”不是“什么都不做”——是“不做多余的事”。不折腾、不添乱、不把简单的事情复杂化。

### 从身体经验出发：养育孩子最深的功课——不折腾、不攀比、不给孩子填满时间

“事无事”——在母亲的身体里，“事无事”是什么？

- **她不折腾。** 不给孩子报满课、不安排太多活动、不让他“不能输在起跑线上”。那是“事无事”——不做多余的事。
- **她不攀比。** 不比别人家的孩子学什么、不追赶“标准进度”。那是“事无事”——不追逐那些“看起来要做的事”。
- **“无事”的深层含义：** 她“无事”了——孩子才“有事”了（有了自己的空间、自己的生长、自己的“事”）。她的“无事”是他的“有事”的前提。

朱先生说“事无事”是不刻意制造事端。母亲的身体告诉我们：**她不折腾、不攀比——“无事”了，孩子才能“有事”（有自己的生长空间）。**

| 朱邦復的“事无事” | 母亲经验的“事无事” |
| :--- | :--- |
| 不刻意制造事端 | 她不折腾、不攀比——“无事”了，孩子才能有自己的空间 |
| 第三人称：无事的处事 | 第一人称：我不做多余的事——他就有了自己的“事” |


## 三、“味无味”——以无味的方式品味

### 朱邦復的解读：安于平淡

朱先生将“味无味”解读为“不追求享受”：

> “不要追求享受。”

“味无味”是“品味无味的味道”——安于平淡、安于那些不刺激、不浓烈、不精彩的时刻。

### 从母亲经验的解读：她安于那些“无味”的日常——重复的喂奶、单调的哄睡、不被看见的陪伴

“味无未”——在母亲的身体里，“味无味”是什么？

- **她的日常是“无味”的。** 喂奶、换尿布、哄睡、擦眼泪——那些重复的、单调的、不被看见的事。那些事“无味”——没有刺激、没有精彩。
- **但她“味无味”**——她安于那些无味的时刻。不是在“忍受”——是在“品味”。她在那份单调中尝到了“本味”——不是“味道”的味道，是“存在”的味道。
- **“味无味”的深层含义：** 她不需要“刺激”来确认自己活着。她在那份平淡中、那份重复中、那份不被看见中——已经“有味”了。

朱先生说“味无味”是不追求享受。母亲的身体告诉我们：**她安于那些“无味”的日常——喂奶、哄睡、重复——她在平淡中尝到了“本味”。**

| 朱邦復的“味无味” | 母亲经验的“味无未” |
| :--- | :--- |
| 安于平淡 | 她安于那些“无味”的日常——在重复中尝到了“本味” |
| 第三人称：平淡的品味 | 第一人称：我不需要“刺激”——我已经“有味”了 |


## 四、“大小多少，报怨以德”——大小多少，用德来回报怨

### 朱邦復的解读：能见微知著，以德报怨

朱先生将“大小多少，报怨以德”解读为“能看到大、小、多、少的变化，以德报怨”：

> “能見微知著，事物尚小、尚少時，即能看到它變大、變多時的情形。人若有不滿，即報之以德。”

“怨”是怨恨、不满。“报怨以德”是用“德”（耐心、理解、不反弹）来回应不满和怨怼。

### 从母亲经验的解读：孩子的发脾气、反抗、让她疲惫——她用“德”（耐心、理解）来回应

“大小多少，報怨以德”——在母亲的身体里，“报怨以德”是什么？

- **孩子发脾气——她报之以“德”。** 她用耐心来回应他的愤怒，用理解来回应他的失控。不是“以怨报怨”（你吼我，我也吼你）——是“报怨以德”（你发泄在我身上，我用“德”来承接）。
- **孩子反抗——她报之以“德”。** 他用“不”来推开她——她用“我在”来回应。那不是“让步”——是“承接”。她接过他的“怨”，还回去的是“德”。
- **“报怨以德”的深层含义：** 不是“忍”——是“转化”。她把他的“怨”接过来，用“德”转化一下，再还给他。她不是“被伤害”的一方——她是“承接”的一方。

朱先生说“报怨以德”是用德回报怨。母亲的身体告诉我们：**孩子发脾气、反抗——她用耐心、理解来承接。不是“忍”——是“转化”。**

| 朱邦復的“报怨以德” | 母亲经验的“報怨以德” |
| :--- | :--- |
| 用德回报怨 | 孩子发脾气——她用耐心来承接。不是“忍”，是“转化” |
| 第三人称：以德报怨的原则 | 第一人称：你“怨”来——我“德”去 |


## 五、“图难于其易，为大于其细”——图谋难事从易处着手，做大事从小处开始

### 朱邦復的解读：从容易处下手、从小处开始

朱先生将“图难于其易，为大于其细”解读为“解决困难从容易处入手、做大事从小地方开始”：

> “圖難於其易，為大於其細。”

难的事要从“易”的部分开始——不是一开始就面对“最难”的部分。大的事要从“细”的部分开始——不是一开始就想着“整体”。

### 从身体经验出发：解决养育的“难”，从最容易的事开始：不是“让他听话”——是“先让自己平静”

“圖難乎其易也”——在母亲的身体里，“图难从易”是什么？

- **她想“解决”他的哭闹——但她从“最容易”的事开始：** 先呼吸、先不慌张、先让自己平静下来。不是直接“让他不哭”——是“先让自己能接住”。那是“从易”开始。
- **她想“教”他——但她从“最容易”的事开始：** 不是“教他道理”——是先“做给她看”。她用行动示范，而不是用语言说教。那是“从易”开始。

**“為大乎其細也”——在母亲的身体里，“为大从细”是什么？**

- **她想“成就”他的成长——但她从“最细”的事开始：** 不是规划他的未来——是回应他今天的需要。今天喂好一顿奶、哄好一次睡、接住一次情绪——那些“细”的事，汇聚成他的“大”。
- **她想“建立”他的安全感——但她从“最细”的事开始：** 不是“你要相信世界”——是她每次被叫的时候都在。那些“细”的回应，汇聚成他的“大”安全。

朱先生说“图难于其易为大于其细”是从易处下手、从小处开始。母亲的身体告诉我们：**解决“难”从最容易的事开始；成就“大”从最细微的事开始。不是“直接”解决——是“从旁边”进入。**

| 朱邦復的“图难于其易为大于其细” | 母亲经验的“圖難乎其易為大乎其細” |
| :--- | :--- |
| 从易处下手、从小处开始 | 解决哭闹从“先让自己平静”开始；成就成长从“回应今天需要”开始 |
| 第三人称：渐进的管理 | 第一人称：我从不“直接”解决——我从“旁边”进入 |


## 六、“天下难作于易，天下大作于细”——天下的难事从易处开始，天下的大事从细处开始

### 朱邦復的解读：所有难事都从易处开始，所有大事都从细处开始

朱先生将“天下难事，必作于易；天下大事，必作于细”解读为“所有难事从易处开始，所有大事从细处开始”：

> “天下難事，必作於易；天下大事，必作於細。”

难的、大的事——不是“一上来就难”——是从“易”开始的。大的、重要的事——不是“一开始就大”——是从“细”开始的。

### 从母亲经验的解读：孩子成长中所有“难”的事——都是从“易”开始的。第一次说不、第一次反抗——她如何处理那些“易”，决定了她如何面对后来的“难”

“天下之難作於易”——在母亲的身体里，“难作于易”是什么？

- **孩子第一次说不——那是“易”的。** 他还不会“反抗”得很厉害——只是轻轻一句“不”。她怎么回应那个“易”——决定了后来她如何面对更“难”的对抗。
- **孩子第一次发脾气——那是“易”的。** 他还没学会大发雷霆——只是小小的跺脚。她怎么回应那个“易”——决定了后来她如何面对更大的情绪风暴。
- **“难作于易”的深层含义：** 如果她在“易”的时候不练习应对——后来“难”的时候她就不懂得怎么办。所有“难”都是从“易”长出来的——她回应“易”的方式，塑造了她面对“难”的能力。

“天下之大作於細”——在母亲的身体里，“大作于细”是什么？

- **他的安全感——是从“细”里长出来的。** 不是一次“大型”的“我信任你”的宣言——是日复一日“细”的回应：他叫，她在；他需要，她来。那些“细”的回应，长成了“大”的安全感。
- **他的信任——是从“细”里长出来的。** 不是一次“深刻的谈话”——是日复一日“细”的承诺：她答应的事，她做到。那些“细”的兑现，长成了“大”的信任。

朱先生说“难作于易大作于细”是所有难事从易处开始、所有大事从细处开始。母亲的身体告诉我们：**所有“难”的事都是从“易”开始的——她怎么回应“易”，决定了如何面对“难”。所有“大”的事都是从“细”开始的——“细”的回应汇聚成“大”的安全感。**

| 朱邦復的“难作于易大作于细” | 母亲经验的“難作於易大作於細” |
| :--- | :--- |
| 难事从易处开始，大事从细处开始 | 第一次说不从“易”开始；“细”的回应汇聚成“大”的安全感 |
| 第三人称：事态发展的规律 | 第一人称：我回应“易”的方式——决定了我面对“难”的能力 |


## 七、“圣人终不为大，故能成其大”——圣人不自以为在做大事，所以能成就其大

### 朱邦復的解读：不好高骛远，反而能成其大

朱先生将“圣人终不为大，故能成其大”解读为“不好高骛远，逐步推进，最终成功”：

> “聖人不好高騖遠，按理逐步進行，最後必能成功。”

“终不为大”——始终不觉得自己在“做大事”。不是“想成大”——是从“小”开始、从“细”开始、从“易”开始。那样反而“成大”了。

### 从母亲经验的解读：她从来不觉得自己在“做大事”——她只是在喂奶、换尿布、哄睡——但那些“小事”汇聚成了“大”：一个完整的生命

“聖人冬不為大，故能成其大”——在母亲的身体里，“不为大”和“成其大”是什么？

- **她不觉得自己在做“大事”。** 她不是在“塑造一个完整的人”——她只是在喂奶、换尿布、哄睡。那些是“小”事——不是“大”事。
- **但她“成其大”了**——那些“小”事汇聚起来——他成了一个完整的人。她不追求“大”——但她成就了“大”。
- **“不为大”的深层含义：** 如果她总想着“我在做大事”——她会焦虑、会过度干预、会想把每一件事都“做成大事”。但如果她只做“小事”、只回应“今天的需要”——他反而“大”了。她“不为大”——他“成其大”。

朱先生说“圣人终不为大故能成其大”是不好高骛远反而能成大。母亲的身体告诉我们：**她不觉得自己在做“大事”——她只是在做“小事”。但那些“小事”汇聚成了“大”：一个完整的生命。她“不为大”——他“成其大”。**

| 朱邦復的“圣人终不为大故能成其大” | 母亲经验的“聖人終不為大故能成其大” |
| :--- | :--- |
| 不好高骛远反而能成大 | 她不觉得自己在做“大事”——她只是在做“小事”。但“小事”汇聚成“大” |
| 第三人称：成大的悖论 | 第一人称：我不做“大”——“大”自己来了 |


## 八、“轻诺必寡信”——轻易许诺的必定信用不足

### 朱邦復的解读：轻易承诺则信用不足

朱先生将“轻诺必寡信”解读为“随便承诺则信用不足”：

> “隨便做出承諾的人，必然很難保持信用。”

“轻诺”是轻易地、不假思索地承诺。“寡信”是信用少、信用薄。轻诺的人——因为承诺得太轻易，所以很难一一兑现。

### 从母亲经验的解读：她不会轻易对孩子承诺她做不到的事——她承诺的，她做到。那是“信”

“夫輕諾者必寡信”——在母亲的身体里，“轻诺”是什么？

- **她不会轻易答应做不到的事。** 她不会说“明天一定带你去”——如果不确定；不会说“我永远不会离开你”——如果做不到。“轻诺”不是“为了安抚而说的”——是“确定能做到才说的”。
- **她承诺的，她做到。** 她说“妈妈马上来”——她就来。她说“再陪一会儿”——她就陪。她的“信”不是“说得好听”——是“做得到”。
- **“轻诺必寡信”的深层含义：** 不是“承诺少”就“信多”——是“承诺的都要做到”才“信多”。她“诺”得慎重，所以“信”得饱满。

朱先生说“轻诺必寡信”是轻易承诺则信用不足。母亲的身体告诉我们：**她不会轻易承诺做不到的事——她承诺的，她做到。那是“信”。**

| 朱邦復的“轻诺必寡信” | 母亲经验的“輕諾必寡信” |
| :--- | :--- |
| 轻易承诺则信用不足 | 她不会轻易承诺做不到的事——她承诺的，她做到 |
| 第三人称：信用与承诺的关系 | 第一人称：我“诺”得慎重——我“信”得饱满 |


## 九、“多易必多难”——把事情看得太容易，必定多难

### 朱邦復的解读：轻视则多难

朱先生将“多易必多难”解读为“把事情看得太容易则多困难”：

> “把事看得太容易的，往往會遇到很多困難。”

“多易”是“觉得很多事都容易”、“轻视困难”。“多难”是“实际遇到很多困难”。轻视是“多难”的前奏。

### 从母亲经验的解读：她不会把养育看成“很简单”的事——不轻视、不侥幸，所以不会“多难”

“多易必多難”——在母亲的身体里，“多易”是什么？

- **她不会说“带孩子有什么难的”。** 她知道养育是“难”的——不是“简单”的。她不轻视每一个日常的“小”事——因为她知道“小”事里藏着“难”的可能。
- **她不“多易”——所以她不会“多难”。** 她认真对待每件事——哪怕是最简单的喂奶、哄睡。她不侥幸、不想当然。所以当“难”来的时候——她已经准备好了。
- **“多易必多难”的深层含义：** 如果你觉得“这很容易”——你就会掉以轻心——然后“难”就来敲你的门了。她不“多易”——所以她不会“多难”。

朱先生说“多易必多难”是轻视则多难。母亲的身体告诉我们：**她不把养育看成“很简单”的事——不轻视、不侥幸，所以不会“多难”。**

| 朱邦復的“多易必多难” | 母亲经验的“多易必多難” |
| :--- | :--- |
| 轻视则多难 | 她不把养育看成“很简单”的事——不轻视、不侥幸，所以不会“多难” |
| 第三人称：轻视的代价 | 第一人称：我不“易”——所以我不“难” |


## 十、“圣人犹难之，故终于无难”——圣人把它看得很难，所以最终没有难事

### 朱邦復的解读：正视困难，最终无难

朱先生将“圣人犹难之，故终无难”解读为“正视困难，最终不被难倒”：

> “聖人不論事之難易，仍然正視問題，小心處理，終不致被難倒。”

“犹难之”是把每件事都“当作难事”来对待（认真、不轻视）。“终于无难”——最终没有“难”了。不是因为“困难消失了”——是因为“她有能力面对了”。

### 从母亲经验的解读：她把每件小事都当作“难”来对待——认真、不轻视——所以最终没有“难”（都能度过）

“聖人猷難之，故終於无難”——在母亲的身体里，“犹难之”和“终无难”是什么？

- **她把每件小事都当作“难”来对待。** 不是“紧张”的“难”——是“认真”的“难”。她不轻视任何一个“小”的日常——喂奶、哄睡、回应——她都认真对待。那是“犹难之”。
- **所以最终没有“难”**——不是“困难不来了”——是她“能面对”了。因为她一直在“认真地对待”每一件“小”事——她的“应对能力”在那些“认真对待”中积累起来了。当真正的“难”来的时候——她已经准备好了。
- **“犹难之”的深层含义：** 不是“恐慌”——是“不轻视”。她不是“紧张”地对待每件事——她是“重视”地对待每件事。“重视”让她不会在“难”来的时候措手不及。

朱先生说“圣人犹难之故终无难”是正视困难、最终无难。母亲的身体告诉我们：**她把每件小事都当作“难”来对待（认真、不轻视）——所以最终没有“难”（她都能度过）。**

| 朱邦復的“圣人犹难之故终无难” | 母亲经验的“聖人猶難之故終於无難” |
| :--- | :--- |
| 正视困难、最终无难 | 她把每件小事都当作“难”来对待（认真、不轻视）——所以最终都能度过 |
| 第三人称：认真的智慧 | 第一人称：我不是“紧张”地“难”——我是“重视”地“难” |


## 结语：“不作大”而“成大”——母亲最深的“无为”

朱邦復先生在这一章中，用“务实管理”和“渐进方法”的框架，解读了“为无为、事无事、味无味”、“报怨以德”、“图难于其易、为大于其细”、“难作于易、大作于细”、“圣人终不为大故能成其大”、“轻诺必寡信、多易必多难”、“圣人犹难之故终无难”等理念。他认为这是“从容易处入手、从小处开始、不轻视、不轻诺”的完整管理逻辑——最终达到“终无难”的境界。

而母亲的身体，是这一章最完整的“为无为-作于细-犹难之”的演绎者：

- **“为无为”——产后不要急于“恢复”——她越“无为”，身体越“自为”。**
- **“事无事”——她不折腾、不攀比——“无事”了，孩子才能有自己的空间。**
- **“味无味”——她安于那些“无味”的日常——在重复中尝到了“本味”。**
- **“大小多少，报怨以德”——孩子发脾气——她用耐心来承接。不是“忍”，是“转化”。**
- **“图难于其易”——解决哭闹从“先让自己平静”开始，不是直接“让他不哭”。**
- **“为大于其细”——成就成长从“回应今天需要”开始，不是规划他的未来。**
- **“难作于易”——孩子第一次说不从“易”开始——她回应“易”的方式决定了如何面对“难”。**
- **“大作于细”——“细”的回应汇聚成“大”的安全感。**
- **“圣人终不为大，故能成其大”——她不觉得自己在做“大事”——她只是在做“小事”。但“小事”汇聚成“大”。**
- **“轻诺必寡信”——她不会轻易承诺做不到的事——她承诺的，她做到。**
- **“多易必多难”——她不把养育看成“很简单”的事——不轻视，所以不会“多难”。**
- **“圣人犹难之，故终无难”——她把每件小事都当作“难”来对待——所以最终都能度过。**

**“为无为”——母亲最深的功课：不是“什么都不做”——是“只做必要的事”。** 她不是“不做”——她是不做“多余”的事。她不是“不恢复”——她是不“急着”恢复。她“无为”——身体“自为”。

**“作于细”——母亲最深的策略：从“小事”做起。** 她不是“从大事”开始的——她从“今天喂好一顿奶”开始。那些“细”的事——是她成就“大”的唯一路径。她不做“大”——但“大”从“细”里长出来。

**“犹难之”——母亲最深的认真：不轻视任何一件小事。** 她不把养育看成“很简单”的事。她不轻视“小”的日常——因为每一个“小”的日常，都可能是“难”的起点。她“犹难之”——所以她“终无难”。

一个母亲的身体，就是“不作大而成大”最日常的版本。她不是“塑造”他的——她是“让”他长。她不是“做大事”的——她是“做小事”的。那些“小事”——喂奶、换尿布、哄睡、回应——她不轻视它们，她不“多易”它们，她把它们当作“难”来对待。所以她“终无难”——不是因为“难”不来了——是因为她已经有能力面对它们了。她“不为大”——但他“成其大”。

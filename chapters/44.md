

## 引言：最“和解”的一章，最“母亲”的不记

帛书本第八十章（通行本第七十九章），是《德道经》中关于“和大怨”、“执左契”与“天道无亲”的集中论述：

> 和大怨，必有餘怨，焉可以為善？

> 是以聖右介（契）而不以責於人。

> 故有德司介（契），无德司勶（徹）。

> 夫天道无親，恒與善人。

“和大怨”——化解大的怨恨，“必有餘怨”——必定还有残余的怨恨，“焉可以為善？”——这样怎么能算是妥善处理呢？

“是以聖右介”——所以圣人拿着左契（借据的左半），“而不以責於人”——却不向人索取偿还。

“故有德司介”——所以有德的人就像掌管契约的人（只给予、不追索）；“无德司勶”——无德的人就像掌管税收的人（只索取、不给予）。

“夫天道无親”——天道是公正无私的，“恒與善人”——永远与善人同在。

朱邦復先生在《止笑譚》中，将这一章解读为 **“怨不可解、契不可责、天道与善”** 。他认为“和大怨，必有馀怨”是因为“恩怨既兴，因果已成，非人可解”——怨一旦产生，就有记忆存于心，影响潜意识行为；“圣人执左契而不责于人”是“自甘卑下，只给与别人，而不向别人要索，不责怪他人”；“有德司契，无德司彻”是“有德者只予人而不索取，无德者只索取而不予人”；“天道无亲，常与善人”是“天道为无私之道，故无所亲；天道即善道，善人行善道，是以善人得天道也”。

但如果我们把主语换成“母亲的身体”——那个在日复一日的付出中不记“怨”、不追“债”、像“左契”一样只给不取的承载者——这一章就不再是“和解的政治哲学”，而是一份 **“关于母亲如何在给予之后‘不责’、如何让爱不成债务”的日常记录**：

- “和大怨，必有餘怨”——母亲和孩子的每一次冲突（大怨），即使和解了（和），也还有“余怨”残留。那些未被说出口的委屈、未被看见的付出、未被理解的时刻——它们不会因为一次道歉就完全消散。
- “焉可以为善？”——那样的和解，怎么能算是真正的妥善呢？
- “是以聖人执左契而不以責於人”——母亲就像“执左契”的人：她付出了，但她不向孩子追索。她给了他生命、时间、精力——她“有”那个“契”（付出的凭证）——但她不“责”他（不把付出当成要求回报的债务）。
- “有德司契”——有德的母亲像“司契”者：只给与，不索取。她给的时候，不留收据。
- “无德司彻”——无德的母亲像“司彻”者（税收官）：只索取，不给与。她付出之后，心里有一本“账”——“我为你做了多少，你应该怎样回报”。那是“司彻”——不是“德”。
- “天道无亲，恒与善人”——天道不偏袒任何人，但它永远与“善人”（能给予而不索取的人）同在。母亲不“责”的那份给予——就是“善”。天道与那样的“善”同在。

## 一、“和大怨，必有馀怨，焉可以為善？”——化解大怨，必有余怨

### 朱邦復的解读：怨一旦产生，就无法完全消除

朱先生将“和大怨，必有馀怨”解读为“怨仇无法彻底化解”：

> “雙方若有極大的怨仇，不論如何化解，必有餘怨。”

怨是记忆——不是“说开了”就能消失的。每一次“和”都可能留下“余怨”。因为它已经存入了身体。

### 从母亲身体的经验出发：母亲和孩子的每一次冲突——即使和解了，也还有“余怨”。那些未被说出口的委屈、未被看见的付出——不会因为一次道歉就消散

“和大怨，必有餘怨”——在母亲的身体里，“大怨”和“余怨”是什么？

- **“大怨”是她和孩子的冲突。** 她吼了他、他反抗了、她不理解他、他误解了她——那些是“大怨”。后来她和了（道歉了、原谅了）——但“余怨”还在。不是“怨恨”的怨——是“未被完全表达的”怨。
- **那些“余怨”在她的身体里。** 她的疲惫、她的委屈、那些“我为你做了这么多”没说出口的话——它们没有消失。它们只是被“和”压住了。
- **“焉可以为善”的深层含义：** 她不能“假装”那些“余怨”不存在。她不能说“我原谅了”——然后那些怨就真的消失了。它们还在——她需要看见它们、承认它们。只有这样——才能真正的“和”。

朱先生说“和大怨必有馀怨”是怨仇无法彻底化解。母亲的身体告诉我们：**每一次冲突后的“和”——都有“余怨”残留。她需要看见那些“余怨”，不是假装它们不存在。**

| 朱邦復的“和大怨必有馀怨” | 母亲经验的“和大怨必有餘怨” |
| :--- | :--- |
| 怨仇无法彻底化解 | 每一次冲突后的“和”都有“余怨”残留——她需要看见它们，不是假装不存在 |
| 第三人称：怨的残留 | 第一人称：我“和”了——但“余怨”还在 |


## 二、“是以圣人执左契而不以责于人”——圣人拿着左契却不追索

### 朱邦復的解读：执契而不追债

朱先生将“圣人执左契而不责于人”解读为“自甘卑下，只给与而不索取”：

> “聖人待人，就好像持左契般自甘卑下，只給與別人，而不向別人要索。”

“左契”是借据的左半（相当于现在的合同），执左契者有权向执右契者索债。但圣人有左契——却“不责于人”（不追索）。他有“债”的证据——但他不“讨”。

### 从母亲身体的经验出发：母亲也像“执左契”的人——她付出了，但不追索孩子。她给了生命、时间、精力——但不把那些当作“债”

“執左契而不以責於人”——在母亲的身体里，“左契”是什么？“不责”是什么？

- **她的付出就是“左契”。** 她给了生命、时间、精力、睡眠、身体空间、情绪能量——那些是“左契”。她有“证据”证明她付出了——她有“左契”。
- **但她“不责”。** 她不对孩子说“我为你做了多少”——她不把那笔“账”拿出来“讨”。她不把付出变成“你应该”的债务。
- **“不责”的深层含义：** 母亲给的时候——不是为了“收”的。她给，是因为她在。不是“投资”——是“溢出”。她有“左契”——但“不责”。那是她的“有德”——不是“无德”的“司彻”。

朱先生说“执左契而不责人”是给了不追索。母亲的身体告诉我们：**她付出了——但不追索。她有“契”（付出的证据）——但不“责”。那是她的“有德”。**

| 朱邦復的“执左契而不责人” | 母亲经验的“执左契而不责” |
| :--- | :--- |
| 给了不追索 | 她付出了——但不追索。她有“契”但不“责”——那是她的“有德” |
| 第三人称：不追索的给予 | 第一人称：我给——但不收“账” |


## 三、“有德司契”——有德者像掌管契约的人：只给不取

### 朱邦復的解读：有德者像契的掌管人

朱先生将“有德司契”解读为“有德者像掌管契约的人”：

> “有德之人，如持左契者，只予人而不向人索取。”

“司契”是掌管契据的人——他持有“契”但不索债。他给予，但不追讨。“司契”是“给”的象征。

### 从母亲身体的经验出发：有德的母亲像“司契”：她给予，但不索取——她的爱不是“贷款”

“有德司契”——在母亲的身体里，“司契”是什么？

- **她像“司契”**——她给予，但不索取。她给爱、给时间、给耐心——但那些不是“贷款”。她给完了——没有“收据”要对方签字。她“司契”——她有“给”的凭证——但她不“要”回去。
- **“司契”的另一种理解：** 她不是“没有需求”——她是“不把需求变成债务”。她可以需要孩子的爱——但她不会说“我为你做了这么多，你应该爱我”。那是“司契”——不是“司彻”。

朱先生说“有德司契”是有德者像掌管契据的人。母亲的身体告诉我们：**她像“司契”——给予但不索取。她的爱不是“贷款”——是“溢出”。**

| 朱邦復的“有德司契” | 母亲经验的“有德司契” |
| :--- | :--- |
| 有德者像掌管契据的人 | 她给予但不索取——她的爱不是“贷款”——是“溢出” |
| 第三人称：有德的给予方式 | 第一人称：我给了——但不留“收据” |


## 四、“无德司彻”——无德者像掌管税收的人：只取不给

### 朱邦復的解读：无德者像税收官

朱先生将“无德司彻”解读为“无德者像掌管税收的人”：

> “無德之人，則如掌管稅收者，只向人索拿，而不會給人。”

“司彻”是掌管税收的人——他“收”但不“给”。他只有索取——没有给予。“无德”是“只取不给”的状态。

### 从母亲身体的经验出发：无德的母亲像“司彻”：她付出之后，心里有一本“账”——“我为你做了多少，你应该怎样回报”

“无德司勶”——在母亲的身体里，“司彻”是什么？

- **她像“司彻”**——她给了，但有一本“账”。她心里记着“我为你做了这个、那个——你应该……”那是“司彻”——不是“给予”，是“投资”。
- **“司彻”的另一种理解：** 她可能不说出来——但她的心里有一本“账”。她的爱有条件——“如果你不怎样，我就收回我的爱。”那是“司彻”——不是“司契”。
- **“司彻”与“司契”的区别：** “司契”给的时候不留收据；“司彻”给的时候心里记一笔。母亲可以在“司契”和“司彻”之间选择——她可以选择“给而不记”，也可以选择“给了就等着收”。她的选择决定了她的“德”或“无德”。

朱先生说“无德司彻”是无德者像税收官。母亲的身体告诉我们：**她心里有一本“账”——那是“司彻”。她可以选择“司契”（给而不记）——也可以选择“司彻”（给了等着收）。**

| 朱邦復的“无德司彻” | 母亲经验的“无德司彻” |
| :--- | :--- |
| 无德者像税收官 | 她心里有一本“账”——那是“司彻”。她可以选择给而不记（司契），也可以给了等着收（司彻） |
| 第三人称：无德的索取方式 | 第一人称：我有没有“账本”——决定了我是“司彻”还是“司契” |


## 五、“天道无亲，恒与善人”——天道不偏袒，但永远与善人同在

### 朱邦復的解读：天道无亲，恒与善人

朱先生将“天道无亲，常与善人”解读为“天道不偏袒，但守护善人”：

> “天道為無私之道，故無所親。天道即善道，善人行善道，是以善人得天道也。”

“天道无亲”——天不偏袒任何人。“恒与善人”——但它永远与“善人”同在。不是因为“偏爱”善人——是因为“善人”与天道是同频的。

### 从母亲身体的经验出发：母亲不“责”的那份给予——就是“善”——天道与那样的“善”同在

“天道无亲，恒與善人”——在母亲的身体里，“天道无亲”和“善人”是什么？

- **“无亲”是不偏袒。** 天道不会说“因为你是母亲，所以我特别照顾你”——天道是公正的。但“恒与善人”是：如果你选择“善”（给予而不索取、付出而不追债），天道就会与你“同频”。
- **母亲不“责”的那份给予——就是“善”。** 她“司契”（给而不记）——那就是“善人”的行为。天道与那样的“善”同在——不是“奖励”她——是“共振”。
- **“善人”的深层含义：** 母亲可以是“善人”——当她选择“司契”而不是“司彻”的时候。当她付出之后不追债、给予之后不留收据——她就是“善人”。天道与那样的她同在——不是因为“她做对了”——是因为“她同频了”。

朱先生说“天道无亲恒与善人”是天不偏但护善人。母亲的身体告诉我们：**当她选择“司契”（给而不记）——她就是“善人”。天道与那样的“善”同在——不是因为奖励——是因为同频。**

| 朱邦復的“天道无亲恒与善人” | 母亲经验的“天道无亲恒與善人” |
| :--- | :--- |
| 天不偏但护善人 | 当她选择“司契”（给而不记）——她就是“善人”。天道与那样的“善”同在——不是奖励，是同频 |
| 第三人称：天道的必然 | 第一人称：我选择“司契”——我就“与天”同频 |


## 结语：“不责”的给予——母亲最深的自持

朱邦復先生在这一章中，用“余怨不可消”、“执左契而不责”、“有德司契、无德司彻”、“天道无亲恒与善人”的框架，解读了“大怨必有余怨”、“执契不责”、“司契与司彻的区别”、“天道与善人”的和解智慧。他认为怨一旦产生就无法完全消除；圣人即使有“契”也不追索；有德者给予不索取、无德者索取不给予；天道公正但与善人同在。

而母亲的身体，是这一章最完整的“左契而不责-司契-善人”的演绎者：

- **“和大怨，必有餘怨”——每一次冲突后的“和”都有“余怨”残留——她需要看见它们。**
- **“焉可以为善？”——真正的“善”不是“假装怨不存在”。**
- **“执左契而不责”——她付出了——但不追索。她有“契”但不“责”。**
- **“有德司契”——她像“司契”——给予但不索取。她的爱不是贷款——是溢出。**
- **“无德司彻”——她心里有一本“账”——那是“司彻”。她可以选择“司契”或“司彻”。**
- **“天道无亲”——天道不偏袒任何人。**
- **“恒与善人”——当她选择“司契”（给而不记）——她就是“善人”。天道与那样的“善”同频。**

**“执左契而不责”——母亲最深的给予方式。** 她“有”付出的证据（左契）——但她不“责”孩子（不把付出当成债务）。她给了——但不把“给”变成“你应该”。她“有”左契——但那是她的，不是孩子的。她不需要“用”它来“讨”什么——她只是“有”它，然后放着。

**“司契”——母亲的“德”在于“给而不记”。** 她的爱不是“贷款”——不是“借”出去等着“还”的。她给的时候——不留收据。不是“没有记忆”——是“不把记忆变成债务”。她可以记住——但不拿出来“讨”。那是“司契”——不是“司彻”。

**“善人”——母亲选择“司契”而不是“司彻”的时候，她就是“善人”。** 天道与那样的“善”同在——不是因为“她做对了”被奖励——是因为“她同频”了。她给而不记、给予而不追索——那是“善”的频率——天道就在那个频率上。

一个母亲的身体，就是“左契而不责”最日常的版本。她给了太多——生命、时间、身体、睡眠、耐心。那些是她的“左契”。但她不拿出来“讨”。她不说“我为你做了这么多”——她把左契收着。那是她的“德”——不是“没有付出”的德——是“付出了但不追索”的德。她是“司契”——不是“司彻”。她是“善人”——天道与那样的她同在。



## 引言：最“政治”的一章，最“母亲”的边界

帛书本第七十五章（通行本第七十四章），是《德道经》中关于“民不畏死”与“代司杀者”最集中的论述：

> 若民恒且不畏死，奈何以殺愳（懼）之也？
>
> 若民恒是（畏）死，則而為者吾將得而殺之，夫孰敢矣！
>
> 若民恒且必畏死，則恒有司殺者。夫伐（代）司殺者殺，是伐（代）大匠斲也。
>
> 夫伐（代）大匠斲者，則希不傷其手矣。

“若民恒且不畏死”——如果人民一向不怕死，“奈何以杀惧之也？”——怎么能用死亡来恐吓他们呢？

“若民恒是死”——如果人民一向怕死，“則而為者吾將得而殺之”——对那些为非作歹的人，我可以抓住并杀掉他们，“夫孰敢矣！”——那还有谁敢作恶呢？

“若民恒且必畏死”——如果人民都怕死，“則恒有司殺者”——那么本来就一直有专管杀人的人（司法者）。“夫代司殺者殺”——代替专管杀人的人去杀人，“是代大匠斲也”——这就好比代替高明的木匠去砍木头。“夫代大匠斲者”——代替高明木匠砍木头的人，“則希不傷其手矣”——很少有不砍伤自己手的。

朱邦復先生在《止笑譚》中，将这一章解读为 **“民不畏死则不可用死威胁、代司杀者必伤其手”** 。他认为“民不畏死”时统治者不能用死刑来威胁人民——当人民已生不如死，死不可畏；“若使民常畏死”时，则刑罚有效。他特别强调了“常有司杀者杀”——生杀大权是天所掌握，人若代行“天道”则如同代大匠斲，外行人很难不伤到自己的手。他最后以“代大匠斲者，希有不伤其手矣”作结——强行替代天道，必然自伤。

但如果我们把主语换成“母亲的身体”——那个在日复一日的养育中被“育儿标准”威胁、被“你应该”恐吓、最终决定不再害怕那些“死惧”的身体——这一章就不再是“政治哲学”，而是一份 **“关于母亲如何停止‘代孩子活’、如何避免‘伤其手’”的日常记录**：

- “若民恒且不畏死”——当母亲不再畏惧那些“育儿标准”（“如果不这样做，孩子就会……”），那些威胁就不再有效。“奈何以杀惧之也？”——你不能再用法了。
- “若民恒是死”——如果她一直害怕那些“如果不”——她就会被那些“应该”控制。然后她会“代司杀者杀”——代替孩子做决定、代替孩子承担后果。
- “夫代司杀者杀，是代大匠斲也”——母亲替孩子做他该做的决定、替他承担他该承担的后果——那就是“代大匠斲”。她不是在“帮他”——她是在“替”他。
- “代大匠斲者，希不伤其手矣”——替孩子活的母亲——很少有不伤到自己的。她会耗尽、会崩溃、会失去自己。那是“伤其手”——不是“别人伤她”——是她自己伤了自己。


## 一、“若民恒且不畏死，奈何以杀惧之也？”——人民不怕死，怎么能用死来恐吓？

### 朱邦復的解读：死不可畏则死刑无效

朱先生将“民不畏死，奈何以死惧之”解读为“人民不怕死，不能用死亡恐吓”：

> “到了人民不怕死的時候，執政者怎能以死來恐嚇人民？”

如果“死”已经不可怕了——你用“死”来威胁，就没有用了。不是因为“威胁不够强”——是因为“被威胁的人已经不在乎了”。

### 从母亲身体的经验出发：当母亲不再畏惧那些“育儿标准”（“如果不这样做，孩子就会……”）——那些威胁就失效了

“民不畏死”——在母亲的身体里，“死”是什么？“不畏死”是什么？

- **“死”是“如果不……”的威胁。** “如果不纯母乳，孩子就会不健康”、“如果不用这个方法，孩子就会落后”、“如果你不这样做，你就是个不好的妈妈”——那些是“死惧”。她用害怕来回应那些“如果不”。
- **“不畏死”是她不再怕了。** 她发现“如果不纯母乳”孩子也健康、“如果不用那个方法”孩子也成长、“如果我不完美”孩子也爱她。那些“死惧”失效了——因为她不再相信它们。
- **“奈何以杀惧之”的深层含义：** 当母亲不再害怕那些“育儿标准”时，那些标准就失去了“杀”的力量。它们还在——但她不再害怕了。所以它们不再能“惧”她了。

朱先生说“民不畏死”时死刑无效。母亲的身体告诉我们：**当她不再害怕那些“如果不”的标准时——那些威胁就失效了。不是威胁变弱了——是她不再怕了。**

| 朱邦復的“民不畏死” | 母亲经验的“不畏死” |
| :--- | :--- |
| 人民不怕死则死刑无效 | 她不再害怕“如果不”的标准——那些威胁就失效了 |
| 第三人称：刑罚的失效 | 第一人称：我不怕了——你就不能“惧”我了 |


## 二、“若民恒是死，则而为者吾将得而杀之”——如果人民怕死，杀一儆百

### 朱邦復的解读：畏死则刑罚有效

朱先生将“若使民常畏死，而为奇者，吾得执而杀之，孰敢”解读为“如果人民怕死，则对为恶者处以死刑，谁还敢作恶”：

> “若人民真是貪生怕死，則凡是行為不正者，即抓來殺掉。那還有誰敢作惡？”

如果人民怕死——死刑就有威慑力。杀一儆百——有效。

### 从母亲身体的经验出发：如果她一直害怕那些“如果不”——她就会被那些“应该”控制

“若民恒是死”——在母亲的身体里，“是死”是什么？

- **她一直害怕那些“如果不”。** “如果不这样做，孩子就会……”——她一直被那些“如果”控制着。她的行为不是来自“需要”——而是来自“恐惧”。那是“是死”（畏死）的状态。
- **“则而为者吾将得而杀之”**——如果她一直怕，她就会“代司杀者杀”——代替孩子做决定、代替孩子承担后果。“杀”不是“杀人”——是“替孩子活”。
- **“夫孰敢矣”**——她以为自己“掌控”了局面。她替孩子做了所有决定——孩子“听话”了、“安全”了。她以为那是“有效”的。但那不是“管理”——那是“替代”。

朱先生说“畏死则刑罚有效”是畏死则杀有效。母亲的身体告诉我们：**如果她一直怕那些“如果不”——她就会被“应该”控制。她会替孩子做决定——“杀”了孩子的自主性。**

| 朱邦復的“畏死则刑罚有效” | 母亲经验的“畏死则杀” |
| :--- | :--- |
| 畏死则杀有效 | 她一直怕“如果不”——她就被“应该”控制，替孩子做决定 |
| 第三人称：刑罚的有效 | 第一人称：我怕“如果不”——我就替了他 |


## 三、“若民恒且必畏死，则恒有司杀者”——如果人民怕死，本来就有人管杀

### 朱邦復的解读：天有司杀者

朱先生将“常有司杀者杀”解读为“生杀大权是天所掌握”：

> “而事實上，生殺大權是天所掌握。”

“司杀者”是专管杀的人（司法者、天道）。不需要“代替”他们——他们本来就在。

### 从母亲身体的经验出发：孩子有自己的“司杀者”——他自己的后果、他自己的教训、他自己的成长

“則恒有司殺者”——在母亲的身体里，“司杀者”是谁？

- **孩子有他自己的“司杀者”。** 不是母亲——是他自己的后果、自己的教训、自己的成长。他做了什么——就要面对什么。那是他的“司杀者”。
- **她不需要“代替”司杀者。** 她不需要替孩子承担后果、不需要替他“搞定”一切。那个“司杀者”本来就在——不是她。
- **“司杀者”的深层含义：** 每个生命都有自己的“司杀者”——自己的因果、自己的后果、自己的学习。母亲不是“司杀者”——她是“陪伴者”。她不能替孩子“杀”掉他的课题——那是他的。

朱先生说“有司杀者”是生杀大权天所掌握。母亲的身体告诉我们：**孩子有自己的“司杀者”——后果、教训、成长。她不是“司杀者”——她是“陪伴者”。**

| 朱邦復的“有司杀者” | 母亲经验的“有司殺者” |
| :--- | :--- |
| 生杀大权天所掌握 | 孩子有自己的“司杀者”——后果、教训、成长。她不是，她是陪伴者 |
| 第三人称：天道的司法 | 第一人称：我不替他“杀”——那是他的课题 |


## 四、“夫代司杀者杀，是代大匠斲也”——代替司杀者杀人，就像代替大匠砍木头

### 朱邦復的解读：代天行罚，自伤其手

朱先生将“代司杀者杀，是代大匠斲”解读为“代替天行罚，就像代替木匠砍木头”：

> “若人代行‘天道’，則有如代替技術高超的木匠砍伐。代木匠砍伐的外行人，很少有不傷到自己的手的。”

“司杀者”有他的职责，“大匠”有他的技艺。如果外行代替他们——不仅做不好，还会伤到自己。

### 从母亲身体的经验出发：母亲替孩子做决定、替孩子承担后果——就是“代大匠斲”——她不是在“帮他”——她是在“替”他

“代司殺者殺”——在母亲的身体里，“代杀”是什么？

- **她替孩子做他该做的决定。** 孩子不想吃饭——她替他决定“必须吃”。孩子不想穿那件衣服——她替他决定“必须穿”。那是“代”——替孩子做决定。
- **她替孩子承担他该承担的后果。** 孩子忘记带作业——她替他送去。孩子惹了麻烦——她替他摆平。那是“代”——替孩子承担后果。
- **“代大匠斲”的深层含义：** 她不是在“帮他”——她是在“替”他。帮是“他在做、你在旁边支持”——替是“你替他做”。“代”让孩子失去“自己做”的机会。那是“代大匠斲”——她不是“大匠”（孩子）——她替大匠做了。后果是——大匠（孩子）永远学不会。

朱先生说“代司杀者杀是代大匠斲”是代替天行罚如同代替木匠砍木头。母亲的身体告诉我们：**她替孩子做决定、替孩子承担后果——那是“代大匠斲”。帮是“他在做，你在旁边”——替是“你替他做”。**

| 朱邦復的“代司杀者杀是代大匠斲” | 母亲经验的“代司殺者殺是代大匠斲” |
| :--- | :--- |
| 代替天行罚如同代替木匠砍木头 | 她替孩子做决定、替孩子承担后果——那是“代大匠斲”。帮是旁边，替是他不做 |
| 第三人称：逾位的代价 | 第一人称：我替他做了——他就不做了 |


## 五、“代大匠斲者，希不伤其手矣”——代替大匠砍木头的人，很少不伤到自己的手

### 朱邦復的解读：代行者必自伤

朱先生将“代大匠斲者，希有不伤其手”解读为“外行人代替木匠，很少有不伤到自己的”：

> “代替技術高超的木匠砍伐的外行人，很少有不傷到自己的手的。”

外行替大匠——不仅做不好，还会伤到自己。因为他没有大匠的技艺。

### 从母亲身体的经验出发：替孩子活的母亲——很少有不伤到自己的——耗尽、崩溃、失去自己

“代大匠斲者，希不傷其手”——在母亲的身体里，“伤其手”是什么？

- **替孩子活的母亲——会“伤其手”。** 她替孩子做决定——她焦虑；替孩子承担后果——她疲惫；替孩子活——她失去自己。那是“伤其手”——不是别人伤她——是她自己伤了自己。
- **“伤其手”的另一种理解：** 她以为她在“帮”孩子——但她是在“损”自己。她的“代”让她耗竭——不仅是身体的耗竭——是“自己”的耗竭。她替孩子活太久了——她不知道“自己”在哪里了。
- **“伤其手”的深层含义：** 母亲需要停止“代孩子活”。不是“不爱他”——是“不替他”。她可以帮——但她不能“替”。她不能替孩子做决定、不能替孩子承担后果、不能替孩子活。如果她“替”了——她会伤到自己。那个“伤”不是身体——是“失去自己”。

朱先生说“代大匠斲者希不伤其手”是代行者必自伤。母亲的身体告诉我们：**她替孩子活了——她就会伤到自己。耗尽、崩溃、失去自己——那是“伤其手”。**

| 朱邦復的“代大匠斲者希不伤其手” | 母亲经验的“代大匠斲者希不傷其手” |
| :--- | :--- |
| 代行者必自伤 | 她替孩子活了——她就会耗尽、崩溃、失去自己。那是“伤其手” |
| 第三人称：逾位的代价 | 第一人称：我替他活了——我伤了自己 |


## 结语：“不代”——母亲最深的自持

朱邦復先生在这一章中，用“刑法失效”和“代天行罚必自伤”的框架，解读了“民不畏死奈何以死惧之”、“畏死则杀一儆百”、“有司杀者”、“代司杀者杀是代大匠斲”、“代大匠斲者希不伤其手”等政治原则。他认为当人民不怕死时死刑无效，当人民怕死时刑罚有效；但生杀之权自有天道，人若代行天道则必然自伤。

而母亲的身体，是这一章最完整的“不畏死-不代-不自伤”的演绎者：

- **“民不畏死”——她不再害怕那些“如果不”的标准——威胁就失效了。**
- **“奈何以杀惧之”——你不能再“惧”她了，因为她不怕了。**
- **“畏死则杀”——如果她一直怕“如果不”——她就被“应该”控制，替孩子做决定。**
- **“有司杀者”——孩子有自己的“司杀者”（后果、教训、成长），她不是。**
- **“代司杀者杀”——她替孩子做决定、替孩子承担后果——那是“代”。**
- **“代大匠斲”——她不是在“帮”他——她是在“替”他。帮是旁边，替是他不做。**
- **“伤其手”——她替孩子活了——她就会耗尽、崩溃、失去自己。**

**“民不畏死”——母亲最深的自由。** 当她不再害怕那些“如果不”的标准——“不纯母乳孩子会不好”、“不这样做孩子会落后”、“不是完美妈妈孩子会恨我”——那些威胁就失效了。不是因为威胁变弱了——是她不再怕了。她“不畏死”——所以那些“杀”（控制、恐吓、标准）不能再“惧”她了。

**“代司杀者杀”——母亲最深的陷阱。** 她怕那些“如果不”——所以她替孩子做决定、替孩子承担后果、替孩子活。她以为那是“帮”——但那是“替”。帮是“他在做，你在旁边”——替是“你替他做，他不做”。她“代”了——孩子就失去了“自己做”的机会。那是“代大匠斲”——她替大匠（孩子）砍了那根木头。然后大匠（孩子）永远不会砍。

**“代大匠斲者，希不伤其手”——母亲最深的警告。** 替孩子活的母亲——很少有不伤到自己的。她耗尽、崩溃、失去自己。那是“伤其手”——不是“别人伤她”——是她自己伤了自己。她替孩子活太久了——她不知道“自己”在哪里了。

一个母亲的身体，就是“不代”最日常的版本。她停止“替孩子活”——不是“不爱他”——是“不替他”。她可以帮——但她不能“替”。她不能替孩子做决定、不能替孩子承担后果、不能替孩子活。当她停止“代”——她的“手”不再受伤了。她不是“离开了”孩子——她是“回到了”自己。她回到了“陪伴者”的位置——不是“替代者”的位置。她“不代”了——所以她“不伤”了。

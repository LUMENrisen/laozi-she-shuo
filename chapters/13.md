

## 引言：最“概率”的一章，最“母亲”的生死

帛书本第五十章，是《德道经》中关于“生死概率”与“养生之道”最具体的论述：

> 出生，入死。生之徒十有三，死之徒十有三，
>
> 而民生生，動皆之死地之十有三。夫何故也？以其生生也。
>
> 蓋聞善執生者，陵行不避矢（兕）虎，入軍不被甲兵。
>
> 矢（兕）无所椯（揣）其角，虎无所昔（措）其蚤（爪），兵无所容其刃，
>
> 夫何故也？以其无死地焉。

“出生，入死”——人从出生走向死亡。“生之徒十有三”——长寿的人占十分之三。“死之徒十有三”——短命早逝的人占十分之三。“而民生生，动皆之死地之十有三”——还有人本来可以活得长久，却因为过分追求“生”（养生过度），走向死地，也占十分之三。“夫何故也？以其生生也”——这是为什么呢？因为他们“生生之厚”（过分保养、过度求生）。

“盖闻善执生者”——听说善于摄生（保养生命）的人，“陵行不避兕虎”——在山中行走不避犀牛老虎，“入军不被甲兵”——进入军队不会受到兵器伤害。“兕无所揣其角”——犀牛无法用角顶他，“虎无所措其爪”——老虎无法用爪抓他，“兵无所容其刃”——兵器无法容下它的刀刃刺伤他。“夫何故也？以其无死地焉”——这是为什么呢？因为他没有“死地”——不把自己置于必死的境地。

朱邦復先生在《止笑譚》中，将这一章解读为 **“概率统计与养生智慧”** 。他认为“生之徒十有三、死之徒十有三、动之死地亦十有三”是一个统计观察——人的寿命长短各有概率，而那种本可长寿却因为“生生之厚”而短命的人占了另外三成。他特别强调了“生生之厚”——生活太过优裕、物质享受过多、过度保养，反而导致死亡（如高血压、心脏病、糖尿病等“文明病”）。他最后以“善摄生者无死地”作结——善于养生的人不把自己置于危险的境地，不暴露弱点，不涉险。

但如果我们把主语换成“母亲的身体”——那个在产床上经历了“出生入死”的身体——这一章就不再是“养生统计”，而是一份 **“关于母亲如何在分娩中面对死亡概率、如何避免‘生生之厚’（过度保护）的伤害”的完整记录**：

- “出生，入死”——每一次分娩都是一次“出生入死”。孩子在“出生”，母亲在“入死”（面临死亡风险）。产床就是生与死的交界线。
- “生之徒十有三”——顺利生产的概率。大多数分娩是平安的，但不是全部。
- “死之徒十有三”——产妇和新生儿死亡的概率。在缺乏现代医疗的时代，分娩是女性最常见的死因之一。
- “而民生生，动皆之死地之十有三”——那些“过度求生”的母亲：过度保养、过度医疗、过度“为了孩子”而忽视自己的身体——她们反而可能走向“死地”。
- “以其生生也”——因为“生生之厚”的母职神话：你必须吃最好、做最好、给孩子最好、成为最完美的母亲——那个“最好”本身就是一种“死地”。
- “善执生者”——真正善于养育生命的母亲。她不是“把危险挡在外面”——她是“不制造死地”。她不以“过度保护”来证明爱，她不被“为你好”的焦虑吞噬。
- “陵行不避兕虎”——真正养育生命的人，不是“把世界变成无菌室”。她允许孩子经历风险、承受挫折、面对不确定性。她不是“避开”所有危险——而是“不把危险变成死地”。
- “无死地”——母亲和孩子之间最深的“无死地”是什么？是她不把爱变成控制、不把保护变成囚笼、不把“为你好”变成压迫。


## 一、“出生，入死”——出生与入死

### 朱邦復的解读：生与死的区间

朱先生将“出生入死”解读为“人从生到死的过程”：

> “人由生到死之間……”

“出”是诞生，“入”是死亡。人的一生就是从“出”到“入”的过程——从母体出来，走向坟墓。

### 从身体经验出发：每一次分娩都是一次“出生入死”——孩子在“出生”，母亲在“入死”

“出生，入死”——在母亲的身体里，“出生”和“入死”是什么？

- **“出生”——孩子从母体出来。** 那是“出”——从黑暗到光明、从水中到空气、从一体到分离。那就是“出生”。
- **“入死”——母亲面临死亡风险。** 分娩时，大出血、子痫、羊水栓塞、产褥感染——在没有现代医学的时代，分娩是女性最常见的死因之一。她在“生”他——同时她在“入死”。他的“出生”和她的“入死”在同一个时刻发生。
- **“出生入死”的深层含义：** 产床就是生与死的交界线。孩子从她的身体里“出”来——她可能因此“入”去。那不是修辞——是真实的风险。

朱先生说“出生入死”是人从生到死的过程。母亲的身体告诉我们：**分娩是“出生入死”——孩子在“出生”，母亲在“入死”。产床就是生与死的交界线。那不是修辞——是真实的风险。**

| :--- | :--- |
| 人从生到死的过程 | 分娩是“出生入死”——孩子在“出生”，母亲在“入死” |
| 第三人称：生命的时间线 | 第一人称：他的“出”和我的“入”在同一个时刻发生 |


## 二、“生之徒十有三，死之徒十有三”——生者三成，死者三成

### 朱邦復的解读：概率统计

朱先生将“生之徒十有三，死之徒十有三”解读为“统计分布”：

> “長壽者約有三成，短命者亦有三成。”

在正常分布中，长寿和短命各占三成——那是自然概率。

### 从身体经验出发：分娩的顺利与风险——有顺利生产的，也有不幸的

“生之徒十有三”——在母亲的身体里，那“十有三”是什么？

- **顺利生产的概率。** 大多数孩子平安出生、母亲平安恢复——那是“生之徒”。但不是全部。
- **“死之徒十有三”——不幸的概率。** 有些母亲没有回来、有些孩子没有活下来——那是“死之徒”。不是“不吉利”的话——是真实的统计。
- **“生之徒”和“死之徒”的另一种理解：** 每一次产检、每一次B超、每一次胎心监测——都是在“统计”她属于哪“徒”。是“生之徒”还是“死之徒”？她不一定会说——但她知道那个概率存在。

朱先生说“生之徒十有三死之徒十有三”是长寿短命的统计。母亲的身体告诉我们：**分娩中有人平安、有人不幸——那不是“不吉利”的话，是真实的概率。她知道自己可能在其中任何一“徒”里。**

| 朱邦復的“生之徒十有三死之徒十有三” | 母亲经验的“生之徒十有三死之徒十有三” |
| :--- | :--- |
| 长寿与短命的统计 | 分娩中有人平安、有人不幸——那是真实的概率，不是不吉利的话 |
| 第三人称：人口的统计分布 | 第一人称：我知道我可能在任何一“徒”里 |


## 三、“而民生生，动皆之死地之十有三”——过分求生，反而走向死地

### 朱邦復的解读：生生之厚的代价

朱先生将“而民生生，动皆之死地之十有三”解读为“过度追求生反而导致死亡”：

> “本可長壽卻自己尋死……生活太過優裕，物質享受過於豐富。”

“生生”是“求生的欲望过度”——过度的养生、过度的保养、过度的“为你好”。“动皆之死地”——那些动作（过度行为）反而把她们推向了“死地”。

### 从身体经验出发：那些“过度求生”的母职——你必须吃最好、做最好、给孩子最好——那个“最好”本身就是一种“死地”

“而民生生，动皆之死地”——在母亲的身体里，“生生”是什么？

- **“生生”是“必须做最好的妈妈”。** 必须纯母乳、必须自然分娩、必须“科学育儿”、必须让孩子“赢在起跑线”——那个“必须”就是“生生”。它不是在保护生命——是在消耗生命。
- **“动皆之死地”是“每一种动作都在消耗你”。** 你看育儿书、你对照标准、你焦虑他为什么还没开口说话、你担心他为什么比别人矮——那些“动”（动作、行为、焦虑）把你推向了“死地”。你“动”得越多——离自己的中心越远。
- **“生生”的另一个层面：** 那些“过度保护”的母亲——她们把孩子“包裹”得严严实实、不允许他经历任何风险——那不是“保护”，是“死地”。孩子在无菌室里长大——但无菌室本身就是一个“死地”。他没有机会成为自己。

朱先生说“生生之厚”是过度追求生反而走向死。母亲的身体告诉我们：**“必须做最好的妈妈”——那个“必须”就是“生生之厚”。它不是在保护生命——是在消耗生命。无菌室本身就是一种“死地”。**

| 朱邦復的“民生生动皆之死地” | 母亲经验的“民生生动皆之死地” |
| :--- | :--- |
| 过度求生反而走向死地 | “必须做最好的妈妈”——那个“必须”不是保护，是消耗。无菌室就是死地 |
| 第三人称：养生的悖论 | 第一人称：我越追求“最好”的母职——我越走向“死地” |


## 四、“蓋聞善執生者”——善于摄生的人

### 朱邦復的解读：善于养生的人

朱先生将“善摄生者”解读为“善于养生的人”：

> “善於養生的人。”

“执生”不是“抓住生命不放”——是“持守生命的根本”。“善执生”是知道如何真正让生命延续。

### 从母亲经验的解读：真正善于养育生命的母亲——不是“把危险挡在外面”，而是“不制造死地”

“善執生者”——在母亲的身体里，“善执生”是什么？

- **她不是“把危险挡在外面”的妈妈。** 她不是那个说“别去、别碰、别尝试”的人——她是那个说“试试看，我在旁边”的人。
- **她“不制造死地”。** 死地不是“外面的危险”——死地是“被剥夺的成长空间”。她不给焦虑留出空间、不给控制留出空间、不给“为你好”的借口留出空间。
- **“善执生”的深层含义：** 她知道真正的“生”不是“完美无缺”——是“有机会成为自己”。她不是“完美妈妈”——她是“真实妈妈”。

朱先生说“善摄生者”是善于养生的人。母亲的身体告诉我们：**真正善于养育生命的母亲——不是把危险挡在外面，而是不制造“死地”。她不给焦虑和控制留出空间。**

| 朱邦復的“善摄生者” | 母亲经验的“善執生者” |
| :--- | :--- |
| 善于养生的人 | 不是把危险挡在外面——是不制造“死地”，不给焦虑留出空间 |
| 第三人称：养生的榜样 | 第一人称：我不是“无菌室”——我是“他能长的地方” |


## 五、“陵行不避兕虎，入軍不被甲兵”——不避猛兽，不被兵器所伤

### 朱邦復的解读：无死地则不惧危险

朱先生将“陆行不遇兕虎，入军不被甲兵”解读为“不涉险则危险不临”：

> “善養生者……不涉足危險之處。”

一个“无死地”的人——走在山里也不会被犀牛老虎攻击，进入军队也不会被兵器伤害。不是因为他“厉害”——是因为他不把自己放在“那个位置”。

### 从母亲经验的解读：她不是“把世界变成无菌室”——她允许孩子经历风险，但不把风险变成“死地”

“陵行不避兕虎”——在母亲的身体里，“避”是什么？

- **她不是“禁止一切”。** 她不把孩子关在家里——“别出去，有危险”。她让他出去、让他爬、让他跑、让他摔倒。
- **但她“不避”——不是“不管”。** 她不是“让他随便跑”然后不管——她是“在旁边看着”。她不让风险变成“死地”——不让他因为一次摔倒就恐惧一生。
- **“入军不被甲兵”的养育版本：** 她不是“不让孩子接触艰难”——而是不让孩子在艰难中感到“我被抛弃了”。艰难本身不是“死地”——被抛弃才是“死地”。

朱先生说“陆行不遇兕虎”是无死地则不惧危险。母亲的身体告诉我们：**她不是把世界变成无菌室——她允许孩子经历风险、承受挫折、面对不确定性。她不把风险变成“死地”。**

| 朱邦復的“陵行不避兕虎” | 母亲经验的“陵行不避兕虎” |
| :--- | :--- |
| 无死地则不惧危险 | 她允许孩子经历风险、承受挫折——她不把风险变成“死地” |
| 第三人称：养生的安全 | 第一人称：我不是“禁止”——我是“在旁边” |


## 六、“兕无所揣其角，虎无所措其爪”——犀牛角、虎爪、兵器都无所施

### 朱邦復的解读：危险不能触及无死地之人

朱先生将“兕无所投其角，虎无所措其爪，兵无所容其刃”解读为“危险无法伤害不设死地之人”：

> “犀牛有利角，老虎有锐齿，兵器也能致人于死，但皆无法对其产生效應。”

不是犀牛变“弱”了——是那个人不在它角能触碰的位置。危险还在——只是那个人不把自己放在“可以被伤害的地方”。

### 从母亲经验的解读：她的“无死地”——是她不把爱变成控制，不把保护变成囚笼

“兕无所揣其角”——在母亲的身体里，“无死地”是什么？

- **她的“无死地”是她不把“为你好”变成“你得听我的”。** 她不把“我是你妈”变成“你得按我说的活”。那是“兕角”——它刺不到她，因为她不在“控制欲”的位置上。
- **她的“无死地”是她不把“保护”变成“囚笼”。** 她不把“我是为了你好”变成“你不能有自己的路”。那是“虎爪”——它抓不到她，因为她不在“控制”的位置上。
- **她的“无死地”是她不把“爱”变成“债务”。** 她不让孩子觉得“我欠我妈的”。那是“刀刃”——它伤不到她，因为她不在“我要你回报”的位置上。
- **危险还在——但她不在“可以被伤害”的位置。** 不是因为她“比危险强”——是因为她不在那个角、那个爪、那个刃能触及的地方。

朱先生说“兕无所投其角……”是危险无法触及无死地之人。母亲的身体告诉我们：**她不把爱变成控制、不把保护变成囚笼、不把“为你好”变成压迫——她就“无死地”了。危险还在，但她不在那个位置。**

| 朱邦復的“兕无所投其角……” | 母亲经验的“兕无所揣其角……” |
| :--- | :--- |
| 危险无法触及无死地之人 | 她不把爱变成控制、不把保护变成囚笼——“无死地”是她不在能被伤到的位置 |
| 第三人称：无死地的安全 | 第一人称：危险还在——但我已经离开了会被触及的位置 |


## 七、“夫何故也？以其无死地焉”——因为没有“死地”

### 朱邦復的解读：无死地是养生的根本

朱先生将“以其无死地”解读为“不置身于危险之中”：

> “因為他從不涉足危險之處。”

“死地”是“必死的境地”——那个你一旦进去就出不来的位置。“无死地”不是“没有危险”——是“不进入那个位置”。

### 从母亲经验的解读：真正的“无死地”——是她和孩子之间没有被“必须”占据的空间

“无死地”——在母亲的身体里，“无死地”是什么？

- **她和孩子之间没有“你必须”。** 没有“你必须听话”、“你必须优秀”、“你必须让我骄傲”——那些“必须”是“死地”。一旦占据，关系就“死”了。
- **她和孩子之间没有“你应该”。** 没有“你应该更懂事”、“你应该更努力”、“你应该成为我想要的样子”——那些“应该”是“死地”。一旦进入，孩子就没有自己了。
- **真正的“无死地”是“爱而不占”——她爱他，但不占有他；她保护他，但不囚禁他；她在乎他，但不通过“控制”来表达在乎。** 那个“不占”的空间——就是她和孩子之间的“无死地”。
- **“无死地”不是“安全的空间”——是“不被焦虑占据的空间”。** 焦虑就是“死地”——一旦焦虑占据了她，她就看不到他了。她的“无死地”就是她放下焦虑的那一刻。

朱先生说“以其无死地”是因为不置身于危险之中。母亲的身体告诉我们：**她和孩子之间没有被“必须”和“应该”占据的空间——那就是“无死地”。爱而不占、保护而不囚、在乎而不控制。**

| 朱邦復的“以其无死地焉” | 母亲经验的“以其无死地焉” |
| :--- | :--- |
| 不置身于危险之中 | 她和孩子之间没有被“必须”和“应该”占据——那就是“无死地” |
| 第三人称：无死地的原则 | 第一人称：我不占据他——我就“无死地”了 |


## 结语：产床是“出生入死”最真实的现场

朱邦復先生在这一章中，用“概率统计”和“无死地养生”的框架，解读了“生之徒十有三、死之徒十有三、民生生动皆之死地十有三”的生死比例，以及“善摄生者无死地”的养生智慧。他认为“生生之厚”是过度的求生欲望——越是追求“完美养生”，越是走向“死地”。最后，“无死地”是不把自己置于危险的境地。

而母亲的身体，是这一章最完整的“出生入死-无死地”的演绎者：

- **“出生，入死”——分娩是“出生入死”——孩子在“出生”，母亲在“入死”。**
- **“生之徒十有三”——分娩中有顺利的、平安的。**
- **“死之徒十有三”——分娩中也有不幸的、没有回来的。**
- **“而民生生，动皆之死地”——“必须做最好的妈妈”那个“必须”——不是保护，是消耗。无菌室就是死地。**
- **“善执生者”——真正善于养育生命的母亲——不把危险挡在外面，而是不制造“死地”。**
- **“陵行不避兕虎”——她允许孩子经历风险、承受挫折——她不把风险变成“死地”。**
- **“兕无所揣其角”——她把“为你好”变成“你可以成为自己的样子”——角就刺不到她了。**
- **“虎无所措其爪”——她把“保护”变成“信任”——爪就抓不到她了。**
- **“兵无所容其刃”——她把“爱”变成“给予空间”——刃就伤不到她了。**
- **“无死地”——她和孩子之间没有被“必须”和“应该”占据的空间。**

**“出生入死”——母亲最懂这个词。** 她在产床上经历了“出”与“入”的交替。她的孩子“出”来了——她可能“入”去了。那不是夸张——是真实的概率。每一次分娩都是一次“出生入死”。她是那个同时面对“生”与“死”的人。

**“生生之厚”——母亲最懂这个词的陷阱。** 她曾被“必须做最好的妈妈”吞噬——那个“必须”比任何危险都更接近“死地”。无菌室不是保护——是剥夺。过度保护不是爱——是囚禁。“生生之厚”不是“给更多”——是“占据了被给予的空间”。

**“无死地”——母亲最懂这个词的意义。** 她的“无死地”不是“把孩子关在安全的笼子里”——是“不把爱变成控制、不把保护变成囚笼、不把‘为你好’变成压迫”。危险还在——但她不在那个角、那个爪、那个刃能触及的位置。

一个母亲的身体，是“出生入死”最真实的现场。她在产床上知道什么叫做“生”与“死”之间的窄门。她也知道什么叫做“无死地”——那不是在“无菌室”里的人生——那是在“爱而不占、保护而不囚、在乎而不控制”的空间里的人生。

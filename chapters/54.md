

## 引言：最“不成局”的一章，最“成局”的日常

帛书本第十章，是全书中最奇特的一章——它以六个问句构成，没有明确的结论，没有肯定的陈述：

> 戴營魄抱一，能毋離乎？槫氣至柔，能嬰兒乎？
>
> 修（滌）除玄藍（鑒），能毋疵乎？愛民活國，能毋以知乎？
>
> 天門啟闔，能為雌乎？明白四達，能毋以為乎？

朱邦復先生在《老子止笑譚》中，对这一章的处理非常特殊——他没有像其他章节那样给出逐句的“解”、“释”、“通”、“论”，而是直接写道：

> “本章僅六問而未成局，疑有誤。”

在朱先生看来，这一章“不成局”——没有起承转合、没有论证结论、没有可判定的答案。它不像是一篇完整的经文，更像是散落的碎片。

但如果我们把主语换成“母亲的身体”——那个每天早上起来都要回答六个问题的身体——这一章就不再是“未成局”的残篇，而是**一份极其完整的“母亲能力清单”**。六个问句是六道考题，而母亲的身体每天都在作答：

- 能不离吗？——能。胎盘与胎儿的分离，就是不离之离。
- 能婴儿吗？——能。产后身体的柔软与气力恢复，就是婴儿之柔。
- 能无疵吗？——能。身体的自我修复能力，就是无疵之修。
- 能无知吗？——能。凭感觉而非知识养育，就是无知之知。
- 能为雌吗？——能。感知并回应孩子的呼吸，就是雌之为。
- 能无为吗？——能。明白却不多嘴的陪伴，就是无为之为。

这一章不是“未成局”——它是母亲每天的“晨间六问”。是她的身体在被质询：“你还能做到吗？”而她——日复一日——都在回答：“能。”

让我们逐句对照。


## 一、“戴營魄抱一，能毋離乎？”——形神合一，能不分离吗？

### 朱邦復的判定：未成局，无逐句解读

朱先生对这一句没有给出具体的注解。他整章的回应只有一句“疑有誤”——因为六个问句没有形成一个完整的论述结构。因此，以下“朱解”一栏，是根据朱先生整体思想框架的补全推断。

### 从身体经验出发：胎盘与胎儿——能不离吗？能。分离本身就是合一的结果

“戴營魄抱一，能毋離乎？”——如果换成母亲的身体，最直接的对应是**胎盘与胎儿**。

- **“抱一”的状态：** 在孕期的前九个月，胎儿和胎盘是一体的。胎盘是胎儿的“营”（营养供给）——它通过脐带输送氧气、养分，带走代谢废物。胎儿和胎盘“抱一”——不能分离，因为一旦分离（胎盘早剥），胎儿的生命就会受到威胁。
- **“毋離”的答案：** 胎儿和胎盘能“不离”吗？能。在整个孕期中，它们一直“不离”——胎盘牢牢地附着在子宫壁上，胎儿通过脐带与胎盘相连。这是一个长期的、持续的“不离”状态。
- **但“离”是必然的、必需的。** 分娩时，胎儿出来了——胎盘还留在里面。然后子宫收缩，胎盘剥离、娩出。它们终于“离”了。但“离”不是“失”——不是因为不够“抱一”而分离，而是因为“离”是“生”的条件。如果它们继续“不离”（胎盘不剥离、不娩出），母亲会大出血，孩子也无法独立存活。

**身体经验的回答：** 能不离——在整个孕期中一直不离；也必须离——在分娩时必须分离。离与不离都是“成”的一部分。抱一不是为了“不分开”，而是为了“在正确的时候分开”。

| 朱邦復的判定（推断） | 身体经验的“能毋離乎” |
| :--- | :--- |
| 形神合一的境界追求 | 胎盘与胎儿的“抱一”——整个孕期不离，分娩时分离 |
| “未成局”的一部分 | “能”——我的身体里曾经有一个“抱一”的系统 |


## 二、“槫氣至柔，能嬰兒乎？”——聚气到最柔，能像婴儿吗？

### 朱邦復的判定：未成局，无逐句解读

朱先生未对此句作单独注解。

### 从身体经验出发：产后的气力恢复——能婴儿吗？能。回到最初的呼吸

“槫氣至柔”——一个母亲刚生完孩子，她的呼吸是什么样的？

- **分娩时的呼吸是急促的、用力的、有目的的。** 每一次宫缩，她都在深呼吸、用力推、喘息。
- **产后第一次深呼吸：** 孩子出来了，胎盘娩出了，她的身体开始“回落”。她做一次深呼吸——那口气是长的、慢的、放松的。她的身体从“用力”模式切换到了“恢复”模式。那个深呼吸的频率，**接近于婴儿的呼吸频率**。
- **“能嬰兒乎”的答案：** 能。她的呼吸变深了、变慢了、变“柔”了。她的身体在放松——不是刻意“练”出来的，是**分娩完的生理必然**。宫缩停止后，她的身体自动“退”回到一个更低能耗的状态。那个状态，就是“婴儿”式的呼吸——深长、柔软、不费力。

**身体经验的回答：** 能。当你生完孩子，你的呼吸自动变回了婴儿的频率。你不需要“练”，你的身体知道该怎么做。

| 朱邦復的判定（推断） | 身体经验的“能嬰兒乎” |
| :--- | :--- |
| 把气练到像婴儿一样柔软 | 产后的呼吸变深变慢——回到了婴儿的频率 |
| “未成局”的一部分 | “能”——我不需要练，我的身体自会回到最初 |


## 三、“修（滌）除玄藍（鑒），能毋疵乎？”——洗涤心灵的镜子，能没有瑕疵吗？

### 朱邦復的判定：未成局，无逐句解读

朱先生未对此句作单独注解。

### 从身体经验出发：产后的身体修复——能无瑕疵吗？能。疤痕本身就是生命的“疵”，但不需要被“除”掉

“滌除玄鑒，能毋疵乎？”——如果是母亲的身体，这问的是什么？

- **“疵”是那些“不完美”的痕迹：** 妊娠纹、剖腹产疤痕、会阴撕裂的缝合线、色素沉淀、皮肤松弛。
- **“能毋疵乎”的答案是：** 能——但不是通过“除去”瑕疵，而是通过“接受”它们为“无疵”。疤痕本身就是“疵”——它是不平整的、凸起的、有纹理的。但母亲不会说“我要把疤痕完全消除”——因为疤痕是她成为母亲的物理证据。它不是需要被“洗涤”的“污点”，它是生命留下的“签名”。

**身体经验的回答：** 能。我不需要“无疵”——因为那些“疵”本身就是我生命的一部分。妊娠纹不是瑕疵，是皮肤被生命撑开过的证明。剖腹产疤痕不是污点，是孩子来到这个世界的通道。如果你试图“涤除”它们，你就是在试图“涤除”你成为母亲的那一部分。

| 朱邦復的判定（推断） | 身体经验的“能毋疵乎” |
| :--- | :--- |
| 把心灵的镜子擦到没有污点 | 接受妊娠纹、剖腹产疤痕为“无疵”——它们不是需要被除去的 |
| “未成局”的一部分 | “能”——我的“疵”就是我的证明 |


## 四、“愛民活國，能毋以知乎？”——爱民治国，能不靠知识吗？

### 朱邦復的判定：未成局，无逐句解读

朱先生未对此句作单独注解。

### 从身体经验出发：凭感觉养育孩子——能无知吗？能。因为身体比知识更早到达

“愛民活國，能毋以知乎？”——如果把“治国”换成“养育一个新生儿”呢？

- **知识是什么？** 是育儿书、是睡眠训练法、是喂养时间表、是“专家说你应该……”
- **“能毋以知乎”的答案：** 能。孩子刚出生那些天，母亲不是靠“知识”在养育——她是靠身体在回应。孩子哭，她就抱；孩子饿，她就喂；孩子睡，她就睡（或者醒着盯着他看）。这些行为不是“知识”——是**本能、直觉、身体的记忆**。
- **“无知”不是“没文化”，是“不依赖书本知识做决定”。** 她不是“我知道喂奶要喂多久”才喂的——她是“孩子想吃，我就给”。她不是“我知道抱着睡不好”才不抱的——她是“孩子需要抱，我就抱”。知识是后来才追认的——最初的那些夜晚，她的身体知道该怎么做，而她的脑子还在学习。

**身体经验的回答：** 能。在孩子出生的最初几天，你不是用知识在带他——你是用身体在带他。你不需要读“如何回应哭声”这本书——因为你的身体在你读到它之前就已经在做了。

| 朱邦復的判定（推断） | 身体经验的“能毋以知乎” |
| :--- | :--- |
| 治理国家可以没有知识吗？（似乎不能） | 养育新生儿不是靠知识——是靠身体的直觉和回应 |
| “未成局”的一部分 | “能”——我凭感觉带他，知识是后来才来的 |


## 五、“天門啟闔，能為雌乎？”——天门的开合，能作为雌吗？

### 朱邦復的判定：未成局，无逐句解读

朱先生未对此句作单独注解。

### 从身体经验出发：感知孩子的呼吸——能为雌吗？能。因为“雌”就是“在门边等待”

“天門啟闔”——如果“天门”指的不是头顶的穴位，而是**生命进出呼吸的通道**呢？

“能為雌乎”——“雌”在这里不是“女性”，而是 **“在门边等待、感知门的状态、不主动推也不主动拉，只是观察和等待”**。

一个母亲在深夜，孩子就在身边呼吸。“天门”在开合——孩子的鼻孔在呼吸、她的鼻孔也在呼吸。她不是“打开”或“关闭”呼吸的人——她只是躺在那里，听着、感知着、等待着。“為雌”就是这种状态：**不主动、不控制、不扰动——只是“在”那里。**

- **孩子哭了——她醒。** 她没有“主动去醒”——她的身体在声音到达之前就“感知”到了变化。这就是“雌”的感知模式：不是主动探测，是接收。
- **孩子不动了——她惊。** 她不需要“检查”他是否还在呼吸——她的身体会在几秒内感知到“呼吸节奏改变了”。这也是“雌”的感知模式：持续在场、不主动侵入，但能感知最微小的变化。

**身体经验的回答：** 能。不需要“开”或“阖”的动作——只需要“在”那里，感知门的状态。“雌”就是那个状态：在门边，不推不拉，只是等待门自然开合。

| 朱邦復的判定（推断） | 身体经验的“能為雌乎” |
| :--- | :--- |
| 在动态中保持柔静、被动？ | 深夜感知孩子的呼吸——不主动探测，只是接收 |
| “未成局”的一部分 | “能”——我不需要“开关”，我只需要“在” |


## 六、“明白四達，能毋以為乎？”——明白通达，能不作为吗？

### 朱邦復的判定：未成局，无逐句解读

朱先生未对此句作单独注解。

### 从身体经验出发：明白但不干预——能无为吗？能。因为“明白”是知道什么时候该闭嘴

“明白四達，能毋以為乎？”——这是母亲每天面临的质询。

- **孩子第一次学走路——他摔倒了。** 妈妈“明白”该怎么做——她可以跑过去扶他、安慰他、检查他有没有受伤。但她选择“無為”——她蹲下来，看着他，说：“你试试站起来。”她“明白”怎么做，但她“無為”——她把那个“为”留给孩子。
- **孩子和朋友吵架——他哭了。** 妈妈“明白”该怎么解决——她可以替他说、替他道歉、替他做决定。但她选择“無為”——她问他：“你想怎么做？”她“明白”答案，但她把“为”的空间留给他。
- **孩子长大后——他做决定。** 妈妈“明白”怎么选才是“对”的——但她选择“無為”——她说：“这是你的事，你自己决定。”她“明白”方向，但她不再“為”他指明方向。

**身体经验的回答：** 能。但不是“不知道怎么做”，而是“知道该在什么时候不做”。不“为”不是“无能为力”，是“有能力而为但选择不干预”。

| 朱邦復的判定（推断） | 身体经验的“能毋以為乎” |
| :--- | :--- |
| 通晓一切但能忍住不干预吗？ | 孩子摔倒时忍住不扶、孩子做决定时忍住不替 |
| “未成局”的一部分 | “能”——我明白，但我不做 |


## 结语：六问不是“未成局”，是“晨间六问”

朱邦復先生认为这一章“僅六問而未成局，疑有誤”——因为六个问句没有给出答案，没有完成一个论证。它不像是一篇完整的经文。

但如果把主语换成“母亲”——**这六问不是“未成局”，而是母亲每天醒来时被自己的身体质询的六道题。**

- “能毋離乎？”——你能做到不离开吗？她回答：能。孩子需要的时候，我一直都在。
- “能嬰兒乎？”——你能回到最初的状态吗？她回答：能。生完孩子后，我的呼吸变深了。
- “能毋疵乎？”——你能没有瑕疵吗？她回答：能。疤痕不是瑕疵——它是生命的签章。
- “能毋知乎？”——你能不靠知识吗？她回答：能。我凭感觉带孩子，知识是后来才来的。
- “能為雌乎？”——你能只“在”而不“动”吗？她回答：能。孩子在旁边呼吸，我只需要倾听。
- “能毋為乎？”——你能明白但不去干预吗？她回答：能。我知道怎么做，但我选择让他自己走。

这一章不是“不成局”——它是一份母亲的“晨间六问”。每天醒来，她都在回答这些问题。不是用语言，是用身体——用喂养、用陪伴、用等待、用放手、用恢复、用继续。

朱先生看到的是“残篇”，我们看到的是“日常”。六个问句不是散落的碎片——它们是一份持续了千年之久的、关于母亲身体能否继续运行的质询清单。而答案，每天都在给出：能。

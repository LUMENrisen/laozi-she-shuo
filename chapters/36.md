

## 引言：最“认知”的一章，最“母亲”的谦卑

帛书本第七十二章（通行本第七十一章），是《德道经》中关于“知与不知”最精炼的论述：

> 知不知，尚矣；不知不知，病矣。
>
> 是以聖人之不病，以其病病。是以不病。

“知不知，尚矣”——知道自己有所不知，是上等的。“不知不知，病矣”——不知道自己不知道，是一种病。

“是以聖人之不病”——所以圣人不病，“以其病病”——是因为他把“病”当作病来对待。“是以不病”——所以不病。

朱邦復先生在《止笑譚》中，将这一章解读为 **“知与不知的认知层级”** 。他认为“知，不知，上”是“上智者虚怀若谷，貌似不知”——知道自己不知道，才是真正的“上”；“不知，知，病”是“不知者自以为知，是一种缺失”——不知道却自以为知道，是“病”。他特别列举了三种“病”：愚病（无判断力）、钝病（有观察力无判断力）、私病（欲望高、自我心重）。圣人“以其病病”——知道这些是病，所以不病。

但如果我们把主语换成“母亲的身体”——那个在产后知道自己“不知道”怎么当妈妈、知道自己“不知道”孩子为什么哭、知道自己“不知道”能不能撑过今夜的身体——这一章就不再是“认知论”，而是一份 **“关于母亲如何以‘知不知’的谦卑姿态守护自己和孩子的日常记录”**：

- “知不知，尚矣”——母亲知道自己“不知道”。她不知道自己能不能当好妈妈、不知道他为什么哭、不知道明天会不会更好。她知道自己的“不知”——那是“尚”。
- “不知不知，病矣”——那些假装“什么都知道”的母亲——不知道自己不知道——才是“病”。
- “圣人之不病，以其病病”——产后母亲正是因为把自己的“病”（崩溃、抑郁、焦虑）当作“病”来对待，才避免了真正的“病”。她不美化它、不忽视它——她把“病”当作“病”，所以不病。


## 一、“知不知，尚矣”——知道自己不知道，是上等

### 朱邦復的解读：知之为知之，不知为不知

朱先生将“知，不知，上”解读为“知道自己不知道，是上等”：

> “上智者，虛懷若谷，貌似不知。”

知道自己“不知道”——不是“无知”——是“知”的起点。知道自己有限，才能学习。那是“上”。

### 从母亲经验出发：母亲知道自己“不知道”——她不知道自己能不能当好妈妈、不知道他为什么哭、不知道明天会不会更好

“知不知”——在母亲的身体里，“知不知”是什么？

- **她知道自己不知道。** 孩子哭了——她不知道是饿了还是困了；她抱了、喂了、哄了——他还在哭——她不知道“还有什么办法”。她承认自己的“不知”。不是“失败”——是“开始”。
- **她不知道自己能不能撑过今夜。** 凌晨三点，孩子还在哭，她已经筋疲力尽——她不知道“明天怎么办”。她“知不知”——知道自己不知道。
- **“知不知”的深层含义：** 她不是“全知”的妈妈——她是“知道自己不知道”的妈妈。那个“知不知”让她保持开放——不是封闭。她不知道，所以她可以学习、可以问、可以试。

朱先生说“知不知上是”是知道自己不知道是上等。母亲的身体告诉我们：**她不知道自己能不能当好妈妈——但她知道她“不知道”。那是“尚”——不是“失败”。**

| 朱邦復的“知不知上” | 母亲经验的“知不知尚矣” |
| :--- | :--- |
| 知道自己不知道是上等 | 她不知道自己能不能当好妈妈——但她知道她“不知道”。那是“尚” |
| 第三人称：认知的谦虚 | 第一人称：我不知道——所以我可以学 |


## 二、“不知不知，病矣”——不知道自己不知道，是一种病

### 朱邦復的解读：自以为知却不知，是病

朱先生将“不知，知，病”解读为“不知道却自以为是，是病”：

> “人不知而自以為知之病有三：1.愚病……2.钝病……3.私病……”

“不知不知”是“不知道自己不知道”——以为自己什么都知道。那是“病”——因为它堵塞了学习的可能。

### 从母亲经验出发：那些假装“什么都知道”的母亲——不知道自己不知道——才是“病”

“不知不知”——在母亲的身体里，“不知不知”是什么？

- **有人说“带孩子有什么难的”——那是“不知不知”。** 她们不知道带孩子有多难——但她们以为自己知道。那是“病”——不是“自信”。
- **她说“我什么都懂”——那是“不知不知”。** 产后，有些妈妈不敢承认“我不知道”——她们怕别人说“你不是个合格的妈妈”。她们假装“什么都知道”——那是“不知不知”。那不是“强大”——是“病”。
- **“不知不知”的深层含义：** 当母亲不敢说“我不知道”——她就堵住了求助的路。她假装知道——她就不可能学习。那是“病”——不是因为“无知”——是因为“以为自己有知”。

朱先生说“不知知病”是不知道却自以为是病。母亲的身体告诉我们：**那些假装“什么都知道”的母亲——不知道自己不知道——才是“病”。“不知不知”堵住了求助和学习的路。**

| 朱邦復的“不知知病” | 母亲经验的“不知不知病矣” |
| :--- | :--- |
| 不知道却自以为是病 | 假装“什么都知道”的母亲——不知道自己不知道——才是“病” |
| 第三人称：认知的病态 | 第一人称：我说“我不知道”——我不是“不够好”——我是“在开始” |


## 三、“圣人之不病，以其病病”——圣人不病，是因为他把病当作病

### 朱邦復的解读：以病为病，所以不病

朱先生将“圣人不病，以其病病”解读为“圣人知道这些是病，所以不病”：

> “聖人無此毛病，因知此病之害。唯有知其害，始可免此病。”

“病病”是“把病当作病”——承认病的存在、看见病的危害、不美化也不忽视。因为“病病”，所以“不病”。

### 从母亲经验出发：产后母亲正是因为把自己的“病”（崩溃、抑郁、焦虑）当作“病”来对待，才避免了真正的“病”

“以其病病”——在母亲的身体里，“病病”是什么？

- **她把自己的“崩溃”当作“病”来对待。** 不是“我没用”——是“我需要帮助”。她“病病”——承认自己崩溃了。然后她找人帮忙、她休息、她停下来。因为“病病”——所以不“病”（不一直崩溃）。
- **她把自己的“抑郁”当作“病”来对待。** 不是“我不配做妈妈”——是“我的激素出了问题”。她“病病”——看见那是“病”。然后她去求助、去接受治疗。因为“病病”——所以不“病”（不一直抑郁）。
- **她把自己的“焦虑”当作“病”来对待。** 不是“我太紧张了”——是“我的身体在报警”。她“病病”——承认那是“病”。然后她慢下来、她呼吸、她不强迫自己。因为“病病”——所以不“病”（不一直焦虑）。
- **“病病”的深层含义：** 母亲不美化自己的“病”。她不假装“我很好”。她说“我不够好”——然后她问“我该怎么办”。她把“病”当作“病”——所以她不“病”。

朱先生说“以其病病”是把病当作病，所以不病。母亲的身体告诉我们：**她承认自己的崩溃、抑郁、焦虑是“病”——不美化、不忽视。然后她求助、她休息、她停下来。因为“病病”——所以不“病”。**

| 朱邦復的“以其病病” | 母亲经验的“以其病病” |
| :--- | :--- |
| 把病当作病，所以不病 | 她承认崩溃是“病”——然后求助、休息、停下来。因为病病，所以不病 |
| 第三人称：病的认知与超越 | 第一人称：我说“我不够好”——我才能“好” |


## 四、“是以不病”——所以不病

### 朱邦復的解读：最终不病

朱先生将“是以不病”解读为“圣人不病”：

> “是以不病。”

因为“病病”——所以最终“不病”。不是没有“病”——是“病”被看见了、被承认了、被处理了。

### 从母亲经验的身体出发：产后的母亲因为“知不知”和“病病”——所以她“不病”

“是以不病”——在母亲的身体里，“不病”是什么？

- **她因为“知不知”——所以不“病”。** 她知道自己不知道——所以她学习、她求助、她不是“独自硬撑”。那个“知不知”让她保持开放——不被封闭。
- **她因为“病病”——所以不“病”。** 她承认崩溃、承认抑郁、承认焦虑——她不美化它。她把“病”当作“病”——然后处理它。所以她不“病”。
- **“不病”的深层含义：** 不是“没有病”——是“没有不被处理的病”。她有崩溃的时候——但她看见了、承认了、求助了。所以她不“病”——她度过了。

朱先生说“是以不病”是所以不病。母亲的身体告诉我们：**她因为“知不知”而学习、因为“病病”而求助——所以她“不病”。不是没有病——是没有不被处理的病。**

| 朱邦復的“是以不病” | 母亲经验的“是以不病” |
| :--- | :--- |
| 所以不病 | 她因为“知不知”而学习、因为“病病”而求助——所以她“不病” |
| 第三人称：不病的最终状态 | 第一人称：我有病——但我承认了、求助了、度过了 |


## 结语：“知不知”是母亲的生存智慧

朱邦復先生在这一章中，用“认知层次”和“以病为病”的框架，解读了“知不知上、不知知病”、“圣人之不病以其病病”、“是以不病”等认知原则。他认为真正的“上”是知道自己不知道，“病”是不知道却自以为知道；圣人能把“病”当作病来对待，所以不病。

而母亲的身体，是这一章最完整的“知不知-病病-不病”的演绎者：

- **“知不知，尚矣”——她知道自己“不知道”——那是“尚”。**
- **“不知不知，病矣”——假装“什么都知道”的母亲——才是“病”。**
- **“圣人之不病，以其病病”——她承认崩溃是“病”——然后求助、休息、停下来。**
- **“是以不病”——她因为“知不知”而学习、因为“病病”而求助——所以她“不病”。**

**“知不知”——母亲最深的谦卑。** 她知道自己不知道。不知道孩子为什么哭、不知道自己能不能撑过今夜、不知道明天会不会更好。她承认自己的“不知”——那是“尚”，不是“失败”。因为她“知不知”，所以她可以学习、可以求助、可以“不病”。

**“不知不知”——母亲最深的陷阱。** 那些假装“什么都知道”的母亲——不知道自己不知道——才是“病”。她们不敢说“我不知道”——因为那是“不合格”的标签。但那个“不敢”本身，让她们堵住了学习之路、求助之路。她们“不知不知”——然后“病”了。

**“病病”——母亲最深的清醒。** 她不美化自己的“病”。她不假装“我很好”——她说“我不够好”。她把崩溃、抑郁、焦虑当作“病”来对待——承认它、看见它、处理它。因为“病病”——所以不“病”。

一个母亲的身体，就是“知不知-病病-不病”最日常的版本。她知道自己不知道——所以她学习。她承认自己的病——所以她求助。她因为“知不知”和“病病”——所以“不病”。不是“没有病”——是“没有不被处理的病”。

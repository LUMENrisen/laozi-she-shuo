

## 引言：最“修身”的一章，最“身体”的智慧

帛书本第三十三章，是《德道经》中关于“认知、力量、知足、归宿”最精炼的论述：

> 知人者，知（智）也。自知者，明也，
>
> 勝人者，有力也。自勝者，強也。
>
> 知足者，富也。強行者，有志也。
>
> 不失其所者，久也。死不忘者，壽也。

“知人者智”——了解他人是智慧。“自知者明”——了解自己是明达。“胜人者有力”——战胜别人是有力量。“自胜者强”——战胜自己才是强大。“知足者富”——知道满足才是富有。“强行者有志”——坚持力行才是有志。“不失其所者久”——不失去自己位置的人才能长久。“死而不亡者寿”——身体死去而精神不亡才是长寿。

朱邦復先生在《止笑譚》中，将这一章解读为 **“从外求到内求的递进”**。他认为“知人”和“胜人”是向外追求——了解别人、战胜别人，这固然是“智”和“有力”，但层次较低；“自知”和“自胜”是向内探索——了解自己、战胜自己，这才是“明”和“强”。他特别强调了“知足者富”——富有不是拥有多少，而是需要多少；“强行者有志”——有意志的人不是“想”做什么，是“坚持”做什么。最后“不失其所者久”——守住自己的根本位置才能长久；“死而不亡者寿”——精神不灭才是真正的长寿。

但如果我们把主语换成“母亲的身体”——那个在怀孕和分娩中被彻底改变、在日复一日的养育中被消耗、在孩子的成长中不断“失去自己”又“找到自己”的身体——这一章就不再是“修身的格言”，而是一份 **“关于母亲如何从‘知人’转向‘自知’、从‘胜人’转向‘自胜’、从‘知足’走向‘强行’、最终在‘不失其所’中获得‘死而不亡’”的完整旅程记录**：

- “知人者智”——她知道孩子的每个信号：饿了、困了、不舒服了。她是“知人”的——她了解那个最依赖她的人。
- “自知者明”——但更重要的是，她知道自己什么时候撑不住了、什么时候需要休息、什么时候该求助。不是“硬撑”才是好妈妈——知道自己的边界才是“明”。
- “胜人者有力”——她曾经和别的母亲比较过：谁的孩子先走路、谁的孩子更听话。那种“胜人”是“有力”的——但它不能持久。
- “自胜者强”——她战胜了自己的焦虑、自己的完美主义、自己的“我应该”。那才是真正的“强”。
- “知足者富”——她不再追求“最好”的玩具、“最贵”的教育。她知道“够用”就是“富”。孩子需要的不是最好的——是刚刚好的。
- “强行者有志”——她每天醒来、每天重复、每天继续。不是因为她“有力量”——是因为她“有意志”。那是一种“强行”——即使疲惫、即使不想动、即使没有力气——她仍然起来了。那就是“志”。
- “不失其所者久”——她始终守住“母亲”这个位置。不是“完美的母亲”——是“在那里”的母亲。她守住的是“陪着他”的那个位置。
- “死而不亡者寿”——即使有一天她不在了，她在他生命中留下的痕迹、她给他的安全感、信任感、爱的能力——会继续存活。那才是真正的“寿”——不是身体的寿命，是影响的寿命。

让我们逐句对照。


## 一、“知人者，智也”——了解他人是智慧

### 朱邦復的解读：了解他人是智慧

朱先生将“知人者智”解读为“了解他人是智者”：

> “善於觀察判斷者，必須有足夠的知識及經驗。能正確地觀察判斷他人，即是智者。”

“知人”是了解别人的能力——他的性格、他的需求、他的行为模式。这是智慧的一部分。

### 从身体经验出发：她知道孩子的每个信号——饿了、困了、不舒服了。她是“知人”的

“知人者，智也”——在母亲的身体里，“知人”是什么？

- **她能分辨孩子的哭声。** 饿了的哭、困了的哭、不舒服的哭、吓到的哭——音调不同、节奏不同、用力方式不同。她不需要“学习”——她是用身体“记住”的。
- **她知道他的需求。** 他不说话，但她知道。他动了一下，她就知道他醒了。他安静得太久，她就知道他睡着了。她“知人”——她了解那个最依赖她的人。
- **“知人”是母亲最原初的智慧。** 她从孩子出生的第一天就开始“读”他——不是用理论、不是用工具——是用手、用眼、用身体。她“知”了他。

朱先生说“知人者智”是了解他人是智慧。母亲的身体告诉我们：**她能分辨孩子的哭声、知道他还没说出口的需求——那就是“知人”。她天生就是那个“智者”。**

| 朱邦復的“知人者智” | 母亲经验的“知人者智” |
| :--- | :--- |
| 了解他人是智慧 | 她能分辨孩子的哭声、知道他的需求——她“知”了那个最依赖她的人 |
| 第三人称：智慧的表现 | 第一人称：我不用他说——我就知道 |


## 二、“自知者，明也”——了解自己才是明达

### 朱邦復的解读：了解自己才是真正的明

朱先生将“自知者明”解读为“了解自己是明道之人”：

> “人要瞭解自己，不能假外界刺激、感官偵測，須從己身內省。”

了解自己——知道自己的极限、自己的欲望、自己的恐惧、自己的真实状态——比了解别人更难，也更重要。

### 从身体经验出发：她知道什么时候撑不住了、什么时候需要休息、什么时候该求助

“自知者，明也”——在母亲的身体里，“自知”是什么？

- **她知道自己的极限。** “我现在撑不住了”、“我需要休息”、“我需要帮助”——能说出这些话，不是软弱，是“自知”。
- **她知道自己的身体在说什么。** 不是所有疲惫都是“产后正常”——有些疲惫是身体在报警：你需要停下来、你需要被照顾、你需要被看见。
- **“明”的另一个层面：** 她知道“我不是超人”。她不需要“硬撑”来证明她是好妈妈。她知道自己有边界——那就是“明”。

朱先生说“自知者明”是了解自己才是真正的明达。母亲的身体告诉我们：**她知道什么时候撑不住了、什么时候需要休息、什么时候该求助——那就是“自知”。“硬撑”不是好妈妈——知道自己能撑多久才是“明”。**

| 朱邦復的“自知者明” | 母亲经验的“自知者明” |
| :--- | :--- |
| 了解自己才是真正的明 | 她知道自己的极限——什么时候需要休息、什么时候需要求助。那不是软弱——是“明” |
| 第三人称：自我认知的价值 | 第一人称：“硬撑”不是好妈妈——知道自己能撑多久才是“明” |


## 三、“勝人者，有力也”——战胜别人是有力量

### 朱邦復的解读：胜人是有力

朱先生将“胜人者有力”解读为“战胜他人是有力量”：

> “力有單位、大小，作用於物，大者勝小者。”

“胜人”是在比较中获胜——你比别人强、你比别人快、你比别人好。这是一种“力”——但它来自外在的比较。

### 从身体经验出发：她曾经和别的母亲比较过——谁的孩子先走路、谁的孩子更听话。那是“有力”，但不能持久

“勝人者，有力也”——在母亲的身体里，“胜人”是什么？

- **她比较过。** 谁的孩子先走路、谁的孩子先说话、谁的孩子更“乖”——她曾经拿自己的孩子和别人比。赢的时候，她“有力”——一种短暂的、靠外在支撑的力量。
- **但那种“有力”不能持久。** 因为永远有孩子比她的更早、更快、更好。比较是无穷无尽的——你赢了一次，马上会有下一轮比较。那种“有力”是脆弱的。
- **“胜人”的代价：** 她越是想“胜人”——越是焦虑。不是因为她不够好——是因为“胜人”的系统本身就是无法停止的。

朱先生说“胜人者有力”是战胜他人是有力量。母亲的身体告诉我们：**她曾经比较过——谁的孩子先走路、谁更听话。那是“有力”——但它不能持久。因为比较没有尽头。**

| 朱邦復的“胜人者有力” | 母亲经验的“胜人者有力” |
| :--- | :--- |
| 战胜他人是有力量 | 她比较过——谁的孩子先走路、谁更听话。那是“有力”，但不能持久 |
| 第三人称：外在力量的本质 | 第一人称：我赢过几次——但比较没有尽头 |


## 四、“自勝者，強也”——战胜自己才是强大

### 朱邦復的解读：战胜自己才是真正的强

朱先生将“自胜者强”解读为“战胜自我才是真正的强者”：

> “能剋服自我，才是真正的強者。”

“自胜”不是“否定自己”——是“不让自己被欲望、恐惧、习惯所控制”。当你能管理自己、超越自己——那才是“强”。

### 从身体经验出发：她战胜了自己的焦虑、完美主义、“我应该”——那才是“强”

“自勝者，強也”——在母亲的身体里，“自胜”是什么？

- **她战胜了“我应该”。** 社会告诉她“你应该这样养孩子”——但她放下了那个“应该”，按照自己的方式、按照孩子的需要来。那不是“任性”——是“自胜”。
- **她战胜了完美主义。** 孩子衣服脏了、辅食弄得到处都是、家里乱成一团——她没有崩溃。她对自己说“没关系”——那是“自胜”。
- **她战胜了焦虑。** 孩子发烧了、睡觉不踏实、发育比别的孩子慢——她没有陷入恐慌。她告诉自己“他在按自己的节奏长”——那是“自胜”。
- **“自胜”不是“一次性的”——是“日复一日的功课”。** 每一天她都要战胜那个“我是不是不够好”的声音。每一次她选择相信自己、相信孩子——那是“强”。

朱先生说“自胜者强”是战胜自己才是真正的强大。母亲的身体告诉我们：**她战胜了“我应该”、完美主义、焦虑——那是“自胜”。每一次她选择相信自己、相信孩子——都是“强”。**

| 朱邦復的“自胜者强” | 母亲经验的“自胜者强” |
| :--- | :--- |
| 战胜自己才是真正的强大 | 她战胜了“我应该”、完美主义、焦虑——每一次相信自己和孩子，都是“强” |
| 第三人称：内在力量的本质 | 第一人称：我每天都要战胜那个“不够好”的声音——那是我的“强” |


## 五、“知足者，富也”——知道满足才是富有

### 朱邦復的解读：知足的人才是富有的

朱先生将“知足者富”解读为“满足于既有者是富足之人”：

> “能滿足於既有者，是富足之人。”

富有不是拥有多少——是“觉得够了”。当你觉得“够了”，你就富了。当你觉得“还要更多”——你永远贫穷。

### 从身体经验出发：她不再追求“最好”的玩具、“最贵”的教育。她知道“够用”就是“富”

“知足者，富也”——在母亲的身体里，“知足”是什么？

- **她不再追求“最好”的。** 最贵的玩具、最精英的早教、最完美的育儿方式——她曾经追过。但她发现——孩子需要的不是“最好”，是“刚刚好”。
- **“知足”不是“放弃”——是“看见足够的价值”。** 她看见“他平安”就足够、看见“他笑了”就足够、看见“他睡了”就足够。那些“足够”构成了她的“富”。
- **“富”的另一个层面：** 她不需要在别人面前证明“我给孩子买了最好的”。她的富在于孩子不需要“最好的”——他只需要“她”。

朱先生说“知足者富”是满足于既有者是富足的。母亲的身体告诉我们：**她不再追求“最好”的——她知道“够用”就是“富”。孩子的笑、孩子的睡、孩子的平安——那些就是她的“富”。**

| 朱邦復的“知足者富” | 母亲经验的“知足者富” |
| :--- | :--- |
| 满足于既有者是富足的 | 她不再追求“最好”的——她知道“够用”就是“富”。孩子的平安、笑、睡——就是她的“富” |
| 第三人称：真正的富有 | 第一人称：我不需要“最好”的——我只需要“刚刚好”的 |


## 六、“強行者，有志也”——坚持力行才是有志

### 朱邦復的解读：坚持去做才是有志向

朱先生将“强行者有志”解读为“不计艰难而行的，可称做有志者”：

> “不計艱難以行的，可稱做有志者。”

“强行”不是“强迫”——是“持续去做、不放弃”。有志不是“想”——是“做”。不是“想要”做什么——是“坚持”做什么。

### 从身体经验出发：她每天醒来、每天重复、每天继续——不是因为有力，是因为有志

“強行者，有志也”——在母亲的身体里，“强行”是什么？

- **她每天早上醒来。** 即使昨夜起了三次、即使今天还要面对同样的事、即使没有任何“奖励”。她醒来——不是“有力”，是“有志”。
- **她每天重复。** 喂奶、换尿布、哄睡、陪玩——一样的事，第二天再来。她“强行”着——不是因为“容易”，是因为“志”。
- **“强行”的深层含义：** 她的“志”不是“要把孩子培养成什么”——她的“志”是“今天再陪他一天”。那种“持续”不是靠“力量”——是靠“志”。

朱先生说“强行者有志”是坚持去做的人是有志向的。母亲的身体告诉我们：**她每天醒来、每天重复、每天继续——不是因为有力，是因为有志。她的“志”是“再陪他一天”。**

| 朱邦復的“强行者有志” | 母亲经验的“强行者有志” |
| :--- | :--- |
| 坚持去做的人是有志向的 | 她每天醒来、每天重复——不是因为有力，是因为“再陪他一天”的志 |
| 第三人称：意志的价值 | 第一人称：我不是“有力”——我是“有志” |


## 七、“不失其所者，久也”——不失去自己位置的人才能长久

### 朱邦復的解读：守住自己的根本才能长久

朱先生将“不失其所者久”解读为“坚持原则不移的，能够久存于宇宙间”：

> “不失其所者久也。……有理性之人，今古同源，不失其所。”

“所”是位置、根本、归宿。不失“所”——就是不丢掉自己的根本、不偏离自己的位置。这样的人才能“久”。

### 从身体经验出发：她始终守住“母亲”这个位置——不是“完美的母亲”，是“在那里”的母亲

“不失其所者，久也”——在母亲的身体里，“所”是什么？

- **她的“所”是“母亲”这个位置。** 不是“完美的母亲”——是“在”那里。“在那里”是她的根本。她不离开——不因为困难而离开、不因为疲惫而离开、不因为“我不够好”而离开。
- **“不失其所”的另一种理解：** 她不是“为孩子放弃了自己”——她是“在成为母亲的过程中重新找到了自己的位置”。那个位置不是“牺牲”——是“在场”。
- **“久”的证明：** 她的孩子知道她一直在那里。不是“完美”地在——是“不离”地在。那才是“久”——不是时间的长短，是存在的密度。

朱先生说“不失其所者久”是守住自己的根本才能长久。母亲的身体告诉我们：**她始终守住“母亲”这个位置——不是“完美的母亲”，是“在那里”的母亲。孩子知道她一直在——那就是她的“久”。**

| 朱邦復的“不失其所者久” | 母亲经验的“不失其所者久” |
| :--- | :--- |
| 守住自己的根本才能长久 | 她始终守住“母亲”这个位置——不是“完美”，是“在那里”。孩子知道她一直在——那就是“久” |
| 第三人称：根本的坚守 | 第一人称：我不是“完美”——我是“不离” |


## 八、“死不忘者，壽也”——身体死去而精神不亡才是长寿

### 朱邦復的解读：精神不灭才是长寿

朱先生将“死而不亡者寿”解读为“身体死去而精神不亡者，可称之为长寿”：

> “人能自知、自胜、知足且有志者，当其身体死后，精神却永留人间。”

“死”是肉体的结束；“亡”是精神的消失。“不亡”——精神还在、影响还在、记忆还在——那才是真正的“寿”。

### 从身体经验出发：即使有一天她不在了——她在他生命中留下的安全感、信任感、爱的能力——会继续存活。那才是真正的“寿”

“死不忘者，壽也”——在母亲的身体里，“不忘”是什么？

- **即使她有一天不在了——她在他身上留下的痕迹不会消失。** 她给他的安全感、她在他哭泣时的回应、她让他感受到的“有人会来”——这些会在他生命中继续“活”着。
- **“不亡”不是“他记得她”——是“她给他的能力还在运作”。** 他对世界的信任、他对关系的安全感、他对自己的接纳——这些都是从她那里来的。即使她走了——那些能力不会“亡”。
- **“寿”的另一种理解：** 一个母亲的“寿命”不是以她活了多少年计算的——是以她影响了多少生命、那些影响持续了多久计算的。她通过他——继续活着。
- **母亲的“不亡”是最直观的：** 她不需要“被记住”——她已经被她养育的生命吸收了。她的爱、她的耐心、她的回应方式——成为了孩子的一部分。那就是“不亡”——她在他里面。

朱先生说“死而不亡者寿”是身体死去而精神不亡才是长寿。母亲的身体告诉我们：**即使她走了——她在他生命中留下的安全感、信任感、爱的能力——会继续存活。那才是真正的“寿”。**

## 结语：母亲的“自胜”与“不亡”——从外部比较到内在扎根

朱邦復先生在这一章中，用六个递进的命题，从“知人”到“自知”、从“胜人”到“自胜”、从“知足”到“强行”、最后到“不失其所”和“死而不亡”——建立了一个从外求到内求、从短暂到长久的完整路径。

而母亲的身体，是这一条路径最完整的“行走者”：

- **“知人者智”——她知道孩子的哭声、知道他的需求。** 那是她的智慧。
- **“自知者明”——她知道自己的极限、知道什么时候需要休息。** 那是她的明达。
- **“胜人者有力”——她曾经比较过，和别人比谁的孩子更好。** 那是她短暂的“有力”。
- **“自胜者强”——她战胜了“我应该”、完美主义、焦虑。** 那是她真正的“强”。
- **“知足者富”——她不再追求“最好”的——她知道“够用”就是“富”。**
- **“强行者有志”——她每天重复、每天继续——不是因为有力，是因为有志。**
- **“不失其所者久”——她始终守住“母亲”的位置——不是“完美”的母亲，是“在那里”的母亲。**
- **“死而不亡者寿”——即使她走了，她在他生命中留下的安全感和爱的能力会继续存活。**

**母亲的一生是从“知人”走向“自知”的一生。** 她开始于了解那个最依赖她的人——然后她学会了解自己。不是“放弃”自己——是“在照顾他之中发现自己”。

**母亲的一生是从“胜人”走向“自胜”的一生。** 她开始于和别人比较——然后她学会战胜自己的焦虑、自己的完美主义、自己的“不够好”。那才是真正的“强”。

**母亲的一生是“强行”的一生——不是因为有力，是因为有志。** 她每天重复、每天继续、每天“再陪他一天”。那不是靠“力量”——那是靠“意志”。

**母亲的一生是“死而不亡”的一生。** 她的身体会老、会病、会离开——但她在他生命中留下的痕迹不会“亡”。她给他的安全感、信任感、爱的能力——会继续活着。

这就是母亲身体的“自知与自胜”——不需要被记住，只需要被活。她在他里面——继续活着。



## 引言：最反战的一章，最母亲的一章

帛书本第三十一章，是《德道经》中关于“兵器与战争”最集中的论述：

> 夫兵者，不祥之器也。物或惡之，故有欲者弗居。
>
> 君子居則貴左，用兵則貴右。故兵者非君子之器也。
>
> 兵者不祥之器也，不得已而用之，銛襲為上，勿美也。若美之，是樂殺人也。
>
> 夫樂殺人，不可以得志於天下矣。
>
> 是以吉事上左，喪事上右；是以便（偏）將軍居左，上將軍居右，言以喪禮居之也。
>
> 殺人眾，以悲依（哀）立（莅）之；戰勝，以喪禮處之。

“兵者，不祥之器也”——兵器，是不吉祥的器物。“物或恶之”——连万物都厌恶它。“故有欲者弗居”——所以有道之人不居于它。

朱邦復先生在《止笑譚》中，将这一章解读为 **“兵器是不祥之物，有道者避而远之”**。他认为战争是凶事，不能赞美、不能以杀为乐、即使战胜也要哀悼。

但当我们站在母亲的角度来读时，这一章变得比“反战的政治哲学”更深——它变成了一个母亲看着自己拼死生下的孩子被送上战场时，从身体深处发出的声音。

让我们保持一贯的对照格式，逐句走进这一章。


## 一、“夫兵者，不祥之器也”——兵器是不吉祥的器物

### 朱邦復的解读：兵器代表伤害和死亡

朱先生将“夫佳兵者不祥之器”解读为“锐利的兵器代表危险”：

> “兵器以伤害力强为佳，人性则避害就利。”

武器本身就是伤害的载体——它的设计就是为了破坏。有道者“不处”——不靠近、不依赖、不赞美。

### 从母亲身体与送子出征的视角：“兵者”是可能杀死我孩子的工具

对母亲来说，“不祥”不是抽象的概念。她的孩子——她怀胎十月、阵痛分娩、夜夜哺乳、看着他蹒跚学步——可能会被这些“兵器”杀死。她拼死让他生——“兵者”却可能让他死。

母亲的身体知道“不祥”的重量。她的产道曾经是他的第一个战场——她用力把他推出来，让他活。现在，他要被送进一个真正的战场，一个可能让他死的地方。**母亲是“兵者不祥”的第一证人。**

| 朱邦復的“兵者不祥之器” | 母亲经验的“兵者不祥之器” |
| :--- | :--- |
| 兵器代表伤害和破坏 | 我拼死生下的孩子，可能会被它杀死——这是“不祥”最具体的含义 |
| 第三人称：兵器的危险性 | 第一人称：他曾经是我的全部生命——现在它可能夺走他 |


## 二、“物或惡之”——连万物都厌恶它

### 朱邦復的解读：人们厌恶兵器

朱先生将“物或恶之”解读为“人常厌恶兵器”：

> “兵器以伤害力强为佳，人性则避害就利。”

人们厌恶兵器，因为它是伤害的来源。你看到刀子、枪——你不会觉得“好”——你会觉得“危险”。

### 从母亲身体与送子出征的视角：母亲的身体厌恶战争，因为它违背了她的全部生命逻辑

“物或恶之”最直接的承载者，是母亲的身体。

母亲的身体曾经是孩子的第一个“世界”。在那个世界里，没有兵器、没有战争、只有温暖、滋养、保护。她的身体“惡”兵器——因为兵器是孩子出生后要面对的、她无法再保护他免受的伤害。

她的身体在产后也经历过“兵器”——产钳、手术刀——她知道被侵入、被切割、被撕裂是什么感觉。她的身体厌恶兵器——因为她的生命以保护为目的，而兵器以伤害为目的。两者是相反的。

| 朱邦復的“物或恶之” | 母亲经验的“物或惡之” |
| :--- | :--- |
| 人们厌恶兵器 | 母亲厌恶战争——因为她的身体从怀孕起就在保护，而战争在摧毁 |
| 第三人称：人对伤害的自然反应 | 第一人称：我不允许任何东西伤害他——而战争是最大的“恶” |


## 三、“故有欲者弗居”——所以有道之人不以此为居

### 朱邦復的解读：有道者不把兵器当作常态

朱先生将“故有道者不处”解读为“有道者避而远之”：

> “故有道者不處。”

“居”是停留、以此为居所。有道者不把兵器当作自己的居所。

### 从母亲身体与送子出征的视角：母亲只想让孩子“居”在家里，不想让他“居”在战场上

“弗居”在母亲这里，是一个祈祷。

她不想让孩子“居”在战争里。她想让他“居”在家里——在她的餐桌旁、在她的目光中、在她的牵挂里。但战争把他的“居”从家变成了战场。他不再“居”于母亲的庇护中——他“居”于兵器的阴影下。

“有欲者弗居”在母亲的视角里，是一个愿望：“让他不要留在战争里。让他回来。让他‘弗居’于兵。”

| 朱邦復的“有欲者弗居” | 母亲经验的“有欲者弗居” |
| :--- | :--- |
| 有道者不把兵器当作常态 | 我不想让他“居”在战场上——我只想让他“居”在家里 |
| 第三人称：不依赖伤害性工具 | 第一人称：他的“居”应该是家，不是战壕 |


## 四、“君子居則貴左，用兵則貴右”——平时以左为贵，用兵时以右为贵

### 朱邦復的解读：左右各有象征意义

朱先生将“君子居则贵左，用兵则贵右”解读为“左为吉，右为凶”：

> “吉祥之事以左方为主，凶害则以右方为主。”

左是阳、是吉、是生；右是阴、是凶、是杀。平时居左——用兵（进入战争状态）则居右。

### 从母亲身体与送子出征的视角：他从“左”（生）走向了“右”（杀），母亲无法留住他

“左”是生、吉、养的方向。母亲的孩子从小在“左”的环境里成长——被喂养、被保护、被爱。那是母亲为他建立的“左”。

“右”是杀、凶、战的方向。当孩子穿上军装，他就从“左”走向了“右”——从生命的领域走向了死亡的领域。母亲的“左”没能留住他。

一个母亲看着孩子从“左”走向“右”，是她一生中最无力的时刻。她曾经能用手臂环抱他、能用身体保护他——但现在，她只能看着他走向一个她无法保护他的地方。

| 朱邦復的“居左用右” | 母亲经验的“居左用右” |
| :--- | :--- |
| 左为吉、右为凶 | 他从“左”（我的怀抱）走向了“右”（战场）——我无法留住他 |
| 第三人称：左右的文化象征 | 第一人称：我把他养在“左”——他却在“右”里消失了 |


## 五、“故兵者非君子之器也”——兵器不是君子的器具

### 朱邦復的解读：君子不用兵器

朱先生将“兵者非君子之器”解读为“兵器非君子所用”：

> “危險的兵器為不吉祥的東西，不是君子所用之器具。”

君子不用兵器——因为他追求和平、滋养、生长，而不是破坏、伤害、杀戮。

### 从母亲身体与送子出征的视角：“兵”不是我想给孩子的“器”

“器”是工具、是器具。母亲给孩子的东西应该是“器”——是让他可以生活的工具、是让他可以成长的器物。但“兵”不是她想要给孩子的“器”。她不想给他枪、不想给他刀、不想给他任何用来杀人或被杀的“器”。

她希望他手里拿的是书本、是工具、是创造的东西——而不是兵器。她希望他使用“器”去建设生活，而不是去结束生命。

| 朱邦復的“兵者非君子之器” | 母亲经验的“兵者非君子之器” |
| :--- | :--- |
| 兵器不是君子所用的器具 | 这不是我想给他的“器”——我给他的应该是创造的工具，不是毁灭的武器 |
| 第三人称：君子不用的原则 | 第一人称：我给他的应该是书本——不是枪 |


## 六、“兵者不祥之器也，不得已而用之，銛襲為上”——兵器是不祥的，不得已才用，恬淡为上

### 朱邦復的解读：不得已才用，用时要恬淡

朱先生将“不得已而用之，恬淡为上”解读为“在不得已的情况下使用，也应以恬淡为上”：

> “不得已而用之，恬淡為上。”

“恬淡”是不执着、不沉浸在情绪中。用了就用了——不兴奋、不恐惧、不后悔。

### 从母亲身体与送子出征的视角：他去参战是“不得已”——但母亲的生命里，已经有过太多“不得已”

“不得已”是整个战争伦理中最艰难的一个词。

对一个母亲来说，“不得已”是什么？是她的儿子被征召入伍——不是“愿意”，是“被强制”；是她的儿子被送上战场——不是“选择”，是“不得不”。她不想让他去，但“不得已”。

母亲一生中有过很多“不得已”——分娩时的撕裂是不得已、产钳是不得已、让孩子自己面对世界是不得已。但把孩子送上战场，是最大的“不得已”。因为她知道——他可能回不来。

| 朱邦復的“不得已而用之恬淡为上” | 母亲经验的“不得已而用之銛襲為上” |
| :--- | :--- |
| 兵器不得已才用，用时要恬淡 | 他去参战是“不得已”——但我不可能“恬淡”。我的心里全是恐惧 |
| 第三人称：用兵的节制 | 第一人称：我做不到“恬淡”——因为失去他的可能性比死亡还重 |


## 七、“勿美也”——不要赞美它

### 朱邦復的解读：战胜了不要赞美战争

朱先生将“胜而不美”解读为“战胜了不能当作美事”：

> “以武力爭勝了，也不能算是好事。”

“美”是把战争当作“值得赞美的事情”。

### 从母亲身体与送子出征的视角：母亲不会赞美战争。她站在月台上，她的沉默就是最深的“勿美”

谁会在母亲面前赞美战争？如果战争是一件“美事”，那她的孩子算什么？如果战争值得赞美，那她的孩子岂不是一件“被赞美的事的耗材”？

母亲不会赞美战争。她站在村口、站在车站、站在送别的人群中——她不会说“这是光荣的”。她会沉默。她会看着列车远去。她的眼泪不会变成赞美。她的心在说：“请你回来。”

| 朱邦復的“胜而不美” | 母亲经验的“勿美也” |
| :--- | :--- |
| 战胜了不能当作美事 | 我不会赞美战争——你的光荣是用他的生命换来的，我无法“美”它 |
| 第三人称：战后的态度 | 第一人称：我站在站台上沉默——那是我的“勿美” |


## 八、“若美之，是樂殺人也”——如果赞美它，就是以杀人为乐

### 朱邦復的解读：赞美战争就是以杀人为乐

朱先生将“而美之者，是乐杀人”解读为“以战争为美，就是以杀人为乐”：

> “若有炫耀武力者，是樂於殺人。”

如果你把“战争”当作“美事”来赞美——你就是在“乐杀人”。

### 从母亲身体与送子出征的视角：赞美战争，就是把她孩子的死亡当作“可以接受的损耗”

“若美之，是乐杀人”在母亲这里，意思变得尖锐：

如果你赞美战争，你就是在赞美杀死她孩子的可能性。如果你说“战争是光荣的”、“牺牲是伟大的”——你就是在把她孩子的生命当作“可以接受的损耗”。你不是在杀他一次——你是在把他的死亡当作“值得的”来第二次确认他的可被牺牲。

母亲不会“乐杀人”。她乐的是孩子活着、孩子回家、孩子平安。她乐的是生命，不是死亡。赞美战争的人，和母亲是相反的。

| 朱邦復的“若美之是乐杀人” | 母亲经验的“若美之是樂殺人也” |
| :--- | :--- |
| 赞美战争就是以杀人为乐 | 你若赞美战争，就是把他的死当作“可以接受的”——而我永远无法接受 |
| 第三人称：美战即乐杀 | 第一人称：我的“乐”是他回来——不是他牺牲 |


## 九、“夫樂殺人，不可以得志於天下矣”——以杀人为乐的人，不可能实现志向

### 朱邦復的解读：嗜杀者不得人心

朱先生将“夫乐杀人者，则不可得志于天下矣”解读为“以杀人为乐者不可能得到天下人的归心”：

> “樂於殺人者，人人懼之，不可能得到天下人的歸心。”

一个以杀人为乐的人——人们怕他、恨他、远离他。他不可能“得志”——因为他失去了人心。

### 从母亲身体与送子出征的视角：母亲的“得志”只有一个——孩子活着回来

“得志”不是“政治成功”——是“愿望实现”。以杀人为乐的人，不可能实现真正的愿望——因为他的愿望建立在死亡之上。而母亲的愿望建立在生命之上。

母亲“得志”的唯一方式是：她的孩子活着回来。如果所有人都像母亲一样，以生命为志向，战争就不会发生。老子说“乐杀人者不得志于天下”，在母亲这里就是：一个不珍视生命的世界，不配得到真正的和平。

| 朱邦復的“乐杀人者不得志于天下” | 母亲经验的“樂殺人不可得志於天下” |
| :--- | :--- |
| 嗜杀者失去人心 | 我的“得志”只有一个——他活着回来。一个以杀人为乐的世界，不配拥有母亲的祈祷 |
| 第三人称：嗜杀的政治后果 | 第一人称：我只想要他活着——这才是真正的“得志” |


## 十、“吉事上左，喪事上右”——吉事以左为尊，丧事以右为尊

### 朱邦復的解读：左右对应吉凶

朱先生将“吉事尚左，凶事尚右”解读为“吉祥之事以左为主，凶害以右为主”：

> “吉祥之事以左方為主，凶害則以右方為主。”

左是生，右是杀。战争是凶事——所以以右为尊。

### 从母亲身体与送子出征的视角：孩子走向“右”——那是一个可能的丧事

“上左”是吉事，“上右”是丧事。出征以“右”为尊——意味着出征本身就是“丧事”。母亲的孩子走向“右”——他走向的可能是一场丧事。

他的行囊里装着母亲给他的东西——一件冬衣、一封信、一个护身符——但没有人给他“丧事”的仪式。因为那个仪式在他出发之前就已经在母亲心里举行了。她在心里为他举办了无数次的“丧礼”——每一次都希望它不会变成真的。

| 朱邦復的“吉事左丧事右” | 母亲经验的“吉事上左喪事上右” |
| :--- | :--- |
| 吉事左，丧事右 | 我的孩子走向“右”——我为他预演的“丧礼”已经开始了 |
| 第三人称：吉凶的文化象征 | 第一人称：我送他走向“右”——我的心已经在办丧事了 |


## 十一、“偏將軍居左，上將軍居右”——偏将军在左，上将军在右

### 朱邦復的解读：用兵以丧礼处之

朱先生将“偏将军居左，上将军居右”解读为“用兵以丧礼处之”：

> “作戰時副將在左方，主將在右方，是因為把用兵當作喪事來辦。”

“偏将军”是副将——在左（吉位）；“上将军”是主将——在右（凶位）。主将居右——表明“用兵”是“凶事”。

### 从母亲身体与送子出征的视角：将军居右——但母亲的孩子可能成为任何位置上的牺牲者

“上将军居右”——最高的将领在“丧位”。战争本身就是丧事。

对母亲来说，她的孩子不需要成为将军。她只希望他活着。但战争不以母亲的愿望为转移——它给每个士兵分配了位置，不管那个位置在“左”还是在“右”。他可能在左、可能在右、可能在中间——但无论在哪里，他都在“丧”的范围内。

| 朱邦復的“偏将军居左上将军居右” | 母亲经验的“偏將軍居左上將軍居右” |
| :--- | :--- |
| 用兵以丧礼处之 | 他可能在“左”也可能在“右”——但无论他在哪里，他都在“丧”的可能性里 |
| 第三人称：战争的礼仪 | 第一人称：无论他在哪个位置——他都离“丧”不远了 |


## 十二、“殺人眾，以悲依（哀）立（莅）之”——杀人众多，要以悲哀面对

### 朱邦復的解读：面对杀戮要悲哀

朱先生将“杀人之众，以悲哀立之”解读为“杀人了要以悲哀的心情悼念”：

> “殺人多了，要以悲哀的心情悼念死者。”

战争的结果是杀人。不能因为“我们赢了”就高兴——要悲哀，因为生命被夺去了。

### 从母亲身体与送子出征的视角：每一个被杀的人，都是某个母亲的儿子

母亲不需要被教导“以悲哀面对”——她的一生就是悲哀的练习。

当她听说战事、当她收到电报、当她看到邮差骑车上山——她的身体已经在下沉。她的“悲哀”不是选择——是本能。她知道每一个被杀的人，都是某个母亲的儿子。她为所有的母亲悲哀——也为她自己的、可能被列入那个名单的、她拼死生下的孩子悲哀。

| 朱邦復的“杀人之众以悲哀莅之” | 母亲经验的“殺人眾以悲依立之” |
| :--- | :--- |
| 面对杀戮要悲哀 | 每一个被杀的人，都是某个母亲的儿子——我为他们、也为我自己悲哀 |
| 第三人称：对生命的哀悼 | 第一人称：我的悲哀从未停止——从我送他走的那天起 |


## 十三、“戰勝，以喪禮處之”——战胜了，也要以丧礼对待

### 朱邦復的解读：战胜了也要哀悼

朱先生将“战胜，以丧礼处之”解读为“战胜了也要以办丧事的心情面对”：

> “即使戰勝了，也要以辦喪事的心情對待勝利。”

战争没有“赢”。即使赢了——仍然要用丧礼来对待。

### 从母亲身体与送子出征的视角：战争没有“赢”——即使他回来了，他也已经不是原来的他了

母亲最懂这个道理。即使孩子活着回来了——他也不是“完好”的。他带着伤、带着记忆、带着杀过人的眼睛。那个回来的孩子，已经不是她送出去的那个了。他的左肩可能缺了一块，他的眼神可能少了一些光。战争在他身上留下了不可逆转的痕迹。

母亲知道，即使“战胜”——也是“丧事”。因为她失去了那个完整的、无伤的、不会做噩梦的儿子。“战胜”不是凯旋——是幸存者的沉默。“以丧礼处之”——她抱着已经残缺的孩子，用沉默完成了那个丧礼。

| 朱邦復的“战胜以丧礼处之” | 母亲经验的“戰勝以喪禮處之” |
| :--- | :--- |
| 战胜了也要以丧礼对待 | 即使他回来了——他也不是原来那个了。我的“丧礼”是从他出发那天开始的 |
| 第三人称：战胜后的态度 | 第一人称：他回来了，但我失去的那个他已经回不来了 |


## 结语：母亲是“兵者不祥”的最终注释

朱邦復先生在这一章中，用反战的军事伦理来解读“兵者不祥之器”——战争是凶事，不能赞美、不能以杀为乐、即使战胜也要哀悼。

而母亲的身体——那个曾经孕育过生命、现在正在等待孩子从战场上归来的身体——是这一章最真实的、最不被言说的注释：

| 帛书原文 | 朱邦復的解读 | 母亲经验的解读 |
| :--- | :--- | :--- |
| 兵者不祥之器 | 兵器代表伤害和破坏 | 我拼死生下的孩子，可能会被它杀死——这是“不祥”最具体的含义 |
| 物或恶之 | 人们厌恶兵器 | 母亲厌恶战争——因为她的身体从怀孕起就在保护，而战争在摧毁 |
| 有欲者弗居 | 有道者不把兵器当作常态 | 我不想让他“居”在战场上——我只想让他“居”在家里 |
| 居左用右 | 左吉右凶 | 他从“左”（我的怀抱）走向了“右”（战场）——我无法留住他 |
| 兵者非君子之器 | 兵器不是君子之器 | 这不是我想给他的“器”——我给他的应该是创造的工具 |
| 不得已而用之 | 不得已才用，用时要恬淡 | 他去参战是“不得已”——但我不可能“恬淡” |
| 勿美也 | 战胜了不能当作美事 | 我不会赞美战争——你的光荣是用他的生命换来的 |
| 若美之是乐杀人 | 赞美战争就是以杀人为乐 | 你若赞美战争，就是把他的死当作“可以接受的损耗” |
| 乐杀人者不得志 | 嗜杀者失去人心 | 我的“得志”只有一个——他活着回来 |
| 吉事左丧事右 | 左吉右凶 | 我送他走向“右”——我的心已经在办丧事了 |
| 偏将军居左上将军居右 | 用兵以丧礼处之 | 无论他在哪个位置——他都离“丧”不远了 |
| 杀人之众以悲哀莅之 | 面对杀戮要悲哀 | 每一个被杀的人，都是某个母亲的儿子 |
| 战胜以丧礼处之 | 战胜了也要哀悼 | 即使他回来了——他也不是原来那个了 |

**母亲的身体是战争的第一道防线，也是最后一道哀悼。**

她是那个在产床上用力推、让生命得以开始的人；也是那个在站台上看着生命走向可能终结的人。她从“左”开始，看着他走向“右”——但她不能阻止。她只能等待、只能哀悼、只能在他回来的时候，用她那双已经苍老的、仍然记得他第一次哭、第一次笑、第一次叫“妈妈”的手，抱住他残缺的身体。

老子说“战胜，以丧礼处之”。母亲的身体已经为每一场可能的“战胜”预演了丧礼。因为她知道：战争没有赢家——只有丧事。无论结果如何，她都以“丧礼处之”——因为她的孩子从走向战场的那一刻起，就已经不是她拼死生下的那个孩子了。

这就是母亲视角的“兵者不祥之器”——不是政治哲学的命题，是身体深处最真实的恐惧、最沉默的哀悼、最坚定的祈祷：“让他回来。让他回来。让他回来。”

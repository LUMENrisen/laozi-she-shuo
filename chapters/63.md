

## 引言：最“否定”的一章，最“回归”的母职

帛书本第十九章，是《德道经》中关于“舍弃人为标榜、回归自然本真”最集中的论述：

> 絕聲（聖）棄知（智），民利百負（倍）。
>
> 絕仁棄義，民復畜（孝）茲（慈）。
>
> 絕巧棄利，盗賊无有。
>
> 此三言也，以為文未足，故令之有所屬。
>
> 見素抱樸，少私寡欲。

“绝圣弃智”——抛弃圣贤的标榜和智巧的追求，人民获利百倍。“绝仁弃义”——抛弃仁义的提倡，人民回归孝慈。“绝巧弃利”——抛弃机巧和功利，盗贼自然消失。这三句话，作为文字还不够充分，所以要让它“有所属”——归属到“见素抱朴，少私寡欲”这个根本上来。

朱邦復先生在《止笑譚》中，将这一章解读为 **“去标榜、反刻意”的治理逻辑**。他认为“圣智、仁义、巧利”都是“智者”用来役民的手段——它们本身不是坏的，但它们被提倡的后果是制造竞争、虚伪、盗窃。所以“绝”不是“消灭”，而是“不标榜”。“见素抱朴，少私寡欲”是回归自然状态的路径——朴素、不雕琢、不贪婪。

但如果我们把主语换成“母亲”——那个每天都在养育、陪伴、回应孩子的身体——这一章就不再是“政治哲学”，而是一份**关于“如何不被‘好妈妈’的标签绑架”的解放手册**：

- “绝圣弃智”——不追求“育儿专家”的标签。你不需要成为“最懂育儿的人”，不需要读遍所有育儿书、掌握所有方法论。你只需要“看见”你的孩子。
- “绝仁弃义”——不强调“你应该孝顺我”。当你不把“孝顺”当作目标时，孩子反而会自然地靠近你。
- “绝巧弃利”——不教孩子“用技巧获利”。不鼓励他用小聪明获取好处、不奖励他用“表演”来换取奖励。
- “此三言也，以为文未足”——这三句话还不够透彻，因为“绝”是一个动作，但“绝”之后要“有所属”——归属于“见素抱朴”。不是“空”了之后什么都没有——是“空”了之后，有一个更本真的状态在。
- “见素抱朴”——回到最朴素的状态。不装饰、不表演、不戴面具。母亲不需要“做一个好妈妈”——她只需要“做她自己”。孩子不需要“做一个好孩子”——他只需要“做他自己”。
- “少私寡欲”——少一点“我的期望”、“我的标准”、“我的安排”。不是“没有期望”——是“不把期望当作要求”。

让我们逐句对照。


## 一、“絕聖棄知，民利百倍”——抛弃圣贤标榜，人民获益百倍

### 朱邦復的解读：不标榜才能不竞争

朱先生将“绝圣弃智，民利百倍”解读为“不崇拜圣贤、不追求智谋”：

> “不崇拜聖賢，不追求智謀，人民獲得的利益更多。”

他的逻辑是：当你把“圣贤”当作目标时，人人都去争那个位置；但“圣贤”是稀缺的，所以大多数人注定失败。不标榜它，人们就不需要去争它——反而能安居乐业。这就是“利百倍”。

### 从身体经验出发：不追求“育儿专家”的标签——你只需要“看见”孩子

“絕聖棄知”——在母亲的家庭里，“圣”和“智”是什么？

- **“圣”是“好妈妈”的标签、是“育儿专家”的称号、是“别人家的妈妈”的标准。** 你追求这个标签，你就会焦虑、会比较、会觉得自己不够好。你越追求“圣”的称号，你离孩子越远——因为你忙着证明自己是“好妈妈”，而不是在陪伴他。
- **“智”是“育儿方法论”的武装。** 你读了很多书、学了很多技巧、掌握了很多“应该”和“不应该”。但你越“智”，你越容易忽略孩子的真实状态——你的注意力在“方法”上，而不是在“他”身上。
- **“民利百倍”的养育版本：** 当你不追求“好妈妈”的标签、不依赖“育儿方法论”时，孩子反而受益更多。因为你的注意力回到了他的身上——你不是在“使用方法”，你是在“回应他”。

朱先生说“绝圣弃智”是不标榜圣贤和智谋。母亲的身体告诉我们：**你不追求“育儿专家”的标签时，你才能真正“看见”孩子。他需要的是一个真实的妈妈，不是一个“好妈妈”的表演。**

| 朱邦復的“绝圣弃智” | 母亲经验的“绝圣弃智” |
| :--- | :--- |
| 不标榜圣贤、不追求智谋，人民获益 | 不追求“好妈妈”标签、不依赖育儿方法论，孩子反而获益 |
| 第三人称：去标榜的政治逻辑 | 第一人称：我不需要做一个“育儿专家”——我只需要做他的妈妈 |


## 二、“絕仁棄義，民復孝慈”——抛弃仁义提倡，人民回归孝慈

### 朱邦復的解读：不强调仁义，才能回归自然的关系

朱先生将“绝仁弃义，民复孝慈”解读为“不强调仁德义行，人民自然孝慈”：

> “不強調仁德，不追求義行，人民自然返歸孝慈。”

他的逻辑是：当你不再“提倡”孝慈时，孝慈反而会自然回归。因为“提倡”本身就意味着它已经缺失了——你越用力“提倡”，反而越强化“缺失”的感觉。

### 从身体经验出发：不强调“你应该孝顺我”——孩子自然靠近你

“絕仁棄義”——在母亲的家庭里，“仁”和“义”是什么？

- **“仁”是“你应该对家人好”的规则。** 当你开始强调“你应该对妈妈好”的时候，你已经不是在建立关系——你是在施加要求。
- **“義”是“你应该这样做”的原则。** 当你开始用“原则”来规范孩子对父母的行为时，你已经不是在引导他——你是在约束他。
- **“民復孝慈”的养育版本：** 当你不强调“你要孝顺”时，孩子反而会自然地亲近你。不是因为“你对他好”所以“他回报你”——是因为你们之间有真实的连接。他的“孝”是关系的自然产物，不是义务的履行。

朱先生说“绝仁弃义”是不强调仁义，人民回归孝慈。母亲的身体告诉我们：**当我不对孩子说“你要孝顺我”的时候，他反而会靠近我。因为他的靠近不是因为“应该”——是因为“想”。**

| 朱邦復的“绝仁弃义” | 母亲经验的“绝仁弃义” |
| :--- | :--- |
| 不强调仁义，人民回归自然的孝慈 | 不强调“你应该孝顺”，孩子反而自然地亲近父母 |
| 第三人称：去标榜的社会逻辑 | 第一人称：他靠近我不是因为“应该”——是因为“想” |


## 三、“絕巧棄利，盗賊无有”——抛弃机巧功利，盗贼消失

### 朱邦復的解读：不鼓励机巧，犯罪自然减少

朱先生将“绝巧弃利，盗贼无有”解读为“不标榜机巧、不鼓励功利”：

> “不標榜機巧，不鼓勵功利，偷盜之徒即無以產生。”

他的逻辑是：当社会把“利”作为目标时，那些无法通过正当手段获利的人，就会选择不正当手段。“巧”和“利”本身就是“盗”的诱因。不标榜它们，人们就不会被诱惑。

### 从身体经验出发：不鼓励“用技巧获利”——孩子不学会讨好和表演

“絕巧棄利”——在母亲的家庭里，“巧”和“利”是什么？

- **“巧”是“用什么方式获得好处”。** 孩子发现“如果我表演乖巧就能得到奖励”——这是“巧”。他学会了用行为来交换好处。
- **“利”是“好处本身”。** 奖励、表扬、物质回报——这些都是“利”。当孩子被“利”所驱动时，他的行为就不是出于内在动机，而是为了外部回报。
- **“盗賊无有”的养育版本：** 当你不鼓励“用技巧换取好处”时，孩子就不会发展出“讨好”、“表演”、“钻空子”的行为模式。他不是在“避免盗贼”——是他根本没有“需要去偷”的动机。因为他的行为不是为了“换取”，而是为了“做”。

朱先生说“绝巧弃利”是不标榜机巧和功利，盗贼消失。母亲的身体告诉我们：**当我不奖励“表演”时，孩子就不需要“表演”。他做对的事，是因为那是他想要做的——不是因为“有好处”。**

| 朱邦復的“绝巧弃利” | 母亲经验的“绝巧弃利” |
| :--- | :--- |
| 不标榜机巧功利，盗贼自然消失 | 不鼓励“用技巧换取好处”——孩子不需要讨好和表演 |
| 第三人称：去诱因的社会逻辑 | 第一人称：他不表演、不讨好——因为他不需要靠“巧”来得到关注 |


## 四、“此三言也，以為文未足”——这三句话还不够，要让它们“有所属”

### 朱邦復的解读：否定之后需要肯定

朱先生将“此三者以为文不足，故令有所属”解读为“这三者是人为观念，要使之有所归属”：

> “‘聖智、仁義、巧利’這三者，都是人造的觀念，並非出於自然，應當摒棄，使人民另有遵遁。”

他的逻辑是：“绝”只是第一步——你不能只“否定”而不“肯定”。你要让被“绝”之后的状态“有所属”——归属于一个更根本的东西。

### 从身体经验出发：“绝”不是空——“有所属”是回到你自己

“此三言也，以為文未足”——在母亲的身体里，“未足”是什么意思？

- **“绝圣弃智”——去掉“好妈妈”的标签。**
- **“绝仁弃义”——去掉“你应该孝顺”的要求。**
- **“绝巧弃利”——去掉“用表演换取好处”的模式。**

但“绝”之后不是“空”的——不是“什么都没有了”的无底洞。“令之有所属”——要让它们归属于一个更根本的东西。

- **归属于“看见孩子”。** 你不是在“用方法”——你是在“看见他、回应他、陪伴他”。
- **归属于“真实的连接”。** 你不是在“建立关系”——你是在“和他在一起”。
- **归属于“不被标签绑架的养育”。** 你不是在“做一个好妈妈”——你是在“做你孩子的妈妈”。

朱先生说“令之有所属”是让“绝”之后的状态有归属。母亲的身体告诉我们：**去掉标签、去掉要求、去掉表演——然后你回到最根本的东西：和他在一起。不是“空”——是“回归”。**

| 朱邦復的“令之有所属” | 母亲经验的“令之有所属” |
| :--- | :--- |
| 否定之后要有肯定的归属 | 去掉标签、要求、表演——回到“看见他、陪伴他” |
| 第三人称：去标榜的完整逻辑 | 第一人称：我不是“空”了——我是回到了“他”的身边 |


## 五、“見素抱樸”——回归最朴素的状态

### 朱邦復的解读：朴素、不雕琢

朱先生将“见素抱朴”解读为“保持朴素的环境”：

> “保持樸素的環境，杜絕私念私慾。”

“素”是未染色的丝——“朴”是未加工的木材。两个词都指向一个状态：**未经修饰、不附加额外东西的本来面目。**

### 从身体经验出发：素颜、不表演、不戴面具——母亲最本真的样子

“見素抱樸”——在母亲的身体里，“素”和“朴”是什么？

- **“素”——不化妆、不打扮、不修饰。** 你不是在“展示”你自己——你只是“在”。你的脸上有疲惫、有泪痕、有熬夜的痕迹——但那是真实的。你不需要“漂亮”——你只需要“在这里”。
- **“朴”——不被“好妈妈”的模板所定义。** 你不是“按照标准”在带孩子——你是“按照你的方式”在带他。你的方式可能不够“科学”、不够“专业”、不够“完美”——但它是真实的。
- **“見素抱朴”的养育版本：** 孩子不需要一个“完美的妈妈”——他需要一个“真实的妈妈”。你的朴素、你的不完美、你的“不够好”——正是他能够靠近你的理由。因为你是真实的，他才能真实地回应你。

朱先生说“见素抱朴”是保持朴素。母亲的身体告诉我们：**我不需要完美——我只需要真实。我的疲惫、我的眼泪、我的不专业——都是他能够信任的“证据”。**

| 朱邦復的“见素抱朴” | 母亲经验的“见素抱朴” |
| :--- | :--- |
| 朴素、不雕琢、不加修饰 | 素颜、不表演、不戴面具——母亲最本真的样子 |
| 第三人称：回归自然状态 | 第一人称：我不需要完美——我只需要在这里 |


## 六、“少私寡欲”——减少私念和欲望

### 朱邦復的解读：减少私欲才能回归自然

朱先生将“少私寡欲”解读为“减少私念私欲”：

> “杜絕私念私慾。”

他的逻辑是：“私”和“欲”是偏离“素朴”的根源。少一些“我想要”、“我觉得应该”、“我认为必须”——才能回到那个未被欲望扭曲的本真状态。

### 从身体经验出发：少一点“我的期望”——孩子才能成为他自己

“少私寡欲”——在母亲的身体里，“私”和“欲”是什么？

- **“私”是“我的标准”。** 我想要他成为什么样的人、走什么样的路、达到什么样的高度——这些“我想要”就是“私”。当“私”太重时，孩子的“自己”就被挤压了。
- **“欲”是“我的期望”。** 我期望他听话、优秀、让我骄傲、让我安心——这些“期望”就是“欲”。当“欲”太强时，孩子就不是在活他自己——他是在活我的期望。
- **“少私寡欲”的养育版本：** 少一点“你应该成为什么”——多一点“你正在成为什么”。不是“没有期望”——是“期望不成为要求”。孩子需要知道“有人希望我好”——但他不需要被“期望”压得喘不过气。

朱先生说“少私寡欲”是减少私念和欲望。母亲的身体告诉我们：**少一点“我想要你成为……”，多一点“我看见你正在成为……”。当我的期望退后时，他的“自己”才有空间浮现。**

| 朱邦復的“少私寡欲” | 母亲经验的“少私寡欲” |
| :--- | :--- |
| 减少私念和欲望，回归自然 | 少一点“我想要你成为……”——多一点“我看见你正在成为……” |
| 第三人称：欲望管理的逻辑 | 第一人称：当我的期望退后时，他的“自己”才能长出来 |


## 结语：回归不是“空”，是“素”

朱邦復先生在这一章中，用“去标榜、回归朴”的逻辑，解读了“绝圣弃智、绝仁弃义、绝巧弃利”之后的状态。他认为否定之后需要“有所属”——归属于“见素抱朴，少私寡欲”这个根本状态。

而母亲的身体，是这一章最完整的“实践场”：

- **“绝圣弃智”**——不追求“好妈妈”的标签、不依赖育儿方法论。你不需要成为“育儿专家”——你只需要“看见”他。
- **“绝仁弃义”**——不强调“你应该孝顺我”。不把“孝”当作目标——他自然地亲近你。
- **“绝巧弃利”**——不鼓励“用技巧换取好处”。不奖励表演、不鼓励讨好——他不需要“巧”来得到关注。
- **“令之有所属”**——去掉标签、要求、表演之后，回到“看见他、陪伴他”这个根本。
- **“见素抱朴”**——素颜、不表演、不戴面具。你不需要完美——你只需要真实。
- **“少私寡欲”**——少一点“我想要你成为……”，多一点“我看见你正在成为……”。当期望退后时，他的“自己”才有空间浮现。

**“绝”不是“空”**——是“把那些多余的、附加的、遮挡的东西去掉”。去掉之后，露出来的不是“什么都没有”——是“素”，是“朴”，是你最本真的样子。

一个母亲读这一章，她不需要“学会”什么新东西——她需要“放下”很多旧东西：放下“好妈妈”的表演、放下“育儿专家”的焦虑、放下“你应该怎样”的期望。然后她就回到了最朴素的状态——那个“看见他、回应他、陪伴他”的，最真实、最不完美的自己。

**素，不是“没有颜色”——是“没有被染色之前的颜色”。朴，不是“没有形状”——是“没有被切割之前的形状”。母亲最本真的状态，就是没有被“好妈妈”的标签染色、没有被“育儿方法论”切割的——她自己。**

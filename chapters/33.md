

## 引言：最“军事”的一章，最“母亲”的“不争”

帛书本第六十九章（通行本第六十八章），是《德道经》中关于“善为士者不武、善战者不怒、善胜敌者不与”的集中论述：

> 善為士者不武，善戰者不怒，善勝敵者弗與，善用人者為之下。
> 
> 是胃（謂）不靜（爭）之德，是胃（謂）用人，是胃（謂）天，古之極也。

“善为士者不武”——善于为将帅的人不逞其勇武。“善战者不怒”——善于作战的人不轻易发怒。“善胜敌者弗与”——善于克敌制胜的人不与敌人正面交锋。“善用人者为之下”——善于用人的人对下谦卑。

“是谓不争之德”——这就是不争的德行。“是谓用人”——这就是用人的力量。“是谓天”——这就是符合天道。“古之极也”——这是自古以来的最高准则。

朱邦復先生在《止笑譚》中，将这一章解读为 **“不争之德的几个例证”** 。他认为“善为士者不武”是有智谋的将帅外表不表现勇武；“善战者不怒”是英勇的战士内心平静、不轻易发怒；“善胜敌者不与”是常胜之军不与敌人交锋；“善用人者为之下”是善于用人的自谦自下。他总结说：“这些是不与人争的德行，能充分发挥人的力量，符合了天道的极致。”

但如果我们把主语换成“母亲的身体”——那个在日复一日的养育中不靠“武”征服、不发“怒”压制、不“与”孩子正面冲突、用“为之下”来赢得孩子信任的身体——这一章就不再是“军事哲学”，而是一份 **“关于母亲如何以‘不武、不怒、不与、为之下’来达成‘不争之德’的日常记录”**：

- “善为士者不武”——最好的“战士”不靠武力。母亲不靠“命令”来让孩子服从——她不“武”。她用“在”来赢得信任，不是用“力量”来压服。
- “善战者不怒”——最好的“战士”不愤怒。母亲面对孩子的哭闹、叛逆、对抗——她不轻易发怒。她不是“没有脾气”——是她不把“怒”当作武器。她能“不怒”——因为她知道他需要的是“稳”，不是“暴”。
- “善胜敌者不与”——最好的“胜利”是不与对方交锋。母亲不和孩子的“对抗”正面冲突。他不吃饭——她不等他吃完，她换个方式；他大哭——她不吼“别哭了”，她蹲下来等。她“不与”——她不进入“对抗”的战场。
- “善用人者为之下”——最好的“使用”是谦下。母亲想要孩子靠近她吗？她不是用“权威”把他拉过来——她是用“下”（蹲下来、放低自己）让他走过来。她“为之下”——他自然靠近。
- “是谓不争之德”——那是不争的德性。母亲不争“赢”、不争“对”、不争“你应该听我的”——她“不争”。但正因为不争，她反而赢得了。
- “是谓用人之力”——那是“用人之力”的真正方式。不是“压服”人——是“激发”人。她不用“命令”激发孩子的顺从——她用“信任”激发孩子的自主。
- “是谓天，古之极也”——那是符合天道的、自古以来的最高准则。母亲的身体里自有一套“不争”的节律——那是“天”给她的，不是“学”来的。


## 一、“善为士者不武”——善于为将帅的人不逞武勇

### 朱邦復的解读：智勇而不外露

朱先生将“善为士者不武”解读为“有智谋的将帅外表不表现勇武”：

> “有智謀的將帥，其外表溫文儒雅，不表現勇武。”

真正善于统率的人不是靠“武”（外在的勇猛、威慑）来领导的——“武”是最后的、最低的手段。不“武”才是高明的。

### 从母亲身体的经验出发：母亲不靠“命令”让孩子服从——她不“武”

“善為士者不武”——在母亲的身体里，“不武”是什么？

- **她不用“命令”来让孩子服从。** 她不说“你必须”、“你给我”、“不然就……”。那些是“武”——外在的强力。她“不武”——她用“邀请”代替“命令”，用“我们”代替“你必须”。
- **“不武”的另一种理解：** 她不靠“我是你妈”的权威来压孩子。她不把“妈妈”这个身份当作“武器”。“武”是“用力量让人服从”——她不用那个。她用“在”赢得信任，不用“力”来压服。
- **“不武”的深层含义：** 她不是“没有力量”——是她不把“力量”当作工具。“武”是用来“征服”的——她不需要“征服”他。她需要他“靠近”。

朱先生说“善为士者不武”是智勇不外露。母亲的身体告诉我们：**她不用“命令”来让孩子服从——她“不武”。她用“在”赢得信任，不是用“力”压服。**

| 朱邦復的“善为士者不武” | 母亲经验的“善為士者不武” |
| :--- | :--- |
| 智勇不外露 | 她不用“命令”让孩子服从——她不“武”。她用“在”赢得信任 |
| 第三人称：将帅的德行 | 第一人称：我不“武”——我不需要征服他 |


## 二、“善战者不怒”——善于作战的人不轻易发怒

### 朱邦復的解读：静而制胜

朱先生将“善战者不怒”解读为“英勇的战士内心平静”：

> “英勇的戰士，內心保持平靜，不輕易發怒。”

“怒”是情绪的爆发——会让人失去判断、失去掌控。真正善战的人——不是“怒”的——是“静”的。静才能看见形势、做出判断。

### 从母亲身体的经验出发：母亲面对孩子的哭闹、叛逆——她不轻易发怒

“善戰者不怒”——在母亲的身体里，“不怒”是什么？

- **她不轻易发怒。** 孩子哭闹、叛逆、对抗——她的第一个反应不是“怒”（爆发、吼叫、压制）——是“稳”。她能“不怒”——不是因为她“没有脾气”——是因为她知道“怒”是武器，而她不想用武器对他。
- **“不怒”的另一种理解：** 她不是“压抑”情绪——她是“选择”不怒。她可以在心里有波动——但不在行为上“怒”。她“不怒”——是因为孩子需要“稳”，不是“暴”。
- **“不怒”的深层含义：** 母亲知道：发怒可以“赢”一时——但会“失”一世。她选择不怒——因为“怒”会推开他，而她想让他靠近。

朱先生说“善战者不怒”是心平气和才能神智清明。母亲的身体告诉我们：**她面对孩子的哭闹不轻易发怒——“怒”是武器，而她不想用武器对他。“不怒”是她的“稳”。**

| 朱邦復的“善战者不怒” | 母亲经验的“善戰者不怒” |
| :--- | :--- |
| 心平气和才能神智清明 | 她面对孩子的哭闹不轻易发怒——“怒”是武器，她不想用武器对他 |
| 第三人称：战士的节制 | 第一人称：我不是“没脾气”——我是选择“不怒” |


## 三、“善胜敌者弗与”——善于克敌制胜的人不与敌人交锋

### 朱邦復的解读：不战而屈人之兵

朱先生将“善胜敌者不与”解读为“不战而屈人之兵”：

> “常勝之軍，不必與敵人交鋒。”

“与”是正面交锋、接触、对抗。“不与”是不进入那个“对抗”的战场。真正的胜利不是“打赢”战斗——是“不让战斗发生”。

### 从母亲身体的经验出发：母亲不和孩子的“对抗”正面冲突

“善勝敵者弗與”——在母亲的身体里，“弗与”是什么？

- **她不和他“对抗”正面交锋。** 他不吃饭——她不逼着他“必须吃完”；他大哭——她不吼“别哭了”；他说“不”——她不硬掰成“行”。她“不与”——她不在那个“对抗”的战场上。
- **“弗与”的另一种理解：** 她不是“让步”——她是“换个战场”。对抗的战场是“赢/输”的——她不在那里玩。她换一个方式、等一个时机、绕过那堵墙。“不与”让她能“胜”——不是赢过对方，是让对抗本身不发生。
- **“弗与”的深层含义：** 她知道“正面冲突”的代价——赢了是关系受损，输了是失控。她不玩那个游戏。她“不与”——所以她没有“输”的战场。

朱先生说“善胜敌者不与”是不战而屈人之兵。母亲的身体告诉我们：**她不和孩子正面冲突——不是让步，是换战场。“不与”让对抗本身不发生。**

| 朱邦復的“善胜敌者不与” | 母亲经验的“善勝敵者弗與” |
| :--- | :--- |
| 不战而屈人之兵 | 她不和孩子正面冲突——不是让步，是换战场。“不与”让对抗不发生 |
| 第三人称：不战之胜 | 第一人称：我不和你“打”——我换一个方式 |


## 四、“善用人者为之下”——善于用人的人对下谦卑

### 朱邦復的解读：自下用人

朱先生将“善用人者为之下”解读为“自谦自下才能用人”：

> “善於用人的，必自謙自下。”

“用人”不是“用”人——是“让”人愿意为你所用。“为之下”是把自己放低。低——人才能“上”来。高——人只能“仰”望。

### 从母亲身体的经验出发：母亲想要孩子靠近她吗？她不是用“权威”拉过来——是用“下”让他走过来

“善用人者為之下”——在母亲的身体里，“为之下”是什么？

- **她用“下”来让孩子靠近。** 她蹲下来、放低声音、不在高处发号施令。她“为之下”——他自然走过来。不是“被拉过来”的——是“自己走过来的”。
- **“为之下”的另一种理解：** 她不是“低下”的人——她是“主动选择低”的人。她可以高——但她选择低。低——才能让他“上来”。高——他只能“仰望”，不能“靠近”。
- **“为之下”的深层含义：** 她想要他靠近她吗？她用“下”来让他“上”来。不是她“拉”他——是他“走”向她。因为她在“下”的位置——他不需要“爬”才能接触她。他在她旁边。

朱先生说“善用人者为之下”是自谦自下才能用人。母亲的身体告诉我们：**她想要孩子靠近——她用“下”让他“上”来。不是“拉”他——是他“走”向她。**

| 朱邦復的“善用人者为之下” | 母亲经验的“善用人者為之下” |
| :--- | :--- |
| 自谦自下才能用人 | 她想要孩子靠近——她用“下”让他“上”来。不是拉，是走 |
| 第三人称：用人之道 | 第一人称：我蹲下来——他就走过来了 |


## 五、“是谓不争之德”——这就是不争的德行

### 朱邦復的解读：不争的德行

朱先生将“是谓不争之德”解读为“不争的德行”：

> “這些是不與人爭的德行。”

不武、不怒、不与、为之下——所有这些都是“不争”的表现。它们不是“弱”——是“德”。不争之德——不是“没有力量”——是“力量不用于对抗”。

### 从母亲身体的经验出发：母亲不争“赢”、不争“对”、不争“你应该听我的”——她“不争”，所以赢得了

“是胃不靜之德”——在母亲的身体里，“不争之德”是什么？

- **她不争“赢”。** 她不需要“赢”过孩子——她不是“对手”。她不在“赢/输”的框架里。
- **她不争“对”。** 她不需要“证明自己是错的”——她知道“对”不是目的。“关系”才是。
- **她不争“你应该听我的”。** 她不需要“服从”来确认自己的位置——她的位置不是靠“服从”建立的。
- **“不争”的结果——她“赢”了。** 不是因为“争”赢的——是因为“不争”赢的。她赢了孩子的信任、孩子的靠近、孩子的安全感。那些不是“争”来的——是“不争”来的。

朱先生说“是谓不争之德”是这些是“不争”的德行。母亲的身体告诉我们：**她不争“赢”、不争“对”、不争“你应该听我的”——她“不争”，所以赢了。那些不是“争”来的——是“不争”来的。**

| 朱邦復的“是谓不争之德” | 母亲经验的“是胃不爭之德” |
| :--- | :--- |
| 这些是“不争”的德行 | 她不争赢、不争对、不争服从——她“不争”，所以赢了信任和靠近 |
| 第三人称：不争的德行 | 第一人称：我不争——但我赢了 |


## 六、“是谓用人之力”——这就是用人的力量

### 朱邦復的解读：用人之力的真谛

朱先生将“是谓用人之力”解读为“能充分发挥人的力量”：

> “是謂用人之力。”

“用人之力”不是“利用”人——是“让人愿意为你出力”。不争、谦下——才能激发人。压服只能得到“服从”——谦下才能得到“愿意”。

### 从母亲身体的经验出发：不是“压服”他——是“激发”他。她不用命令激发顺从——她用信任激发自主

“是胃用人”——在母亲的身体里，“用人”是什么？

- **她不是“压服”他——是“激发”他。** 她用信任激发他的自主、用空间激发他的探索、用等待激发他的成长。那不是“用力”压出来的——那是“用人”激发出来的。
- **“用人之力”的另一种理解：** 她的力量不是来自“控制”他——是来自“激发”他。他越自主——她越轻松。那不是“推卸”——那是“善用”。她让他成为他自己——那就是“用人之力”。

朱先生说“是谓用人之力”是能充分发挥人的力量。母亲的身体告诉我们：**她不是“压服”他——是“激发”他。用信任激发自主——那是“用人之力”。**

| 朱邦復的“是谓用人之力” | 母亲经验的“是胃用人” |
| :--- | :--- |
| 能充分发挥人的力量 | 她不是“压服”他——是“激发”他。用信任激发自主 |
| 第三人称：用人之力 | 第一人称：我不“用”他——我“激”他 |


## 七、“是谓天，古之极也”——这就是天道，自古以来的最高准则

### 朱邦復的解读：符合天道，古之极则

朱先生将“是谓配天之极”解读为“符合了天道的极致”：

> “是謂配天之極。”

“天”是天道。“极”是极致、最高准则。不争之德——不是“人为”的策略——是“天道”本身。自古以来的最高准则。

### 从母亲身体的经验出发：母亲的身体里自有一套“不争”的节律——那是“天”给她的

“是胃天，古之極也”——在母亲的身体里，“天”和“极”是什么？

- **她的身体里有一套“不争”的节律——那是“天”给她的。** 宫缩不是“争”——是“让”。分娩不是“用力取”——是“让生命通过”。她的身体本身就在“不争”中运作——她不需要“学”不争——她的身体“本来就是”不争的。
- **“古之极”的另一种理解：** 那不是“新的发现”——那是“自古以来的最高准则”。母亲的身体一直知道这个准则——从她成为母亲的那一刻起，“不争”就在她身体里了。
- **“天”的深层含义：** 那不是“神”——是“自然本身”。母亲的身体就是“自然”的一部分——她的不争、她的让、她的承——都是“天”在运作。她不需要“成为”不争——她“本来”就是不争。

朱先生说“是谓配天之极”是符合天道的极致。母亲的身体告诉我们：**她的身体里自有一套“不争”的节律——那是“天”给她的。她不需要“学”不争——她“本来”就是不争。**

| 朱邦復的“是谓配天之极” | 母亲经验的“是胃天古之極也” |
| :--- | :--- |
| 符合天道的极致 | 她的身体里自有一套“不争”的节律——那是“天”给她的 |
| 第三人称：天道的极致 | 第一人称：我不需要“学”不争——我“本来”就是不争 |


## 结语：“不争之德”——母亲最深的智慧

朱邦復先生在这一章中，用“不争之德的几个例证”的框架，解读了“善为士者不武、善战者不怒、善胜敌者不与、善用人者为之下”，并归结为“不争之德”、“用人之力”、“配天之极”。他认为这些是不与人争的德行，能充分发挥人的力量，符合天道的极致。

而母亲的身体，是这一章最完整的“不武、不怒、不与、为之下”的演绎者：

- **“善为士者不武”——她不用“命令”让孩子服从——她不“武”。她用“在”赢得信任。**
- **“善战者不怒”——她面对孩子的哭闹不轻易发怒——“怒”是武器，她不想用武器对他。**
- **“善胜敌者弗与”——她不和孩子正面冲突——不是让步，是换战场。**
- **“善用人者为之下”——她想要孩子靠近——她用“下”让他“上”来。**
- **“是谓不争之德”——她不争赢、不争对、不争服从——她“不争”，所以赢了。**
- **“是谓用人之力”——她不是“压服”他——是“激发”他。用信任激发自主。**
- **“是谓天，古之极”——她的身体里自有一套“不争”的节律——那是“天”给她的。**

**“善为士者不武”——母亲最好的“战斗”是不战斗。** 她不用“命令”来让孩子服从——她用“在”来赢得信任。“武”是用来“征服”的——而她不需要征服他。她需要他“靠近”。她“不武”——所以他靠近。

**“善战者不怒”——母亲最好的“防御”是不发怒。** 她面对孩子的哭闹、叛逆——不轻易发怒。不是“没有脾气”——是她知道“怒”是武器，而她不想用武器对他。她可以“不稳”的时候——但她选择“稳”。“不怒”是她的选择，不是她的缺失。

**“善胜敌者弗与”——母亲最好的“胜利”是不对抗。** 她不和孩子正面冲突——不是“让步”，是“换战场”。她不在那个“赢/输”的游戏里玩。她“不与”——所以对抗本身不发生。那不是“逃避”——那是“更高明的处理”。

**“善用人者为之下”——母亲最好的“领导”是谦下。** 她想要孩子靠近——她用“下”让他“上”来。不是“拉”他——是让他“走”向她。她在低处——所以他不需要“爬”才能接触她。他走在她旁边——不是在她下面。

一个母亲的身体，就是“不争之德”最日常的版本。她不“武”——所以孩子不怕她；她不“怒”——所以孩子不躲她；她不“与”——所以对抗不发生；她“为之下”——所以孩子靠近她。那不是“策略”——那是她的存在方式。那是“天”——从她身体里长出来的、不学而知的、不争之德。

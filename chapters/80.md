

## 引言：最“权谋”的一章，最“生理”的节律

帛书本第三十六章，是《德道经》中关于“翕张、强弱、予夺”辩证关系最集中的论述：

> 將欲拾（翕）之，必古（固）張之。
>
> 將欲弱之，必固強之。將欲去之，必古（固）與之。
>
> 將欲奪之，必古（固）予之。是胃（謂）微明。
>
> 友弱勝強，魚不脫於潚（淵），邦利器不可以視（示）人。

“将欲翕之，必固张之”——想要收缩它，必定先让它扩张。“将欲弱之，必固强之”——想要削弱它，必定先让它强盛。“将欲去之，必固与之”——想要除去它，必定先给予它。“将欲夺之，必固予之”——想要夺取它，必定先给予它。这就是“微明”——微妙的光明。“柔弱胜刚强”——柔弱能胜刚强。“鱼不可脱于渊”——鱼不能脱离深水。“邦利器不可以示人”——国家的利器不可以炫耀给人看。

朱邦復先生在《止笑譚》中，将这一章解读为 **“自然规律的微明与柔弱胜刚强”**。他认为“将欲翕之，必固张之”等四句是“能量变化中物极必反的规律”——收缩前必先扩张，削弱前必先强盛。他特别强调“是谓微明”——这个道理其实很“明”，但一般人看不见、察觉不到，所以是“微明”。他最后以“柔弱胜刚强”作为结论——静能制动、柔能克刚。而“鱼不可脱于渊”是比喻——人不可脱离根本；“邦利器不可以示人”是警告——利器不可炫耀。

但如果我们把主语换成“母亲的身体”——那个在分娩中经历了子宫的“翕张”循环、在产后经历了身体的“强弱”交替、在喂养中经历了“予夺”节律的身体——这一章就不再是“权谋之术”，而是一份 **“关于宫缩如何‘先张后翕’、产后如何‘先弱后强’、母乳喂养如何‘先予后夺’的生理记录”**：

- “将欲翕之，必固张之”——子宫在收缩（翕）之前，必须被撑开（张）。胎儿的头部扩张了宫颈——然后宫缩才能有效收缩。没有“张”，就没有“翕”。
- “将欲弱之，必固强之”——宫缩在达到最强之后，才会开始减弱。没有那个“最强”的峰值，就不会有后续的“弱”。分娩的“弱”（宫缩逐渐停止）是以“强”（最强宫缩）为前提的。
- “将欲去之，必固与之”——孩子要“离开”（娩出），身体必须先“给予”——给她空间、给她通道、给她推力。“去”的前提是“与”。
- “将欲夺之，必固予之”——产后身体要“夺回”自己（收缩、恢复），必须先“给予”——给予营养给胎儿、给予空间给胎儿、给予能量给分娩。“夺”的前提是“予”。
- “是谓微明”——这个道理其实很明显，但只有身体知道。宫缩的节律不需要被“学习”——身体自己知道。
- “柔弱胜刚强”——产后身体的“柔弱”（松弛、缓慢、接纳）胜过“刚强”（僵硬、控制、抗拒）。不僵、不抗——才能恢复。
- “鱼不可脱于渊”——母亲不能脱离她的“渊”：她的身体、她的节奏、她的感受。她不能“脱”离那个根本，否则她就会失去方向。
- “邦利器不可以示人”——她的“利器”不是用来展示的。她的疲惫、她的脆弱、她的“还不够好”——不必向世界炫耀。她需要把它们收起来——不是“藏住不说”，是“不需要用它们来证明什么”。

让我们逐句对照。


## 一、“將欲翕之，必固張之”——想要收缩，必先扩张

### 朱邦復的解读：收缩之前必有扩张

朱先生将“将欲歙之，必固张之”解读为“收缩前必先张开”：

> “要使機構收縮，先得使之張開。”

这是物理规律——你要让一个东西收缩，它必须先处于“张开”的状态。如果没有“张”的空间——就没有“翕”的可能。

### 从身体经验出发：子宫在收缩（翕）之前，必须先被撑开（张）

“將欲翕之，必固張之”——在母亲的身体里，“翕”和“张”是什么？

- **宫颈的扩张（张）是宫缩（翕）的前提。** 分娩开始时，子宫颈要从闭合（约1厘米）到完全打开（10厘米）。那个“张”——胎头下降、宫颈扩张——是宫缩能有效“翕”的必需前提。
- **没有“张”就没有“翕”。** 如果宫颈没有扩张——宫缩再强也无效。宫缩的“翕”（收缩、推出）必须建立在“张”（宫颈打开、产道通畅）的基础上。身体的节律是“先张后翕”——不是偶然，是必然。
- **“張”是痛苦的。** 宫颈扩张是疼痛的、缓慢的、需要时间的过程。但如果没有“張”——生命就无法通过。母亲的身体最懂这个：“张”不是为了伤害——是为了让“翕”有效。

朱先生说“将欲歙之必固张之”是收缩前必先扩张。母亲的身体告诉我们：**子宫在收缩（翕）之前必须被撑开（张）——宫颈扩张是宫缩有效的前提。没有“张”就没有“翕”。**

| 朱邦復的“将欲歙之必固张之” | 母亲经验的“將欲翕之必固張之” |
| :--- | :--- |
| 收缩前必先扩张 | 子宫在收缩之前必须先被撑开——宫颈扩张是宫缩有效的前提 |
| 第三人称：物理的翕张规律 | 第一人称：没有“张”——就没有“翕” |


## 二、“將欲弱之，必固強之”——想要削弱，必先加强

### 朱邦復的解读：削弱前必有强盛

朱先生将“将欲弱之，必固强之”解读为“削弱前必先使其强”：

> “欲削弱能量，須先使之有足夠的強度。”

你要让一个东西“弱”，它必须先达到“强”。没有“强”的顶点——就没有“弱”的开始。

### 从身体经验出发：宫缩在最强的峰值之后，才开始减弱

“將欲弱之，必固強之”——在母亲的身体里，“强”和“弱”是什么？

- **宫缩的强度是逐渐攀升的。** 从轻微的不适到强烈的疼痛——宫缩的“强”是渐进的。当宫缩达到最强峰值——然后才开始“弱”（消退）。
- **没有“强”就没有“弱”。** 如果宫缩没有达到那个峰值——它就不会进入消退期。你不可能跳过“强”直接进入“弱”。分娩的节奏就是“先强后弱”——强到极致，然后弱下来。
- **“强”不是为了痛苦——是为了“完成”。** 那个最强的宫缩——恰恰是孩子即将通过的时刻。宫缩达到最强——宫颈已经全开，他即将出来了。然后宫缩开始“弱”——因为它的任务完成了。

朱先生说“将欲弱之必固强之”是削弱前必先使其强。母亲的身体告诉我们：**宫缩在达到最强峰值之后才开始减弱。没有“强”就没有“弱”。“强”不是为了痛苦——是为了完成。它完成了任务，然后才“弱”下来。**

| 朱邦復的“将欲弱之必固强之” | 母亲经验的“將欲弱之必固強之” |
| :--- | :--- |
| 削弱前必先使其强 | 宫缩在达到最强峰值之后才开始减弱——没有“强”就没有“弱” |
| 第三人称：能量变化的规律 | 第一人称：它最强的时候——正是他即将出来的时候 |


## 三、“將欲去之，必固與之”——想要除去，必先给予

### 朱邦復的解读：除去前必有给予

朱先生将“将欲废之，必固举之”解读为“欲废之前必先抬举”：

> “欲廢棄之人，須先抬舉他。”

在自然规律中，没有“突然的消灭”——要有“给予”才能有“除去”。你给它空间、给它位置、让它存在——然后它才能被“去”。

### 从身体经验出发：孩子要“离开”（娩出），身体必须先“给予”——空间、通道、推力

“將欲去之，必固與之”——在母亲的身体里，“去”和“与”是什么？

- **孩子要“去”（娩出）——母亲必须先“与”。** 她给他空间（宫颈扩张）、给他通道（产道打开）、给他推力（宫缩推送）。“与”是“去”的前提。
- **没有“与”就没有“去”。** 如果不“给予”他出来的空间——他就“去”不了。“去”不是“被剥夺”——是“被允许”。“与”是允许他离开的条件。
- **“与”的另一个层面：** 她不仅给空间——她还给力量。每一次宫缩都是她在“给”——把能量传递给他、把他推向出口。“去”是靠“与”完成的。

朱先生说“将欲废之必固举之”是欲废前必先抬举。母亲的身体告诉我们：**孩子要“离开”（娩出）——母亲必须先“给予”空间、通道、推力。“与”是“去”的前提——没有“与”就没有“去”。**

| 朱邦復的“将欲废之必固举之” | 母亲经验的“將欲去之必固與之” |
| :--- | :--- |
| 欲废前必先抬举 | 孩子要“离开”——母亲必须先“给予”空间、通道、推力。“与”是“去”的前提 |
| 第三人称：自然规律的递进 | 第一人称：我先“给”了他出路——然后他才“去”了 |


## 四、“將欲奪之，必固予之”——想要夺取，必先给予

### 朱邦復的解读：夺取前必有给予

朱先生将“将欲夺之，必固与之”解读为“夺取之前必先给予”：

> “如要奪取他人，必先給與。”

你想要夺走一样东西——你必须先给予它。不是“先给后取”的权谋——是自然规律：没有“给”就没有“取”的空间。

### 从身体经验出发：产后身体要“夺回”自己——必须先“给予”营养、空间、能量给胎儿和分娩

“將欲奪之，必固予之”——在母亲的身体里，“夺”和“予”是什么？

- **产后身体要“夺回”自己——必须先“给予”。** 孕期中，她把营养给了胎儿、把空间给了胎儿、把能量给了分娩。如果没有那些“给予”——身体就没有“夺回”的基础。
- **“予”是“夺”的前提。** 她先给了——然后才能“夺回”。如果她没有给——她就没有“夺”的目标。夺回的前提是“曾经给予”。
- **“夺”的另一个层面：** 她的身体在产后“夺回”激素平衡、“夺回”器官位置、“夺回”身体自主权——但那个“夺”建立在九个月的“给予”之上。予而后夺——不是“失去”，是“循环”。

朱先生说“将欲夺之必固与之”是夺取前必先给予。母亲的身体告诉我们：**产后她要“夺回”自己——必须先“给予”营养、空间、能量给胎儿和分娩。予而后夺——不是“失去”，是“循环”。**

| 朱邦復的“将欲夺之必固与之” | 母亲经验的“將欲奪之必固予之” |
| :--- | :--- |
| 夺取前必先给予 | 产后她要“夺回”自己——必须先“给予”了营养、空间、能量给胎儿 |
| 第三人称：自然规律的递进 | 第一人称：我先给了——然后我才能“夺回” |


## 五、“是謂微明”——这就是微妙的光明

### 朱邦復的解读：这个道理很微妙的明显

朱先生将“是谓微明”解读为“这个道理其实很‘明’，但人看不见，所以叫‘微明’”：

> “這個道理其實很明顯，因為靜能制動，柔能勝剛，弱能伏強。”

“微明”是“虽微而明”——事情还没发生时，征兆已经在那里了。那些“张、强、与、予”就是“翕、弱、去、夺”的“微明”——不明显，但真实存在。

### 从母亲经验的解读：宫缩的节律不需要被“学习”——身体自己知道

“是胃微明”——在母亲的身体里，“微明”是什么？

- **宫缩的节奏是“微明”的。** 身体不需要“学习”宫缩的规律——它自己知道什么时候该张、什么时候该翕、什么时候该强、什么时候该弱。那个“微明”在身体深处——不需要理论来证明。
- **“微明”的另一个层面：** 母亲的身体知道什么时候“予”、什么时候“夺”——不是靠“思考”——是靠“感受”。她知道什么时候该推进、什么时候该等待、什么时候该用力、什么时候该放松。那就是“微明”——身体知道，但她不一定能“说”出来。
- **“微明”是“身体的智慧”。** 它不被大脑“知道”——它被身体“知道”。宫缩的节奏、分娩的时机、恢复的节律——都是“微明”：不显眼，但真实。

朱先生说“是谓微明”是这个道理虽微但明。母亲的身体告诉我们：**宫缩的节律不需要被“学习”——身体自己知道。那就是“微明”——不显眼，但真实。**

| 朱邦復的“是谓微明” | 母亲经验的“是胃微明” |
| :--- | :--- |
| 这个道理微妙而明显 | 宫缩的节奏不需要被“学习”——身体自己知道。那就是“微明” |
| 第三人称：规律的隐蔽性 | 第一人称：我的身体知道——但我无法“说出”它 |


## 六、“友弱勝強”——柔弱胜刚强

### 朱邦復的解读：柔弱能胜刚强

朱先生将“柔弱胜刚强”解读为“静能制动，柔能克刚”：

> “靜能制動，柔能勝剛，弱能伏強。”

柔不是“无力”——是“不刚”。刚硬的东西容易折断，柔软的东西能顺应。在自然的变化中，柔能胜刚。

### 从母亲经验的解读：产后身体的“柔弱”——松弛、缓慢、接纳——胜过“刚强”

“友弱勝強”——在母亲的身体里，“弱”是什么？“强”是什么？

- **产后身体是“弱”的。** 松弛的腹部、缓慢的恢复、被改变的组织——那是“弱”。它不是“刚”的，不是“强”的。
- **但那个“弱”胜过“强”。** 如果她用“强”来对待身体——强行运动、强行恢复、强行“回到产前”——她会受伤。那个“强”会伤害她。而“弱”——接受身体的节奏、慢慢恢复、不急着“变强”——反而能让她真正恢复。
- **“柔弱”的另一种理解：** 分娩时，如果她“柔”（放松、顺应宫缩），产程更顺利；如果她“刚”（紧张、对抗宫缩），产程更艰难。“柔”胜过“刚”——因为“刚”是抵抗通道，“柔”是允许通道。

朱先生说“柔弱胜刚强”是柔能克刚。母亲的身体告诉我们：**产后身体是“弱”的——但那个“弱”（松弛、缓慢、接纳）胜过“强”（强行恢复）。柔能通过——刚会卡住。**

| 朱邦復的“柔弱胜刚强” | 母亲经验的“友弱勝強” |
| :--- | :--- |
| 柔弱能胜刚强 | 产后身体是“弱”的——但那个“弱”（松弛、接纳）胜过“强”（强行恢复） |
| 第三人称：自然辩证法的核心 | 第一人称：我“柔”的时候，反而能通过；“刚”的时候，反而会卡住 |


## 七、“魚不脫於淵”——鱼不能脱离深水

### 朱邦復的解读：人不可脱离根本

朱先生将“鱼不可脱于渊”解读为“鱼必须居水”：

> “一動不如一靜，萬物不可自暴其短，故魚必須居於水。”

鱼不能在陆地上存活——它必须生活在水中。不能脱离它的根本、不能离开它的源泉。

### 从母亲经验的解读：母亲不能脱离她的“渊”——她的身体、她的节奏、她的感受

“魚不脫於潚”——在母亲的身体里，“渊”是什么？

- **“渊”是她的身体。** 她不能脱离身体的感觉——疲惫、需要休息、需要被照顾——而去“完成”那些“应该做的事”。她必须回到身体的“渊”里——才能知道真正需要什么。
- **“渊”是她的节奏。** 她不能脱离自己的节奏——而跟随别人的标准、社会的速度。她需要回到自己的“渊”——那个缓慢的、重复的、属于她和孩子的节奏。
- **“渊”是她的真实感受。** 她不能脱离自己的感受——而用“我应该”来覆盖“我真实”。她需要允许自己“在渊里”——承认疲惫、承认脆弱、承认需要。

朱先生说“鱼不可脱于渊”是人不可脱离根本。母亲的身体告诉我们：**她不能脱离身体的节奏和感受——那就是她的“渊”。她需要回到那个“渊”里——才能知道真正需要什么。**

| 朱邦復的“鱼不可脱于渊” | 母亲经验的“魚不脫於潚” |
| :--- | :--- |
| 人不可脱离根本 | 她不能脱离身体的节奏和感受——那就是她的“渊” |
| 第三人称：根本的不可或缺 | 第一人称：我需要回到我的“渊”里——才知道我需要什么 |


## 八、“邦利器不可以示人”——国家的利器不可以炫耀给人看

### 朱邦復的解读：利器不可炫耀

朱先生将“国之利器不可以示人”解读为“价值的利器不可轻易炫耀”：

> “價值太高的物體或技術，不可輕易炫耀於人。”

“利器”是核心的、可带来大利的东西。你把它炫耀出来——别人会觊觎、会争夺、会利用它来对付你。所以不示人。

### 从母亲经验的解读：母亲的“利器”（她的脆弱、她的付出）不需要向世界展示

“邦利器不可以視人”——在母亲的身体里，“利器”是什么？“示人”是什么？

- **她的“利器”不是用来炫耀的。** 她的付出、她的疲惫、她的“还不够好”——这些不是用来展示给世界看的“证据”。她不需要向任何人证明“我做得很好”。
- **“示人”的问题：** 如果她把自己的“利器”（她的脆弱、她的辛苦）展示出来——她可能会被评价、被比较、被定义。“你看，她多辛苦”不是她需要的——她需要的是“她可以不被评价”。
- **“不可以视人”的另一种理解：** 她不需要把“我经历了什么”展示给别人看。她可以自己知道、自己哀悼、自己走过——不需要向世界展示“我有多难”。

朱先生说“国之利器不可以示人”是利器不可炫耀。母亲的身体告诉我们：**她的脆弱、她的疲惫、她的付出——不需要向世界展示。它们不是用来“证明”的——是用来“经历”的。**

| 朱邦復的“国之利器不可以示人” | 母亲经验的“邦利器不可以視人” |
| :--- | :--- |
| 利器不可炫耀 | 她的脆弱、她的疲惫不需要向世界展示——它们不是用来证明的 |
| 第三人称：策略的隐秘 | 第一人称：我不需要向世界证明“我有多难”——我只需要自己走过 |


## 结语：“微明”是身体的智慧——不显眼，但真实

朱邦復先生在这一章中，用“自然规律的微明”和“柔弱胜刚强”来解读“将欲翕之必固张之”等四组辩证关系——他认为这些是“物极必反”的规律，人如果能掌握这个规律，就可以在“微明”中看到事物的发展方向。他强调“鱼不可脱于渊”是人不离根本，“邦利器不可以示人”是利器不可炫耀。

而母亲的身体，是这一章最完整的“微明”演绎者：

- **“将欲翕之，必固张之”——子宫在收缩之前必须先被撑开。没有“张”就没有“翕”。**
- **“将欲弱之，必固强之”——宫缩在最强峰值之后才开始减弱。没有“强”就没有“弱”。**
- **“将欲去之，必固与之”——孩子要“离开”——母亲必须先“给予”空间。没有“与”就没有“去”。**
- **“将欲夺之，必固予之”——产后她要“夺回”自己——必须先“给予”了九个月。没有“予”就没有“夺”。**
- **“是谓微明”——宫缩的节律不需要被“学习”——身体自己知道。那是“微明”。**
- **“柔弱胜刚强”——产后身体的“弱”（松弛、接纳）胜过“强”（强行恢复）。**
- **“鱼不可脱于渊”——她不能脱离身体的节奏和感受——那是她的“渊”。**
- **“邦利器不可以示人”——她的脆弱和付出不需要向世界展示——它们不是用来证明的。**

**“微明”——这个道理“微”到看不见——但“明”到身体完全知道。** 母亲的身体不需要学习“翕张”的规律——它一直在“翕张”（宫缩、呼吸、心跳）。它不需要理解“强弱”的辩证——它一直在经历“强弱”（产后的起伏）。它不需要被“示人”——它的“利器”在深处运作，不被看见，但持续有效。

母亲的身体就是“微明”最日常的版本。它不声张——但它运作。它不炫耀——但它完成。它不解释——但它知道。它用宫缩证明了“张而后翕”、用分娩证明了“强而后弱”、用产后恢复证明了“予而后夺”和“弱胜强”。那不是“权谋”——那是“身体”。

一个母亲的身体，不需要读《道德经》来理解“将欲翕之必固张之”——她的子宫在分娩时已经经历了完整的“翕张”循环。她不需要被“教”柔弱胜刚强——她恢复的方式，就是用“柔”来面对身体的“弱”。她不需要“示人”她的“利器”——她的能力在深处工作，不被看见，但让生命得以持续。



## 引言：最“政治”的一章，最“日常”的母职

帛书本第十七章，是《德道经》中关于统治类型与信任关系最集中的论述：

> 大上下知有之，其次親譽之，其次畏之，其下母（侮）之。
>
> 信不足，案（安）有不信。猶呵其貴言也。
>
> 成功遂事，而百省（姓）胃（謂）我自然。

“太上，下知有之”——最高层次的治理，人民仅仅知道有统治者存在。“其次，亲而誉之”——其次的，人民亲近他、赞美他。“其次，畏之”——再次的，人民畏惧他。“其下，侮之”——最差的，人民轻蔑他、侮辱他。“信不足焉，有不信焉”——诚信不足，才会产生不信。统治者要谨慎啊，不轻易发号施令。等到功业成就、事务完成，百姓说：“我们本来就是这样自然的。”

朱邦復先生在《止笑譚》中，将这一章解读为 **“统治者类型的层级与诚信的关系”** 。他认为“太上”是不知有之的最高境界——像阳光、空气、水，人人需要却感觉不到其存在。“其次”是亲誉之——“爱戴而褒誉其君”；“其次”是畏之——“畏惧其君”；“其下”是侮之——“反感而加以侮辱”。他把“信不足焉，有不信焉”解读为“君主诚信不足，人民无法信任他”，“贵言”则是“绝少发言干预”，最后以“功成事遂，百姓皆谓我自然”作为无为而治的终极证明。

但如果我们把主语换成“母亲”——那个每天都在养育、教导、陪伴、放手的身体——这一章就不再是“政治学”，而是**一份关于“母亲的四种存在方式”的清晰图谱**：

- “太上下知有之”——最高级的母亲，她的存在像空气。孩子不会每天说“妈妈真好”，但他饿了有奶、困了有抱、怕了有她在。他活着，她在；他不需要时刻确认她在。她存在，但她的存在方式是“不被注意的支持”。
- “其次亲誉之”——第二级的母亲，孩子会说“妈妈我爱你”、“妈妈是最好的”。好。但孩子已经意识到“妈妈在为我做事”了。多了一层语言，也多了一层距离。
- “其次畏之”——第三级的母亲，孩子怕她。不是因为“尊敬”，是因为“惩罚的威胁”。孩子听话，但听话的原因不是信任，是恐惧。
- “其下侮之”——最糟糕的，孩子轻视她、不尊重她、觉得“你什么都不懂”。

“信不足焉，有不信焉”——如果母亲不可信、说了不做、承诺不兑现，孩子就不会信任她。而最高级的母亲——她“贵言”：不说那么多、不教那么多、不指挥那么多。她只是做——她喂、她抱、她陪、她等。孩子长大了，别人说“你妈妈真不容易”，孩子回答：“是吗？我觉得我一直是自然就这样长大的。”

这才是最高级的“为”。你做了所有的事，但孩子不觉得自己“被塑造”了——他只是觉得自己“自然”地成了现在的样子。这就是“百姓皆谓我自然”在养育场景中的含义：你存在的痕迹越不可见，你的影响越深入。

让我们逐句对照。


## 一、“太上下知有之”——最高级的存在，仅仅被知道

### 朱邦復的解读：存在但不被注意，是最高的治理境界

朱先生将“太上，不知有之”解读为“人民不知有其君”：

> “治理國家最高的境界，是人民不知有其君。”

“不知有之”不是“不存在”，而是“存在但不被注意”。像空气一样——你呼吸它，但你不觉得“我在呼吸空气”。像水一样——你喝它，但你不觉得“我在喝这杯水”。最高级的统治者就是这样：他在，但他不显眼。

### 从身体经验出发：最高级的母亲——她存在，但孩子不觉得“被管理”

“太上，下知有之”——一个母亲做到最高级，是什么状态？

- **孩子饿了，奶来了。** 他不会想“妈妈给我奶”——他只是吃。奶在。
- **孩子困了，怀抱来了。** 他不会想“妈妈哄我睡”——他只是睡。怀抱在。
- **孩子害怕了，声音来了。** 他不会想“妈妈在保护我”——他只是安心。妈妈在。
- **他不觉得“被管理”。** 他不觉得有一个“权力者”在控制他的生活。他只是活着——而那个让“活着”得以可能的存在，一直“在”，但他不“看见”她。
- **“下知有之”中的“下”字有一个重要提醒：** “下”不仅是“下面、下级”，也是“低处”。最高级的母亲像水一样——她处在“下”位：蹲下来、弯下腰、把自己放低。她不站在高处发号施令，她在低处托举。“下知有之”的意思就是：你在低处存在，但你托起了整个生命。

朱先生说“太上不知有之”是“人民不知有其君”，最高境界的治理是“存在但不被注意”。母亲的身体告诉我们：**最高级的养育是——你存在，但不显眼；你做了所有事，但孩子不觉得“被做了”。他活着，而你是让他活着的前提。**

| 朱邦復的“太上不知有之” | 母亲经验的“太上下知有之” |
| :--- | :--- |
| 存在但不被注意——像空气、像水 | 奶在、怀抱在、温度在——但不被“看见”，只在“使用” |
| 第三人称：政治学的最高境界 | 第一人称：我不说“我为你做了多少”——我只是做 |


## 二、“其次親譽之”——其次的，被亲近赞美

### 朱邦復的解读：被爱戴的统治者

朱先生将“其次，亲而誉之”解读为“人民爱戴而褒誉其君”：

> “其次是人民愛戴而褒譽其君。”

这个层次的统治者“做了好事”，人民“看见了他”，人民“赞美了他”。这说明他已经“被看见了”——他不是隐形的。他已经进入了“被评价”的范畴。

### 从身体经验出发：孩子会说“妈妈我爱你”

“其次親譽之”——一个母亲进入这个层级，是什么状态？

- **孩子会说“妈妈我爱你”。** 她已经进入了“被看见”的状态——孩子意识到“妈妈在为我做事”，于是产生了“感谢”和“赞美”。
- **“親譽之”说明距离已经产生了。** 你不再是“空气”——你是一个“被看见的人”。孩子赞美你，说明他已经能够把你作为一个独立的“对象”来看待——你不是“他存在的背景”，你是“一个为他服务的人”。
- **这不是“不好”。** 这是一种“好”，是自然的、健康的。孩子会赞美妈妈，说明他有感恩心、有语言能力、有情感表达能力。只是它已经不是“最高级”的——因为“赞美”本身就意味着你已经被“注意”了。

朱先生说“亲而誉之”是被爱戴的统治者。母亲的身体告诉我们：**孩子说“妈妈我爱你”是好的——但这时候距离已经产生了。他赞美你，说明他已经注意到“你在为他做事”了。这不是“最高级”，但它是“正常的好”。**

| 朱邦復的“亲而誉之” | 母亲经验的“亲而誉之” |
| :--- | :--- |
| 被人民爱戴、赞美 | 孩子会说“妈妈我爱你”“妈妈最好” |
| 第三人称：治理的第二层级 | 第一人称：他赞美我——说明他“看见”我了 |


## 三、“其次畏之”——再次的，被畏惧

### 朱邦復的解读：被畏惧的统治者

朱先生将“其次，畏之”解读为“人民畏惧其君”：

> “人民畏懼其君。”

这个层次的统治者用权力、惩罚、威胁来维持秩序。人民服从他，不是因为“信任”或“爱戴”，而是因为“害怕”。

### 从身体经验出发：孩子因为怕你而听话

“其次畏之”——一个母亲进入这个层级，是什么状态？

- **孩子因为怕你而听话。** 不是因为“妈妈会难过”而听话——是因为“妈妈会生气、会惩罚我”而听话。怕你。
- **“畏”养育的后果：** 孩子会变得谨慎、掩饰、回避——他不做你禁止的事，不是因为他理解了为什么不能做，而是因为他害怕后果。但当他不在你视线范围内时，他可能会做相反的事——因为驱动他的不是“内在理解”，是“外部恐惧”。
- **这里有一个重要的区别：** 孩子“畏”你，不是因为你“强势”——可能是因为你“太不可预测”、情绪不稳定、今天答应的事情明天改变、让他永远不知道“接下来会发生什么”。他不是在怕一个“明确的规则”——他是在怕一个“不可预测的系统”。

朱先生说“畏之”是人民畏惧统治者。母亲的身体告诉我们：**孩子因为怕你而听话——不是因为尊敬或理解，是因为恐惧。不可预测的情绪、不稳定的回应、不一致的规则——这些会让孩子“畏”你。**

| 朱邦復的“畏之” | 母亲经验的“畏之” |
| :--- | :--- |
| 被人民畏惧的统治者 | 孩子因为怕你而听话——因为情绪不稳定、规则不一致 |
| 第三人称：治理的第三层级 | 第一人称：他怕我——不是因为尊重，是因为不知道“接下来会怎样” |


## 四、“其下侮之”——最差的，被轻蔑侮辱

### 朱邦復的解读：被侮辱的统治者

朱先生将“其次，侮之”解读为“令人民反感而加以侮辱”：

> “最糟糕的，則是令人民反感而加以侮辱。”

这个层次的统治者已经失去了所有合法性——人民不仅不服从他，还轻视他、嘲笑他、反抗他。这是治理的彻底失败。

### 从身体经验出发：孩子觉得“你什么都不懂”

“其下侮之”——一个母亲进入这个层级，是什么状态？

- **孩子觉得“你什么都不懂”。** 他不再把母亲当作“权威”——他把母亲当作“无知的、过时的、不值得尊重的人”。
- **“侮之”的表现：** 孩子会翻白眼、说“你根本不懂”、拒绝沟通、故意在母亲面前做她反对的事来“挑衅”她。不是因为他要“证明自己”——是因为他已经不在乎她的意见了。
- **“侮”不是“反抗”是“轻视”。** 反抗还有能量——至少说明“你的态度对他有影响”。轻视是“你的态度已经不重要了”。你在他眼中已经不是“值得认真对待的人”了。

朱先生说“侮之”是人民侮辱统治者。母亲的身体告诉我们：**孩子轻视你、觉得“你什么都不懂”、拒绝沟通——这是“侮”。你已经失去了他眼中的“位置”。**

| 朱邦復的“侮之” | 母亲经验的“侮之” |
| :--- | :--- |
| 被人民侮辱的统治者 | 孩子觉得“你什么都不懂”、翻白眼、拒绝沟通 |
| 第三人称：治理的最底层 | 第一人称：他已经不在意我怎么想了——这是最差的 |


## 五、“信不足，案有不信”——诚信不足，才会有不信

### 朱邦復的解读：不信任源于失信

朱先生将“信不足焉，有不信焉”解读为“诚信不足，人民当然不信任”：

> “這種君主，本來就誠信不足，人民當然無法信任他。”

“信”是统治者与人民之间的黏合剂。当统治者失信了——承诺不兑现、规则不透明、惩罚不可预期——人民的“信”就会断裂。所以“有不信”——不是人民“不信任”是天性，是统治者的“信不足”导致了“不信”。

### 从身体经验出发：如果你不可靠，孩子不会信任你

“信不足，案有不信”——在母亲与孩子的关系中，“信”是什么？

- **“信”是最基础的契约：** “哭了会有人来”——如果这件事在三个月时成立，孩子会建立一个“世界是可信的”预期。如果时来时不来、有时来有时不来，他会建立“世界是不可预测的”预期。
- **“信不足”的表现：** 你说“等你吃完饭我们就出去玩”——然后你食言了。你说“我马上就来”——然后你很久才来。你说“不会再这样了”——然后又这样了。每一次“不信”都在削弱孩子对你的“信”。
- **结果：** 孩子不再相信你的承诺。你说话，他听着，但心里在打问号——“她这次说的会是真的吗？”这就是“有不信”。不是孩子天性多疑——是你给的证据不够“可信”。

朱先生说“信不足焉，有不信焉”——统治者失信，人民就不信。母亲的身体告诉我们：**你可靠，他才会信任你。每一次食言都在削弱他心里的“妈妈是可信的”。**

| 朱邦復的“信不足焉有不信焉” | 母亲经验的“信不足焉有不信焉” |
| :--- | :--- |
| 统治者失信，人民就不信任 | 你食言、不可预测——孩子就会不再相信你的承诺 |
| 第三人称：政治信任的逻辑 | 第一人称：他不再相信我说的“马上来”——因为我“马上”了很多次 |


## 六、“猶呵其貴言也”——慎重啊，不轻易发号施令

### 朱邦復的解读：少说多做

朱先生将“悠兮其贵言”解读为“绝少发言干预”：

> “境界最高的國君，每日悠悠哉哉，絕少發言干預。”

“贵言”——把“说”看作珍贵的、不轻易使用的。不是因为“无话可说”，是因为“说的多了，就不值钱了”。最高的统治者不靠“下命令”来治理——他靠“设计环境”、“建立制度”、“以身作则”。

### 从身体经验出发：母亲不靠“说”来教——她靠“做”

“猶呵其貴言也”——一个母亲“贵言”是什么意思？

- **她不靠“说”来教——她靠“做”来示范。** 她不说“你要安静”——她轻声说话；她不说“你要有耐心”——她耐心等他；她不说“要尊重别人”——她尊重他。
- **“贵言”是“不说那么多废话”。** 孩子不听“你说了什么”——他看你做了什么。每多一句“你应该”，你就多了一层距离。她不是在“管理”他——她是在“让他看到”如何生活。
- **“贵言”的另一个层面：** 她不说“我爱你”——她做“爱”。喂奶、拥抱、陪伴——这些都不需要说“我爱你”。孩子感受到的是“被爱”，而不是“听到‘我爱你’这句话”。

朱先生说“贵言”是统治者少发号施令。母亲的身体告诉我们：**她不说“你应该怎样”——她做“应该怎样”。孩子不是听出来的，是看出来的。话越少，影响力越深。**

| 朱邦復的“贵言” | 母亲经验的“贵言” |
| :--- | :--- |
| 统治者少发号施令 | 母亲不说“我爱你”——她做爱；不说“你要有耐心”——她耐心等他 |
| 第三人称：治理者的言语克制 | 第一人称：我不说那么多——我做给他看 |


## 七、“成功遂事而百姓謂我自然”——功成事遂，百姓说“我们自然如此”

### 朱邦復的解读：最高境界——做了，但没有人觉得“被做了”

朱先生将“功成事遂，百姓皆谓我自然”解读为“做成了，但不居功”：

> “等到社會安定，百姓生活幸福時，人尚不知其功，認為：我們是自然如此的。”

最高境界的“做”是：你做成了，但不居功。人民不觉得“是统治者在帮我们”——他们觉得“我们本来就是这样”。这符合第二章“功成而弗居”的原则——不占有、不宣示、不邀功。

### 从身体经验出发：孩子长大了，说“我一直都是这样长大的”

“成功遂事而百姓謂我自然”——一个母亲做到最高级，是什么状态？

- **孩子长大了，成为一个健康、独立、有安全感的人。** 有人问他：“你妈妈是怎么教你的？”他想了想，说：“我也不知道。我一直就是这样长大的。”
- **他不觉得“被塑造”。** 他不觉得“妈妈把我变成了这样”——他觉得“我就是这样”。但他确实是在母亲的日复一日的回应、保护、陪伴中长成这样的。
- **“謂我自然”的深层含义：** 孩子不记得那些具体的“教育时刻”——他不记得妈妈半夜起来喂奶、不记得妈妈蹲下来系鞋带、不记得妈妈耐心的陪伴——但他成了那个被这些时刻塑造出来的“自然”的自己。他的“自然”不是天生的——是母亲用无数个不被注意的瞬间“做”出来的。

朱先生说“百姓皆谓我自然”——人民不觉得“被治理了”，只觉得“自然如此”。母亲的身体告诉我们：**孩子不记得你做了什么——但你就是他“自然”长成的前提。他觉得自己“本来就是这样”——但他本来的一切，都曾被你日复一日的存在所塑造。**

| 朱邦復的“百姓皆谓我自然” | 母亲经验的“百姓皆谓我自然” |
| :--- | :--- |
| 人民觉得“自然如此”，不觉得被治理了 | 孩子觉得“我一直就是这样长大的”——不记得你做了什么，但你就是他长成的前提 |
| 第三人称：无为而治的最高证明 | 第一人称：他不记得我做的那些事——但他成了那些事塑造出来的人 |


## 结语：存在的四种方式，与最高级的“存在”

朱邦復先生在这一章中，用“统治者与人民的关系”来区分四种层级：不知有之、亲而誉之、畏之、侮之。他特别强调了“信不足焉，有不信焉”的信任逻辑，以及“贵言”和“自然”作为最高境界的特征。

但母亲的身体告诉我们：**这四种层级同样适用于养育——而且母亲每天都在其中选择（或者无意识地处于其中）。**

- **“太上下知有之”——最高级的母亲。** 她存在，但孩子不觉得“被管理”。饿了有奶、困了有抱、怕了有她在。她的“在”是孩子活着的条件，但孩子不“看见”她——正如鱼不“看见”水。她处在“下”位——蹲下来、弯下腰、把自己放低——正是因为她处在最低处，孩子才能被托举到最高处。
- **“其次亲誉之”——孩子赞美母亲。** “妈妈我爱你”、“妈妈最好”。这是健康的，但已经不再是最高境界——因为赞美本身意味着“距离”已经出现。他已经能够把你当作一个“对象”来评价了。
- **“其次畏之”——孩子怕母亲。** 因为怕而听话。不是信任，是恐惧。不可预测的情绪、不稳定的规则、不一致的回应——让孩子不敢靠近你，不敢信任你。
- **“其下侮之”——孩子轻视母亲。** “你什么都不懂”、“你根本不知道”——他已经不再把你当作值得认真对待的人了。这是最深的断裂。

“信不足焉，有不信焉”——信任不是“天生的”，是需要被“证明”的。你说“我马上来”，然后你真的来了——这就是“信”的证据。你每次说了做不到、承诺了不兑现——“信”就在一次次地被磨损。

“犹呵其贵言也”——她不说那么多。她不多教。她不多指挥。她只是做。奶在、怀抱在、温度在。

“成功遂事而百姓谓我自然”——孩子长大了，成为他自己。他不记得妈妈做了什么——他不记得那些夜晚、那些等待、那些耐心的回应。但他成了那个被这些瞬间塑造出来的人。他不会说“是妈妈把我变成这样的”——他说“我自然就是这样”。

**一个母亲最大的成就不是被赞美——是被遗忘。“下知有之”——她的存在被吸收了、被内化了、被忘记了。她不再是一个“需要被记住的人”——她是孩子成为他自己的前提。她处在下位——也正是因为她在最低处，孩子才能长到最高处。**



## 引言：最“做人”的一章，最“母亲”的放下

帛书本通行本第二十四章（帛书对应段落），是《德道经》中关于“自见、自伐、自矜”等自我膨胀行为的集中批判：

> 炊者不立，自視（示）不章，自見者不明，自伐者无功，自矜者不長。其在道，曰：『𥺌（餘）食、贅行。』物或惡之，故有欲者弗居。

“炊者不立”——踮起脚尖（企）的人站不稳。“自視不章”——自我表现的人不彰显。“自見者不明”——自我显露的人不明达。“自伐者无功”——自我夸耀的人没有功劳。“自矜者不长”——自我骄傲的人不能长久。

“其在道”——在道看来，“曰『餘食贅行』”——这些行为就像“吃剩的食物、身上多余的赘肉”。“物或惡之”——连事物都厌恶它，“故有欲者弗居”——所以有道之人不会这样做。

朱邦復先生在《止笑譚》中，将这一章解读为 **“自见自伐者的行为是多余的负担”** 。他认为“企者不立，跨者不行”是“踮脚站不稳、跨步不能走”——都是不自然、不稳定的行为；“自见者不明，自是者不彰，自伐者无功，自矜者不长”是“自我表现、自以为是、自我夸耀、骄傲自大”都不能长久；“馀食赘行”是“吃剩的食物、身上的赘肉”——人人厌恶，所以有道者不处。

但如果我们把主语换成“母亲的身体”——那个在产后急于“企”（快点恢复）、急于“自见”（证明自己是好妈妈）、急于“自伐”（数算自己的付出）、急于“自矜”（在接受赞美时不敢放松）的身体——这一章就不再是“做人的道理”，而是一份 **“关于母亲如何放下‘企’、放下‘自见’、放下‘自伐’、放下‘自矜’，从‘有余食赘行’回到‘弗居’”的日常记录**：

- “炊者不立”——产后急于“站起来”（快点恢复、快点回到状态），反而站不稳。她“企”了——但她没有“立”。
- “自視不章”——她急于展示自己“恢复得很好”、“我是一个好妈妈”——但越是“自视”，越不“章”（彰显）。因为真正的“章”不需要“示”。
- “自見者不明”——她急于“被看见”——发朋友圈、告诉别人“我多辛苦”——但“自见”反而让她“不明”（看不清真正重要的事）。真正的“明”不需要“见”。
- “自伐者无功”——她数算自己的付出——“我做了这个、那个、那么多”——但“自伐”反而让她“无功”。真正的“功”不需要“伐”。
- “自矜者不长”——她接受别人的赞美时“矜”（自得、放不下）——“是啊，我确实不容易”——但“自矜”反而让她“不长”。真正的“长”不需要“矜”。
- “餘食贅行”——那些“急于证明自己”的行为，就像“吃剩的食物、身上多余的赘肉”——是多余的、该放下的。
- “物或惡之”——连她的身体都厌恶那些“急于”和“证明”。身体说“够了”——但她还在“自见”。
- “故有欲者弗居”——所以有道之人（有智慧的母亲）不“居”于那些行为。她放下“企”、放下“自见”、放下“自伐”、放下“自矜”——她不“居”在那里。


## 一、“炊者不立”——踮脚的人站不稳

### 朱邦復的解读：不自然的姿态无法持久

朱先生将“企者不立”解读为“踮脚站不稳”：

> “舉著腳跟的站不穩。”

“企”是踮起脚尖——想让自己显得更高。但那个姿态是不自然的——无法持久。

### 从母亲身体的经验出发：产后急于“站起来”（快点恢复、快点回到状态）——反而站不稳。她“企”了——但没有“立”

“炊者不立”——在母亲的身体里，“炊”是什么？“不立”是什么？

- **她“企”了——产后急于“恢复”。** 她想要快点“站起来”——快点回到产前的状态、快点证明“我已经好了”。那是“企”——踮着脚尖、想显得“已经好了”。
- **结果——“不立”。** 她站不稳。身体还没准备好——“企”着反而让她更累、更慢、更不稳。
- **“炊者不立”的深层含义：** 母亲不能“企”着恢复。她不能“踮脚”假装自己“已经好了”。她需要“脚踏实地”——允许自己“还没好”、允许自己“慢”。那不是“后退”——是“站稳”。

朱先生说“企者不立”是踮脚站不稳。母亲的身体告诉我们：**她急于“站起来”反而站不稳。“企”是踮脚假装“已经好了”——她需要脚踏实地，承认“还没好”。**

| 朱邦復的“企者不立” | 母亲经验的“炊者不立” |
| :--- | :--- |
| 踮脚站不稳 | 她急于“站起来”反而站不稳——“企”着假装“好了”，她需要脚踏实地 |
| 第三人称：不自然的姿态 | 第一人称：我不能“企”——我需要“立”在地上 |


## 二、“自視不章”——自我表现的不彰显

### 朱邦復的解读：自见者不明

朱先生将“自见者不明”解读为“爱表现的人无法彰显自我”：

> “愛表現的人反而無法彰顯自我。”

当你“自见”（刻意展示自己）时——你反而“不明”（不被看见）。因为你的注意力在“如何被看见”上——而不是在“做”本身。

### 从母亲身体的经验出发：她急于展示“我恢复得很好”、“我是个好妈妈”——但越是“自視”，越不“章”

“自視不章”——在母亲的身体里，“自視”是什么？“不章”是什么？

- **她“自視”——急于展示。** 她发朋友圈“我终于恢复体形了”、她告诉别人“我都是自己带孩子的”、她展示“我很棒”的证据。那是“自視”。
- **结果——“不章”。** 她越展示——越不“章”（彰显）。因为真正的“章”不需要“示”——它自己会“章”的。她“自視”了——反而看不清“真正重要的事”。
- **“自視不章”的深层含义：** 母亲不需要“展示”她的恢复——恢复会自己“章”。不需要“展示”她是好妈妈——孩子会自己“章”。她“自視”了——反而挡住了那个“章”。

朱先生说“自见者不明”是自我表现的不彰。母亲的身体告诉我们：**她越展示“我很好”——越不“章”。真正的“章”不需要“示”。**

| 朱邦復的“自见者不明” | 母亲经验的“自視不章” |
| :--- | :--- |
| 自我表现的不彰 | 她越展示“我很好”——越不“章”。真正的“章”不需要“示” |
| 第三人称：展示的悖论 | 第一人称：我不“示”了——它自己会“章” |


## 三、“自見者不明”——自我显露的不明达

### 朱邦復的解读：自见者不明

朱先生将“自见者不明”解读为“自以为是的人难以被接受”：

> “自以為是的人難以被人接受。”

“自见”是“自以为是”、“突出自己”。“不明”是“不明达”。当你“自见”时——你反而看不到自己之外的东西。

### 从母亲身体的经验出发：她急于“被看见”——发朋友圈、告诉别人“我多辛苦”——但“自見”让她看不清真正重要的

“自見者不明”——在母亲的身体里，“自見”是什么？“不明”是什么？

- **她“自見”——急于“被看见”。** 她需要别人看见她的辛苦、承认她的付出、说“你太不容易了”。那是“自見”——她把自己的“辛苦”放到前面。
- **结果——“不明”。** 她越“自見”——越看不清“真正重要的事”。她忙着被看见——没空看见孩子。她“自見”了——但“不明”。
- **“自見者不明”的深层含义：** 母亲不需要“被看见”才能确认自己的价值。她“自見”了——反而看不清。她放下“自見”——才能“明”（看清楚什么真正重要）。

朱先生说“自见者不明”是自以为是的人不彰。母亲的身体告诉我们：**她急于被看见——反而看不清。放下“自見”——才能“明”。**

| 朱邦復的“自见者不明” | 母亲经验的“自見者不明” |
| :--- | :--- |
| 自以为是的人不彰 | 她急于被看见——反而看不清。放下“自見”——才能“明” |
| 第三人称：自见的代价 | 第一人称：我不“见”了——我才能“明” |


## 四、“自伐者无功”——自我夸耀的没有功劳

### 朱邦復的解读：自伐者无功

朱先生将“自伐者无功”解读为“自我夸耀的人没有功劳”：

> “爭強好勝的人不會成功。”

“自伐”是自我夸耀、数算自己的功劳。“无功”是“没有真正的功劳”——因为你数算的时候，功就“散”了。

### 从母亲身体的经验出发：她数算自己的付出——“我做了这个、那个”——但“自伐”反而让她“无功”

“自伐者无功”——在母亲的身体里，“自伐”是什么？“无功”是什么？

- **她“自伐”——数算自己的付出。** “我做了这么多”、“我付出了那么多”、“我为你牺牲了那么多”——那是“自伐”。她把自己的付出放在前面数。
- **结果——“无功”。** 她越数算——越“无功”。因为“功”不是数出来的——是做出来的。她数了——反而把功“散”了。
- **“自伐者无功”的深层含义：** 母亲不需要数算自己的付出。真正的“功”不需要“伐”——它已经在了。她“自伐”了——反而“无功”。她放下“伐”——功才在。

朱先生说“自伐者无功”是自我夸耀的人没功劳。母亲的身体告诉我们：**她越数算付出——越“无功”。真正的“功”不需要“伐”——它已经在了。**

| 朱邦復的“自伐者无功” | 母亲经验的“自伐者无功” |
| :--- | :--- |
| 自我夸耀的人没功劳 | 她越数算付出——越“无功”。真正的“功”不需要“伐” |
| 第三人称：自伐的代价 | 第一人称：我不“伐”了——功在 |


## 五、“自矜者不长”——自我骄傲的不能长久

### 朱邦復的解读：自矜者不长

朱先生将“自矜者不长”解读为“骄傲自大的人不会长久”：

> “驕傲自大的人不能維持長遠。”

“自矜”是自得、骄傲、放不下自己的“付出”和“功劳”。“不长”是不能长久——因为你“矜”在那里，就不动了。

### 从母亲身体的经验出发：她接受别人的赞美时“矜”住了——“是啊，我确实不容易”——但“自矜”让她“不长”

“自矜者不长”——在母亲的身体里，“自矜”是什么？“不长”是什么？

- **她“自矜”——在接受赞美时放不下了。** “是啊，我真的不容易”、“我确实付出了很多”——那是“自矜”。她停在那里了——享受那个“被承认”的感觉。
- **结果——“不长”。** 她“矜”住了——就不长了。因为“长”需要“不矜”——需要“放下”、需要“继续走”。她“自矜”了——就停在那里了。
- **“自矜者不长”的深层含义：** 母亲不需要“矜”住“被承认”的感觉。她不“矜”——才能继续“长”。她放下了——才能继续走。

朱先生说“自矜者不长”是骄傲自大的人不长久。母亲的身体告诉我们：**她“矜”住了——就不长了。放下“矜”——才能继续走。**

| 朱邦復的“自矜者不长” | 母亲经验的“自矜者不长” |
| :--- | :--- |
| 骄傲自大的人不长久 | 她“矜”住了——就不长了。放下“矜”——才能继续走 |
| 第三人称：自矜的代价 | 第一人称：我不“矜”了——我继续走 |


## 六、“其在道，曰：『余食赘行。』”——在道看来，这是“剩饭赘肉”

### 朱邦復的解读：余食赘行是多余的东西

朱先生将“余食赘行”解读为“吃剩的食物、身上多余的赘肉”：

> “餘食贅行。”

“余食”是吃剩的饭——多余、不需要。“赘行”是身上的赘肉——多余、该去掉。那些“自见、自伐、自矜”的行为——就像“余食赘行”——是多余的。

### 从母亲身体的经验出发：那些“急于证明自己”的行为，就像“余食赘行”——多余、该放下

“餘食贅行”——在母亲的身体里，“余食赘行”是什么？

- **她的“急于恢复”是“余食”。** 那种“我必须快点好”的焦虑——是多余的。身体不需要那个压力——它只需要时间。那是“余食”——该放下。
- **她的“证明自己是好妈妈”是“赘行”。** 那些“看，我多辛苦”的展示——是多余的。真正的母亲不需要证明——她就在做。那是“赘行”——该放下。
- **“余食赘行”的深层含义：** 母亲需要识别那些“多余”的东西——那些“急于”、“证明”、“展示”、“数算”、“矜住”——都是“余食赘行”。她可以放下它们——不带走。

朱先生说“余食赘行”是多余的东西。母亲的身体告诉我们：**那些“急于恢复”、“证明自己”是“余食赘行”——多余的，可以放下。**

| 朱邦復的“余食赘行” | 母亲经验的“余食贅行” |
| :--- | :--- |
| 多余的东西 | 那些“急于恢复”、“证明自己”——是“余食赘行”，可以放下 |
| 第三人称：多余的象征 | 第一人称：我不带那些“余食”了 |


## 七、“物或恶之，故有欲者弗居”——连事物都厌恶，所以有道者不处

### 朱邦復的解读：有道者不处于这些行为

朱先生将“物或恶之，故有道者不处”解读为“连一般人都厌恶，有道者更不会做”：

> “連一般人都厭惡這種行為，更何況有道者。”

“物”指人。“恶之”是讨厌。“弗居”是不停留、不处于那些行为中。有道者不会“居”于“自见、自伐、自矜”的状态。

### 从母亲身体的经验出发：她的身体也“恶”那些“急于”——她放下“企”、放下“自见”、放下“自伐”、放下“自矜”——她不“居”于那些

“物或惡之，故有欲者弗居”——在母亲的身体里，“弗居”是什么？

- **她的身体“恶”那些“急于”。** 身体说“够了”——她还在硬撑。身体说“停下来”——她还在前进。那些“急于”和“证明”——身体“恶”之。
- **她“弗居”了**——她放下“企”（不急于恢复）、放下“自见”（不展示）、放下“自伐”（不数算）、放下“自矜”（不矜住）。她不停留于那些“余食赘行”——她“弗居”了。
- **“弗居”的深层含义：** 母亲选择“弗居”——不在那些“急于”和“证明”里停留。她不是说“我不做母亲了”——她是说“我不做‘急切的母亲’了”。她放下了——她“弗居”了。

朱先生说“有道者不处”是有道者不处其中。母亲的身体告诉我们：**她放下“急于”和“证明”——她“弗居”了。不在那里停留。**

| 朱邦復的“有道者不处” | 母亲经验的“弗居” |
| :--- | :--- |
| 有道者不处其中 | 她放下“急于”和“证明”——她“弗居”了。不在那里停留 |
| 第三人称：不处的姿态 | 第一人称：我不“居”了——我走了 |


## 结语：“余食赘行”——母亲放下的负担

朱邦復先生在这一章中，用“自我膨胀的批判”的框架，解读了“企者不立、自见者不明、自伐者无功、自矜者不长”等行为，并归结为“余食赘行”——那些行为就像吃剩的食物、多余的赘肉，连事物都厌恶，有道者不会停留其中。

而母亲的身体，是这一章最完整的“放下余食赘行”的演绎者：

- **“炊者不立”——她急于“站起来”反而站不稳。“企”着假装“好了”，她需要脚踏实地。**
- **“自視不章”——她越展示“我很好”——越不“章”。真正的“章”不需要“示”。**
- **“自見者不明”——她急于被看见——反而看不清。放下“自見”——才能“明”。**
- **“自伐者无功”——她越数算付出——越“无功”。真正的“功”不需要“伐”。**
- **“自矜者不长”——她“矜”住了——就不长了。放下“矜”——才能继续走。**
- **“餘食贅行”——那些“急于恢复”、“证明自己”——是“余食赘行”，可以放下。**
- **“物或惡之”——她的身体也“恶”那些“急于”。**
- **“故有欲者弗居”——她放下“急于”和“证明”——她“弗居”了。**

**“炊者不立”——母亲最深的“不立”是“不企”。** 她不能“踮脚”假装自己“已经好了”。她需要脚踏实地——承认“还没好”、允许“慢”。那不是“后退”——是“站稳”。“企”是假装——“立”是真实。

**“自見、自伐、自矜”——母亲最重的负担。** 她急于“被看见”、急于“数算付出”、急于“矜住被承认”。那些是她肩上的“余食赘行”——她背得太久了。她可以放下它们。不是“不做了”——是“不背了”。

**“弗居”——母亲最深的自由。** 她选择“弗居”——不在那些“急于”和“证明”里停留。她不是说“我不做母亲了”——她是说“我不做‘急切的母亲’了”。她放下了——她“弗居”了。

一个母亲的身体，就是“炊者不立-余食赘行-弗居”最日常的版本。她放下“企”——脚踏实地；放下“自见”——不被看见也“明”；放下“自伐”——不数算也“功”；放下“自矜”——不矜住也“长”。她放下了那些“余食赘行”——她“弗居”了。她不在那里了——她继续走了。

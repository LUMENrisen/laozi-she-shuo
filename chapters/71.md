

## 引言：最“技术”的一章，最“无痕”的母职

帛书本第二十七章，是《德道经》中关于“善”的层次与“无痕”之用的集中论述：

> 善行者无勶（轍）迹，善言者无瑕適（謫），善數者不以檮（籌）𥮥（策）。
>
> 善閉者无（關）籥（𨷲）而不可啟也，善結者无𦄿約而不可解也。
>
> 是以聲（聖）人恒善㤹（救）人，而无棄人，物无棄財，是胃（謂）明。
>
> 故善人，善人之師；不善人，善人之齎（資）也。
>
> 不貴其師，不愛其齎（資），唯（雖）知（智）乎大眯（迷）。是胃（謂）眇（妙）要。

“善行者无辙迹”——善于行走的人不留车辙痕迹；“善言者无瑕谪”——善于言说的人没有可被挑剔的瑕疵；“善数者不以筹策”——善于计算的人不用算筹；“善闭者无关楗而不可启”——善于关闭的人不用门闩却让人打不开；“善结者无绳约而不可解”——善于捆绑的人不用绳索却让人解不开。

所以圣人善于救助人，没有被遗弃的人；善于救助物，没有被遗弃的财物——这就是“明”（袭明、内在的智慧）。

所以善人是不善人的老师；不善人是善人的资源（借镜）。不尊重老师、不爱惜资源——即使自以为聪明，也是大迷惑。这就是“妙要”（精要的奥秘）。

朱邦復先生在《止笑譚》中，将这一章解读为 **“至善无为”的五个例证**。他认为“善行、善言、善数、善闭、善结”都是“知其必然，顺物之性”的表现——不需要工具、不需要痕迹、不需要外在的手段。他特别强调了“圣人常善救人，故无弃人”——真正的圣人能看到每个人的可用之处，不会抛弃任何人；“不善人，善人之资”是“不善之人是善人的借镜”——善人通过观察不善人来反观自己、警醒自己。

但如果我们把主语换成“母亲的身体”——那个每天都在“不留下痕迹地”照顾、引导、陪伴孩子的身体——这一章就不再是“至善的五个技巧”，而是一份 **“母亲如何‘无痕’地养育”的完整图谱**：

- “善行者无辙迹”——母亲抱着孩子在房间里来回走，不会留下脚印。她的“行”是无声的、不留下痕迹的。她走了一万步，但没有一处地板被磨损。
- “善言者无瑕谪”——母亲对孩子说的话，没有“可被挑剔的瑕疵”吗？有的。但孩子不记得那些“瑕疵”——孩子记得的是“妈妈的声音”。她的话语不是在传递“完美的信息”——她是在传递“我在”。
- “善数者不以筹策”——母亲不用计算器来判断孩子是否吃饱、是否发育正常。她用“手”（摸他的肚子）、“眼”（看他的表情）、“心”（感受他的节律）——她不依赖“筹策”（工具）。
- “善闭者无关楗而不可启”——母亲的“闭”是什么？是她放下手机、关上门、切断外界干扰——不是为了“锁住”孩子——是为了让他在她的专注中感到安全。她不需要锁——她的在场就是最牢固的“关楗”。
- “善结者无绳约而不可解”——脐带被剪断了，但母亲和孩子之间的“结”仍然存在。不需要绳子——那是“无绳之结”。你解不开它，因为它不是物理的。
- “圣人恒善救人，而无弃人”——母亲不会“抛弃”任何一个孩子。她不会说“这个孩子太麻烦”——她会说“他需要更多耐心”。
- “善人，善人之师；不善人，善人之资”——第一个孩子是你的“师”；第二个孩子（和你“作对”的那个）是你的“资”。你从“不好带的”孩子身上学到的东西，可能比从“好带的”孩子身上更多。
- “不贵其师，不爱其资”——如果只尊重“好带的孩子”而不感谢“难带的孩子”——你就失去了从不同经历中学习的可能性。“师”（好带的）和“资”（难带的）同样珍贵。
- “是谓妙要”——母亲懂这个“妙要”。她从每一个孩子身上——无论“善”还是“不善”——都学到了如何成为更完整的母亲。

让我们逐句对照。


## 一、“善行者无辙迹”——善于行走的人不留车辙痕迹

### 朱邦復的解读：顺物之性，不留痕迹

朱先生将“善行无辙迹”解读为“善于行走的人走得不留痕迹”：

> “善走者，行路不落痕跡。”

他的逻辑是：“善”不是“走得快”——是“走得顺”。顺应地形、不硬踩、不留下破坏的痕迹。至善的“行”是“无痕”的——不是因为它不存在，而是因为它不干扰、不破坏、不留下“我做过了”的证明。

### 从身体经验出发：母亲抱着孩子在房间里来回走——走了一万步，但没有一处地板被磨损

“善行者无勶迹”——在母亲的身体里，“善行”是什么？

- **凌晨三点，你抱着哭闹的孩子在房间里来回走。** 你走了一万步——从床头到窗边、从窗边到门口、再从门口回到床头。每一步都小心翼翼的——怕吵醒他、怕惊动他、怕他再哭。你走了很多——但地板没有被磨损。你没有留下“我来过”的痕迹。
- **“善行”的另一个层面：** 你弯着腰、弓着背、轻手轻脚——你的“行”不是为了“到达某个目的地”——是为了“让他安静下来”。你的“行”没有“目的地”、没有“痕迹”、没有“可被记录的路程”。
- **母亲一生的“善行”——没有痕迹。** 她走了无数步、做了无数事、付出了无数个夜晚——但这些“行”都不会被记录。没有勋章、没有奖状、没有“运动步数”的统计。她的“行”就是“无痕”的——但它让一个生命安稳地长大了。

朱先生说“善行无辙迹”是善于行走的人不留痕迹。母亲的身体告诉我们：**凌晨三点抱孩子在房间里来回走——那就是“善行”。你走了一万步——但没有一处地板被磨损。你的行是无痕的——但它让一个生命安静下来了。**

| 朱邦復的“善行无辙迹” | 母亲经验的“善行者无勶迹” |
| :--- | :--- |
| 善于行走的人不留痕迹 | 凌晨三点抱孩子在房间里来回走——走了一万步，但没有留下痕迹 |
| 第三人称：至善的行走 | 第一人称：我的行是无痕的——但它让一个生命安静下来了 |


## 二、“善言者无瑕谪”——善于言说的人没有可被挑剔的瑕疵

### 朱邦復的解读：说话恰到好处，无可挑剔

朱先生将“善言无瑕谪”解读为“善于言说的人说话不被挑出毛病”：

> “善言語者，說話不致被人挑出毛病。”

“瑕”是玉上的斑点；“谪”是责备、挑剔。至善的“言”是“无瑕”的——不是因为完美，而是因为恰如其分、不多不少、不造作。

### 从身体经验出发：母亲对孩子说的话——孩子不记得“完美”的话——他记得“妈妈的声音”

“善言者无瑕適”——在母亲的身体里，“善言”是什么？

- **妈妈对孩子说的话，有“瑕疵”吗？有。** 她可能会说错话、会语气不好、会不耐烦、会说“你再这样妈妈就不要你了”——这些都是“瑕”。有可被挑剔的地方。
- **但孩子不记得那些“瑕疵”——他记得的是“妈妈的声音”。** 她哼的歌、她叫他的名字、她在深夜轻声说“妈妈在”——这些不是“完美的语言”——但它们是“孩子需要的语言”。
- **“无瑕”的另一种理解：** 母亲的语言不需要“完美”——它需要“在场”。她说话不是为了“被评判”——她说话是为了“让他听见”。在“被挑剔”的系统里，她的话可能有瑕疵；但在“被听见”的系统里，她的话就是“无瑕”的。
- **“善言”的核心：** 你不是在“传递信息”——你是在“传递存在”。你说“妈妈在这里”——那是无瑕的，因为它是真的。

朱先生说“善言无瑕谪”是善于言说的人说话无可挑剔。母亲的身体告诉我们：**妈妈对孩子说的话，可能有瑕疵——但孩子不记得那些瑕疵。他记得“妈妈的声音”。她的“言”不是用来被评判的——是用来被听见的。**

| 朱邦復的“善言无瑕谪” | 母亲经验的“善言者无瑕適” |
| :--- | :--- |
| 说话恰到好处，无可挑剔 | 妈妈的话可能有瑕疵——但孩子不记得瑕疵，只记得“妈妈在” |
| 第三人称：至善的言说 | 第一人称：我不是在“传递信息”——我是在“传递存在” |


## 三、“善数者不以筹策”——善于计算的人不用算筹

### 朱邦復的解读：不需要工具就能计算

朱先生将“善数不用筹策”解读为“精于计算的人不必假手筹策”：

> “精於計算者，不必假手籌策。”

“筹策”是计算工具（算筹、筹码）。“善数”的人不需要工具——他心中有数，他凭直觉就能“算”。

### 从身体经验出发：母亲不用工具判断孩子是否吃饱——她用“手”（摸）、“眼”（看）、“心”（感受）

“善數者不以檮𥮥”——在母亲的身体里，“善数”是什么？

- **母亲不需要“工具”来判断孩子是否吃饱。** 她没有称重器来称每次吃了多少毫升——她用手摸他的肚子（鼓不鼓）、用眼看他的表情（满不满足）、用心感受他的状态（是不是放松了）。
- **她不需要“算筹”来计算发育是否正常。** 她不用公式、不用图表——她用“手”（摸他的头围）、“眼”（看他是否追视）、“心”（感受他的节奏）。她的“数”不是“数学”的数——是“身体”的数。
- **“不以筹策”的另一个层面：** 她不需要“育儿工具”来“计算”她的爱。她不需要“工具”来判断“我是不是个好妈妈”——她的身体知道，她的直觉知道，她的孩子知道。

朱先生说“善数不用筹策”是善于计算的人不需要工具。母亲的身体告诉我们：**她不需要工具来判断孩子是否吃饱、是否健康——她用手摸、用眼看、用心感受。她的“数”不是数学，是身体。**

| 朱邦復的“善数不用筹策” | 母亲经验的“善數者不以檮𥮥” |
| :--- | :--- |
| 善于计算的人不需要工具 | 用手摸肚子、用眼看表情、用心感受节奏——不需要“工具” |
| 第三人称：至善的计算 | 第一人称：我不需要“工具”——我的身体就是工具 |


## 四、“善闭者无关楗而不可启”——善于关闭的人不用门闩却让人打不开

### 朱邦復的解读：不需要外力就能“闭”

朱先生将“善闭无关楗而不可开”解读为“长于机械者闭门不用门闩，而门不可开”：

> “長於機械者，閉門無須門閂，而門不可開。”

“关楗”是门闩、锁具。“善闭”的人不需要这些外在的工具——他掌握“闭”的原理，所以别人无法打开。

### 从身体经验出发：母亲放下手机、关上门、切断干扰——她的“在场”就是最牢固的“关楗”

“善閉者无關籥而不可啟”——在母亲的身体里，“善闭”是什么？

- **她放下手机、关上门、切断外界的干扰——不是因为“锁住”孩子——是为了“让他感受到她的专注”。** 她不需要“锁”——她的“在场”就是最牢固的“关楗”。她在的时候，孩子就安静了。
- **“善闭”的另一个层面：** 母亲的怀抱——你能“打开”它吗？当孩子在里面的时候，你不能“打开”那个抱。那不是“锁”——那是“包裹”。你不需要用力“关”——你需要的是“在”。
- **“无关楗”不是“无防御”——是“不需要防御”。** 母亲不需要“锁住”门来保护孩子——因为她就在那里。她的“在”本身就是一个“无法被打开”的空间。

朱先生说“善闭无关楗而不可开”是善于关闭的人不用门闩却让人打不开。母亲的身体告诉我们：**她不需要“锁”——她的“在场”就是最牢固的“关楗”。母亲不在的时候，门可以被打开；母亲在的时候，门不需要被关。她的“在”本身就是“闭”。**

| 朱邦復的“善闭无关楗而不可开” | 母亲经验的“善閉者无關籥而不可啟” |
| :--- | :--- |
| 善于关闭的人不用门闩 | 母亲放下手机、专注地陪孩子——她的“在场”就是最牢固的“关楗” |
| 第三人称：至善的关闭 | 第一人称：我不需要锁门——我在这里，他就在安全中 |


## 五、“善结者无绳约而不可解”——善于捆绑的人不用绳索却让人解不开

### 朱邦復的解读：不需要绳子就能“结”

朱先生将“善结无绳约而不可解”解读为“善于结绳的人不用绳子，而让人无法解其结”：

> “能結繩者，不用繩捆，而人無法解其結。”

“绳约”是绳索、捆绑的工具。“善结”的人不需要这些——他掌握“结”的原理，所以别人解不开。

### 从身体经验出发：脐带被剪断了——但母亲和孩子之间的“结”仍然存在——无绳之结

“善結者无𦄿約而不可解”——在母亲的身体里，“善结”是什么？

- **脐带——那是“绳约”吗？** 是。但它在出生时被剪断了。物理的连接断了——但“结”还在。那不是绳子——那是“无绳之结”。
- **“无绳约而不可解”——这个结无法被解开。** 你无法“解开”母亲和孩子之间的连接。那不是物理的、不是法律的、不是任何工具可以“解开”的。它不需要绳子——它比绳子更牢固。
- **“善结”的另一个层面：** 母亲和孩子之间的信任——那是“无绳之结”。即使物理上分开，即使很多年不见，即使说“我不在乎”——那个“结”仍然在那里。你无法“解开”它，因为从来不是用“绳子”系上的。

朱先生说“善结无绳约而不可解”是善于结绳的人不用绳子却让人解不开。母亲的身体告诉我们：**脐带剪断了——但母亲和孩子之间的“结”还在。那是“无绳之结”——你无法解开它，因为它不是用绳子系上的。**

| 朱邦復的“善结无绳约而不可解” | 母亲经验的“善結者无𦄿約而不可解” |
| :--- | :--- |
| 善于结绳的人不用绳索 | 脐带剪断了——但母子之间的“结”还在——那是无绳之结 |
| 第三人称：至善的捆绑 | 第一人称：我们的结不需要绳子——它解不开 |


## 六、“是以圣人恒善救人，而无弃人”——圣人善于救助人，没有被抛弃的人

### 朱邦復的解读：真正有德的人不抛弃任何人

朱先生将“圣人常善救人，故无弃人”解读为“圣人善于助人，故无人不是可用之才”：

> “聖人善於助人，故無人不是可用之才。”

“救”不是“拯救”（从危险中救出）——是“成就、成全”。圣人能看到每个人的独特价值，不会因为“不够好”而抛弃任何人。

### 从身体经验出发：母亲不会“抛弃”任何一个孩子——她不会说“这个孩子太麻烦”——她说“他需要更多耐心”

“聖人恒善救人，而无棄人”——在母亲的身体里，“救”和“弃”是什么？

- **母亲不会“抛弃”任何一个孩子。** 即使他“难带”（爱哭、不睡、挑食、叛逆）——她不会说“这个孩子太麻烦”——她说“他需要更多耐心”。
- **“无棄人”的另一个层面：** 母亲不会抛弃孩子生命中的每一个阶段。婴儿期、幼儿期、儿童期、青春期——每一个阶段都有它的“难度”——但她不会“抛弃”任何一个阶段。她会说“这个阶段会过去”——而不是“我受不了这个阶段”。
- **“救”的深层含义：** 母亲“救”的不是“孩子”——是“孩子成为一个完整的人的可能性”。她看到他的潜能、他的独特、他的“有”——即使他现在看起来“不太好”——她不会“弃”他。

朱先生说“圣人常善救人故无弃人”是圣人不会抛弃任何人。母亲的身体告诉我们：**她不会“抛弃”任何一个孩子——即使他“难带”。她不说“太麻烦”——她说“需要更多耐心”。“救”是“让他成为完整的自己”——她不弃，她就一直在。**

| 朱邦復的“圣人常善救人无弃人” | 母亲经验的“聖人恒善救人而无棄人” |
| :--- | :--- |
| 圣人不会抛弃任何人 | 母亲不会“抛弃”任何一个孩子——即使他“难带”，她说“需要更多耐心” |
| 第三人称：至善的包容 | 第一人称：我不弃——不是因为我伟大，是因为他就是我的“人” |


## 七、“物无弃财”——没有被遗弃的财物

### 朱邦復的解读：万物皆有其用

朱先生将“常善救物，故无弃物”解读为“圣人善于惜物，故无物不能尽其用”：

> “又善於惜物，故無物不能盡其用。”

正如人无弃人——物也无弃物。任何东西都有它的用途，只是你是否“看见”了那个用途。

### 从身体经验出发：母乳用完了、孩子长大了——没有“被遗弃”的阶段——一切都在转化

“物无棄財”——在母亲的身体里，“物”是什么？

- **母乳用完了——它不是“被遗弃”的。** 它完成了使命。它从“喂养”的功能转变为“记忆”的功能——孩子会记得被抱在怀里吃奶的感觉。
- **孩子的衣服穿不下了——它们不是“被遗弃”的。** 它们被收起来、被送给下一个孩子、被做成纪念品。它们“转化”了——不是“废弃”。
- **孩子长大了——他不是“被遗弃”的。** 他的每个阶段都“用完”了——婴儿期、幼儿期、儿童期——但没有一个阶段是“被遗弃”的。它们都在母亲的身体和记忆里“存”着，成为“转化”的一部分。

朱先生说“常善救物故无弃物”是圣人善于惜物，万物皆有其用。母亲的身体告诉我们：**母乳用完了、衣服穿不下了、孩子长大了——它们不是“被遗弃”的——它们完成了使命，然后“转化”了。“弃”是“看不见其转化”——“救”是“看见其转化”。**

| 朱邦復的“常善救物无弃物” | 母亲经验的“物无棄財” |
| :--- | :--- |
| 万物皆有其用 | 母乳用完了、孩子长大了——它们完成了使命，转化了——不是遗弃 |
| 第三人称：至善的惜物 | 第一人称：没有“被遗弃”的阶段——一切都在“转化” |


## 八、“故善人，善人之师；不善人，善人之资”——善人是不善人的老师；不善人是善人的资源

### 朱邦復的解读：善与不善互为借镜

朱先生将“故善人者，不善人之师；不善人者，善人之资”解读为“善人是不善之人的老师，不善之人是善人的借镜”：

> “善人是不善之人的老師，不善之人是善人的借鏡。”

“师”是教你的人，“资”是供你借鉴、警醒的素材。善人不善人不是对立的——它们是相互成就的。善人通过引导不善人而成为善人；不善人通过被善人引导而走向善。两者互为必要条件。

### 从身体经验出发：第一个孩子是你的“师”；第二个孩子（和你“作对”的那个）是你的“资”——你从“不好带的”孩子身上学到的东西，可能比“好带的”更多

“善人，善人之師；不善人，善人之齎”——在母亲的身体里，“师”和“资”是什么？

- **第一个孩子是“师”：** 他教会你怎么换尿布、怎么拍嗝、怎么分辨哭声。他是你的“师”——因为他让你从“不知道”变成“知道”。你感谢他。
- **第二个孩子（“不好带的”那个）是“资”：** 他和你“作对”——不睡、不吃、不配合。他让你“头疼”。但他是你的“资”——因为从他身上你学到了“好带的”孩子不会教你的东西：耐心、变通、灵活性、放下“方法”的执着。他不是“不好的孩子”——他是你的“教材”。
- **“师”和“资”同样珍贵：** 如果只尊重“好带的孩子”（师）而不感谢“难带的孩子”（资）——你就失去了从不同经验中学习的可能性。“资”不是“次等”的——它是“另一种师”。

朱先生说“善人是不善人之师，不善人是善人之资”是善与不善互为借镜。母亲的身体告诉我们：**第一个孩子是“师”——他教会你怎么做妈妈；第二个孩子（难带的那个）是“资”——他教会你如何更完整地做妈妈。“资”和“师”同样重要。**

| 朱邦復的“善人善人之师不善人善人之资” | 母亲经验的“善人善人之師不善人善人之齎” |
| :--- | :--- |
| 善与不善互为借镜 | 第一个孩子是“师”（教会你怎么做妈妈）；难带的孩子是“资”（教会你耐心和变通） |
| 第三人称：教与学的辩证 | 第一人称：我谢谢“好带的”——也谢谢“难带的”，因为两者教会了我不同的事 |


## 九、“不贵其师，不爱其资，虽智大迷”——不尊重老师、不爱惜资源，是最大的迷惑

### 朱邦復的解读：不知“师”与“资”的价值，即使聪明也是迷惑

朱先生将“不贵其师，不爱其资，虽智大迷”解读为“不重视师生关系者，自以为聪明，其实是迷”：

> “不重視師、徒間之互動關係者，雖自以為知，其實是迷。”

如果你不尊重“师”（引导你的人），又不珍惜“资”（供你借鉴的素材）——你就是糊涂。你自以为聪明，但你错过了真正的学习机会。

### 从母亲经验的解读：如果只感谢“好带的孩子”而不感谢“难带的孩子”——你就失去了从全貌中学习的可能性

“不貴其師，不愛其齎”——在母亲的身体里，“不贵其师、不爱其资”是什么？

- **“贵其师”是“感谢第一个孩子教会了你”。** 你承认他的功劳——他让你成为母亲。
- **“爱其资”是“也感谢第二个孩子（难带的）教会了你”。** 你承认他的价值——他让你成为更完整的母亲。
- **如果只“贵师”而不“爱资”——你就失去了从全貌中学习的可能性。** 你会说“老大真好带”——但你不说“老二教会了我很多”。“老大是‘师’——但老二也是‘师’——只是他以‘资’的方式在教你。”
- **“虽智大迷”：** 你觉得自己“懂得怎么带孩子”（因为老大很好带）——但遇到老二你才发现“你什么都不懂”。你“智”了（自以为聪明）——但你“迷”了（因为你只看到了一种可能性）。当你开始“爱其资”（感谢那个难带的孩子教会你更多）——你才从“迷”中走出来。

朱先生说“不贵其师不爱其资虽智大迷”是不知道师与资的价值，即使聪明也是迷。母亲的身体告诉我们：**如果只感谢“好带的孩子”而不感谢“难带的孩子”——你就失去了从全貌中学习的可能性。难带的孩子也是你的“师”——只是他以“资”的方式在教你。当你开始“爱其资”——你才不迷。**

| 朱邦復的“不贵其师不爱其资虽智大迷” | 母亲经验的“不貴其師不愛其齎雖知大眯” |
| :--- | :--- |
| 不尊重师、不爱惜资，是最大的迷惑 | 只感谢“好带的孩子”而不感谢“难带的孩子”——你就失去了从全貌中学习的可能 |
| 第三人称：学习的完整逻辑 | 第一人称：我感谢老大——也感谢老二。他们都是我的“师” |


## 十、“是谓妙要”——这就是精要的奥秘

### 朱邦復的解读：这个道理是精要的奥秘

朱先生将“是谓要妙”解读为“这个道理真是精要奥妙”：

> “這個道理真是精要奧妙。”

“妙要”是最核心的、最精微的东西。它的“妙”在于它不是“书面的逻辑”——是“实践的智慧”。

### 从母亲经验的解读：母亲懂这个“妙要”——她从每一个孩子身上都学到了如何成为更完整的母亲

“是胃眇要”——在母亲的身体里，“妙要”是什么？

- **母亲懂这个“妙要”。** 她不会说“只有好带的孩子才有价值”——她知道“难带的孩子教了她更多”。她不会说“只有乖的孩子才值得爱”——她知道“不乖的孩子更需要爱”。
- **“妙要”的核心：** 你从“师”和“资”身上学到了不同的东西，但它们共同塑造了你——让你从“一个普通母亲”变成了“一个更完整的母亲”。
- **“妙要”的最终落脚点：** 没有“弃”的人，没有“弃”的阶段，没有“弃”的体验——一切都在“转化”为让你成长的东西。这就是母亲从养育中领悟到的“妙要”。

朱先生说“是谓要妙”是这个道理精要奥妙。母亲的身体告诉我们：**她懂这个“妙要”——她从每一个孩子身上都学到了如何成为更完整的母亲。没有“弃”的体验——一切都在“转化”。这就是“妙要”。**

| 朱邦復的“是谓要妙” | 母亲经验的“是胃眇要” |
| :--- | :--- |
| 这个道理精要奥妙 | 母亲懂这个“妙要”——她从每一个孩子（师和资）身上都学到了如何成为更完整的母亲 |
| 第三人称：道理的精微 | 第一人称：没有“弃”的体验——一切都在“转化” |


## 结语：最深的“善”是无痕的

朱邦復先生在这一章中，用“五个善行例证”构建了至善“无痕”的图谱——善行不留痕迹、善言无可挑剔、善数不需工具、善闭不用锁钥、善结不用绳索。他强调“圣人常善救人而无弃人”——真正有德的人能看到万物之“用”，不会抛弃任何人或物。

而母亲的身体，是这一章最完整的“实验场”：

- **“善行者无辙迹”——凌晨三点抱着孩子在房间里走了一万步，但没有留下任何痕迹。**
- **“善言者无瑕谪”——妈妈的话可能有瑕疵——但孩子不记得瑕疵，只记得“妈妈在”。**
- **“善数者不以筹策”——用手摸、用眼看、用心感受——不需要“工具”来判断孩子是否吃饱、是否健康。**
- **“善闭者无关楗而不可启”——母亲不需要“锁”——她的“在场”就是最牢固的“关楗”。**
- **“善结者无绳约而不可解”——脐带剪断了，但母子之间的“结”还在——那是“无绳之结”。**
- **“圣人恒善救人而无弃人”——母亲不“弃”任何一个孩子——即使他“难带”，她说“需要更多耐心”。**
- **“物无弃财”——母乳用完了、衣服穿不下了、孩子长大了——不是“遗弃”，是“转化”。**
- **“善人，善人之师；不善人，善人之资”——第一个孩子是“师”（教会你怎么做妈妈）；难带的孩子是“资”（教会你耐心和变通）。**
- **“不贵其师，不爱其资，虽智大迷”——只感谢“好带的”而不感谢“难带的”——你就会失去从全貌中学习的可能。**
- **“是谓妙要”——母亲懂这个“妙要”——她从每一个孩子身上都学到了如何成为更完整的母亲。**

**“善行者无辙迹”——最深的“善”是不留下痕迹。母亲的一生就是这样的“善”——她做了一切，但没有留下“我做了”的证明。她走了无数步、说了无数话、付出了无数个夜晚——但那些“行”都没有痕迹。不是因为它们不存在——是因为它们不需要被记录。它们的“善”在于“让一个生命安静地长大了”。**

**“无弃人”——母亲不会抛弃任何孩子。“无弃财”——母亲不会浪费任何“素材”。“不善人，善人之资”——“难带的孩子”也是教材。“不贵其师，不爱其资”——你只感谢“好带的”而不感谢“难带的”是因为你还没有看到后者的价值。**

一个母亲的养育，就是“无痕之善”最日常的版本。她不需计算、不需工具、不需锁钥、不需绳索——她的身体就是“善”的工具。她没有“弃”的孩子——每一个孩子都以自己的方式教会了她。她没有“弃”的阶段——每一个阶段都转化成了她的一部分。这就是“眇要”——母亲从日复一日的养育中，自己悟出来的“妙要”。

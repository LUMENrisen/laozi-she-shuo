

## 引言：最“水”的一章，最“母亲”的承受

帛书本第七十九章（通行本第七十八章），是《德道经》中关于“天下莫柔弱於水”与“受邦之诟”的集中论述：

> 天下莫柔弱於水，而攻堅強者莫之能先也，以其无以易之也。
>
> 故柔勝剛，弱勝強，天下莫不知，而莫能行也。
>
> 故聖人之言云，曰：受邦之訽（詬），是胃（謂）社稷之主；受邦之不祥，是胃（謂）天下之王。
>
> 正言若反。

“天下莫柔弱於水”——天下没有比水更柔弱的东西了，“而攻坚强者莫之能先也”——但在攻击坚硬强大的东西时，没有什么能胜过它，“以其无以易之也”——因为水的那种“柔弱”是无可替代的。

“故柔勝剛，弱勝強”——所以柔能胜刚、弱能胜强，“天下莫不知”——天下没有人不知道这个道理，“而莫能行也”——却没有谁能真正实行。

“故聖人之言云”——所以圣人说过：“受邦之诟”——承受国家的屈辱，“是谓社稷之主”——才能成为社稷的主人；“受邦之不祥”——承受国家的不祥，“是谓天下之王”——才能成为天下的君王。

“正言若反”——这些正面的话听起来像是反话。

朱邦復先生在《止笑譚》中，将这一章解读为 **“柔弱胜刚强的例证与知易行难的矛盾”** 。他认为“天下莫柔弱于水”是水最柔弱，但攻坚硬之物无坚不克——因为水能变形、能适应、能持续作用而不损耗。他特别指出“弱之胜强，柔之胜刚，天下莫不知，莫能行”——人人都知道，但很少有人能做到。他最后以“受国之垢，是谓社稷主；受国不祥，是谓天下主”和“正言若反”作结——能承受屈辱才是社稷之主，正道与俗世的看法恰恰相反。

但如果我们把主语换成“母亲的身体”——那个日复一日地在沉默中承受“垢”与“不祥”、以“柔弱”的姿态让生命通过的身体——这一章就不再是“水德哲学”，而是一份 **“关于母亲如何以‘无以易之’的柔弱承载一切、如何在承受‘垢’与‘不祥’中成为家庭的柱石”的日常记录**：

- “天下莫柔弱於水”——母亲的身体也像水一样“柔弱”。羊水是柔的、母乳是柔的、她的韧性是“水”的韧性。
- “攻坚强者莫之能先”——但水能“攻坚强”。母亲的身体可以承受分娩的“攻坚战”。她的“柔弱”无坚不摧——不是通过“硬抗”，是通过“顺应”。
- “以其无以易之也”——水的“柔弱”无法被替代。母亲的“柔弱”也无法被替代。不是因为她“强”得不可替代——是因为她“柔”得不可替代。那是“无以易之”——不是“最强”的——是“唯一”的。
- “柔胜刚，弱胜强”——母亲用“柔”（耐心）胜过“刚”（孩子的倔强、生活的困难）。她用“弱”（允许自己不够、允许自己求助）胜过“强”（那些“我必须坚强”的压力）。
- “天下莫不知，而莫能行”——人人都知道“柔能胜刚”，但很少有人能做到。因为“柔”意味着放下“控制”，意味着承认自己“弱”。
- “受邦之诟”——母亲承受家庭的“诟”（不被看见、不被理解、被轻视）——她成了家庭的“社稷之主”。不是因为她“赢得了”这个位置——是因为她“承受了”那些“诟”。
- “受邦之不祥”——母亲承受家庭的“不祥”（疲惫、崩溃、病痛、不被认可的时刻）——她成了家庭的“天下之王”。
- “正言若反”——这些话听起来“反”的：承受屈辱的——反而是主人；承受不祥的——反而是王者。母亲的身体就是“正言若反”最日常的版本：她看起来“弱”——她却是支柱；她承受“垢”——她却是主。


## 一、“天下莫柔弱於水”——天下没有比水更柔弱的

### 朱邦復的解读：水是至柔的象征

朱先生将“天下莫柔弱于水”解读为“水最柔弱”：

> “天下沒有什麼比水更柔弱的了。”

水是“至柔”的象征。它没有形状、没有硬度、不抵抗。它“柔”——所以它能“通”。

### 从母亲身体的经验出发：母亲也像水一样“柔弱”——羊水是柔的、母乳是柔的、她的存在方式也是“柔”的

“天下莫柔弱於水”——在母亲的身体里，“柔”是什么？

- **羊水是“柔”的。** 它包裹胎儿、保护胎儿、让他在其中自由活动。那是“柔”——不是“硬”的——是“承”的。
- **母乳是“柔”的。** 它像水一样流出、滋养、没有形状。那是“柔”——不是“强”的——是“养”的。
- **她的耐心是“柔”的。** 她不“硬”地要求、不“刚”地对抗——她用“柔”来回应。那是“柔”——不是“弱”——是“能承”。
- **“柔弱”的深层含义：** 母亲的身体像水——软、不抵抗、能适应。那些“柔”让生命可以通过、可以生长、可以安全。不是“弱”的柔——是“能容”的柔。

朱先生说“天下莫柔弱于水”是水最柔弱。母亲的身体告诉我们：**她像水——羊水是柔的、母乳是柔的、她的耐心是柔的。那些“柔”让生命可以通过。**

| 朱邦復的“天下莫柔弱于水” | 母亲经验的“天下莫柔弱於水” |
| :--- | :--- |
| 水是至柔的象征 | 她像水——羊水、母乳、耐心——都是“柔”的。那些“柔”让生命可以通过 |
| 第三人称：水的特性 | 第一人称：我的“柔”不是弱——是让生命通过的方式 |


## 二、“攻坚强者莫之能先”——攻击坚硬之物，没有什么能胜过水

### 朱邦復的解读：水能克刚

朱先生将“攻坚强者莫之能胜”解读为“水克刚”：

> “若用水攻堅強之物，則又無堅不克。”

水虽然“柔”——但能“克刚”。石头被水磨圆、被水穿洞。不是靠“硬”——是靠“持续”。

### 从母亲身体的经验出发：母亲的身体可以承受分娩的“攻坚”——她的“柔弱”无坚不摧

“攻堅強者莫之能先”——在母亲的身体里，“攻坚”是什么？

- **分娩——那是“攻坚”。** 孩子要通过产道——那是“坚”的（产道是窄的、有阻力的）。母亲的“柔弱”（产道的柔软、她放松的顺应）让生命可以通过。她不是用“硬”来“打”开——是用“柔”来“让”开。
- **养育——那也是“攻坚”。** 孩子的哭闹、叛逆、成长中的各种“坚”——她不用“硬”去“攻”——她用“柔”去“化”。她不是“打赢”了困难——她是“让困难过去”了。
- **“攻坚”的深层含义：** 母亲的“柔弱”是“无坚不摧”的——不是靠“攻击”——是靠“顺应”。她“柔”着通过——困难就“过”了。不是“胜”了困难——是“让”困难过了。

朱先生说“攻坚强者莫之能胜”是水能克刚。母亲的身体告诉我们：**分娩的“坚”被她“柔”过了。不是“打”开的——是“让”开的。她的“柔弱”无坚不摧。**

| 朱邦復的“攻坚强者莫之能胜” | 母亲经验的“攻堅強者莫之能先” |
| :--- | :--- |
| 水能克刚 | 分娩的“坚”——她“柔”着让生命通过。不是“打”开——是“让”开 |
| 第三人称：水的克刚 | 第一人称：我不“攻”坚——我“柔”着过 |


## 三、“以其无以易之也”——因为它的那种“柔弱”无可替代

### 朱邦復的解读：水的柔无法被替代

朱先生将“以其无以易之”解读为“水最柔弱，故无取代”：

> “正因為水最柔弱，故無從取代。”

“无以易之”是“无法被替代”。水的“柔”是唯一的、不可替代的。不是因为它“有多强”——是因为它的“柔”是独一份的。

### 从母亲身体的经验出发：母亲的“柔弱”无法被替代——不是因为她“强”得不可替代——是因为她“柔”得不可替代

“无以易之也”——在母亲的身体里，“无以易之”是什么？

- **她可以不被替代。** 不是因为她“做了很多”——是因为她“是那个”。她的存在方式——她的柔、她的承、她的回应——无法被替代。奶瓶可以替代母乳——但“她”不能被替代。
- **“无以易之”的另一种理解：** 她的“柔”无可替代——因为那是从她身体里长出来的、独特的存在方式。不是“工具”能被替换——是“她”不能被替换。
- **“无以易之”的深层含义：** 母亲不需要“证明”自己不可替代——她“已经是”不可替代的了。不是“强”——是“唯一”。她的“柔”没有替代品。

朱先生说“无以易之”是水柔无法被替代。母亲的身体告诉我们：**她的“柔”无可替代——不是因为她“强”——是因为她“是那个”。**

| 朱邦復的“无以易之” | 母亲经验的“无以易之” |
| :--- | :--- |
| 水的柔无法被替代 | 她的“柔”无可替代——不是因为她“强”——是因为她“是那个” |
| 第三人称：水的独特性 | 第一人称：我不是“可替代”的——我是“唯一”的 |


## 四、“柔胜刚，弱胜强”——柔能胜刚，弱能胜强

### 朱邦復的解读：柔克刚的原理

朱先生将“柔胜刚，弱胜强”解读为“柔能克刚，弱能胜强”：

> “弱勝強，柔勝剛，人人知道，但卻無人能行。”

柔不是“软”到不能“胜”——柔的“胜”不是“对抗”的胜——是“化”的胜。弱不是“弱”到不能“胜”——弱的“胜”不是“硬拼”的胜——是“承”的胜。

### 从母亲身体的经验出发：母亲用“柔”（耐心）胜过“刚”（孩子的倔强），用“弱”（允许自己不够）胜过“强”（“我必须坚强”的压力）

“柔勝剛”——在母亲的身体里，“柔胜刚”是什么？

- **孩子的倔强是“刚”。** 他说“不”、他抗拒、他“硬”着不配合。母亲不用“刚”去对“刚”（吼、压、命令）——她用“柔”去对“刚”（等、听、轻轻地说）。那个“柔”——让孩子软下来了。
- **“弱勝強”——在母亲的身体里，“弱胜强”是什么？**
- **“我必须坚强”是“强”。** 社会说“你要坚强”、“你不能崩溃”。她用“弱”去对“强”——她允许自己崩溃、允许自己不够、允许自己求助。那个“弱”——让她胜过了“坚强”的压力。
- **“柔胜刚，弱胜强”的深层含义：** 母亲最懂得“柔”和“弱”的力量。她们不是“强”地对抗——她们“柔”地化。她们不是“硬”地扛——她们“弱”地承。

朱先生说“柔胜刚弱胜强”是柔克刚、弱胜强。母亲的身体告诉我们：**她用“柔”对孩子的“刚”，用“弱”对社会的“强”。那才是“胜”——不是“打”的胜——是“化”的胜。**

| 朱邦復的“柔胜刚弱胜强” | 母亲经验的“柔勝剛弱勝強” |
| :--- | :--- |
| 柔克刚、弱胜强 | 她用“柔”对孩子的“刚”，用“弱”对社会的“强”——那才是“胜” |
| 第三人称：柔弱的胜利 | 第一人称：我不“刚”对“刚”了——我“柔”着化；我不“强”对“强”了——我“弱”着承 |


## 五、“天下莫不知，而莫能行也”——天下没有人不知道，却没有谁能实行

### 朱邦復的解读：知易行难

朱先生将“天下莫不知，莫能行”解读为“人人知道，但无人能行”：

> “弱勝強，柔勝剛，人人知道，但卻無人能行。”

道理很简单——“柔胜刚”，人人都听过。但真正去做的时候——大多数人选择“刚”。因为“柔”需要放下控制、承认脆弱。

### 从母亲身体的经验出发：人人都知道“柔能胜刚”——但能做到“柔”的母亲，很少

“天下莫不知，而莫能行”——在母亲的身体里，“莫能行”是什么？

- **人人都知道“柔能胜刚”——但能做到的很少。** 因为“柔”意味着不控制、不命令、不“硬来”。那比“刚”更难。母亲知道要用“柔”对孩子——但有时候她还是“刚”了。那是“莫能行”。
- **人人都知道“弱能胜强”——但能做到的很少。** 因为“弱”意味着承认自己不够、承认自己需要帮助。那比“强”更难。母亲知道要“弱”——但有时候她还是“强”了。那是“莫能行”。
- **“莫能行”的深层含义：** 不是“不知”——是“不行”。知道和做到之间有一道很宽的裂缝。母亲每天都在那道裂缝上走——有时走过去（选择了“柔”），有时掉下去（选择了“刚”）。她不需要完美——她只需要继续试。

朱先生说“天下莫不知莫能行”是知易行难。母亲的身体告诉我们：**她每天都在走“知”和“行”之间的裂缝——有时选了“柔”，有时选了“刚”。但她还在走——那是“行”的开始。**

| 朱邦復的“天下莫不知莫能行” | 母亲经验的“天下莫不知而莫能行” |
| :--- | :--- |
| 知易行难 | 她每天都在走“知”和“行”之间的裂缝——有时柔，有时刚。但她还在走 |
| 第三人称：知行的鸿沟 | 第一人称：我知道要“柔”——但我还在学“行” |


## 六、“受邦之诟，是谓社稷之主”——承受国家的屈辱，才能成为国家的主人

### 朱邦復的解读：受垢者方为主

朱先生将“受国之垢，是谓社稷主”解读为“能承受屈辱才能领导国家”：

> “能承受國民的屈辱，才能領導國家。”

“受”是承受。“垢”是屈辱、污垢。不是“争”来的主人——是“受”来的主人。承受了别人不愿承受的——才能成为柱石。

### 从母亲身体的经验出发：母亲承受家庭的“诟”——那些不被理解、被轻视、被当作“不就是在家带孩子”——她成了家庭的“社稷之主”

“受邦之訽”——在母亲的身体里，“诟”是什么？“社稷之主”是什么？

- **“诟”是不被理解、被轻视、被当作“没什么了不起”。** “不就是在家带孩子吗”——那是“诟”。不被看见、不被承认、不被重视——那是“诟”。
- **她“受”了那些“诟”**——不是“忍”着——是“承”着。她不说“你看我多辛苦”来“反驳”那些诟——她继续做她的事。她“受”了。
- **她成了“社稷之主”**——不是因为“争”来的——是因为“承”来的。她承受了那些不被看见、不被理解——她成了家庭的主心骨。不是“谁承认她”——是“她就是”。
- **“受垢”的深层含义：** 母亲不是“被认可”才成为主心骨的——她是因为“受了那些不被认可”才成为主心骨的。她承受了那些“垢”——那些“垢”没有击垮她——它们成了她站在那里的地基。

朱先生说“受国之垢是谓社稷主”是受垢者方为主。母亲的身体告诉我们：**她承受了那些不被看见、被轻视——“垢”没有击垮她——她成了家庭的主心骨。那是“受”来的主，不是“争”来的。**

| 朱邦復的“受国之垢是谓社稷主” | 母亲经验的“受邦之訽是胃社稷之主” |
| :--- | :--- |
| 受垢者方为主 | 她承受了不被看见、被轻视——她成了家庭的主心骨。那是“受”来的主 |
| 第三人称：受垢者的位置 | 第一人称：我承了那些“垢”——我成了主 |


## 七、“受邦之不祥，是谓天下之王”——承受国家的不祥，才能成为天下的君王

### 朱邦復的解读：受不祥者方为王

朱先生将“受国不祥，是为天下王”解读为“承受灾祸者才能为天下主”：

> “能為天下負擔起災禍者，才能為天下之君主。”

“不祥”是灾祸、不好的事、别人不愿沾染的东西。“受”了“不祥”——才能“王”（成为真正的引领者）。不是“躲开”不祥——是“接住”不祥。

### 从母亲身体的经验出发：母亲承受家庭的“不祥”——那些疲惫、崩溃、病痛、不被认可的时刻——她成了家庭的“天下之王”

“受邦之不祥”——在母亲的身体里，“不祥”是什么？“天下之王”是什么？

- **“不祥”是那些别人不愿碰的东西。** 孩子的夜醒、她的崩溃、家里乱成一团、病痛、疲惫——那些是“不祥”。别人可能想“躲”开——她“受”了。
- **她“受”了那些“不祥”**——不是“喜欢”——是“接了”。那些崩溃的时刻、那些疲惫到极限的时刻、那些“我撑不住了”的时刻——她没有逃开。她“受”了。
- **她成了“天下之王”**——不是因为她“统治”了家庭——是因为她“承受”了家庭最“不祥”的部分。那些别人不愿接的东西，她接了。她成了那个“王”——不是“权”的王——是“承”的王。
- **“受不祥”的深层含义：** 母亲不是“完美”的才成为“王”——她是因为“承受了不完美”才成为“王”。那些崩溃、疲惫、病痛——她没有拒绝它们——她“受”了。那个“受”让她成了家庭的“王”。

朱先生说“受国不祥是为天下王”是受不祥者方为王。母亲的身体告诉我们：**她承受了家庭的“不祥”——崩溃、疲惫、病痛——她成了家庭的“王”。不是“统治”的王——是“承受”的王。**

| 朱邦復的“受国不祥是为天下王” | 母亲经验的“受邦之不祥是胃天下之王” |
| :--- | :--- |
| 受不祥者方为王 | 她承受了崩溃、疲惫、病痛——她成了家庭的“王”。不是统治——是承受 |
| 第三人称：受不祥者的位置 | 第一人称：我接了那些“不祥”——我成了王 |


## 八、“正言若反”——正话听起来像反话

### 朱邦復的解读：正道与俗见相反

朱先生将“正言若反”解读为“正道与世俗看法相反”：

> “正道是客觀的、永恆的、無私的，俗見是主觀的、暫時的、自我的。兩者不僅完全相反，而且不能相容。”

“正言”是正话、真话。“若反”听起来像是反话。不是“故意说反话”——是“真的正话”在“俗见”的耳朵里听起来像是“反话”。

### 从母亲身体的经验出发：母亲的一生就是“正言若反”——她看起来“弱”，却是支柱；她承受“垢”，却是主

“正言若反”——在母亲的身体里，“正言若反”是什么？

- **她看起来“弱”——她却是支柱。** 社会说“强才是支柱”——她“弱”着，却撑起了一个家。那是“正言若反”。
- **她承受“垢”——她却是主。** 社会说“被尊重的才是主”——她承受着不被看见，却成了主心骨。那是“正言若反”。
- **她承受“不祥”——她却是王。** 社会说“远离灾祸的才是王”——她接了那些“不祥”，却成了家的“王”。那是“正言若反”。
- **“正言若反”的深层含义：** 母亲的一生就是“正言若反”的活样本。外人不理解——因为看起来“反”的。但她知道那是“正”的。她看起来“弱”——但她在支撑；她看起来“被轻视”——但她在承重；她看起来“在后方”——但她在中心。那是“正言若反”——不是“她说反话”——是“她活反话”。

朱先生说“正言若反”是正道与俗见相反。母亲的身体告诉我们：**她的一生就是“正言若反”的活样本——她看起来弱，却是支柱；她承受垢，却是主。外人不理解——但她知道那是“正”的。**

## 结语：“无以易之”的柔软——母亲身体里的水

朱邦復先生在这一章中，用“水德”与“受垢”的框架，解读了“天下莫柔弱于水而攻坚强者莫之能胜”、“柔胜刚弱胜强”、“受国之垢是谓社稷主、受国不祥是谓天下王”、“正言若反”等原则。他认为水是最柔弱而最能克刚的象征；柔胜刚的道理人人知道却少有人行；能承受屈辱和不祥的人才是真正的君主；正道听起来像是反话。

而母亲的身体，是这一章最完整的“柔弱之水-受垢之主-正言若反”的演绎者：

- **“天下莫柔弱於水”——她像水一样“柔”——羊水、母乳、耐心——都是“柔”的。**
- **“攻坚强者莫之能先”——分娩的“坚”被她“柔”着让生命通过——不是“打”开的，是“让”开的。**
- **“无以易之”——她的“柔”无可替代——不是因为她“强”——是因为她“是那个”。**
- **“柔胜刚”——她用“柔”对孩子的“刚”和生活的“刚”——那是“胜”的方式。**
- **“弱胜强”——她用“弱”（允许自己不够）对社会的“强”（“你必须坚强”）——那是“胜”的方式。**
- **“天下莫不知而莫能行”——她每天在“知”和“行”之间走——有时柔、有时刚。但她还在走。**
- **“受邦之诟”——她承受了不被看见、被轻视——她成了家庭的主心骨。**
- **“受邦之不祥”——她承受了崩溃、疲惫、病痛——她成了家庭的“王”。**
- **“正言若反”——她看起来“弱”却是支柱，承受“垢”却是主——外人看是“反”的，她知道是“正”的。**

**“无以易之”——母亲不可替代的“柔”。** 她的“柔”不是“软弱”——是“唯一”。羊水是唯一的、母乳是唯一的、她对那个孩子的回应是唯一的。不是因为她“做得多”——是因为她“是那个”。无法被替代——不是因为“强”——是因为“唯一”。

**“受邦之诟”——母亲的“垢”成了她的“位”。** 她承受了那些不被看见、被轻视、被当作“没什么”——那些“垢”没有击垮她。它们成了她站的地方。她站在“垢”上——成了主。不是“被承认”了才成主——是“承受了不被承认”才成主。

**“正言若反”——母亲的一生就是“反”的活样本。** 外人看来——她在“下”面（家庭的后方），她是“弱”的（没有社会地位），她承受“垢”（不被看见）。但在“正”的眼里——她在“下”面所以能托住，她“弱”所以能承，她承受“垢”所以能成主。那是“正言若反”——外人看是“反”的，她知道是“正”的。

一个母亲的身体，就是“柔弱之水-受垢之主-正言若反”最日常的版本。她像水——柔、持续、无可替代。她承受“垢”和“不祥”——她成了家的柱石。外人看她“弱”却在撑、看她“受垢”却是主——那是“正言若反”。她知道那不是“反”的——那是“正”的。



## 引言：最“悖论”的一章，最“日常”的母体

帛书本第二十二章，是《德道经》中关于“反者道之动”最集中的表达之一：

> 曲則金（全），枉則定（正），洼則盈，敝則新。少則得，多則惑。
>
> 是以聲（聖）人執一，以為天下牧。
>
> 不自視（示）故明，不自見故章，不自伐故有功，弗矜故能長。
>
> 夫唯不爭，故莫能與之爭。
>
> 古之所謂曲全者幾語才（哉），誠金（全）歸之。

“曲则全”——弯曲才能保全；“枉则正”——弯曲才能伸直；“洼则盈”——低洼才能充盈；“敝则新”——破旧才能更新；“少则得”——少取才能多得；“多则惑”——贪多反而迷惑。

所以圣人“执一”——守住道这个根本，以此治理天下。不自我表现所以明白，不自我标榜所以彰显，不自我夸耀所以有功，不骄傲自大所以长久。正因为不争，所以天下没有人能与他争。

古人说的“曲则全”，难道是空话吗？确实能做到全而归之。

朱邦復先生在《止笑譚》中，将这一章解读为 **“均衡律的演绎与证明”** 。他认为“曲则全、枉则正、洼则盈、敝则新”都是能量变化中“物极必反”的表现——结构弯曲才能受力分散而不折断，低洼才能汇聚水流而充盈，破旧才能为新事物腾出空间。他特别强调了“少则得，多则惑”——少容易满足，多反而让人困惑、失去判断。而“执一”就是守住“均衡律”这个根本原则，“不争”则是不追求极端、不与人争利——因为争的结果必然是失衡。

但如果我们把主语换成“母亲的身体”——那个经历了怀孕、分娩、产后恢复、日复一日弯腰抱孩子的身体——这一章就不再是“物理定律”的抽象论证，而是一份 **“身体如何在弯曲中保全、在低洼中充盈、在破旧中更新”的日常记录**：

- “曲则全”——分娩时，胎儿必须“弯曲”着通过产道。他蜷缩着、屈着、不伸直——正是这个“曲”让他能“全”（完整地出生）。如果他不“曲”，他就无法“全”。
- “枉则正”——母亲的腰椎。怀孕时腰椎前凸（枉），是为了平衡增大的腹部（正）。产后腰椎恢复，需要重新“枉”（弯曲）来找到“正”。
- “洼则盈”——骨盆是“洼”。它是一个凹陷的容器——胎儿在其中生长、充盈。空时接纳，盈时释放。
- “敝则新”——产后的身体“敝”了（松弛、伤痕、疲惫）——但正是在这个“敝”中，新的生命状态在形成。你不是“回到原来的自己”——你是“成为一个新的自己”。“敝”是“新”的前提。
- “少则得，多则惑”——产后你的“多”变“少”了：时间少了、精力少了、社会关系少了——但你反而“得”了更多：更明确的目标、更单纯的关注、更深层的连接。“多”是混乱的来源，“少”是清晰的入口。

让我们逐句对照。


## 一、“曲則全”——弯曲才能保全

### 朱邦復的解读：弯曲受力才能保全整体

朱先生将“曲则全”解读为“结构弯曲才能受力而不折断”：

> “施力於物體……結構間若交錯縱橫，各自分擔分力，則成彎曲之形。否則如作用力大於結構的斷面應力時，即告斷裂。彎曲能保障物體之完整。”

他的逻辑是：一根直的棍子容易被折断——因为它把所有受力都集中在断裂面上。但一根弯曲的、有弹性的东西——它会“卸力”——把受力分散到各处，从而保全整体。

### 从身体经验出发：分娩时胎儿必须“弯曲”着通过产道——正是这个“曲”让他能“全”

“曲則全”——在母亲的身体里，“曲”是什么？“全”是什么？

- **分娩时，胎儿必须“弯曲”着通过产道。** 他不是“伸直”着出来的——他是蜷缩着的、低头的、屈身的。他的身体在产道里“曲”到了极致——头屈、身屈、四肢屈——然后他通过了。如果他不“曲”——如果他是“直”的、伸着的——他出不来。
- **“曲”不是“软弱”——是“适应通道的能力”。** 产道是弯曲的、狭窄的、有弹性的。胎儿必须顺应这个通道的形状——他必须“曲”自己。这个“曲”让他能“全”（完整地出生、保全生命）。
- **产后母亲的身体也是“曲”的。** 你弯腰抱孩子、你弓背喂奶、你蜷缩着睡觉——你的身体在“曲”中运作。如果一直“直”（僵硬、挺着）——你会受伤。“曲”是一种生存策略。

朱先生说“曲则全”是弯曲受力才能保全整体。母亲的身体告诉我们：**分娩时，胎儿的“曲”让他能“全”。产后，母亲的“曲”（弯腰、弓背）让她能继续承载——如果一直“直”着，反而会受伤。**

| 朱邦復的“曲则全” | 母亲经验的“曲则全” |
| :--- | :--- |
| 弯曲受力，才能避免断裂、保全整体 | 分娩时胎儿“曲”着通过产道——不曲则不全 |
| 第三人称：材料力学的原理 | 第一人称：他蜷缩着出来——那就是“曲则全”最字面的版本 |


## 二、“枉則正”——弯曲才能伸直

### 朱邦復的解读：先弯曲才能更好地伸直

朱先生将“枉则正”解读为“由于能弯曲，才有伸直的可能”：

> “由於能彎曲，才有伸直的可能。”

一根直的、僵硬的木头，你无法“扳直”它——因为它本来就是直的。但一根弯曲的、有弹性的东西，你可以把它“弄直”——因为它能弯回来。“枉”是“弯”，“正”是“直”。有了“弯”的可能性，才有“直”的恢复。

### 从身体经验出发：怀孕时腰椎前凸（枉），是为了平衡增大的腹部（正）

“枉則正”——在母亲的身体里，“枉”和“正”是什么？

- **怀孕时的腰椎。** 随着胎儿增大，腹部重心前移。为了保持身体平衡，腰椎会自然前凸——“枉”（弯曲）了。如果没有这个“枉”——你会在孕期摔倒。你的腰椎“枉”了，是为了让你能“正”（站立）。
- **产后的腰椎。** 分娩后，腹部压力突然消失——腰椎需要从“前凸”状态恢复到“中立”状态。这个过程需要时间、需要练习、需要耐心。你不能“一夜扳直”——你要慢慢地、在弯曲中找回“正”。
- **“枉則正”的深层含义：** 你需要先“弯”（顺应身体的变化），才能“直”（恢复平衡）。在“枉”中，你才能找到“正”的可能。

朱先生说“枉则正”是先弯曲才能伸直。母亲的身体告诉我们：**怀孕时腰椎前凸（枉）是为了平衡腹部重量（正）。产后你需要慢慢从“枉”回到“正”——在弯曲中找到恢复的可能。**

| 朱邦復的“枉则正” | 母亲经验的“枉则正” |
| :--- | :--- |
| 先弯曲才能伸直 | 怀孕时腰椎前凸（枉）是为了平衡腹部（正） |
| 第三人称：物理的弹性原理 | 第一人称：我的腰椎弯了——但那是为了让我能站着 |


## 三、“洼則盈”——低洼才能充盈

### 朱邦復的解读：低处才能汇聚

朱先生将“洼则盈”解读为“低洼才能汇聚水流”：

> “地先有低窪，水流才能注入。”

水往低处流。如果你想“盈”（充满、充盈）——你首先需要“洼”（低、空）。一个已经满的、高的容器无法再装水——只有低洼的、空的才能“盈”。

### 从身体经验出发：骨盆是“洼”——空时接纳，盈时释放

“洼則盈”——在母亲的身体里，“洼”和“盈”是什么？

- **骨盆是身体最深的“洼”。** 它在躯干的底部——凹陷、中空、像一个容器。非孕期，它是“洼”的——空的、待命的。当胎儿到来，它开始“盈”——充盈、扩张、容纳。
- **“洼則盈”的完整过程：** 骨盆必须是“洼”的（低、空、柔软），才能“盈”（容纳胎儿的生长、承受分娩的扩张）。如果骨盆是“高”的、“满”的——它无法“盈”。你必须先“空”出位置，才能装下新的生命。
- **“盈”之后的“空”：** 分娩后，骨盆又从“盈”回到“洼”——收缩、恢复、等待下一次“盈”。低洼才能充盈——盈了之后又变回洼——这是循环，不是终点。

朱先生说“洼则盈”是低洼才能汇聚水流。母亲的身体告诉我们：**骨盆是身体最深的“洼”——它必须空、低、柔软，才能“盈”（容纳胎儿）。“洼”不是“缺”——是“能容纳的准备”。**

| 朱邦復的“洼则盈” | 母亲经验的“洼则盈” |
| :--- | :--- |
| 低洼才能汇聚水流 | 骨盆——身体最深的“洼”——空时才能容纳胎儿的“盈” |
| 第三人称：水流汇聚的原理 | 第一人称：我的身体有一个“洼”——它在盈与空之间循环 |


## 四、“敝則新”——破旧才能更新

### 朱邦復的解读：旧状态结束才能迎来新状态

朱先生将“敝则新”解读为“破旧才能更新”：

> “事物破舊了，才能更新。”

“敝”是旧、破、完成了使命的状态。当你接受“敝”——不抗拒“旧”的结束——才有空间让“新”到来。越是抓着“旧”不放，“新”就越难来。

### 从身体经验出发：产后的身体“敝”了（松弛、伤痕、疲惫）——但正是在这个“敝”中，新的生命状态在形成

“敝則新”——在母亲的身体里，“敝”和“新”是什么？

- **产后的身体是“敝”的。** 松弛的腹部、剖腹产的疤痕、疲惫的肌肉、改变的内脏位置——你的身体“旧”了、被改变了、不再是“原来的”了。
- **但“敝”不是“结束”——是“新”的前提。** 你不再是“产前那个身体”——但你是“产后这个新的身体”。你有了新的功能（喂养、承载、恢复）、新的形状（被生命改变过）、新的力量（韧性和耐力）。
- **“敝則新”的深层含义：** 如果你执着于“回到原来”——你会痛苦。因为“原来”已经回不去了。但如果你接受“被改变了”——你就会发现“新”的状态：一个完整的、被生命重塑过的、比原来更宽广的身体。

朱先生说“敝则新”是破旧才能更新。母亲的身体告诉我们：**产后的身体“敝”了——但这不是失去，是新状态的起点。你不再是产前的你——但你是更完整的你。“敝”不是终结——“新”从它开始。**

| 朱邦復的“敝则新” | 母亲经验的“敝则新” |
| :--- | :--- |
| 破旧才能更新 | 产后的身体“敝”了——但正是在“敝”中，新的生命状态在形成 |
| 第三人称：事物的更新规律 | 第一人称：我回不去“原来”——但我成为了“新的” |


## 五、“少則得，多則惑”——少取才能多得，贪多反而迷惑

### 朱邦復的解读：少则容易满足，多则难以判断

朱先生将“少则得，多则惑”解读为“少容易满足，多反而困惑”：

> “少雖有不足，然易知易行，多雖有得，卻又難知難行，徒增疑惑。”

“少”的时候，你的注意力集中，你容易“得”（得到满足、达成目标）。“多”的时候，你的注意力分散，你反而“惑”（困惑、无法判断、不知如何选择）。

### 从身体经验出发：产后你的“多”变“少”了——但你反而“得”了更多

“少則得，多則惑”——在母亲的身体里，“少”和“多”是什么？

- **产前：** 你有很多——时间、精力、社交、规划、选择。你“多”——你被“多”包围着。但你“惑”——你不知道该把注意力放在哪里、不知道什么是最重要的。
- **产后：** 你的“多”变“少”了——时间少了、精力少了、社交少了、选择性少了。但你反而“得”了更多——你更清楚什么重要、更专注、目标更明确。
- **“少則得”在养育中的意思：** 你没有精力去多想、多规划、多犹豫——你只能“少”。而正是这个“少”让你“得”了：你得到了他的信任、他的依赖、你们之间深层的连接。你失去的“多”让你得到了一种“少”的纯粹。

朱先生说“少则得多则惑”是少容易满足、多容易困惑。母亲的身体告诉我们：**产后你的“多”变“少”了——但你的“少”让你更清晰、更专注、更“得”。多不是好事——少才是入口。**

| 朱邦復的“少则得多则惑” | 母亲经验的“少则得多则惑” |
| :--- | :--- |
| 少容易得，多容易惑 | 产后时间、精力都变“少”了——但你的关注更清晰，反而“得”了更多 |
| 第三人称：认知的资源定律 | 第一人称：我“少”了——但我“得”到了他 |


## 六、“是以聖人執一，以為天下牧”——圣人执守“道”这个根本，来治理天下

### 朱邦復的解读：守住根本，以不变应万变

朱先生将“圣人抱一为天下式”解读为“守着一，以不变应万变”：

> “聖人所抱之一，即為天道，亦即‘均衡律’。世事變化無窮，人若知順從自然法則，即同道也。”

“一”就是“道”这个根本——均衡律、不变的本质。“抱一”是守住这个根本——不因外界的“曲、枉、洼、敝”而失去中心。“为天下式”是用这个根本作为处理一切的标准。

### 从身体经验出发：你不需要精通所有“方法”——你只需要守住“他”

“執一”——在母亲的身体里，“一”是什么？

- **“一”就是“他”。** 你不需要精通所有育儿方法——你只需要守住“他”。他饿了、他困了、他需要抱了——你的“一”是他的状态。你不需要处理所有复杂的选择——你只需要回应他。
- **“為天下牧”——他是你的“天下”。** 他不是一个需要“被管理”的对象——他是你的“全部世界”。你“牧”的不是“天下”——你“牧”的是他。你的“一”就是这个“单一、专注、不分散”的状态。
- **“執一”的养育实践：** 你不需要知道“所有理论”——你只需要知道“他”。他的节奏、他的信号、他的需求——就是你的“一”。守住这个“一”，你就能“牧”好这个“天下”。

朱先生说“圣人抱一为天下式”是守住道这个根本来治理天下。母亲的身体告诉我们：**你不需要精通所有方法——你只需要守住“他”。他是你的“一”——你的全部世界。守住“一”，你就能回应他的全部。**

| 朱邦復的“圣人执一以为天下牧” | 母亲经验的“圣人执一以为天下牧” |
| :--- | :--- |
| 守住道的根本来治理天下 | 你不需要所有方法——你只需要守住“他”。他就是你的“一” |
| 第三人称：治理的根本原则 | 第一人称：我不需要知道所有——我只需要知道他 |


## 七、“不自視故明，不自見故章”——不自我表现所以明白，不自我标榜所以彰显

### 朱邦復的解读：不刻意表现反而能被看见

朱先生将“不自见故明，不自是故彰”解读为“不自我表现所以能够显明”：

> “不自我表現，所以能夠顯明；不自以為是，所以能秉持公正。”

当你“自见”（刻意表现自己）时，你反而会失去焦点——你的注意力在你如何被看见，而不是在事情本身。当你“不自见”时，你的注意力在“道”上——你反而“明”了。

### 从身体经验出发：你不说“我是个好妈妈”——孩子反而知道你是

“不自視”——在母亲的身体里，“不自視”是什么？

- **你不需要说“我是个好妈妈”。** 你不需要证明、不需要展示、不需要发朋友圈“我做得有多好”。你只是做——喂奶、换尿布、抱他、陪他。
- **“明”的结果：** 孩子不知道“好妈妈”的定义——但他知道“你是”。他不是因为你说了什么才知道——他是因为你做了什么才知道。你的“不自视”让他“明”了。
- **“不自見故章”——你不标榜自己，反而会被“看见”。** 不是被社会看见——是被他看见。他的眼睛不会说谎——他能分辨谁是真心在回应他、谁是“在表演好妈妈”。你越“自见”（表演），他越“不见”你。你越“不自见”，他越“看见”你。

朱先生说“不自见故明”是不刻意表现反而明白。母亲的身体告诉我们：**你不说“我是个好妈妈”——孩子反而知道你是。“自见”让他看不见你——放下“自见”，他才真正“看见”你。**

| 朱邦復的“不自见故明” | 母亲经验的“不自见故明” |
| :--- | :--- |
| 不刻意表现反而能明白 | 你不说“我是好妈妈”——孩子反而知道你是 |
| 第三人称：人际关系的反作用 | 第一人称：我不需要证明——他被我“做”的看见 |


## 八、“不自伐故有功，弗矜故能長”——不自我夸耀所以有功，不骄傲自大所以长久

### 朱邦復的解读：不居功才能有功，不骄傲才能长久

朱先生将“不自伐故有功，不自矜故长”解读为“不自夸才能成事，不骄傲才能维持长久”：

> “不自我誇耀，所以能成事；不驕矜凌人，所以維持長遠。”

当你把功劳归于自己时，你反而会失去它——因为你停止做功了、因为别人看到你居功了、因为你的注意力从“继续做”转移到了“被承认”。功是用来“做”的，不是用来“说”的。

### 从身体经验出发：你不说“这是我做的”——孩子的生长就是你的“功”

“不自伐”——在母亲的身体里，“不自伐”是什么？

- **你不需要说“我把他带得这么好”。** 你不需要把“功”记在自己账上。他的生长——就是你的“功”。但你不需要“伐”（夸耀），因为“功”已经在那里了——他长高了、他笑了、他叫“妈妈”了。
- **“弗矜”——你不骄傲。** 你不会说“看，这都是我的功劳”——因为你知道他的生长有自己的节律。你只是在“做”——而他“长”了。你的“功”不是“做出来的”——是“让他长出来的”。
- **“能長”——你反而能长久。** 如果你“伐”了、你“矜”了——你就把自己放在了“台上”。你停止了学习、停止了调整、停止了“继续做”。而“不伐”“不矜”——你才能继续“長”（持续成长、持续存在）。

朱先生说“不自伐故有功，不自矜故长”是不居功才能有功，不骄傲才能长久。母亲的身体告诉我们：**你不说“我把他带得这么好”——但他的生长就是你的“功”。你不骄傲——因为你只是在“让”他生长。而正是这个“不矜”让你能持续地做下去。**

| 朱邦復的“不自伐故有功” | 母亲经验的“不自伐故有功” |
| :--- | :--- |
| 不居功才能有功 | 你不说“我做的”——他的生长就是你的“功” |
| 第三人称：成败的辩证法 | 第一人称：我不是“做”出了他的生长——我是“让”它发生了 |


## 九、“夫唯不爭，故莫能與之爭”——正因为不争，所以没有人能与他争

### 朱邦復的解读：不争的人没有对手

朱先生将“夫唯不争，故天下莫能与之争”解读为“不与人争，故无人能与之争”：

> “不與人爭，故無人能與之爭。”

当你“争”的时候——你把自己放进了“争”的系统。有对手、有规则、有输赢。当你不“争”的时候——你不在那个系统里。你没有对手——因为你不在“争”的场上。

### 从身体经验出发：你不争“家里最好的位置”——但你成为了家庭的重心

“不爭”——在母亲的身体里，“不爭”是什么？

- **你在家庭里不争“最好的位置”。** 你不争第一口饭、不争最舒服的座位、不争“谁重要”。你把自己放在后面、放在边缘、放在需要处。
- **但你没有“对手”——因为你不在“争”的系统里。** 别人可能争——争位、争利、争注意力——但你不争。你做的事情不是“争”能完成的——你做的事情是“给”。你给奶、给抱、给耐心——这些不在“争”的范围内。
- **“莫能與之爭”的结果：** 你成为了家庭的重心——不是因为你争来了这个位置，而是因为你“不争”、因为你一直在这里、因为你给了他一切他需要的。没有人能“争”走你的位置——因为你不在“争”的赛场上。

朱先生说“夫唯不争故莫能与之争”是不争的人没有对手。母亲的身体告诉我们：**你不争“最好的位置”——但你成为了家庭的重心。因为你不“争”——你“给”。争的人有对手——给的人没有。**

| 朱邦復的“不争故莫能与之争” | 母亲经验的“不争故莫能与之争” |
| :--- | :--- |
| 不争的人没有对手 | 你不争——你“给”。争的人有对手——给的人没有 |
| 第三人称：竞争逻辑的超越 | 第一人称：我不争——我成为重心不是因为争来的 |


## 十、“古之所謂曲全者幾語哉，誠全歸之”——古人说的“曲则全”，确实能“全而归之”

### 朱邦復的解读：古人说得对，确实如此

朱先生将“古之所谓曲则全者，岂虚言哉？诚全而归之”解读为“古人说得对，确实能保全”：

> “古人所说的这些话，实在正确极了，理应牢牢遵守。”

“曲则全”不是空话——它是真实可验证的规律。你按照它行事，确实能得到“全”的结果。

### 从身体经验出发：你“曲”了——你的身体弯曲、你的时间弯曲、你的整个人生方向弯曲——但最终，你“全”了

“誠全歸之”——在母亲的身体里，“全”是什么？

- **你“曲”了。** 你的身体弯曲了（弯腰抱他、弓背喂奶）、你的时间弯曲了（不再是一条直线）、你的整个人生方向弯曲了（你走的不是“原来规划的路”）。
- **但你“全”了。** 你不再只是“原来的自己”——你是“更完整的自己”。你原本以为“全”是“不被改变”——但真正的“全”是“被改变了但仍然是完整的”。
- **“曲”让你能“全”。** 如果你拒绝“曲”——拒绝弯腰、拒绝改变、拒绝适应他的节奏——你会“断”（身体的伤、精神的崩、关系的裂）。你因为“曲”而“全”了。不是“没有被改变”——是“在改变中保全了整体”。

朱先生说“诚全而归之”——确实能“全”。母亲的身体告诉我们：**你“曲”了——身体弯曲、时间弯曲、人生方向弯曲——但你没有“断”。你在弯曲中保全了整体，成为了更完整的自己。“曲”不是失去——是保全的路径。**

| 朱邦復的“诚全而归之” | 母亲经验的“诚全而归之” |
| :--- | :--- |
| 古人说得对——确实能保全 | 你“曲”了——身体弯曲、时间弯曲——但你“全”了 |
| 第三人称：规律的验证 | 第一人称：我在弯曲中保全了整体——“曲”不是失去，是保全的路径 |


## 结语：“曲”是保全的路径，“洼”是充盈的前提

朱邦復先生在这一章中，用“均衡律”解读了“曲则全、枉则正、洼则盈、敝则新、少则得、多则惑”的辩证关系。他认为这些不是“道德劝诫”——是“规律本身”。弯曲是为了受力分散、低洼是为了汇聚水流、破旧是为了让位更新——它们都是“反者道之动”的具体表现。

而母亲的身体，是这一章最完整的“实验场”：

- **“曲则全”——分娩时胎儿的“曲”让他能“全”。**
- **“枉则正”——怀孕时腰椎的“枉”（前凸）是为了“正”（平衡）。**
- **“洼则盈”——骨盆的“洼”是为了“盈”（容纳胎儿）。**
- **“敝则新”——产后的身体“敝”了——但正是在“敝”中，“新”的状态形成。**
- **“少则得”——产后时间、精力都“少”了——但你反而“得”了更多的清晰和专注。**
- **“多则惑”——“多”是混乱的来源——产后你不再“多”了，所以不再“惑”了。**
- **“执一”——你不需要所有方法——你只需要守住“他”。他就是你的“一”。**
- **“不自见”——你不说“我是好妈妈”——孩子反而“看见”了你。**
- **“不自伐”——你不说“我做的”——他的生长就是你的“功”。**
- **“不争”——你不争“最好的位置”——但你成为了家庭的重心。**
- **“曲全”——你“曲”了——但你没有“断”。你在弯曲中保全了整体。**

**“曲则全”——你的身体弯曲了、你的时间弯曲了、你的人生方向弯曲了——但你没有“断”。你在“弯曲”中保全了整体。如果你拒绝“曲”、拒绝改变、拒绝低头——你会“断”（身体的伤、精神的崩、关系的裂）。你因为“曲”而“全”。**

**“洼则盈”——你的身体是“洼”的——骨盆低、重心低、你把自己放低——而正是这个“低”让你能“盈”：能容纳他、承载他、让他从中生长。如果你“高”了——你就无法“盈”。**

一个母亲的身体，就是“曲则全、洼则盈”最日常的版本。她不需要读《道德经》来理解这些——她的身体每天都在经历：弯腰才能抱、低处才能接、弯曲才能保全。

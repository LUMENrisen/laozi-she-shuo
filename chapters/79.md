

## 引言：最“政治”的一章，最“平淡”的母职

帛书本第三十五章，是《德道经》中关于“道的吸引力与感官诱惑”的集中论述：

> 執大象，天下往。往而不害，安平大。
>
> 樂與餌，過格（客）止。
>
> 故道之出言也，曰：『談（淡）呵其无味也。視之，不足見也。聽之，不足聞也。用之，不可既也。』

“执大象，天下往”——守住道的大象（道的广大形象、根本原则），天下人都会来归附。“往而不害，安平大”——归附了也不会受到伤害，反而安乐平和。“乐与饵，过客止”——音乐和美食，能让路过的客人停下脚步。“故道之出言也”——道说出来的时候，“淡呵其无味也”——淡得没有味道。“视之，不足见也”——看它，不值得看、看不见。“听之，不足闻也”——听它，不值得听、听不见。“用之，不可既也”——使用它，却不可穷尽。

朱邦復先生在《止笑譚》中，将这一章解读为 **“道的无形功用与感官诱惑的对比”** 。他认为“大象”即道，人能持守道则天下归附——因为趋利避害是人之本性，有道者利天下，所以天下归之。他特别强调了“乐与饵”——声色的诱惑——只能吸引“过客”（短暂停留的人），而不能让人真正“归”。他最后落脚在道的“淡、无味、不见、不闻”——道不像声光色彩那样刺激感官，但它“用之不竭”，是真正的根本。

但如果我们把主语换成“母亲的身体”——那个在平淡无味的日常中存在着、在看不见听不见的细节中陪伴着、却用之不竭的身体——这一章就不再是“政治哲学”，而是一份 **“关于母亲如何以‘淡呵无味’的存在吸引孩子、以‘用之不竭’的陪伴守护孩子的日常记录”**：

- “执大象，天下往”——一个母亲守住那个不张扬、不刺激的“大象”（她的存在方式），孩子自然走向她。不是因为她“做了很厉害的事”——是因为她“在那里”。
- “往而不害，安平大”——孩子靠近她，不会受伤。他饿了有吃的、困了有抱、怕了有她在。在她的存在里，他“安、平、大”——安全、平和、圆满。
- “乐与饵，过客止”——声光色彩能吸引人停留，但不能让人“归”。母亲也会用奖励、表扬、物质刺激——但这些只能吸引一时。真正让孩子“归”的，不是“乐与饵”，是那个“淡呵无味”的存在。
- “淡呵其无味也”——母亲的存在是“淡”的：她没有甜言蜜语，没有精心设计的“教育”，没有声情并茂的表演。她只是平平淡淡地在那里。但那个“淡”里，有一种孩子无法离开的东西。
- “视之，不足见也”——你“看见”一个母亲做的那些事吗？你看见她深夜醒来、看见她喂奶、看见她换尿布——但你看不见她的疲惫、她的焦虑、她的全部付出。有些东西，是“视之不足见”的。
- “听之，不足闻也”——你“听见”一个母亲说的话吗？你听见她说“快睡吧”、“别哭了”、“妈妈在”——但你看不见那些话背后的重量。有些声音，是“听之不足闻”的。
- “用之，不可既也”——她的爱用不完。即使她疲惫到极限——她还可以再抱一次、再陪一次、再等一次。那个“不可既”——不是“她永远有力”——是“她即使没有力了，也还会继续”。

让我们逐句对照。


## 一、“執大象，天下往”——守住大道，天下归附

### 朱邦復的解读：持守大道则天下归附

朱先生将“执大象，天下往”解读为“顺道而行，天下归之”：

> “人君若順遂大道而行，天下必將歸之。”

“大象”是道的广大之象——道在宏观层面的显现。“执大象”是守住道、行于道。“天下往”是天下自然而然地归向于你——不是因为强制，是因为吸引力。

### 从身体经验出发：母亲守住那个“大象”（不张扬的存在方式），孩子自然走向她

“執大象”——在母亲的身体里，“大象”是什么？

- **“大象”是她的“存在方式”——不张扬、不刺激、不表演。** 她不是用“乐与饵”（奖励、表扬、声光刺激）来吸引孩子——她是用“在那里”来吸引孩子。她不出声地存在——孩子自然走向她。
- **“天下往”的养育版本：** 孩子自然靠近她。不是因为她说“你应该靠近我”——是因为他感受到她。她的“大象”不是“理论”——是她的身体、她的气息、她的在场。
- **“执大象”的深层含义：** 她“执”住的是那个“有空间容纳他、有温度回应他”的状态。那是最根本的——不是方法、不是技巧、不是工具。

朱先生说“执大象天下往”是守道则天下归。母亲的身体告诉我们：**她守住那个不张扬的存在方式——孩子自然走向她。她的“大象”不是“理论”——是她在那里。**

| 朱邦復的“执大象天下往” | 母亲经验的“執大象天下往” |
| :--- | :--- |
| 守道则天下归附 | 孩子自然走向她——不是因为她说“你应该靠近我”，是因为她“在那里” |
| 第三人称：道的吸引力 | 第一人称：我不是用“声光色彩”吸引他——我用“在”吸引他 |


## 二、“往而不害，安平大”——归附了不会受伤害，安乐平和

### 朱邦復的解读：归道则安平

朱先生将“往而不害，安平太”解读为“天下归之且不受害，则天下太平”：

> “果有利可得，人得其所哉。”

“往”是归向，“不害”是安全，“安平大”是安乐、平和、广大（圆满）。归道的结果不是“被统治”——是“被保护、被容纳”。

### 从身体经验出发：孩子靠近她，不会受伤。在他对她的信赖中，他得“安、平、大”

“往而不害，安平大”——在母亲的身体里，“安平大”是什么？

- **“安”——安全。** 他饿了有吃的、困了有抱、怕了有她在。她的存在是一个“安全基地”——他知道“妈妈在”，所以可以放心探索世界。
- **“平”——平和。** 她不是动荡的、不是情绪不稳定的、不是不可预测的。她的回应是稳定的、可预期的——所以他内心是“平”的。
- **“大”——完整、圆满。** 在她的存在里，他不需要“争夺”才能被爱——他是被完整地容纳的。他的存在本身就被接纳了——那就是“大”。
- **“往而不害”的深层含义：** 靠近她，他不会受伤。不是因为“她不会犯错”——是因为即使她犯错，她也不会抛弃他。他不会因为靠近她而被“害”——她不是“乐与饵”（诱惑），她是“大象”。

朱先生说“往而不害安平太”是归道则安平。母亲的身体告诉我们：**孩子靠近她，不会受伤。在他的信赖中，他得了“安”（安全）、“平”（平和）、“大”（完整）。**

| 朱邦復的“往而不害安平太” | 母亲经验的“往而不害安平大” |
| :--- | :--- |
| 归道则安平 | 他靠近她不会受伤——在她那里，他得了“安”（安全）、“平”（平和）、“大”（完整） |
| 第三人称：道的庇护 | 第一人称：在我这里，他不需要争夺才能被爱 |


## 三、“樂與餌，過客止”——音乐和美食，让过客停留

### 朱邦復的解读：声色的诱惑只能吸引过客

朱先生将“乐与饵，过客止”解读为“声色的诱惑只能吸引短暂停留的人”：

> “聲色利誘，能迎合感官，會吸引追求表象的路人流連止步。”

“乐”是音乐，“饵”是食物。“过客”是路过的人——不是“归”的人。声光色彩能让人“停一下”——但不能让人“住下来”。

### 从身体经验出发：奖励、表扬、物质刺激能吸引孩子一时——但不能让他“归”于你

“樂與餌”——在母亲的身体里，“乐与饵”是什么？

- **奖励是“饵”。** “如果你听话，妈妈就给你买玩具”——那是“饵”。它能让他“停一下”——但不能让他“归”。
- **表扬是“乐”。** “你真聪明”、“你太棒了”——那是“乐”。它能让他开心一会儿——但不能让他“归”。
- **“过客止”的养育版本：** 孩子会因为奖励而“听话”——但那个“听话”是暂时的。他停一下，然后又走了。只有“大象”（母亲的存在方式）才能让他真正“归”——不是为了奖励而做，是因为他“在”那里。
- **“乐与饵”与“大象”的区别：** “乐与饵”是外部的、暂时的、需要不断更新的刺激。“大象”是内在的、持续的、不需要更新的在场。孩子会因为“乐与饵”而“停留”——但只有“大象”能让他“归附”。

朱先生说“乐与饵过客止”是声色只能吸引过客。母亲的身体告诉我们：**奖励、表扬能吸引孩子一时——但只有“大象”能让他真正“归”。乐与饵是过客的诱饵——大象是归处的所在。**

| 朱邦復的“乐与饵过客止” | 母亲经验的“樂與餌過客止” |
| :--- | :--- |
| 声色只能吸引过客 | 奖励、表扬能吸引孩子一时——但不能让他真正“归” |
| 第三人称：诱惑的短暂性 | 第一人称：我不需要“奖励”他来靠近我——他是自然归向我的 |


## 四、“道之出言，淡呵其无味也”——道说出来，淡得没有味道

### 朱邦復的解读：道的表述是平淡的

朱先生将“道之出口，淡乎其无味”解读为“道的表现淡而无味”：

> “道之表現，卻是淡而無味。”

道不像“乐与饵”那样刺激感官——它“淡”。没有甜味、没有香味、没有艳丽的声音。它不提供感官快感，但它提供真正的满足。

### 从身体经验出发：母亲的存在是“淡”的——没有甜言蜜语，没有精心设计的表演。但那个“淡”里，有一种孩子离不开的东西

“淡呵其无味也”——在母亲的身体里，“淡”是什么？

- **她不说“甜言蜜语”。** 她不说“你是我最爱的人”、“没有你我活不下去”那些浓烈的话。她说的是“吃饭了”、“该睡了”、“妈妈在”。那是“淡”的。
- **她没有“精心设计的表演”。** 她不是“育儿专家”在镜头前表演“完美的妈妈”——她是真实的、平淡的、甚至有点疲惫的。那是“淡”的。
- **但那个“淡”里有孩子离不开的东西。** 不是“味道”——是“持续”。她的淡是持续的、稳定的、可依赖的。浓烈的东西会消失——淡的东西会一直在。

朱先生说“道之出口淡乎其无味”是道的表现平淡无味。母亲的身体告诉我们：**她不说甜言蜜语——但她说“妈妈在”。那三个字是“淡”的——但孩子离不开它。**

| 朱邦復的“淡乎其无味” | 母亲经验的“淡呵其无味也” |
| :--- | :--- |
| 道的表现平淡无味 | 她不说甜言蜜语——她说“妈妈在”。那是“淡”的——但孩子离不开它 |
| 第三人称：道的不刺激 | 第一人称：我没有“味道”——但我一直在那里 |


## 五、“視之，不足見也”——看它，不值得看、看不见

### 朱邦復的解读：道不值得看、看不见

朱先生将“视之不足见”解读为“不能以目视”：

> “無法以目視。”

“不足见”不是“不值得看”——是“不值得用眼睛去看，因为那不是靠看能捕捉的东西”。道超越视觉——你无法通过“看”来抓住它。

### 从身体经验出发：母亲做的那些事“不值得看”——深夜醒来、重复哄睡——但那些“不值得看”的事，才是真正重要的

“視之，不足見也”——在母亲的身体里，“不足见”是什么？

- **深夜醒来——不值得看。** 你醒了几次？没人记录。你抱着他走了多少步？没人计数。那些事不在“值得看”的范畴里——但它们真实地发生了。
- **重复哄睡——不值得看。** 你唱着同一首歌、拍着同样的节奏、在同一个房间里来回走——那是“不值得看”的。但它让他安静下来了。
- **“不足见”的深层含义：** 母亲的一生，大部分是“不足见”的。那些被看见的“伟大母亲”故事，只是极少数瞬间——真正的母职，是那些“不值得看”的、重复的、被遗忘的日常。

朱先生说“视之不足见”是道不值得用眼睛看。母亲的身体告诉我们：**她做的那些事“不值得看”——深夜醒来、重复哄睡——但那些“不值得看”的事，才是真正重要的。“不足见”正是它的价值所在。**

| 朱邦復的“视之不足见” | 母亲经验的“視之不足見也” |
| :--- | :--- |
| 道不值得用眼睛看 | 她做的事“不值得看”——深夜醒来、重复哄睡——但那些才是真正重要的 |
| 第三人称：道的不可视 | 第一人称：我不在“值得看”的范畴里——但我做的事，他离不了 |


## 六、“聽之，不足聞也”——听它，不值得听、听不见

### 朱邦復的解读：道不值得听、听不见

朱先生将“听之不足闻”解读为“不能以耳闻”：

> “無法以耳聞。”

道超越听觉——你无法通过“听”来抓住它。它的声音不是“被听见”的——是被“感受”到的。

### 从身体经验出发：母亲说的话“不值得听”——“吃饭了”、“该睡了”、“妈妈在”——但她不在的时候，那些话会在他心里回响

“聽之，不足聞也”——在母亲的身体里，“不足闻”是什么？

- **“吃饭了”、“该睡了”、“妈妈在”——这些是“不值得听”的。** 它们太普通、太日常、太没“内容”。你不会把它们放进名人名言集。
- **但她不在的时候——那些话会在他心里回响。** 他饿了的时候会想起她说“吃饭了”；他困了的时候会想起她说“该睡了”；他怕了的时候会想起她说“妈妈在”。那些“不值得听”的话——在需要的时候，成了最清晰的声音。
- **“不足闻”的深层含义：** 母亲的声音不是“被倾听”的——是被“内化”的。它不是“名言”——是“背景音”。但那个背景音，成了他最持久的声音记忆。

朱先生说“听之不足闻”是道不值得用耳朵听。母亲的身体告诉我们：**她说的话“不值得听”——“吃饭了”、“该睡了”、“妈妈在”——但她不在的时候，那些话会在他的心里回响。“不足闻”不是“不值得”——是“不需要被记住，却忘不了”。**

| 朱邦復的“听之不足闻” | 母亲经验的“聽之不足聞也” |
| :--- | :--- |
| 道不值得用耳朵听 | 她说“吃饭了”、“该睡了”——那些话“不值得听”，但她不在的时候，它们在他心里回响 |
| 第三人称：道的不可闻 | 第一人称：我不是在说“名言”——但我的声音，他忘不了 |


## 七、“用之，不可既也”——使用它，不可穷尽

### 朱邦復的解读：道用之不竭

朱先生将“用之不足既”解读为“用之不竭”：

> “卻能滿足人的心靈，取之不盡，用之不竭。”

“既”是尽、完、用光。“不可既”是用不完、不会耗尽。道不是消耗品——你用多少，它也不会少。

### 从身体经验出发：她的爱用不完——即使她疲惫到极限，她还可以再抱一次、再等一次、再陪一次

“用之，不可既也”——在母亲的身体里，“不可既”是什么？

- **她的爱用不完。** 不是因为她“永远不累”——是因为她即使累了，还会继续。她说“再抱最后一次”——但“最后一次”总不是最后一次。
- **她的耐心用不完。** 不是因为她“天生有耐心”——是因为她知道他还在需要。他说“再讲一个故事”——她讲了；他说“再陪一会儿”——她陪了。那个“再”是“不可既”的。
- **“不可既”的深层含义：** 她的爱不是“能源”（会用完的）——是“源泉”（持续涌出的）。不是因为她“有很多”——是因为她持续地“有”。她被消耗了——但她还在给。
- **“不可既”的悖论：** 她自己也有限——但她的给没有“既”（尽头）。不是因为“无穷”——是因为“即使有限，也还在给”。那不是“力量”——那是“意志”；不是“资源”——那是“选择”。

朱先生说“用之不足既”是道用之不竭。母亲的身体告诉我们：**她的爱用不完——即使她疲惫到极限，她还可以再抱一次、再等一次、再陪一次。那不是“力量”——是“意志”；不是“资源”——是“选择”。**

| 朱邦復的“用之不足既” | 母亲经验的“用之不可既也” |
| :--- | :--- |
| 道用之不竭 | 她的爱用不完——即使疲惫到极限，她还可以再抱一次、再等一次 |
| 第三人称：道的无穷 | 第一人称：我不是“永远有力”——我是“即使有限，也还在给” |


## 结语：母亲是“大象”——不显眼，但天下归之

朱邦復先生在这一章中，用“大象”与“乐与饵”的对比，构建了一个深刻的“显隐之辨”：真正的吸引力不是声光色彩（乐与饵）——是“大象”（道）。那些“淡、无味、不见、不闻”的东西，反而“不可既”（用之不竭）。

而母亲的身体，是这一章最完整的“大象”展示者：

- **“执大象，天下往”——她守住那个不张扬的存在方式——孩子自然走向她。**
- **“往而不害，安平大”——他靠近她，不会受伤。在她那里，他得了“安、平、大”。**
- **“乐与饵，过客止”——奖励、表扬能吸引孩子一时——但不能让他真正“归”于她。**
- **“淡呵其无味”——她不说甜言蜜语——她说“妈妈在”。那是“淡”的——但孩子离不开它。**
- **“视之不足见”——她做的事“不值得看”——深夜醒来、重复哄睡——但那些才是真正重要的。**
- **“听之不足闻”——她说“吃饭了”、“该睡了”——那些话“不值得听”，但她不在时，它们在他心里回响。**
- **“用之不可既”——她的爱用不完——即使疲惫到极限，她还可以再抱一次、再等一次。**

**“大象”是母亲的存在方式——不是声光色彩，是平淡无味的日常。** 她不靠“乐与饵”吸引孩子——她是靠“在”吸引他。她不靠表演吸引注意力——她是靠“持续”吸引信任。

**“视之不足见”——母亲做的那些事，没有一件是“值得看的”。** 喂奶、哄睡、深夜醒来——它们不在“精彩瞬间”的范畴里。但正是那些“不值得看”的事，构成了孩子生命中最坚实的根基。

**“听之不足闻”——母亲说的那些话，没有一句是“值得听的”。** “吃饭了”、“该睡了”、“妈妈在”——它们不是“名言”。但她不在的时候——它们成了他心里最清晰的声音。

**“用之不可既”——母亲的爱用不完。** 不是因为她“永远不累”——是因为她即使累了，也还会继续。那不是“力量”——那是“意志”；不是“资源”——那是“选择”。她选择了一再地“再抱一次”。

一个母亲的一生，就是“大象”最日常的版本。她不显眼——但孩子归向她。她的存在是“淡”的——但孩子离不开它。她做的事“不足见”——但那些事构成了他的一切。她说的话“不足闻”——但那些话会一直在他心里。

“执大象，天下往”——你守住的不是“方法”，是“存在”。孩子走向的不是“完美的你”——是“在的你”。那个“在”——就是“大象”。

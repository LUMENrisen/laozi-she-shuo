

## 引言：最“雌性”的一章，最“身体”的回归

帛书本第二十八章，是《德道经》中关于“雌雄、黑白、荣辱”辩证关系最集中的论述，也是与女性身体经验直接相关的章节之一：

> 知其雄，守其雌，為天下溪。為天下溪，恒德不雞（離）。恒（德）不雞（離），復歸嬰兒。
>
> 知其白，守其辱，為天下。為天下浴（谷），恒德乃足。德乃足，復歸於樸。
>
> 知其，守其黑，為天下式。為天下式，恒德不貣（忒）。德不貣（忒），復歸於无極。
>
> 楃（樸）散則為器，聖人用則為官長。夫大制无割。

“知其雄，守其雌”——知道雄的强，但守住雌的柔，成为天下的溪流。成为天下的溪流，恒常的德就不会离开；德不离开，就能回归婴儿的状态。

“知其白，守其辱”——知道白的显，但守住辱的暗，成为天下的山谷。成为天下的山谷，恒常的德就充足；德充足了，就能回归朴（未加工的原木）的状态。

“知其（白），守其黑”——知道白的明亮，但守住黑的暗，成为天下的范式。成为天下的范式，恒常的德就不会有差错；德没有差错，就能回归无极（无限的、未分化的本源）。

“朴散则为器”——原木被雕琢分散后就成为各种器具。圣人使用它（这个道理）就成为官长。真正的大制（完善的治理）是不割裂的。

朱邦復先生在《止笑譚》中，将这一章解读为 **“知雄守雌的策略与回归本真的路径”** 。他认为“守雌、守辱、守黑”是“知其雄、知其白、知其白”之后的主动选择——不是不知道“雄”的优势，而是选择守住“雌”的柔弱；不是没有能力占据“白”的位置，而是选择守住“辱”的卑下。他特别强调了“复归于婴儿、复归于朴、复归于无极”是三个递进的回归阶段——回到最初的状态、回到最简单的形态、回到无限的可能性。最后，“朴散则为器”是讲“道”被应用后产生了具体的作用，“大制不割”则是“完整不可分割”的根本原则。

但如果我们把主语换成“母亲的身体”——那个在怀孕和分娩中经历了“雄与雌、白与黑、荣与辱”完全翻转的身体——这一章就不再是“策略性的守下”，而是 **“身体如何在‘知雄’之后‘守雌’，如何在‘知白’之后‘守辱’，如何在‘散’之后回归‘朴’”的完整记录**：

- “知其雄，守其雌”——你知道“强”是怎样的（怀孕前的身体状态），但你选择守住“柔”（产后身体的脆弱、缓慢、接纳）。你不是“弱”——你是主动“守”了那个“雌”的位置，因为那是生命需要通过的位置。
- “为天下溪”——产道就是“溪”。它是低处的、流动的、敞开的通道。生命通过它从“内”流向“外”。母亲就是“天下溪”——她流着，生命就出来了。
- “复归婴儿”——产后母亲需要重新学习“怎么当自己”。她的身体像婴儿一样——需要被照顾、被允许、不被催促。她“复归婴儿”不是退步——是重新开始。
- “知其白，守其辱”——你知道“干净”是怎样的，但你守住了“脏”（屎尿屁、恶露、奶渍）。你不嫌“辱”——因为你知道这是生命流过的痕迹。
- “为天下谷”——骨盆就是“谷”。低、空、能容。它是凹陷的，但正是那个“凹陷”让生命得以被容纳和释放。
- “复归于朴”——产后身体回到“朴”的状态——不修饰、不打扮、不表演。你不需要“雕琢”——你只需要“在”。
- “朴散则为器”——母亲的身体承载的生命最终成为独立的个体（“器”）。你“散”了——你把身体的一部分给了另一个人，让他成为“器”。
- “夫大制无割”——母亲和孩子从未真正分离。即使物理上分开了、即使脐带剪断了——你们之间没有“割”开的东西。连接还在，只是形式变了。

让我们逐句对照。


## 一、“知其雄，守其雌”——知道雄的强，但守住雌的柔

### 朱邦復的解读：知道强的优势，但选择守柔

朱先生将“知其雄，守其雌”解读为“知道雄的强，但守住雌的柔”：

> “雄为阳刚，具动能，雌为阴柔，具静能。若能以静为主……”

他认为“知雄”是认知层面——你“知道”什么是雄（强、动、显）；“守雌”是实践层面——你“守住”什么是雌（弱、静、隐）。这不是“不得已”——是主动选择。

### 从身体经验出发：你知道怀孕前身体是“强”的——但你选择守住产后的“弱”，因为那是生命需要通过的位置

“知其雄，守其雌”——在母亲的身体里，“雄”和“雌”是什么？

- **“雄”——孕前的身体状态。** 你曾经“强”——能跑、能跳、能做很多事。那是“雄”——充满动能、主动、向外。
- **“雌”——孕后的身体状态。** 你“弱”了——容易累、需要休息、行动慢。那是“雌”——柔、静、向内。
- **但你选择“守雌”。** 你不是“变弱”了——你是在“守”那个“雌”的位置。因为你知道——生命需要你“守”在这里。如果你“不守”了——如果你急着“变回雄”——你会伤害自己、伤害那个正在需要你的生命。
- **“守雌”不是“弱”——是“主动选择做通道”。** 产道是“雌”的——敞开、柔软、被动地接住和释放。母亲的身体就是“守雌”的日常版本——她不“强”了，但正是那个“不强”让生命可以通过。

朱先生说“知其雄守其雌”是知道强的优势但守住柔的位置。母亲的身体告诉我们：**你知道曾经“强”是怎样的——但你现在“守”住了“弱”的位置。因为生命需要你“弱”下来——让它通过。**

| 朱邦復的“知其雄守其雌” | 母亲经验的“知其雄守其雌” |
| :--- | :--- |
| 知道强的优势，但守住柔的位置 | 知道孕前身体的“强”——但选择守住房后身体的“弱”，因为那是生命需要通过的位置 |
| 第三人称：策略性的守下 | 第一人称：我不是“弱”——我是“守”在那个让生命通过的位置 |

## 二、“為天下溪”——成为天下的溪流

### 朱邦復的解读：谿谷是低处的汇聚之所

朱先生将“为天下谿”解读为“如谿谷一般，可蓄集流水”：

> “蓄水於谿，聚能如集德。”

溪是低处的、流动的、敞开的通道。它不拒绝任何水流——它只是接纳、引导、让水通过。

### 从身体经验出发：产道就是“溪”——低处的、敞开的、生命流出的通道

“為天下溪”——在母亲的身体里，“溪”是什么？

- **产道就是“溪”。** 它是低处的——在身体的底部。它是敞开的——分娩时需要张开。它是流动的——羊水、血液、生命都从那里流出。
- **母亲的身体就是“天下溪”。** 她让生命通过。她不“堵”住那个通道——她“开”了。她不是“强”了——她是“通”了。
- **“溪”的另一个层面：** 溪是“流”而不是“存”的。它不“抓住”水——它让水流过去。母亲也是这样——她让生命从她身体里流过，但她不“抓住”他。他通过她——然后成为独立的。

朱先生说“为天下谿”是如谿谷般蓄集流水。母亲的身体告诉我们：**产道就是“溪”——它让生命流过。她不“留住”他——她只是让他通过。**

| 朱邦復的“为天下谿” | 母亲经验的“為天下溪” |
| :--- | :--- |
| 谿谷蓄集流水 | 产道就是“溪”——生命通过它流出 |
| 第三人称：谿谷的比喻 | 第一人称：我是“溪”——他流过我，然后成为他自己 |

## 三、“恒德不離，復歸嬰兒”——恒常的德不离开，就能回归婴儿

### 朱邦復的解读：守住雌柔，德性不离，回归婴儿般的本真

朱先生将“常德不离，复归于婴儿”解读为“守住雌柔，德性不离开，回归婴儿状态”：

> “蓄水於谿，聚能如集德，则如婴儿般返归大自然。”

婴儿是“最接近自然本态”的状态——柔软、不伪装、不造作、完全依赖但不羞耻。

### 从身体经验出发：产后你“复归婴儿”——身体需要被照顾、被允许、不被催促

“復歸嬰兒”——在母亲的身体里，“婴儿”是什么？

- **产后你需要被“照顾”。** 刚生完孩子，你的身体像婴儿一样——不能自主行动（伤口痛）、需要别人帮忙（换药、递水、换姿势）、吃流质食物。你不是“婴儿”——但你的身体需要“婴儿式的照顾”。
- **你“回归”了“需要依赖”的状态。** 怀孕时你是“强大的”——你承载了另一个人。产后你“弱”了——你需要休息、需要慢、需要别人来承载你。你“回归”了“婴儿”的位置——不是退步，是“允许自己需要”。
- **“复归婴儿”不是“变回无知”——是“回到柔软”。** 你不再“硬撑”了。你不再说“我没事”——你说“我需要休息”。你不再伪装——你让自己的身体回到最本真、最不修饰的状态。

朱先生说“复归于婴儿”是回归婴儿般的本真状态。母亲的身体告诉我们：**产后你“复归婴儿”——你需要被照顾、被允许、不被催促。你回到了“柔软”的状态——不是退步，是允许自己需要。**

| 朱邦復的“复归于婴儿” | 母亲经验的“復歸嬰兒” |
| :--- | :--- |
| 回归婴儿般的本真与柔软 | 产后你需要被照顾、被允许——你回到了“需要依赖”的状态 |
| 第三人称：德性的回归 | 第一人称：我不是“退步”——我是回到了“需要”的位置 |

## 四、“知其白，守其辱”——知道白的显，守住辱的暗

### 朱邦復的解读：知道白的光明，但守住辱的卑下

朱先生将“知其白，守其辱”解读为“知道白的光明，但守住辱的卑下”：

> “知道荣显的可贵，却能身处卑污。”

“白”是显、是荣、是干净；“辱”是暗、是卑、是脏。知道“白”是什么，但选择“守”辱——不是被迫的，是主动的。

### 从身体经验出发：你知道“干净”是怎样的，但你守住了“脏”——屎尿屁、恶露、奶渍

“知其白，守其辱”——在母亲的身体里，“白”和“辱”是什么？

- **“白”——干净、整齐、体面。** 你曾经在意的——衣服整洁、头发梳好、身上没有异味。
- **“辱”——脏、乱、狼狈。** 产后你身上有恶露、有奶渍、有汗味、有泪痕。你的睡衣不是“干净的”——是“被用过的”。你不再“干净”了——你“脏”了。
- **但你“守”住了那个“脏”。** 因为你知道——这是生命流过的痕迹。你不嫌它“辱”——因为你是在为另一个生命“脏”。你接纳了那个“辱”——你知道它不是“污点”，是“证据”。

朱先生说“知其白守其辱”是知道白的光明但守住辱的卑下。母亲的身体告诉我们：**你不再“干净”了——但你“守”住了那个“脏”，因为你知道那是生命流过的痕迹。它不是“辱”——它是证据。**

| 朱邦復的“知其白守其辱” | 母亲经验的“知其白守其辱” |
| :--- | :--- |
| 知道白的光明，但守住辱的卑下 | 你知道“干净”是怎样的——但你守住了“脏”（恶露、奶渍），因为那是生命流过的痕迹 |
| 第三人称：荣辱的辩证 | 第一人称：我不嫌它“脏”——因为那是他来过的地方 |

## 五、“為天下谷”——成为天下的山谷

### 朱邦復的解读：山谷是空虚的、低处的、能容纳的

朱先生将“为天下谷”解读为“虚其心、处低下”：

> “虚心若谷，德性充足。”

谷是空的——它虚、低、能纳。成为“天下谷”就是成为那个“能容纳一切”的低处。

### 从身体经验出发：骨盆就是“谷”——低、空、能容。它空的时候接纳，盈的时候释放

“為天下浴”——在母亲的身体里，“谷”是什么？

- **骨盆就是“谷”。** 它是凹陷的、中空的、在身体底部的结构。它“低”——在躯干的最下方。它“空”——非孕期是空的通道。它“能容”——孕期容纳胎儿、分娩时释放。
- **母亲的身体就是“天下谷”。** 她接纳——受精卵着床时，她“接”住了；她容纳——孕期九个月，她“装”住了；她释放——分娩时，她“放”了。她就是那个“谷”——空的时候等着，盈的时候释放。
- **“谷”的深层含义：** 谷是“空的”但“不虚”——它是“准备好了”。空是为了盈，盈是为了放。没有“空”——就没有“盈”的可能。

朱先生说“为天下谷”是虚心若谷、处低下而能容纳。母亲的身体告诉我们：**骨盆就是“谷”——低、空、能容。它空的时候接纳，盈的时候释放。没有空就没有盈。**

| 朱邦復的“为天下谷” | 母亲经验的“為天下浴” |
| :--- | :--- |
| 虚心若谷，处低下而能容纳 | 骨盆就是“谷”——低、空、能容。它空的时候接纳，盈的时候释放 |
| 第三人称：谷的虚空与容纳 | 第一人称：我的“谷”空的时候等他来，盈的时候让他走 |

## 六、“恒德乃足，復歸於樸”——恒常的德充足了，就能回归“朴”

### 朱邦復的解读：德充足则回归朴

朱先生将“常德乃足，复归于朴”解读为“德性充足，真实自然”：

> “虚其心、处低下、德性充足，真实自然。”

“朴”是未加工的原木——粗粝、未雕琢、不加修饰。回归“朴”就是回到最原始、最真实的状态。

### 从身体经验出发：产后身体回到“朴”的状态——不修饰、不打扮、不表演

“復歸於樸”——在母亲的身体里，“朴”是什么？

- **产后身体不修饰了。** 你不上妆、不戴首饰、不穿“好看”的衣服。你的身体像“朴”——粗粝、原始、未经雕琢。你不需要“装饰”自己——你只需要“在”。
- **“朴”不是“简陋”——是“不需要额外的东西”。** 你不需要“好看”来证明自己的价值——你只需要“在”。你的身体是朴实的、真实的、没有表演的。这就是“朴”——被使用过的、被磨过的、但不加修饰的本来面目。
- **“朴”的力量：** 朴木虽然粗糙，但它能撑起一座房子。母亲的身体虽然“不美”了——但它撑起了一个生命。朴是功能性的——不是装饰性的。

朱先生说“复归于朴”是回归朴素、真实的状态。母亲的身体告诉我们：**产后你回到“朴”——不修饰、不打扮、不表演。你不需要“漂亮”——你只需要“在”。**

| 朱邦復的“复归于朴” | 母亲经验的“復歸於樸” |
| :--- | :--- |
| 回归朴素、真实、不加修饰的状态 | 产后身体不修饰、不打扮、不表演——“朴”是真实的、不需要额外东西的自己 |
| 第三人称：质朴的回归 | 第一人称：我不需要“漂亮”——我只需要“在” |

## 七、“知其（白），守其黑，為天下式”——知道白的显，守住黑的暗，成为天下的范式

### 朱邦復的解读：知白守黑，成为榜样

朱先生将“知其白，守其黑，为天下式”解读为“知道白的光明但守住黑的暗处，成为天下的榜样”：

> “瞭解光明顯赫之可貴，卻甘居黯淡卑下的環境，此人可為天下的榜樣。”

“白”是光、是显；“黑”是暗、是隐。知道“白”但“守黑”——这是“知雄守雌”在视觉层面的表达。

### 从身体经验出发：你“知白”——你知道被看见、被认可、被赞赏是什么样的；但你“守黑”——你选择待在暗处、不被看见、不被记录

“知其，守其黑，為天下式”——在母亲的身体里，“白”和“黑”是什么？

- **“白”——被看见、被认可、被赞美。** 你知道“白”是什么样的——站在台上、被夸奖、被感谢、被看见。
- **“黑”——不被看见、不被记录、不被感谢。** 你“守黑”——深夜喂奶、凌晨哄睡、默默付出——都在“黑”里。没有人看见、没有人记录、没有人说“谢谢”。
- **“為天下式”——你成为了“标准”。** 不是因为“你被看见了”——而是因为你“在暗处”做了那些事，成为了“守护”的范式。你不是“榜样”因为“谁都知道你”了——你是“榜样”因为“你真的在那里”。

朱先生说“知其白守其黑为天下式”是知道白的显但守住黑的隐，成为天下的榜样。母亲的身体告诉我们：**你“知白”——你知道被看见是什么感觉；但你“守黑”——深夜的付出、凌晨的回应——都在暗处。正因为你在暗处，你成为了“标准”。**

| 朱邦復的“知其白守其黑为天下式” | 母亲经验的“知其守其黑為天下式” |
| :--- | :--- |
| 知道白的显但守住黑的隐，成为天下的范式 | 你知道被看见是什么感觉——但你选择在暗处（深夜喂奶、凌晨哄睡），正因为如此，你成为了“标准” |
| 第三人称：知显守隐的策略 | 第一人称：我不是在聚光灯下——我在暗处，但我成为了范式 |

## 八、“恒德不忒，復歸於無極”——恒常的德不出差错，就能回归无极

### 朱邦復的解读：守住黑，德就没有差错，回归无极

朱先生将“常德不忒，复归于无极”解读为“守黑而无差错，回归无极境界”：

> “守黑，德性就不会有差错，能返归于无極境界。”

“无极”是无限的、未分化的状态——不是“什么都没有”，是“什么都有可能”的原始状态。

### 从身体经验出发：你“复归无极”——身体的无限可能性。它已经证明自己能创造生命——现在它还能做什么？

“復歸於无極”——在母亲的身体里，“无极”是什么？

- **“无极”是“无限可能”的状态。** 你的身体已经做了一件无限的事——它创造了一个完整的生命。你现在不知道它还能做什么——因为它已经超出了你的认知范围。
- **“复归无极”不是“回到原点”——是“回到无限的可能性”。** 你不再被“原来的自己”限制。你不再说“我只能做到那样”——你说“我不知道我还能怎样”。因为你的身体已经“证”了——它证明了它比你想象的更大。
- **“无极”是“未定型”的。** 你不是“恢复”成原来的你——你是“成为”一个新的、未知的你。你的身体已经改变了——它的可能性也因此改变了。

朱先生说“复归于无极”是回归无限的、未分化的本源状态。母亲的身体告诉我们：**你“复归无极”——你已经证明身体能做远超你想象的事。现在你不知道它还能做什么——那就是“无极”。**

| 朱邦復的“复归于无极” | 母亲经验的“復歸於无極” |
| :--- | :--- |
| 回归无限的、未分化的本源状态 | 你已经证明身体能做远超想象的事——现在它还能做什么？“无极”是未知的可能性 |
| 第三人称：无极的回归 | 第一人称：我回不去原来的我了——但我可以成为我还不知道的新的我 |

## 九、“朴散则为器，圣人用则为官长”——朴分散了就成为器，圣人用它成为官长

### 朱邦復的解读：朴（道）被应用就产生具体的作用

朱先生将“朴散则为器”解读为“原木经过雕琢成为各种器皿”：

> “原木經過雕琢後，就變成各種可用的器皿。”

“朴”是未加工的原木；“散”是被切开、雕琢、成形。朴被应用后就成为“器”（有具体功能的东西）。圣人用这个道理来治理，就成为众人的首领。

### 从身体经验出发：母亲的身体“散”了——它承载的生命成为独立的“器”

“朴散則為器”——在母亲的身体里，“散”和“器”是什么？

- **你“散”了。** 你曾经是一个“朴”——完整的、未分割的自己。但怀孕和分娩让你“散”了——你把身体的一部分给了一个新的生命。你不再是“完整的原来的你”——你被“散”了。
- **那个生命成为了“器”。** 他从你的身体里出来——成为一个独立的、有功能的、可以运作的个体。他就是那个“器”——从“朴”中散出来的、已经成形的、完整的。
- **“散”不是“破碎”——是“分化”。** 你没有被“打碎”——你是被“展开”了。你不是“失去”了——你是在“给出”中成为了一个更大的整体。

朱先生说“朴散则为器”是原木雕琢后成为有用的器皿。母亲的身体告诉我们：**你“散”了——但你散出的东西成为了一个独立的生命。你不是失去了自己——你是在“给出”中成为了更大的整体。**

| 朱邦復的“朴散则为器” | 母亲经验的“朴散則為器” |
| :--- | :--- |
| 原木经过雕琢成为器皿 | 你的身体“散”了——你给出的一部分成为了一个独立的、完整的生命（器） |
| 第三人称：应用的逻辑 | 第一人称：我被“散”了——但散出的东西成为了一个完整的人 |

## 十、“夫大制无割”——真正的大制是不割裂的

### 朱邦復的解读：真正的事物之理是整体互为一体的

朱先生将“大制不割”解读为“真正的事物之理是整体互为一体的，不能分割”：

> “真正的事物之理，是整体互为因果，不能分割的。”

“大制”是最完善的治理/最完整的结构。“不割”是“不能被分割”的——它是一个整体。如果你把它切开了，它就坏了。

### 从身体经验出发：母亲和孩子从未真正分离——脐带剪断了，但连接还在

“夫大制无割”——在母亲的身体里，“无割”是什么？

- **脐带剪断了——但连接还在。** 物理的连接被“割”了——但那个“连接”没有被割断。它还在——在新的形式里。你不知道它在哪里——但你知道它还在。
- **母亲和孩子从未真正分离。** 即使孩子长大了、离开了、有了自己的生活——那个“连接”仍然在。它不是物理的——但它“无割”。你不能割断它，因为它不是物理的。
- **“大制无割”的深层含义：** 母亲不是“两个独立的人”——她是一个“关系”。那个关系不能“割”。你切开的是“脐带”——但你切不开“连接”。因为那个连接不是“器物”——它是“关系”。器可以割——关系不能割。

朱先生说“大制不割”是真正的整体不能被分割。母亲的身体告诉我们：**脐带剪断了——但母亲和孩子从未真正分离。那个连接不能割——因为它不是物理的。它是“大制”——完整的、不可分割的关系。**

| 朱邦復的“大制不割” | 母亲经验的“大制无割” |
| :--- | :--- |
| 真正的整体不能被分割 | 脐带剪断了——但母亲和孩子从未真正分离。连接不能割，因为它不是物理的 |
| 第三人称：整体性的原则 | 第一人称：我们不是两个独立的个体——我们是同一个“无割”的关系 |

## 结语：“守雌”不是弱——是让生命通过的通道

朱邦復先生在这一章中，用“知雄守雌、知白守辱、知白守黑”的辩证结构，构建了一个“主动守下”的智慧框架——知道强的优势但不占、知道显的好处但处卑、知道光的位置但居暗。他认为这样做的结果是“复归于婴儿、复归于朴、复归于无极”——回到最本真、最原始、最无限的状态。

而母亲的身体，是这一章最完整的“实践场”：

- **“知其雄，守其雌”——你知道孕前身体的“强”——但你现在“守”住了产后的“弱”，因为那是生命需要通过的位置。**
- **“为天下溪”——产道就是“溪”——低处、敞开、生命流出。**
- **“恒德不离，复归婴儿”——产后你需要被照顾、被允许——你回到了“婴儿”的状态——不是退步，是允许自己需要。**
- **“知其白，守其辱”——你知道“干净”是怎样的——但你守住了“脏”（恶露、奶渍），因为那是生命流过的痕迹。**
- **“为天下谷”——骨盆就是“谷”——低、空、能容。**
- **“恒德乃足，复归于朴”——产后身体不修饰、不打扮——回到“朴”的状态，不需要额外的东西。**
- **“知其白，守其黑”——你知道被看见是什么感觉——但你选择在暗处、在深夜、在不被记录的地方付出——正因为你在暗处，你成为了范式。**
- **“恒德不忒，复归于无极”——你已经证明身体能做远超想象的事——现在它还能做什么？“无极”是未知的可能性。**
- **“朴散则为器”——你“散”了——但散出的东西成为了一个独立的、完整的生命（器）。**
- **“夫大制无割”——脐带剪断了——但母亲和孩子从未真正分离。连接不能割，因为它是“关系”——不是“器物”。**

**“知其雄，守其雌”——母亲最懂这句话。她知道什么是“强”，但她选择“守”那个“弱”的位置。因为产道是“弱”的、是“雌”的——它必须“守”住那个柔软、敞开、不抵抗的状态，生命才能通过。如果它“雄”了——如果它“强”了——生命就过不来。**

**“夫大制无割”——母亲和孩子不是一个“可以被切开”的关系。脐带可以剪——但连接不能割。因为那不是“物”的连接——是“生命”的连接。它不是“器物”——它是“关系”。器可以割，关系不能割。母亲和孩子就是“大制”——不可分割的整体。**

一个母亲的身体从“知雄守雌”开始——她“守”住了那个“雌”的位置，让生命通过；到“朴散为器”——她“散”了，那个生命成为独立的个体；再到“大制无割”——她明白那个连接从未被割断。这就是“守雌”的一生——不是“弱”的一生——是“让生命通过”的一生。

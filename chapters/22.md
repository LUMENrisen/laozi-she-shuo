

## 引言：最“效率”的一章，最“身体”的扎根

帛书本第五十九章，是《德道经》中关于“治人事天莫若啬”与“深根固柢”的集中论述：

> 治人事天，莫若嗇。夫惟嗇，是以早服。早服是謂重積德。重積德則无不克，无不克則莫知其極。莫知其極，可以有國。有國之母，可以長久。是胃（謂）深槿（根）固氐（柢），長生久視之道也。

“治人事天，莫若啬”——治理人民、事奉天道，没有比“啬”（节俭、爱惜、不浪费）更重要的了。

“夫惟啬，是以早服”——正因为吝啬，所以能够早早就服从于道。“早服是谓重积德”——早早服从于道，就是不断积累深厚的德。“重积德则无不克”——德积累深厚了，就没有什么不能克服的。“无不克则莫知其极”——到了无所不克的地步，就不知道它的极限在哪里了。

“莫知其极，可以有国”——不知道它的极限，就可以拥有国家。“有国之母，可以长久”——有了立国的根本，就可以长久。“是谓深根固柢”——这就是根深蒂固，“长生久视之道也”——是长生久视的道理。

朱邦復先生在《止笑譚》中，将这一章解读为 **“效率是道的基本策略”** 。他认为“啬”就是“效率”：“收入多，付出少，有效率”——用物少、成事多、思维深。他特别强调了“早服”——因为讲求效率，所以很早就服膺于道、积德丰厚。“重积德则无不克”——积累深厚了，就无所不能。“莫知其极”——到了这个境界就不可限量。“有国之母可以长久”——有了根本就可以长久。最后以“深根固柢，长生久视之道”作结——由根源建立起来的，才是长久之道。

但如果我们把主语换成“母亲的身体”——那个在养育中日复一日地“啬”用精力的身体——这一章就不再是“效率的政治哲学”，而是一份 **“关于母亲如何通过‘啬’（精打细算地使用自己）来‘早服’（早早意识到自己的有限性）、在‘重积德’（日复一日的陪伴）中‘无不克’、最终在孩子生命中‘深根固柢’”的日常记录**：

- “治人事天，莫若啬”——对母亲来说，“治人”是陪伴孩子，“事天”是顺应生命的节律。没有比“啬”（精打细算、不浪费精力）更重要的事。她不能把所有力气都用在“看起来有用”的事上——她必须把力气用在“真正重要”的事上。
- “夫惟啬，是以早服”——因为她精打细算地使用自己，所以她早早地意识到：她不能什么都做、不能什么都管、不能什么都“对”。她需要“服”——服从自己的极限、服从孩子的节律、服从“不是所有事都能控制”的事实。
- “早服是谓重积德”——早早地认识到自己的有限性，就是日复一日地“积德”。不是“做大事”才积德——是“每一天不浪费精力在无关的事上”才积德。重复的、简单的、坚持的事——才是“积德”。
- “重积德则无不克”——日复一日地陪伴、等待、回应——积累到一定程度，就没有什么“过不去的”。她经历过孩子的夜醒、生病、叛逆、疏远——但因为她一直在“积”（没有放弃），她总能“克”（度过）。
- “无不克则莫知其极”——她不知道自己“能承受多少”——但每次她觉得“到极限了”，她都又过了一天。她的“极”是不确定的——因为她总是“还能再坚持一天”。
- “莫知其极，可以有国”——“国”是她的家庭、她的孩子。她不知道自己的极限在哪里——所以她可以“有国”（承担起一个家）。
- “有国之母，可以长久”——她作为“母”的存在方式——可以长久地存在于孩子的生命里。不是因为她“活得久”——是因为她“根”扎得深。
- “是谓深根固柢”——母亲在孩子生命中建立的信任、安全感、回应模式——就是“深根”。它不会被轻易拔除——因为它扎得足够深。


## 一、“治人事天，莫若啬”——治理人民、事奉天道，没有比“啬”更重要的

### 朱邦復的解读：“啬”就是效率

朱先生将“治人事天，莫若啬”解读为“必须要有‘啬’的观念”：

> “自我修身，追求道理，必須要有效率觀念。”

他将“啬”解释为“效率”——收入多、付出少，“用物少，成事多，思维深”。这是大自然最成功的策略——能量循环无分毫浪费。

### 从身体经验出发：对母亲来说，“治人”是陪伴孩子，“事天”是顺应生命节律。没有比“啬”更重要的事

“治人事天”——在母亲的身体里，“治人”和“事天”是什么？

- **“治人”——她陪伴孩子、回应他、引导他。** 那是“治人”——不是“治理”是“陪伴”。
- **“事天”——她顺应生命的节律。** 她不是“逆”着孩子的成长节奏走的——她是“顺”着走的。那是“事天”——顺应天道。

**“莫若啬”——没有比“啬”更重要的事。** “啬”不是“吝啬”的啬——是“精打细算地使用自己”。她不能把所有力气都用在“看起来有用”的事上——她必须把力气用在“真正重要”的事上。她不能什么都做、什么都管、什么都“对”——她只能“啬”着用自己。

朱先生说“啬就是效率”——母亲的身体告诉我们：**她不能什么都做——她必须精打细算地使用自己。把力气用在“真正重要”的事上——那是“啬”。**

| 朱邦復的“啬即效率” | 母亲经验的“啬” |
| :--- | :--- |
| 收入多、付出少，有效率 | 她精打细算地使用自己——把力气用在真正重要的事上 |
| 第三人称：效率的策略 | 第一人称：我不能什么都做——我必须“啬”着用自己 |


## 二、“夫惟啬，是以早服”——正因为啬，所以能早服

### 朱邦復的解读：因效率而早服

朱先生将“夫唯啬，是以早服”解读为“因为讲求效率，所以早服于道”：

> “因為講求效率，所以很早就服膺於道。”

“服”是服从、服膺于道。“早服”是早早地就“服”了——不是“晚服”或“不服”。效率让他早早意识到：只有顺应道，才能不浪费。

### 从母亲经验的解读：因为她精打细算地使用自己，所以她早早意识到：她不能什么都做、什么都管——她需要“服”

“夫惟嗇，是以早服”——在母亲的身体里，“早服”是什么？

- **她早早地“服”了。** 她精打细算地使用自己——所以她早早意识到：她不能什么都做、什么都管、什么都“对”。她需要“服”——服从自己的极限、服从孩子的节律、服从“不是所有事都能控制”的事实。
- **“早服”的另一种理解：** 她不是“学了育儿方法之后才服”——她是“当了妈妈之后很快就服了”。因为她的精力告诉她：你不可能做到所有事。你只能“啬”着做最重要的事。
- **“早服”不是“妥协”——是“认清”。** 她不是“放弃”了——她是“选择”了。选择不做那些“看起来对”但“消耗自己”的事。那是“早服”。

朱先生说“啬则早服”是效率让她早服于道。母亲的身体告诉我们：**她早早意识到不能什么都做——她“服”了。不是妥协——是选择。选择只做最重要的事。**

| 朱邦復的“啬则早服” | 母亲经验的“夫惟嗇是以早服” |
| :--- | :--- |
| 效率让人早服于道 | 她早早意识到不能什么都做——她“服”了。不是妥协，是选择 |
| 第三人称：效率与服从 | 第一人称：我早早地就“服”了——因为我只有这么多力气 |


## 三、“早服是谓重积德”——早服就是重积德

### 朱邦復的解读：早服即积德

朱先生将“早服谓之重积德”解读为“早服于道就是积德”：

> “早服謂之重積德。”

“早服”本身就是“积德”——不是“做了大事才积德”——是“早早服从道的节奏”本身就是积德。

### 从母亲经验的解读：早早认识到自己的有限性，就是日复一日地“积德”——不是做大事才积德，是每一天不浪费精力才积德

“早服是胃重積德”——在母亲的身体里，“重积德”是什么？

- **她天天在做——但那些事不是“大事”。** 喂奶、换尿布、哄睡、回应——每一件都是“小”事。但日复一日地坚持做那些“小”事——就是“积德”。不是“做大事”才积德——是“每一天不浪费精力在无关的事上”才积德。
- **“重积德”的另一种理解：** 她不是“一次性”的——是“重复”的。“重”是“重复”——日复一日地、一次又一次地。她每天“积”一点——积久了就“重”了（深厚了）。
- **“积德”不是“积累功劳”——是“积累力量”。** 她积累的不是“别人说她好”的资本——她积累的是“她能够继续”的力量。那才是“德”。

朱先生说“早服即积德”是早服本身就是积德。母亲的身体告诉我们：**她日复一日地做那些“小”事——那就是“重积德”。重复的、简单的、坚持的事——才是“积德”。**

| 朱邦復的“早服即积德” | 母亲经验的“早服是胃重積德” |
| :--- | :--- |
| 早服本身就是积德 | 她日复一日地做那些“小”事——重复的、简单的、坚持的——才是“积德” |
| 第三人称：积德的本质 | 第一人称：我不是做“大事”——我是重复做“小”事 |


## 四、“重积德则无不克”——积德深厚则无所不克

### 朱邦復的解读：积德深厚则无所不克

朱先生将“重积德则无不克”解读为“积德深厚则无所不能”：

> “重積德則無不克。”

“克”是克服、战胜。德积累深厚了——就没有什么不能克服的。

### 从母亲经验的解读：日复一日的陪伴、回应、坚持——积累到一定程度，没有什么“过不去的”

“重積德則无不克”——在母亲的身体里，“克”是什么？

- **她经历了夜醒、生病、叛逆、疏远——但她都“克”了。** 不是因为“她很有办法”——是因为“她一直在”。她日复一日地陪伴、回应、坚持——积累到一定程度，就没有什么“过不去的”。
- **“无不克”的另一种理解：** 不是她“每一件事都解决得很好”——是“每一件事她都度过了”。她“克”的不是“问题”——她“克”的是“放弃”。
- **“无不克”不是“胜利”——是“不放弃”。** 她每次觉得“不行了”——她都又过了一天。那是“无不克”——不是“都解决了”，是“都度过了”。

朱先生说“重积德无不克”是积德深厚则无所不克。母亲的身体告诉我们：**她日复一日地坚持——积累到一定程度，没有什么“过不去的”。不是“都解决了”——是“都度过了”。**

| 朱邦復的“重积德无不克” | 母亲经验的“重積德則无不克” |
| :--- | :--- |
| 积德深厚则无所不克 | 她日复一日地坚持——没有什么“过不去的”。不是“解决了”——是“度过了” |
| 第三人称：积德的力量 | 第一人称：我不是“都解决了”——我是“都度过了” |


## 五、“无不克则莫知其极”——无所不克则不知其极

### 朱邦復的解读：到了极限就无法衡量

朱先生将“无不克则莫知其极”解读为“无所不克则不知极限”：

> “到了這個境界，則不知其極限。”

“极”是极限、终点。当一个人“无不克”时——你不知道他的极限在哪里。不是“没有极限”——是“极限不确定”。

### 从母亲经验的解读：她不知道自己“能承受多少”——每次觉得到极限了，她又过了一天

“无不克則莫知其極”——在母亲的身体里，“其极”是什么？

- **她不知道自己的极限。** 每次她觉得“我撑不住了”——第二天她还是醒了、还是做了、还是陪了。她不知道自己的极限在哪里——因为她的极限总是在“还能再坚持一天”的地方。
- **“莫知其极”不是“没有极限”——是“极限不确定”。** 她不知道“什么时候会到极限”——因为她每次都“又过了一天”。她的“极”是移动的——随着她每天的“积德”而延后。
- **“莫知其极”的另一种理解：** 她不知道自己能走多远——但她知道自己还能再走一步。不是“知道终点”——是“能走下一步”。

朱先生说“无不克则莫知其极”是无所不克则不知极限。母亲的身体告诉我们：**她不知道自己的极限——每次觉得“到了”，她又过了一天。她的“极”是移动的——随着“积德”而延后。**

| 朱邦復的“无不克则莫知其极” | 母亲经验的“无不克則莫知其極” |
| :--- | :--- |
| 无所不克则不知极限 | 她不知道自己能承受多少——每次觉得到极限了，她又过了一天 |
| 第三人称：极限的不确定性 | 第一人称：我不知道我的极限——我只会“再走一步” |


## 六、“莫知其极，可以有国”——不知其极，可以拥有国家

### 朱邦復的解读：不知极限则可以拥有国家

朱先生将“莫知其极，可以有国”解读为“不可限量，就可以治理国事”：

> “不可限量，就可以治理國事。”

一个不知极限的人——可以承担大任。不是因为“他有多强”——是因为“他不设限”。

### 从母亲经验的解读：她不知道自己的极限在哪里——所以她可以承担一个家

“莫知其極，可以有國”——在母亲的身体里，“有国”是什么？

- **“国”是她的家。** 她承担的不是“国家”——是一个家。一个家就是一个“国”——有秩序、有边界、有爱、有需要。
- **她不知道自己的极限——所以她能承担。** 如果她知道“我做不了”——她可能就不做了。但因为她“莫知其极”（不确定）——她继续了、她承担了、她“有国”了。
- **“可以有国”的深层含义：** 她的“国”不是“统治”来的——是“承担”来的。她不知道自己的极限——所以她能承担一个家。

朱先生说“莫知其极可以有国”是不知极限则可治理国事。母亲的身体告诉我们：**她不知道自己的极限——所以她能承担一个家。如果她知道“我做不了”——她可能就不做了。**

| 朱邦復的“莫知其极可以有国” | 母亲经验的“莫知其極可以有國” |
| :--- | :--- |
| 不知极限可治理国事 | 她不知道自己的极限——所以能承担一个家 |
| 第三人称：不知限的承担 | 第一人称：我不知道我能不能做到——但我做了 |


## 七、“有国之母，可以长久”——有国之母则可以长久

### 朱邦復的解读：有国母则可长久

朱先生将“有国之母，可以长久”解读为“有了根本则可以长久”：

> “有道，與大自然同宗，故可長久。”

“母”是根本、起源。“有国之母”是有了立国的根本——那个“母”让它可以长久。

### 从母亲经验的解读：她作为“母”的存在方式——可以长久地存在于孩子的生命里

“有國之母，可以長久”——在母亲的身体里，“有国之母”是什么？

- **她作为“母”的位置——可以长久。** 不是因为她“活得久”——是因为她“扎得深”。她在孩子生命中建立的存在方式——可以长久地存在下去。
- **“长久”的另一种理解：** 她的影响不会因为她“不在”就消失。她给的信任、安全感、爱的能力——那些会继续。那是“长久”——不是因为“她在”——是因为“她给的在”。
- **“有国之母”不是“拥有国”——是“作为国之母”。** 她不是“统治”孩子——她是“作为母亲”存在于孩子的生命里。那个存在方式是“长久”的。

朱先生说“有国之母可以长久”是有了根本则可以长久。母亲的身体告诉我们：**她作为“母”的位置——可以长久地存在于孩子的生命里。不是因为“她在”——是因为“她给的在”。**

| 朱邦復的“有国之母可以长久” | 母亲经验的“有國之母可以長久” |
| :--- | :--- |
| 有根本则可长久 | 她作为“母”的位置——可以长久地存在于孩子的生命里 |
| 第三人称：立国的根本 | 第一人称：我在他生命里——不是因为“我在”，是因为“我给的”在 |


## 八、“是谓深根固柢”——这就是深根固柢

### 朱邦復的解读：深根固柢是长久的根本

朱先生将“是谓深根固柢”解读为“由根源建立起来，才是长久之道”：

> “此‘深根固柢，長生久視’之道，即以效率為基本，自我要求，全力以赴，大道可成也。”

“根”是树根，“柢”是树根（古同“根”）。“深根固柢”是根扎得深、扎得稳。这样的树不会被拔除。

### 从母亲经验的解读：母亲在孩子生命中建立的信任、安全感、回应模式——就是“深根”——不会被轻易拔除

“是胃深槿固氐”——在母亲的身体里，“深根固柢”是什么？

- **她建的“根”不在表面。** 她不是通过“教”来建根的——她是通过“在”来建根的。日复一日的陪伴、回应、不放弃——那些在看不见的地方扎了根。
- **“深根”不会被轻易拔除。** 即使她偶尔犯错、即使她不在身边——那个“根”还在。因为它是“深”的——不是“浅”的。
- **“深根固柢”的另一种理解：** 孩子对她的信任——不是因为“她做对了”才有的——是因为“她一直在”才有的。那个“一直在”就是“深根”。

朱先生说“深根固柢”是长久之道。母亲的身体告诉我们：**她在孩子生命中建立的信任、安全感、回应模式——就是“深根”——不会被轻易拔除。因为它是“在”里长出来的，不是“做”里长出来的。**

| 朱邦復的“深根固柢” | 母亲经验的“深槿固氐” |
| :--- | :--- |
| 根深蒂固是长久之道 | 她建立的信任、安全感——就是“深根”，不会被轻易拔除 |
| 第三人称：长久的根本 | 第一行人：我建的根不在表面——在深处，不会被拔 |


## 结语：“啬”——母亲最深的生存智慧

朱邦復先生在这一章中，用“效率论”和“积德论”的框架，解读了“治人事天莫若啬”的“啬即效率”原则，以及“早服、重积德、无不克、莫知其极、有国之母、深根固柢”的完整链条。他认为“啬”是效率，“早服”是早早服道，“积德”是积累深厚，“无不克”是无所不能，“莫知其极”是不可限量，“有国之母”是立国根本，“深根固柢”是长久之道。

而母亲的身体，是这一章最完整的“啬-早服-积德-深根”的演绎者：

- **“治人事天，莫若啬”——她不能什么都做——她必须精打细算地使用自己。把力气用在真正重要的事上。**
- **“夫惟啬，是以早服”——她早早意识到不能什么都做——她“服”了。不是妥协，是选择。**
- **“早服是谓重积德”——她日复一日地做那些“小”事——重复的、简单的、坚持的——才是“积德”。**
- **“重积德则无不克”——她日复一日地坚持——没有什么“过不去的”。不是“解决了”——是“度过了”。**
- **“无不克则莫知其极”——她不知道自己能承受多少——每次觉得到极限了，她又过了一天。**
- **“莫知其极，可以有国”——她不知道自己的极限——所以能承担一个家。**
- **“有国之母，可以长久”——她作为“母”的位置——可以长久地存在于孩子的生命里。**
- **“是谓深根固柢”——她建立的信任、安全感——就是“深根”——不会被轻易拔除。**

**“啬”——母亲最深的生存智慧。** 她不能什么都做、什么都管、什么都“对”——她必须“啬”着用自己。把力气用在“真正重要”的事上。那些“看起来重要”但“消耗自己”的事——她不做了。那是“啬”。

**“早服”——母亲早早“服”了。** 她早早意识到：我不能什么都做、我不能什么都“对”、我不能控制一切。她“服”了——不是“放弃”——是“选择”。选择只做最重要的事。

**“重积德”——母亲日复一日地“积德”。** 不是做“大事”——是做“小”事。喂奶、换尿布、哄睡、回应——每一件都是“小”事。但重复地做那些“小”事——就是“积德”。积累久了——就成了“重”。

**“深根固柢”——母亲建的“根”是深的。** 她不是通过“教”来建根的——是通过“在”来建根的。日复一日的陪伴、回应、不放弃——那些在看不见的地方扎了根。即使她偶尔犯错、即使她不在身边——那个“根”还在。因为它是“深”的。

一个母亲的身体，就是“啬”最日常的版本。她精打细算地使用自己——她早早“服”了——她日复一日地“积德”——她在孩子生命中扎下了“深根”。那个根不会被轻易拔除——因为它是从“啬”里长出来的，从“早服”里长出来的，从“日复一日”里长出来的。那是“深根固柢”——不是“深”在表面——是“深”在看不见的地方。



## 引言：最“空”的一章，最“满”的身体

帛书本这一章（通行本第四章）是全书中意象最“虚空”的之一——它讲的是“道”的虚空、不盈、和光同尘、在先于帝的状态。原文：

> 道冲，而用之又弗盈也。
>
> 潚（淵）呵始（似）萬物之宗。
>
> 銼（挫）其（銳），解其紛，和其光，同其塵。
>
> 湛呵似或存。吾不知誰子也，象帝之先。

这一章与通行本第四章基本一致，核心意象：**道是“冲”的（虚空的），但用起来永远不“盈”（不满、不竭）；它像深渊一样，是万物的源头；它“挫锐解纷、和光同尘”，锋利的被磨平、纷乱的被解开、光芒被调和、尘垢被混同；它寂静中似乎存在，不知从何而来，却在一切神明之先。**

朱邦復先生在《止笑譚》中，将这一章解读为**“宇宙本体的虚空性”**——道是能量的本源，虚空却能生万有，“用之不盈”是因为它是无尽的能量场。

但从身体经验看，这一章的每一个词都指向一个具体的物理空间：**子宫。** 虚空却能容、容纳而不满、深渊般的存在、不知谁是它的“子”、却在一切秩序之前——这不是“道”的比喻，这是每一个母亲身体里真实发生过的、从虚空到充盈的九个月。

这可能是帛书《德道经》中，最接近“母体经验”的一章。

---

## 一、“道冲，而用之又弗盈也”——虚空能容，容而不满

### 朱邦復的解读：空间能量的“不盈”定律

朱先生对这一句的解读，延续了他的“空间-能量”模型：

> “道冲而用之或不盈，渊兮似万物之宗。”
>
> “宇宙本體對孕育於其中的渺小人類說來，無邊無際，無始無終。故站在人的立場，可以視之為‘無盡’。”

他特别强调了“不盈”的含义——虚空之所以能“用之不盈”，是因为它是无穷的。**你从虚空里取东西，它不会减少；你把东西放进去，它不会满。**

这是一个关于“容量”的论述——真正的“大”是能容而不满。

### 从身体经验出发：子宫从空虚到充盈，再回空虚，却从未“满”

一个母亲的身体里，有一个最直观的“冲而用之弗盈”的实例：**子宫。**

- **“冲”**——子宫的正常状态是空虚的、狭窄的、几乎不存在的。它是一个潜在的空间，而非实际的空间。
- **“用之又弗盈”**——当一个生命需要空间时，它开始扩张，从拳头大小扩张到能容纳一个完整的胎儿、羊水、胎盘——数升的内容物。但它从不“盈”——不会撑破、不会停止生长，因为它会随着生命的需求继续扩大，直到那个生命准备好离开。
- **“弗盈”的另一个层面**——孩子出生后，子宫收缩回原来的大小。它虚空了，但不是“空了”——它还有一个记忆，一个“曾经装过一个完整生命”的记忆。下次需要时，它仍然能再装满。虚空而不空——这就是“用之又弗盈”。

朱先生说的“无始无终的能量场”，在子宫里是**真实的、可感的、月复一月的体验**。一个母亲不需要读《道德经》就知道“虚空能容”——因为她的身体就是一个反复从虚空到充盈、再从充盈回虚空的空间。

### 对照小结

| 朱邦復的“道冲而用之不盈” | 身体经验的“道冲而用之不盈” |
| :--- | :--- |
| 宇宙本体的能量场，虚空却无穷无尽 | 子宫从空虚到扩张再到收缩，容量追随生命需求 |
| 第三人称：物理空间的能量特性 | 第一人称：我的身体里有一个“虚空能容”的器官 |

## 二、“淵兮似萬物之宗”——深渊般的本源

### 朱邦復的解读：能量的无尽之源

朱先生将“渊”解读为“深不可测的本源”：

> “淵大廣博是萬事萬物之本源。”

道像深渊——你看不到底、摸不到边，但它是一切事物的源头。这是一个关于“深度”的意象——真正的本源不在表面，在深处。

### 从身体经验出发：子宫是最原初的“深渊”

“渊”最直接的身体意象是什么？**子宫。** 它在身体的深处——骨盆的最中央，被骨骼、肌肉、脏器层层包裹。你从外面看不到它，摸不到它，但它是一切生命的“宗”（源头）。

**“淵”的另一个意象：羊水。** 胎儿在子宫里，漂浮在羊水中。羊水是深色的、温热的、流动的——它是胎儿最早的“渊”。胎儿在“渊”里待了九个月，从“渊”中获得了氧气、养分、体温。每个活着的人，都曾经在一个“渊”里。

朱先生用“本源”这个词来解读“万物之宗”——但如果“宗”是子宫，“萬物之宗”就是那个**让一切生命得以开始的物理空间**。它不是比喻，它是真的。每一个活着的人，都从那里来。

### 对照小结

| 朱邦復的“渊兮似万物之宗” | 身体经验的“渊兮似万物之宗” |
| :--- | :--- |
| 深不可测的能量本源 | 子宫在身体深处、羊水包裹胎儿的温热液体 |
| 第三人称：宇宙的生成原点 | 第一人称：我在那个“渊”里待了九个月 |

---

## 三、“挫其锐，解其纷，和其光，同其尘”——磨去锋芒、解开纷乱、调和光芒、混同尘垢

### 朱邦復的解读：去除极端、归于中道

朱先生将这一句解读为“道的调和特性”：

> “道是鋒芒盡斂，紛擾畢解，光輝隱遁，混同塵俗。”
>
> “事物各有其殊異現象，殊異是偏頗、極端，唯有所有殊異的總和，才是‘道’。”

在朱先生看来，“挫锐”是去除尖锐的边缘，“解纷”是解开复杂的纠葛，“和光”是不让光芒刺眼，“同尘”是与世俗混同而不再突出。这是**道的“去极化”特质**——不极端、不突出、不显眼。

### 从身体经验出发：分娩时胎儿的“挫锐”——产道挤过最硬的头骨

“挫其锐”如果是一个母亲的身体经验，最直接的意象是什么？**分娩时产道对胎儿头骨的挤压。**

胎儿是“锐”的——他的头骨是全身最硬的部分，像一枚炮弹。分娩时，胎儿需要通过产道——而产道是弯曲的、狭窄的、有弹性的。“锐”（头骨）被产道“挫”了——它不是被“磨平”（字面意思），而是被**顺应**了——胎儿的头骨在通过产道时会轻微重叠、变形，以便顺利通过。这种“变形”不是被摧毁，而是被“引导”通过一个狭窄的通道。这就是“挫其锐”的真实版本——生命的入口太窄，你必须“变软”一点才能通过。

**“解其纷”**——你解开过新生儿的脐带吗？那是一团纠缠的、湿润的、螺旋状的绳索。它连接着两个生命。胎盘娩出后，你看着它——它是“纷”的。一团组织、一堆血管、一个圆盘、一个结——但它的“纷”不是混乱，是**有组织的复杂性**。你不需要“解”它，因为它本身就是“解”的结果——母体和胎儿通过这团纷乱达成了交流。

**“和其光”**——新生儿的第一道光。他在黑暗的子宫里待了九个月，从不见光。出生后，光第一次照在他身上——不是刺眼的、强烈的光，而是被产房的灯光、母亲皮肤的反光、被羊水膜过滤后的柔和光。他的眼睛在适应。“和光”就是不让第一道光太刺眼，让他在光中睁开眼睛。

**“同其尘”**——母亲的皮肤。你听过“新生儿不要洗掉胎脂”的建议吗？胎脂是覆盖在新生儿皮肤上的一层白色蜡状物质，它像是“尘”——但它不是需要被洗掉的，它是保护层。母亲不会说“你真脏”，她会说“这是你的第一层衣服”。产房里的血、羊水、汗水、胎脂——那是“尘”——而母亲和孩子一起，在“尘”中完成了第一次见面。

朱先生用“修养”来解读“和光同尘”——但在产房里，“和光同尘”是真实发生的物理事件：光线被调暗、皮肤上带着胎脂、血水与汗水混在一起。那不是“境界”，那是**分娩当天的现场**。

### 对照小结

| 朱邦復的“挫锐解纷、和光同尘” | 身体经验的“挫锐解纷、和光同尘” |
| :--- | :--- |
| 去除极端、归回中道、修养境界 | 胎头被产道顺应、脐带的纷乱组织、新生儿的第一道光、胎脂与羊水 |
| 第三人称：道的调和特性 | 第一人称：分娩当天的现场描述 |

## 四、“湛呵似或存”——安静得好像存在，又好像不存在

### 朱邦復的解读：似有似无的本源

朱先生将“湛”解读为“明确透澈”，同时强调“似或存”——它好像存在，但又捉摸不定：

> “大道明確透澈，似存在於虛無之間。”

道是那种“你知道它在，但你不确定它在哪”的东西。它不显露，但它不缺席。

### 从身体经验出发：孕早期的“存在感”——你知道它在，但你感觉不到

一个母亲最熟悉的“湛呵似或存”是什么？**孕早期的“存在感”。**

你知道自己怀孕了——验孕棒上有两条杠。但你感觉不到它。没有胎动、没有明显隆起、没有可以触摸的轮廓。它“似或存”——你知道它在那里，但你找不到它的证据。你唯一的“证据”是疲惫、恶心、停经——这些是**副作用**，不是“存在”本身。真正的“它”还在沉默中生长，不声不响。

**“湛”的另一个层面：羊水中的胎儿。** 他在羊水里，你在外面。他能听到你的声音，但你听不到他的。他能感觉到你的呼吸和心跳，但你感觉不到他的。他是一个“湛呵似或存”的存在——他在那里，但你不确定他在哪里，在做什么，在想什么（如果他那时已经有“想”的能力）。你知道他在那里，是因为他在踢（孕晚期），但孕早期呢？他只是“似或存”——存在，但无法被感知。

朱先生说“道似存在於虛無之間”——孕早期的胎儿就是这种“似有似无”的状态：生命已经开始了，但它的痕迹还无法被直接触摸。

### 对照小结

| 朱邦復的“湛呵似或存” | 身体经验的“湛呵似或存” |
| :--- | :--- |
| 道在虚无中存在，不可捉摸 | 孕早期胎儿的“存在”——你知道他在，但感觉不到 |
| 第三人称：本体的隐现 | 第一人称：我知道你在那里，但我找不到你 |

## 五、“吾不知誰子也”——不知谁之子

### 朱邦復的解读：道先于一切存在

朱先生将“吾不知谁之子”解读为“道的先在性”：

> “吾不知其來自何方，但於天地生成之前，已經無所不在了。”

道不是任何人的“子”——因为它先于一切。它不是被生的，它是生者本身。

### 从身体经验出发：“誰子”的不确定性——代孕、领养、不知生父的母亲

“吾不知谁子也”——如果一个母亲说出这句话，它有好几层意思。

**第一层：最原始的“不知”。** 在亲子鉴定技术之前，一个母亲“不知谁子”——她不一定知道孩子的父亲是谁。这不是羞耻，是**生命的模糊性**。孩子是她的，但“谁”的？她可能不知道。但孩子仍然是她的孩子。血缘是确定的，但“谁”的名字是不确定的。道“不知谁子”——不是因为不存在，而是因为**它的来源无法被追溯到一个单一的名**。

**第二层：代孕的模糊。** 一个代孕的母亲——她“生”了孩子，但孩子不是“她的子”。她不知“谁子”——这个孩子归谁？生物学的孩子，还是法律的孩子？这是一个极度复杂的“谁子”问题。道的“不知谁子”在这里变成了法律与伦理的交界地带。

**第三层：领养的模糊。** 一个领养孩子的母亲——她“养育”了孩子，但她不是生物学上的“子”的来源。孩子是“谁子”？从伦理上，是她的；从生物上，不是。道的“不知谁子”——因为它不来自一个可以被确认的“亲”的关系。

朱先生说“道不是任何人的子”，这是宇宙论。但母亲的经验告诉我们：**“不知谁子”是每天都在发生的真实——有些孩子来自未知的父亲，有些孩子来自另一个女人的子宫，有些孩子来自一个文件而不是一个身体。** 道的“先在性”不是抽象的本体论，它是**一切“来源”被模糊化、被去标签化的真实状态**。

### 对照小结

| 朱邦復的“吾不知谁子也” | 身体经验的“吾不知谁子也” |
| :--- | :--- |
| 道先于一切存在，不是被生的 | 生命的来源模糊——不知生父、代孕、领养、血缘与养育的分离 |
| 第三人称：宇宙的本体论 | 第一人称：我的孩子来自哪里——一个复杂的问题 |

## 六、“象帝之先”——在一切秩序之前

### 朱邦復的解读：道先于造物主

朱先生将“象帝之先”解读为“道比造物主更早”：

> “道成於天地之先，為宇宙萬物的基本法則。”

“帝”在先秦指“神”或“造物主”。“象帝之先”说道在神明之前就已经存在了。

### 从身体经验出发：母职先于父权秩序

“象帝之先”——如果主语是一个母亲，这句话意味着什么？

**在所有的社会规则之前，在所有的法律文件之前，在所有的出生证明之前——母职先于一切秩序而存在。**

- 在你拿到出生证明（“帝”——国家、法律、制度）之前，你已经在做母亲了。
- 在医生给你下诊断（“帝”——医学权威）之前，你已经知道自己的身体发生了变化。
- 在法官裁定抚养权（“帝”——法律秩序）之前，你和孩子已经建立了连接。

**“象帝之先”在生理学上还有一个意思：母体先于胎儿的性别认识。** 在你知道是男孩还是女孩（“帝”——社会性别的标签）之前，你已经抱着他了。性别是“帝”（社会秩序、分类系统），而拥抱是“先”的。

朱先生用“道比造物主更早”来解读“象帝之先”——但在母亲的体验里，“象帝之先”意味着：**在孩子被贴上任何标签（性别、民族、阶级、户籍）之前，她已经认识他了。** 那个认识，先于一切社会秩序。那个连接，先于一切法律认定。那个爱，先于一切分类系统。这才是“道”被体验的方式——不是作为宇宙法则，而是作为**“先于一切标签的、从身体里长出来的”**那种原始联系。

### 对照小结

| 朱邦復的“象帝之先” | 身体经验的“象帝之先” |
| :--- | :--- |
| 道在造物主之前 | 母职在法律、诊断、社会标签之前 |
| 第三人称：宇宙的时间序列 | 第一人称：在我知道你是男孩还是女孩之前，我已经认识你了 |

## 结语：深渊、子宫与“先于一切”的道

朱邦復先生在这一章的解读中，给我们呈现了一个**关于“虚空”和“先在”的本体论模型**：道是虚空的但用之不竭，是深渊般的本源，是挫锐解纷的调和者，是先于一切秩序的存在。

而身体经验告诉我们：**这个“虚空”、“深渊”、“先于一切”的道，有一个最具体的物理空间——子宫。**

- “道冲而用之弗盈”——子宫能扩能缩，容纳一个完整生命却从不“满”。
- “渊兮似万物之宗”——胎儿在羊水的深渊里漂浮了九个月。
- “挫其锐，解其纷”——产道顺应的过程，脐带——那团生命与生命之间的“纷”缠结。
- “和其光，同其尘”——新生儿的第一道光，胎脂与羊水——产房里的“尘”。
- “湛呵似或存”——孕早期“你知道它在，但你感觉不到”的似有似无。
- “吾不知谁子也”——生命的来源模糊、养育与血缘分离、亲之名无法定义所有连接。
- “象帝之先”——母职先于出生证明、先于性别标签、先于一切社会秩序。

朱先生读到的是**宇宙的“虚空”**——能量场、空间、本源。我们从身体里读到的是**生命的“虚空”**——子宫、羊水、产道、胎脂、胎心、脐带、胎盘。

但如果把这两者放在一起看：**宇宙的虚空，与身体的虚空，说的可能是同一件事。** 子宫是一个微观的宇宙——能量（脐带血）、空间（扩张与收缩）、时间（九个月）、生成（一个细胞分裂成万亿个）——都在一个母亲的身体里发生。而道，就是这个过程背后的那个“先于一切”的逻辑：先于秩序、先于规则、先于标签、先于“这是谁的”。在这一切被决定之前，生命已经开始了。在标签贴上去之前，连接已经建立了。在定义“我是谁”之前，我已经存在了。

**“象帝之先”——在一切秩序之前，子宫已经在工作了。**

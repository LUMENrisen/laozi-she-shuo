

## 引言：最“软”的一章，最“硬”的隐喻

帛书本第八章，是《德道经》中意象最绵密、最诗意的章节之一：

> 上善治（似）水。水善利萬物而有靜（爭），居眾之所惡，故幾於道矣。
>
> 居善地，心善潚（淵），予善信，正（政）善治，事善能，蹱（動）善時。
>
> 夫唯不靜（爭），故无尤。

“上善若水”——最高的善就像水一样。水善于利万物而不争，处在众人厌恶的低处，所以接近道。然后是一个“善”的七重奏：居善地、心善渊、与善仁、言善信、正善治、事善能、动善时。最后总结：不争，所以没有过失。

朱邦復先生在《止笑譚》中，把“水”解读为“德之極”的自然样板。他用“水有三態”、“毛細管現象”、“溶解運輸功能”来解释水的“利万物而不争”。他认为水的“幾於道”在于它的“無私無住”——不居功、不恋位、不抱怨。

但如果我们把“水”换成“母亲的身体”——尤其是母乳、羊水、体液——这一章的七个“善”就不再是抽象的德行，而是一份**母亲身体的功能说明书**。“居善地”是胎儿在子宫里得到的那个位置；“心善渊”是母亲能够承载情绪的那个深层容量；“予善信”是母乳稳定的供给；“正善治”是身体自动调节的内环境；“事善能”是同时处理多任务的身体；“动善时”是母亲感知孩子需求的时机感。而“不争”——母亲在家庭中的位置，总是被排在最后，却从不争抢那个“中心”的座位。

让我们逐句逐“善”对照。

---

## 一、“上善治（似）水”——最高的善像水 / 母亲的身体是“水做的”

### 朱邦復的解读：水的自然德性

朱先生在这一句的开篇注解中，从水的物理特性入手：

> “水有三態，順隨能量之狀況而變化，完全符合自然之道。”
>
> “水因應環境之變而變，且無私無住，無所不在，是德之極也。”

水的“几于道”是因为它不像其他东西那样固守一个形状。它是液态的，能流、能渗、能汽化、能凝结。它在任何环境下都能找到自己的形态——这正是道的特性：无形、无执、无我。

### 从身体经验出发：身体的70%是水——水不只是比喻，水就是母亲身体的材质

一个母亲的身体，有70%是水。这不是“像水”，这是“就是水”。

- **羊水：** 胎儿在羊水中度过九个月。羊水是透明的、流动的、温暖的液体——它是孩子的第一个“世界”。而这个世界，来自母亲的身体。羊水就是母亲身体里“上善治水”的那个“水”——它滋养、保护、缓冲、维持恒温。没有羊水，就没有胎儿的生存环境。
- **母乳：** 乳汁的主要成分是水（约87%）。母亲的身体把血液转化为乳汁——把“自己”变成“水”，喂给孩子。每一个母乳喂养的孩子，都是在喝“母亲身体的水”。
- **血液、汗水、唾液、泪水：** 分娩时的血、产后出汗的汗、喂夜奶时忍不住的泪、亲吻孩子时的口水——母亲身体的“水”以各种形态流出。“上善”是那个持续在流动的、不断在分泌的、从不问“为什么要流”的水。

朱先生说“水因应环境而变”——母亲的身体也是如此：孕期分泌羊水、产后分泌乳汁、发烧时出汗降温、情绪起伏时流泪释放。她的身体“水”随着需求而变——不是主动选择，是本能反应。这确实是“几于道”的——没有犹豫、没有计算、没有功利的计较，只是顺应。

### 对照小结

| 朱邦復的“上善若水” | 身体经验的“上善若水” |
| :--- | :--- |
| 水顺应环境变化，无形无执 | 身体70%是水——羊水、母乳、血液、汗水、泪水持续流动 |
| 第三人称：水的物理德性 | 第一人称：我的身体就是流动的水本身 |

## 二、“水善利萬物而有靜（爭）”——利万物而不争 / 身体供养生命却不居功

### 朱邦復的解读：无私的给予

朱先生将“利万物而不争”解读为“提供生机而不争功”：

> “水提供萬物生機而不爭功，處身於最惡劣的環境而不怨。”

水做了什么？它滋养了所有生命——植物靠它存活、动物喝它解渴、人体依赖它代谢。但水不会说“是我养活了你们”。它只是流过去、渗透、蒸发、凝结、再流回来。不居功，是水的本色。

### 从身体经验出发：身体供养胎儿的生命，却不在出生后索取回报

一个母亲的身体，是“利万物”最具体的版本：

- **孕期：** 母亲的身体把氧气通过胎盘输送给胎儿、把营养通过脐带输送给胎儿、把抗体通过血液输送给胎儿——这些“利”都是沉默的、不显示的、不被感谢的。
- **分娩后：** 身体继续“利万物”——通过母乳喂养、通过日夜守护、通过持续关注——但它不会说“我为你做了多少”。
- **“不争”的另一个层面：** 母亲的身体在家庭中常常是“被遗忘的位置”。孩子的照片里可能没有她（因为她一直在镜头后面），家庭的荣誉里可能没有她（因为她的工作不被计入“贡献”）。但她不会争——“你在后面，我来拍；你先吃，我随后；你先睡，我收拾。”这种“不争”就是水的姿态：流到最低处，把自己放在最后。

朱先生用“不争功”来解读“利万物而不争”——但在母亲那里，“不争”不是一种选择，而是**她的功能本身就不被计入“争”的范畴**。她的贡献是隐性的、持续性的、无法量化的——就像水一样，流过了，却不在石头上留下“我流过”的刻痕。

### 对照小结

| 朱邦復的“利而不争” | 身体经验的“利而不争” |
| :--- | :--- |
| 水滋养万物但不居功 | 身体供养胎儿/孩子却不索求回报 |
| 第三人称：自然界的水循环 | 第一人称：我在喂奶、在守护、在清理，但没有人说“谢谢” |

## 三、“居眾之所惡，故幾於道”——处在最低处 / 身体是家庭中最“脏”的角落

### 朱邦復的解读：甘居低位

朱先生将“处众人之所恶”解读为“甘居下位”：

> “水提供萬物生機而不爭功，處身於最惡劣的環境而不怨。”

水是流向低处的——山谷、洼地、下水道。那些人们不想去的地方、不想待的位置、不想做的事情——水都在那里。它不抱怨“为什么我要在最低处”，它只是流下去。

### 从身体经验出发：母亲的身体是家庭里最“被嫌弃”的那个部位

“居眾之所惡”——母亲的身体常被“嫌弃”：

- **妊娠纹：** 这是社会审美认为“丑”的东西。但它是生命生长时皮肤被撑开的痕迹。水在最低处，妊娠纹在身体最“不美”的地方——腹部、臀部、大腿——那些被藏起来的部位。
- **溢奶、漏尿、失禁：** 产后常见的问题——尿液、乳汁的不自主流出。这些是“众之所惡”的——人们不想谈论、不想看见、不想承认。但母亲的身体在经历这些。她在“最恶”的地方——被社会禁忌覆盖的区域——忍耐着、调理着、恢复着。
- **产后情绪：** 抑郁、焦虑、疲惫——这些“负面”状态也是“众之所惡”的。人们不愿意承认一个母亲会崩溃、会愤怒、会想逃跑。但母亲的身体在承受这些。她在“最恶”的情绪状态中，仍然在喂养、守护、陪伴。

朱先生说水“处众人之所恶”——母亲的身体也“处众人之所恶”：那些被社会嫌恶的、被语言禁忌的、被影像回避的身体状态——她都在经历。但她不会说“我不愿意”。她像水一样，流入了那些洼地——妊娠纹、溢奶、漏尿、产后抑郁——然后慢慢流出来，恢复，继续流动。

### 对照小结

| 朱邦復的“处众人之所恶” | 身体经验的“处众人之所恶” |
| :--- | :--- |
| 水甘居低洼之处 | 身体承受被社会视为“丑”或“脏”的状态——妊娠纹、溢奶、漏尿 |
| 第三人称：水的低位特性 | 第一人称：我的身体在“不被看见”的状态中恢复了 |

## 四、“居善地”——水选择最低处 / 母亲选择“蹲下来”

### 朱邦復的解读：善于选择位置

朱先生将“居善地”解释为“人应效法水德，谦卑处下”：

> “人應效法水之德，謙卑處下，虛靜沈寂。”

水总是流向最低的地方——不是“被迫”的，是“善于”选择最低处。因为最低处才能容纳最多、才能承载最大。

### 从身体经验出发：蹲下来、弯下腰、降下来——母亲的身体总是比孩子“低”

“居善地”最直接的养育版本：**母亲的物理位置，总是比孩子低。**

- **哺乳时：** 母亲的身体是孩子的“床”，她弓着背、低着头、让乳头对准孩子的嘴——她的位置比孩子低（或者说，她把自己放低）。
- **换尿布时：** 母亲蹲下来、弯下腰、跪在地板上——她的身体低于站着时的孩子。
- **学步时：** 母亲弯着腰、抓着孩子的手、一步步倒退着走——她的身体是屈的、弯的、低的。
- **安抚时：** 母亲坐在地上、把孩子放在膝盖上、面对面地说话——她的眼睛和孩子的眼睛在同一个高度。

“居善地”就是这种“降下来的位置”。水总是处在最低处，母亲也总是处在“低于孩子”的位置。她不是“被迫”的——她“善于”这样做。因为只有降下来，才能接住；只有低下来，才能托起。

朱先生用“谦卑处下”来解读“居善地”——但母亲的身体比“谦卑”更具体：她的膝盖、脊柱、手肘、肩膀——都在重复“降下来”这个动作，日复一日、年复一年。

### 对照小结

| 朱邦復的“居善地” | 身体经验的“居善地” |
| :--- | :--- |
| 水善于选择最低处 | 母亲的身体总是降下来——蹲、跪、弯腰、俯身 |
| 第三人称：位置的选择智慧 | 第一人称：我的膝盖比孩子的眼睛低 |

## 五、“心善潚（淵）”——心像深渊一样深 / 母亲能承载孩子的一切情绪

### 朱邦復的解读：心要静、要深

朱先生将“心善渊”解读为“虚静沉寂”：

> “虛靜沈寂。”

水在深处是静的、深的、不动的。心应该像深渊一样——表面可能波动，但深处始终保持平静。

### 从身体经验出发：母亲的心像一个“深渊”——孩子的情绪全部落入其中，而水面不溢

“心善渊”——在养育中，这个意象是什么意思？

- **孩子的哭、叫、闹、笑、怒、惧——全都落入母亲的心。** 母亲的心像一个深潭——孩子扔进来的石头再多，水面也不会溢出来（或者即使溢了，也在你看不见的夜晚、在关着门的卫生间里）。
- **她承载但不崩溃。** 孩子愤怒时摔东西、说“我恨你”、拒绝吃饭——这些“石头”落入她的“渊”，她会在深处沉淀它们、消化它们、不让它们堵住水面。
- **她的“渊”是包容的，不是冷漠的。** 深的、静的水，不是冷的水。它仍然流动、仍然有温度、仍然能映照上方的风景。母亲的心也是这样——它能承载孩子的全部情绪，但不会因为这些情绪而失去自己的温度。

朱先生说“心善渊”是“虚静沉寂”——而在母亲那里，“渊”不是逃避、不是麻木——是**足够深的容量**。她的心因为足够深，所以能容纳孩子的全部跌宕，而她自己还能保持平衡。

### 对照小结

| 朱邦復的“心善渊” | 身体经验的“心善渊” |
| :--- | :--- |
| 心要深、要静、虚寂 | 心要足够深，能承载孩子的所有情绪而不溢出 |
| 第三人称：心灵的修养境界 | 第一人称：孩子的愤怒、悲伤、恐惧都落入我的“渊”——我接住了 |

## 六、“予善信”——给予值得信赖 / 母乳是最“可信赖”的食物

### 朱邦復的解读：给予要值得信任

朱先生将“与善仁”解读为“禀公无私”：

> “稟公無私，言而有信。”

水给予万物的时候，是公正的、可预期的——它不会今天给明天不给（除非干旱），也不会给这个多、给那个少。它的给予是“可信赖的”。

### 从身体经验出发：母乳是“信”——孩子饿了，它就在

“予善信”——母亲的身体是孩子最原初的“可信赖”来源：

- **母乳是“信”的。** 孩子饿了、哭了，乳房就在那里。温度合适、味道一样、供给稳定。它不是“有时有、有时没”的东西——它是可靠的、持续的、可预期的。这种“可预期性”是孩子建立“世界是安全/不安全的”心理底色的第一块基石。
- **母亲的回应也是“信”的。** 孩子哭，母亲就会出现（不一定每次都“及时”，但几乎总是“最终”会来）。这种“有回应”的反复经验，会让孩子形成一种“有人会来”的信任感。
- **“予善信”的另一个层面：** 母亲的身体有自己的节律——月经、睡眠、觉醒——这些节律是“可信赖的”，就像水总是往下流一样可预测。

朱先生说“给予要值得信赖”——母亲的身体就是那个“信”的来源：稳定的供给、持续的回应、可靠的节律。孩子不需要“怀疑”明天会不会有奶——奶就在那里，只要他需要。

### 对照小结

| 朱邦復的“与善仁” | 身体经验的“予善信” |
| :--- | :--- |
| 给予要公正、值得信任 | 母乳是可预期的、稳定的供给——孩子饿了就在 |
| 第三人称：给予者的德行 | 第一人称：我的身体是一个“信”的源头 |

## 七、“正（政）善治”——水善于治理 / 母亲的身体是“自调节的系统”

### 朱邦復的解读：善于处理事务

朱先生将“正善治”解读为“工作有绩效”：

> “工作有績效。”

水能调节环境——通过蒸发降温、通过流动带走废物、通过凝结释放热量。它能够“治理”它所处的系统。

### 从身体经验出发：身体自动调节——体温、激素、内环境

“正善治”——母亲的身体是一套高度自动化的“治理系统”：

- **体温调节：** 怀孕时体温升高，产后出汗降温——身体自己在“治理”自己的温度。
- **激素调节：** 孕期激素水平变化（雌激素、孕激素、催产素、泌乳素）——身体自己调节着一切：什么时候排卵、什么时候分娩、什么时候泌乳。
- **内环境稳态：** 身体的酸碱平衡、电解质平衡、血糖调节——所有这些都在“自动治理”中。

母亲的身体不需要“思考”如何治理——它自己就在做。正如水不需要“思考”如何流向低处。它的“善治”在于**不主动治理、却能治理好**——这不就是“无为而治”的身体版本吗？

朱先生用“工作有绩效”来解读“正善治”——母亲的身体也是“有绩效”的：它孕育了生命、维持了内环境、调节了激素、维持了稳态。但它的“绩效”是自动的、不费力气的、不标榜的。

### 对照小结

| 朱邦復的“正善治” | 身体经验的“正善治” |
| :--- | :--- |
| 水善于“治理”所流经的系统 | 身体自动调节体温、激素、内环境——无为而治 |
| 第三人称：水的生态功能 | 第一人称：我的身体自己就知道该怎么“管”自己 |

## 八、“事善能”——水能胜任各种工作 / 母亲能同时处理多重任务

### 朱邦復的解读：做事有能力

朱先生将“事善能”解读为“行事有能力”：

> “行事有能力。”

水有“本事”——它能溶解、能运输、能排泄、能维持生命。它是一种“多功能溶剂”，能胜任多种任务。

### 从身体经验出发：母亲的身体能同时处理多种任务

“事善能”——母亲的身体是“多任务处理系统”：

- **孕期：** 母亲的身体同时承担着“自己的生存”和“胎儿的生存”两套任务——在同一个身体里运行两个生命系统。
- **哺乳期：** 母亲的身体在喂奶的同时，可能还在工作、在处理家务、在照顾其他孩子。它的“能”是同时的、并行的、不需要暂停的。
- **深层的“能”：** 身体在夜间也能工作——呼吸、心跳、消化、修复——这些都在“后台”运行，不需要母亲“主动”启动它们。她睡着的身体仍在“工作”。

朱先生说“行事有能力”——母亲的身体是“多能手”：能孕育、能分泌、能修复、能转化。它同时运行多个功能，而且不会说“我太忙了”。

### 对照小结

| 朱邦復的“事善能” | 身体经验的“事善能” |
| :--- | :--- |
| 水能胜任多种任务 | 身体能同时孕育、分泌、修复、转化——多任务运行 |
| 第三人称：水的多功能性 | 第一人称：我在做一件的时候，身体已经在准备另一件了 |

---

## 九、“蹱（動）善時”——水知道什么时候动 / 母亲的身体知道什么时机最合适

### 朱邦復的解读：行动要把握时机

朱先生将“动善时”解读为“等待适当之时机”：

> “欲有所為，應等待適當之時機。”

水不是乱动的——它有季节、有潮汐、有流动的时机。冬天结冰、春天融雪、夏天蒸发——它知道什么时候该动、什么时候该静。

### 从身体经验出发：身体知道什么时候该分娩、什么时候该泌乳、什么时候该回应

“动善时”——母亲的身体是“时机的大师”：

- **分娩的时机：** 子宫知道什么时候该开始收缩——不是医生决定的，是身体自己判断的。催产素在正确的时间释放，宫颈在正确的时间软化，胎儿在正确的时间转身——这些全是身体的“时机感”。
- **泌乳的时机：** 母乳的“下单-生产-供给”系统——孩子的吮吸触发催产素释放、触发泌乳反射——身体在“正确的时间”做“正确的事”。它不需要看表。
- **回应的时机：** 一个母亲能“感知”孩子的细微变化——哭声中的不同音调、睡眠中的不同呼吸节奏。她会在正确的时间回应（即使在外人看来她只是“恰好”醒了）。这是身体层面的“时机感”。

朱先生说“动善时”是“把握时机”——母亲的身体没有“把握”这个动作，它只是**“在正确的时间做正确的事”**。就像水在春天融化、在夏天蒸发——它不需要“把握”时机，它就是时机本身。

### 对照小结

| 朱邦復的“动善时” | 身体经验的“动善时” |
| :--- | :--- |
| 水知道什么时候流动、什么时候静止 | 身体知道什么时候分娩、什么时候泌乳、什么时候回应 |
| 第三人称：时机的把握 | 第一人称：我的身体就是那个“时机”本身 |

---

## 十、“夫唯不爭，故无尤”——不争所以没有怨 / 母亲不争位，却“无尤”

### 朱邦復的解读：不争就没有过失

朱先生将“不争”解读为“顺遂自然”：

> “水無爭，故為上善。……自然界事物之聚散，係因整體能量變化之故，一切有其必然之因果。”

水不争——它不跟岸争宽度、不跟石头争高度、不跟风争方向。它只是流。所以它没有过失、没有怨尤、没有敌人。

### 从身体经验出发：母亲在家庭中总是“把自己放在最后”，但她不会有怨——因为“无尤”

“夫唯不争，故无尤”——在养育者的日常中：

- **母亲不争“第一口饭”**——她总是让孩子先吃，自己吃凉的。
- **母亲不争“最前排”**——她总是让孩子站在前面，自己在后面。
- **母亲不争“被看见”**——照片里很少她，因为她在拍；荣誉里很少她，因为她在默默做。

但她不会说“为什么总是我在付出”——因为她“无尤”。“尤”就是怨恨、就是计较、就是“为什么不是我”。而她之所以不抱怨，不是因为压抑了，而是因为她**不是在“争”的系统里运作的**。

她不是在“我应该得到”的队列里——她是在“我应该给”的通道里。水不是“我应该得到河床”才流的——它只是因为低，所以流。母亲不是因为“我应该得到回报”才做的——她只是因为爱，所以做。

朱先生说“不争，故无尤”——母亲是“无尤”的典范：她把自己放在最后，但她不觉得自己被亏欠了。因为她不是在“争”的游戏里。

### 对照小结

| 朱邦復的“不争故无尤” | 身体经验的“不争故无尤” |
| :--- | :--- |
| 不争的人不会有怨 | 母亲在家庭中把自己放最后，但不抱怨 |
| 第三人称：不争的处世哲学 | 第一人称：我不是在“争”的系统里，我是在“给”的系统里 |

---

## 结语：“上善若水”——母亲的身体就是那“水”

朱邦復先生在这一章中，用水作为“上善”的象征——水不争、善利、处下、能容、可信、能治、能事、能时。他为我们描绘了一幅关于水的完整“德性图谱”。

而母亲的身体，是这幅图谱最原初的载体：

- **水的“几于道”——身体70%是水的、持续流动的、从不居功的。**
- **水的“利万物而不争”——身体供给胎儿/孩子生命所需，却不索取回报。**
- **水的“处众人之所恶”——身体承受社会认为“脏”“丑”“禁忌”的状态（妊娠纹、溢奶、漏尿）。**
- **水的“居善地”——身体总是“降下来”：蹲、跪、弯腰、俯身。**
- **水的“心善渊”——母亲的心足够深，承载孩子的一切情绪而不溢出。**
- **水的“予善信”——母乳供给稳定、母亲回应可靠——“世界是可信的”。**
- **水的“正善治”——身体自动调节内环境——体温、激素、代谢——无为而治。**
- **水的“事善能”——身体同时运行多种功能——孕育、分泌、修复、转化。**
- **水的“动善时”——身体知道什么时候分娩、泌乳、回应——它就是时机本身。**
- **水的“不争”——母亲在家庭中总是把自己放最后，但她“无尤”——因为她的位置不在“争”的系统里，而在“给”的系统里。**

水是道的隐喻，而母亲的身体是水的化身。她不需要“学”水的德行——她的身体就是水的运行方式：流下去、滋养、不居功、不抱怨、在最低处、在最深处。她本身就是“上善”的日常版本。

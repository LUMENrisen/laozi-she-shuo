

## 引言：有与无的辩证法，空间与内容的身体课

帛书本第十一章，是《德道经》中关于“有”与“无”辩证关系最集中的论述之一。但在此之前，帛书本先插入了一句属于通行本第五十一章的内容，作为这一章的“序言”：

> 生之，畜之。生而弗有，長而弗宰，是謂玄德。
>
> 卅輻同一轂，當其无有，車之用也。
>
> 然（埏）埴為器，當其无有，埴器之用也。
>
> 鑿戶牖，當其无有，室之用也。
>
> 故有之以為利，无之以為用。

“生之，畜之”——生成它、养育它。“生而弗有”——生了却不占有。“长而弗宰”——让它成长却不主宰。这就是“玄德”。

然后进入经典的“容器三喻”：三十根辐条汇集于一个空心的车毂——正因为中间是空的，才有车的功用。揉捏陶土做成器皿——正因为中间是空的，才有器皿的功用。开凿门窗建成房屋——正因为中间是空的，才有房屋的功用。所以“有”提供便利，“无”发挥功用。

朱邦復先生在《止笑譚》中，将这一章解读为 **“空间能量的运用”** ——他延续了第五章“橐籥”（风箱）的逻辑：空间（无）是功能得以发挥的前提。车毂的空、器皿的空、房屋的空——都是“空间之用”。他认为“有”是物之利，“无”是物之用，两者相辅相成，但“用”的核心在于“无”。

但如果我们把主语换成“母亲的身体”呢？“卅輻同一轂，當其无有，車之用也”——最直接的对应是什么？**骨盆。“埏埴為器，當其无有，埴器之用也”——子宫。“鑿戶牖，當其无有，室之用也”——产道与怀抱。** 而“生之畜之，生而弗有，长而弗宰”——这难道不是母亲与孩子关系的完整描述吗？她生了，但不占有；她养了，但不主宰。这才是“玄德”——母亲的身体是“无”的原型容器，而孩子是那个被“有”之利所承载的生命。

让我们逐句对照。


## 一、“生之，畜之。生而弗有，長而弗宰，是謂玄德”——生成、养育、不占有、不主宰

### 朱邦復的解读：玄德的本质是不占有、不居功

朱先生在《止笑譚》中，对这一句的解读与通行本第二章“功成弗居”逻辑一致：

> “生而不有，为而不恃，长而不宰，是最微妙之德性。”

他认为“玄德”的“玄”在于它的不显眼、不居功——它做了所有的事，但不认为那是“自己的功劳”。这是道的最高德性：创造了却不拥有，滋养了却不控制。

### 从身体经验出发：母亲的身体——生了却不占有，养了却不主宰

“生之，畜之”——母亲的每一个行为都在做这件事。她生下了孩子，她喂养了孩子。但她不能、也不会说“这个孩子是我的”——因为她知道他终有一天要离开。

- **“生而弗有”**——她生了孩子，但她不能占有他。他不是她的“东西”。他是一个独立的人。哪怕在脐带剪断的那一刻，他已经从“她的一部分”变成了“他独立的自己”。她“弗有”——她不拥有他。
- **“長而弗宰”**——她看着他长大，但她不能主宰他。不能替他做选择、不能替他走路、不能替他活。她必须退后，让他自己成为他自己。
- **“玄德”**——这种“生而不有、长而不宰”的状态，是最深的德性。因为它不被看见、不被记功、不被感谢。它只是日复一日地做着“生”和“畜”的动作——然后放手。

朱先生用“道的德性”来解读“玄德”。而母亲的身体就是“玄德”的日常版本：她每天都在“生之畜之”，但从不觉得自己“拥有”或“主宰”了什么。

| 朱邦復的“玄德” | 身体经验的“玄德” |
| :--- | :--- |
| 创造但不占有、滋养但不控制，是最深的德 | 生了孩子但不能占有、看着他长大但不能主宰——日复一日的“生之畜之” |
| 第三人称：道的运作方式 | 第一人称：我生了，但不拥有；我养了，但不控制 |


## 二、“卅輻同一轂，當其无有，車之用也”——三十辐条汇集于毂，因为有虚空，才有车的作用

### 朱邦復的解读：虚空的空间是功能的载体

朱先生将“卅輻同一轂”解读为空间与功能的关系：

> “卅根辐，接合在毂轴上，始成轮。毂需中空，否则无车可用。”

他进一步在《章五》的“橐籥”比喻中强调：虚空才能“动而愈出”。车毂的空心是“无”，但正是这个“无”让辐条得以聚拢、让车轴得以穿过、让车轮得以转动。没有这个“无”，车就只是堆木头。

### 从身体经验出发：骨盆——虚空才能让生命通过

“卅輻同一轂，當其无有，車之用也”——如果用母亲的身体来对应这个比喻，“毂”是什么？**骨盆。**

- **骨盆是“毂”。** 它不是实心的——它是中空的、环形的、有开口的骨骼结构。胎儿的头部需要从骨盆的“空”中通过，才能进入产道、来到这个世界。
- **“當其无有”——骨盆的空腔，才能有“车之用”。** 如果骨盆是实心的，生命就无法通过。它必须是空的、有空间的、有通道的。那个“空”才是功能的载体。
- **“无”不是“什么都没有”——它是“有这个空间才能做那件事”。** 骨盆的空腔不是“缺失”——它是专门为“让生命通过”而设计的缺口。

朱先生看到的是车毂的“空”让车轮转动。母亲的身体告诉我们：**骨盆的“空”让生命转动——从体内转到体外，从“我的一部分”转到“独立的他”。**

| 朱邦復的“卅辐共一毂” | 身体经验的“卅辐共一毂” |
| :--- | :--- |
| 车毂中空，车轮才能转动 | 骨盆中空，胎儿才能通过 |
| 第三人称：机械结构的空间原理 | 第一人称：我的骨盆是空的——那个“空”让生命进来了，又让生命出去了 |


## 三、“然（埏）埴為器，當其无有，埴器之用也”——揉捏陶土做成器皿，因为有虚空，才有器皿的作用

### 朱邦復的解读：陶器的空腔才是它的“用”

朱先生将“埏埴以为器”解读为“器具必须中空，才能盛物”：

> “和泥烧制成容器，器具必须中空，才能盛物。”

陶器的“有”是它的壁——泥土的厚度、形状、烧制的硬度。但陶器的“用”是它的“无”——那个空心的腔体。没有那个空腔，它就只是一个泥块，不能装水、不能盛米、不能作为器皿。

### 从身体经验出发：子宫——虚空才能孕育生命

“埏埴為器”——如果用母亲的身体来对应这个比喻，“埴器”是什么？**子宫。**

- **子宫是“器”**——它是有壁的（肌肉层）、有形状的（梨形）、有厚度的（从几毫米到几厘米）。它的“有”是组织、血管、肌肉。
- **“當其无有”——子宫的空腔，才是它的“用”。** 子宫的主要功能不是它的“壁”——是它的“空”。胚胎着床需要那个空腔、胎儿生长需要那个空腔、羊水充盈需要那个空腔。
- **“无有”的张力：** 子宫的“无有”是动态的——非孕期它几乎是闭合的腔隙（“无”空间），孕期它扩张到能容纳一个完整的生命（“有”空间）。但它的“用”始终是那个“空”——无论大小。

朱先生看到的是陶器的空腔可以盛物。母亲的身体告诉我们：**子宫的空腔可以盛命——盛一个生命九个月，然后把他倒出来，再收缩回空的状态，准备盛下一个。**

| 朱邦復的“埏埴以为器” | 身体经验的“埏埴以为器” |
| :--- | :--- |
| 陶器的空腔让它能盛物 | 子宫的空腔让它能盛命 |
| 第三人称：器皿的功能原理 | 第一人称：我的子宫是空的——那个“空”曾经装过一个完整的人 |


## 四、“鑿戶牖，當其无有，室之用也”——开凿门窗，因为有虚空，才有房屋的作用

### 朱邦復的解读：房屋的空腔才是居住的空间

朱先生将“凿户牖以为室”解读为“中间要有足够的空间，才能发挥居室的功效”：

> “开凿门户为房舍，中间更要有足够的空间，才能发挥居室的功效。”

房屋的“有”是墙、是梁、是柱、是瓦。但房屋的“用”是它的“无”——那个可以走进去、住在里面、转身、躺下、呼吸的空间。没有那个“无”，房子只是一个雕塑。

### 从身体经验出发：产道与怀抱——虚空才能让人“住进来”

“鑿戶牖”——如果用母亲的身体来对应这个比喻，“戶牖”是什么？**产道与怀抱。**

- **产道是“门”**——它是孩子从“体内”到“体外”的通道。它是“鑿”出来的——不是预先开好的，是宫缩和胎儿的共同作用下“打开”的通道。它必须“当其无有”——在分娩时它必须扩张、必须是“空的”，孩子才能通过。
- **怀抱是“室”**——孩子出生后，母亲的身体（尤其是胸口和臂弯）成为他第一个“房间”。那个怀抱是“空的”吗？它必须有空间——孩子要能躺进去、能蜷缩、能被包裹。但它是“有”的——有温度、有心跳、有气息。它的“用”是那个“空”的容纳，但那“空”充满了温度。
- **“室之用”的深层含义：** 一个母亲的身体在多年后，仍然是一个“室”——孩子随时可以“住进来”（打电话、回家、倾诉）。那个“空”始终在，即使孩子不在里面。它不是一个物理的“无”——它是一个关系的“无”：只要你需要，我就在。

朱先生看到的是房屋的空腔让人可以居住。母亲的身体告诉我们：**产道的“空”让孩子从里面出来，怀抱的“空”让孩子可以在外面被接住。这两个“空”都是“室之用”——一个是入口，一个是出口，但都是“可以让生命通过或停留”的空间。**

| 朱邦復的“凿户牖以为室” | 身体经验的“凿户牖以为室” |
| :--- | :--- |
| 房屋的空腔让人能居住 | 产道的空腔让孩子能通过，怀抱的空腔让孩子能停留 |
| 第三人称：建筑的功能原理 | 第一人称：我的产道是门，我的怀抱是室——都是“可以让生命通过”的空 |


## 五、“故有之以為利，无之以為用”——“有”提供便利，“无”发挥作用

### 朱邦復的解读：利与用的分工

朱先生将“有之以为利，无之以为用”解读为“有”和“无”的功能分配：

> “有具備能量之功，但僅限於既‘有’者；‘無’指尚未確定之情況，人因此可自由選擇，使之符合所需用。”

他认为“有”是“材料、结构、物质”——它提供的是“利”（便捷、可操作的基础）；“无”是“空间、可能性、选择”——它提供的是“用”（实际功能的实现）。两者缺一不可，但“用”的核心在于“无”。

### 从身体经验出发：母亲的身体——有是载体，无是出口

“故有之以為利，无之以為用”——在母亲的身体里，“有”和“无”的分工是什么？

- **“有”是她的组织、器官、血液、乳汁、骨骼、肌肉。** 这些东西有厚度、有颜色、有形状——它们是“利”，是功能的载体。骨盆的骨骼是“有”（提供支撑和保护），子宫的肌肉是“有”（提供收缩的动力），乳房的腺体是“有”（提供分泌的能力），怀抱的手臂是“有”（提供包裹和连接）。
- **“无”是那些空间、通道、开口、空腔。** 骨盆的出口是“无”（生命通过的通道），子宫的腔是“无”（胎儿容身的空间），乳头的开口是“无”（乳汁流出的通道），怀抱中间那个“空”的位置是“无”（孩子被容纳的空间）。
- **没有“有”，就没有“无”的载体；没有“无”，就没有“有”的功能。** 骨盆的骨骼（有）是为了保护那个空腔（无）——而那个空腔是为了让生命通过。子宫的肌肉（有）是为了收缩那个腔体（无）——而那个腔体是为了让胎儿存在。它们是一个整体。

朱先生看到的是“有”和“无”的辩证关系——有提供基础，无发挥功能。母亲的身体是这种辩证关系最直观的存在：**她的“有”（身体的组织和器官）为“无”（生命的通道和空间）提供了基础，而她的“无”（那些空腔和出口）才是她的身体之所以“有用”的核心。**

| 朱邦復的“有之以为利，无之以为用” | 身体经验的“有之以为利，无之以为用” |
| :--- | :--- |
| 有是材料、结构——提供便利；无是空间——发挥功能 | 有的组织、器官是载体；无的腔体、通道是出口和入口 |
| 第三人称：物理空间的二元架构 | 第一人称：我的“有”是为了保护我的“无”——而我的“无”才是生命通过的地方 |


## 结语：容器、空间与母亲的身体

朱邦復先生在这一章中，通过三个经典的“容器隐喻”（车毂、陶器、房屋），建立了一个清晰的“有-无”功能模型：“有”是基础、材料、结构；“无”是空间、功能、作用。两者缺一不可，但“用”的核心在于“无”。

而母亲的身体，是这三个容器隐喻的最原初载体：

- **车毂（骨盆）**——中空的骨骼结构，让生命通过。
- **陶器（子宫）**——中空的器官，让生命在其中生长九个月。
- **房屋（产道与怀抱）**——中空的通道与容纳空间，让生命被接住、被安放。

而贯穿这一切的，是“生之畜之，生而弗有，长而弗宰”——她生成、养育，但不占有、不主宰。她用她的“有”（身体）创造了“无”（空间），再通过那个“无”让另一个生命走向他自己的“有”。她就是这个循环本身。

**“有之以为利，无之以为用”**——这句话在母亲的身体里被还原为最朴素的事实：她的组织、血液、骨骼（有）为她的空腔、通道、怀抱（无）提供基础，而后者才是生命得以被容纳、被孕育、被生出的关键。

一个母亲不需要读《道德经》就知道“无之以为用”——她的身体每天都在经历：空的子宫才能有新的生命，空的乳房才能有新的乳汁，空的怀抱才能接住新的到来。她的“无”不是缺失——它是最深的“有”。

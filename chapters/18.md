

## 引言：最“婴儿”的一章，最“身体”的质疑

帛书本第五十五章，是《德道经》中以“赤子”为喻、讨论“含德之厚”与“物壮则老”的集中论述：

> 含德之厚者，比於赤子。逢（蜂）𢔯（）𧍥（虺）地（蛇）弗螫，攫鳥猛獸弗搏。
>
> 骨弱筋柔而握固。未知牝牡之會而朘怒，精之至也。終曰（日）號而不𢖻，和之至也。
>
> 和曰常，知和（常）曰明，益生曰祥，心使氣曰強。
>
> 物壯即老，胃（謂）之不道，不道早已。

“含德之厚者，比於赤子”——含德深厚的人，好比初生的婴儿。“蜂虺蛇不螫，攫鸟猛兽不搏”——毒蜂、毒蛇不刺他，凶鸟、猛兽不抓他。

“骨弱筋柔而握固”——筋骨柔弱，但握持却很牢固。“未知牝牡之会而朘怒”——不知道男女交合之事，生殖器却自然勃起，“精之至也”——这是精气充足到极致。“终日号而不嗄”——整天哭号却不嘶哑，“和之至也”——这是和气充足到极致。

“和曰常”——和气就是常道，“知和曰明”——知道和气就是明达，“益生曰祥”——有益生命叫做吉祥，“心使气曰强”——用心意驱动气叫做逞强。

“物壮即老”——事物到了壮盛就会衰老，“谓之不道”——这叫做不合道，“不道早已”——不合道的事物会早早消亡。

朱邦復先生在《止笑譚》中，对这一章的处理相当特殊——他直接在开头就表达了对文本的质疑：

> “此说本人无法苟同，仅据原文解释。盖婴儿虽系人最接近自然之本态，却必须得到父母保护，否则难以生存。”

他无法接受“毒虫不螫、猛兽不据”的字面意思——认为婴儿不可能真的不受动物伤害。他承认婴儿是“接近自然本态”的象征，但拒绝将这种象征当作物理事实。他在解读后半段时，延续了“知和曰常，知常曰明”与“物壮则老”的逻辑——认为“和”是常态，“强”会导致衰老。

但如果我们把主语换成“母亲的身体”——那个在分娩和养育中亲身经历“骨弱筋柔而握固”、“终日号而不嗄”的身体——这一章就不再是“象征性的赤子之喻”，而是一份 **“关于母亲如何在‘骨弱筋柔’中握固、如何在‘终日号而不嗄’中保持和气的真实记录”**：

- “含德之厚者，比於赤子”——母亲的身体在产后，也像一个“赤子”。它柔软、脆弱、需要被照顾、需要时间恢复——就像婴儿一样。
- “骨弱筋柔而握固”——产后的母亲，身体是“弱”的、是“柔”的。但她的“握”是“固”的——她抱着孩子的手不松，即使她已经没有力气了。那是“精之至也”——不是因为她“强”——是因为她“精”足。
- “终日号而不嗄”——母亲日日夜夜地回应孩子、安抚孩子、在深夜醒来——但她没有“嘶哑”。不是因为她不累——是因为她的“和”还在。那是“和之至也”——她的和气没有因为消耗而枯竭。
- “和曰常”——“和”是常态。母亲的身体在产后经历巨大的变化——激素波动、睡眠剥夺、身体损伤——但它在“回归”那个“和”的状态。那不是“恢复”旧状态——是“重新找到”平衡。
- “物壮即老”——产后急于恢复、急于“变强”——反而会提前“衰老”（损伤、耗竭）。那是“不道”——不合于身体的自然节律。


## 一、“含德之厚者，比於赤子”——含德深厚的人，好比赤子

### 朱邦復的解读：质疑，仅据原文解释

朱先生在《止笑譚》中写道：

> “此说本人无法苟同，仅据原文解释。盖婴儿虽系人最接近自然之本态，却必须得到父母保护，否则难以生存。”

他认为婴儿不可能真的不受毒蛇猛兽伤害——这是一个“比喻”，不是物理事实。婴儿之所以“近道”，是因为他的“自然本态”——柔软、不伪装、不造作——而不是因为“能免疫危险”。

### 从身体经验出发：母亲的身体在产后也像一个“赤子”——柔软、脆弱、需要被照顾

“比於赤子”——在母亲的身体里，“赤子”是什么？

- **产后身体像“赤子”一样。** 它柔软（腹直肌松弛、盆底肌松软）、脆弱（需要时间愈合）、需要被照顾（不能劳累、不能急）。母亲的身体在产后——就像婴儿一样——需要被“父母”照顾。但那个“父母”不是别人——是“她自己”。她需要允许自己像婴儿一样被照顾。
- **“赤子”的另一种理解：** 母亲的身体在产后也“必须得到保护，否则难以生存”——不是被毒蛇猛兽伤——是被“急于恢复”的期待伤。如果她不保护自己——不休息、不拒绝“速成”的要求——她的身体就会被“伤”。
- **“含德之厚”的深层含义：** 母亲的身体刚刚完成了一件极其消耗的事——它“含”着“德”（完成生命的能量）。那个“德”是“厚”的——不是“薄”的。它需要时间来“含住”——而不是被“消耗”。

朱先生说“婴儿虽近自然本态却必须被保护”——母亲的身体在产后也一样。她需要被保护——不被“速成”的标准伤、不被“你应该”的期待伤。保护自己，就是“含德”的实践。

| 朱邦復的“赤子之喻” | 母亲经验的“赤子” |
| :--- | :--- |
| 婴儿象征自然本态，但必须被保护 | 产后身体也像“赤子”——柔软、脆弱、需要被自己保护 |
| 第三人称：质疑象征 | 第一人称：我的身体现在就像一个婴儿——需要被好好照顾 |


## 二、“骨弱筋柔而握固”——筋骨柔弱，握持却牢固

### 朱邦復的解读：婴儿的“弱”与“固”并存

朱先生将“骨弱筋柔而握固”解读为“身体柔软但握力却很强”：

> “其骨質弱，筋肉柔軟，但卻能握得很緊。”

婴儿的身体是“弱”的（骨质不硬、肌肉不强），但他的手却“握固”——握得很紧。这是“精之至”的表现——精气充足，不在于“肌肉”的硬，在于“精”的足。

### 从身体经验出发：产后的母亲身体是“弱”的，但她抱着孩子的手不松——那是“精之至”

“骨弱筋柔而握固”——在母亲的身体里，“骨弱筋柔”和“握固”是什么？

- **她的身体是“弱”的。** 产后——肌肉松弛、核心无力、身体虚弱。那是“骨弱筋柔”。
- **但她的“握”是“固”的。** 她抱着孩子的手不松——即使她没有力气了、即使她已经抱了很久了。不是因为她的“肌肉”强——是因为她的“精”在。那不是“肌肉记忆”——是“生命记忆”。她握着——因为他在。
- **“握固”的另一种理解：** 她不是“抓”着他——是“握”着他。“握”是柔软的、有温度的、不勒的。婴儿握你的手指——不是“抓紧”——是“握住”。母亲抱孩子也是一样——不是“抓紧”——是“握住”。那是“精之至”——不是“力之至”。

朱先生说“骨弱筋柔而握固”是身体柔软但握力强。母亲的身体告诉我们：**产后她“弱”了——但她握着孩子的手不松。那不是“肌肉”的力量——是“精”的力量。**

| 朱邦復的“骨弱筋柔而握固” | 母亲经验的“骨弱筋柔而握固” |
| :--- | :--- |
| 身体柔软但握力很强 | 产后她“弱”了——但握着孩子的手不松。那不是“肌肉”——是“精” |
| 第三人称：婴儿的生理特征 | 第一人称：我的身体是“弱”的——但我的手没有松 |


## 三、“未知牝牡之會而朘怒”——不知交合之事，生殖器却自然勃起

### 朱邦復的解读：自然的本能反应

朱先生将“未知牝牡之会而朘怒”解读为“不知道性事却自然勃起”：

> “不知性事卻能勃起，是因為精力充沛。”

婴儿没有“性意识”——但身体有自然的反应。那是“精之至”——精气充足，不需要“意识”驱动，身体自己就会反应。

### 从身体经验出发：母亲的身体也有“自然反应”——产后的乳汁分泌不是靠“意识”的

“未知牝牡之會而朘怒”——在母亲的身体里，“朘怒”是什么？

- **乳汁分泌不是靠“意识”的。** 婴儿吮吸时，泌乳反射自动启动——她不需要“命令”身体产奶。那是身体的“自然反应”——就像婴儿的“朘怒”一样。她不需要“知道”怎么产奶——身体自己知道。
- **“精之至”的另一层含义：** 母亲身体的“精”充足——它能够“自动”运作。不是靠“努力”的——是靠“充足”的。当她的身体有足够的“精”（营养、休息、恢复）——它就能自然运作。不需要“用力”。
- **“精之至”的深层含义：** 婴儿的“朘怒”是因为“精之至”——母亲的身体的自然反应也是因为“精之至”。“精”不是“刻意”的——是“自然”的。

朱先生说“未知牝牡之会而朘怒”是自然本能反应。母亲的身体告诉我们：**乳汁分泌也是“自然反应”——不是靠“意识”的。那是“精之至”——身体知道怎么做。**

| 朱邦復的“未知牝牡之会而朘怒” | 母亲经验的“未知牝牡之會而朘怒” |
| :--- | :--- |
| 不知道性事却自然勃起 | 乳汁分泌也不是靠“意识”的——身体自己知道。那是“精之至” |
| 第三人称：婴儿的生理反应 | 第一人称：我的身体也在“自然反应”——我不需要“用力” |


## 四、“終日號而不嗄”——整天哭号却不嘶哑

### 朱邦復的解读：声音嘶哑不是因为哭得多，是因为“不和”

朱先生将“终日号而不嗄”解读为“哭了一整天嗓子也不哑”：

> “終日哭號不休，聲音卻不嘶啞，因其哭號發之自然，非故意也。”

婴儿哭了一天，嗓子也不会哑——因为他哭得“自然”，不是“用力”的。他的“气”是“和”的——不是因为“嗓子好”，是因为“气顺”。

### 从身体经验出发：母亲日日夜夜地回应孩子、安抚孩子、在深夜醒来——但她没有“嘶哑”

“終日號而不嗄”——在母亲的身体里，“号而不嗄”是什么？

- **她回应孩子——日日夜夜。** 孩子哭，她回应；孩子叫，她起来；孩子醒，她到。那是“终日号”——不是她哭，是她“回应”哭。
- **但她没有“嗄”（嘶哑）。** 不是因为“她不累”——是因为她的“气”还是“和”的。她不是“硬撑”的——她是在“自然”地回应。她的“气”没有因为消耗而“不和”。那是“和之至也”。
- **“和之至”的深层含义：** 她和孩子的共振是“和”的——即使她很累、即使她已经很久没睡了。那个“和”让她能够持续而不“嘶哑”。不是“她有多强”——是“她的和还在”。

朱先生说“终日号而不嗄”是哭得自然所以不哑。母亲的身体告诉我们：**她日夜回应——但没有“嘶哑”。那是“和之至”——不是因为“有力”，是因为“气顺”。**

| 朱邦復的“终日号而不嗄” | 母亲经验的“終日號而不𢖻” |
| :--- | :--- |
| 哭得自然所以不哑 | 她日夜回应——但没有“嘶哑”。那是“和之至”——因为“气顺” |
| 第三人称：婴儿的自然啼哭 | 第一人称：我还在回应——我的“和”还在 |


## 五、“和曰常，知和曰明”——和就是常道，知和就是明达

### 朱邦復的解读：“和”是常态，知道“和”就是明达

朱先生将“知和曰常，知常曰明”解读为“和是常道，知常是明”：

> “瞭解柔和稱為‘常’，瞭解常道則是‘明’。”

“和”不是“特殊状态”——是“常态”。“知和”是知道“和”是常态。“知常”是知道这个常态就是道——那是“明”。

### 从身体经验出发：母亲的身体知道“和”是常态——产后恢复不是在“追赶”，是在“回到和”

“和曰常”——在母亲的身体里，“和”是什么？

- **产后身体在“回归和”的状态。** 激素在波动、器官在复位、肌肉在恢复——那不是“乱”——那是“在回到和”。身体知道“和”在哪里——它不需要“追赶”一个外部标准。它只是“回到和”。
- **“知和曰明”的另一种理解：** 母亲知道“和”就是她的身体在说的那个状态——不是“我应该更瘦”——是“我感觉到了平衡”。她知道自己什么时候在“和”里、什么时候不在。那就是“明”。

朱先生说“和曰常知和曰明”是和是常道，知和是明。母亲的身体告诉我们：**产后不是在“追赶”——是在“回到和”。她知道自己什么时候在“和”里——那就是“明”。**

| 朱邦復的“和曰常知和曰明” | 母亲经验的“和曰常知和曰明” |
| :--- | :--- |
| 和是常道，知和是明 | 产后不是在“追赶”——是在“回到和”。知道自己何时在“和”里，就是“明” |
| 第三人称：和与常的关系 | 第一人称：我的身体知道“和”在哪里——那就是“明” |


## 六、“益生曰祥”——有益生命叫做吉祥

### 朱邦復的解读：有益于生命的事情是吉祥的

朱先生将“益生曰祥”解读为“增加生存的机会是吉祥”：

> “增加生存的機會是吉祥。”

“益生”是对生命有益的。“祥”是吉祥、好的。

### 从母亲经验的解读：对母亲来说，“益生”不是“更快恢复”——是“好好休息”、“慢慢来”

“益生曰祥”——在母亲的身体里，“益生”是什么？

- **“益生”不是“更快恢复”——是“好好休息”。** 对她来说，“益”身体的东西——是睡觉、是营养、是不着急。那不是“快速恢复”——那是“好好照顾”。
- **“益生曰祥”的另一种理解：** 她做那些“对生命有益”的事——不是“为了变强”——是为了“活着”。睡觉、吃饭、休息、不强迫自己——那是“祥”。

朱先生说“益生曰祥”是有益生命是吉祥。母亲的身体告诉我们：**对她来说，“益生”是休息、是慢慢来、是不强迫自己——那是“祥”。**

| 朱邦復的“益生曰祥” | 母亲经验的“益生曰祥” |
| :--- | :--- |
| 有益生命是吉祥 | 对她来说，“益生”是休息、是慢慢来、是不强迫自己 |
| 第三人称：生的价值 | 第一人称：我不是“变强”——我是“好好活着” |


## 七、“心使氣曰強”——用心意驱动气叫做强

### 朱邦復的解读：刻意用意志力驱动是逞强

朱先生将“心使气曰强”解读为“有心赌气叫做逞强”：

> “有心賭氣則叫做逞強。”

“心使气”是“用意志力驱动身体”——那不是“真强”——是“逞强”。“强”是表面的，不是真正的。

### 从母亲经验的解读：母亲用“意志力”强迫自己恢复——那是“心使气”，是“强”不是“和”

“心使氣曰強”——在母亲的身体里，“心使气”是什么？

- **她用“意志力”强迫自己恢复。** “我必须快点好”、“我必须马上恢复”、“我必须回到状态”——那是“心使气”。她用“意念”在驱动身体——不是“身体”在自然恢复。
- **“強”的代价：** 那是“逞强”——不是真正的“强”。她“强”了——但身体在反抗。她“强”着起床、运动、干活——然后身体用疼痛、疲惫、崩溃来回应她。那不是“强”——是“耗”。
- **“心使气”的深层含义：** 真正的恢复不需要“心使气”——身体自己会恢复。她只需要“不挡道”。当她“心使气”（强迫、命令、催促）的时候——她是在“挡道”。身体的自然恢复被她的“意志力”打断了。

朱先生说“心使气曰强”是有心赌气是逞强。母亲的身体告诉我们：**她用意志力强迫自己恢复——那是“心使气”，是“强”不是“和”。真正的恢复不需要“强”——只需要“让”。**

| 朱邦復的“心使气曰强” | 母亲经验的“心使氣曰強” |
| :--- | :--- |
| 有心赌气是逞强 | 她用意志力强迫自己恢复——那是“心使气”，是“强”不是“和” |
| 第三人称：意志与气的分别 | 第一人称：我“强”了——但身体在反抗 |


## 八、“物壮即老”——事物壮盛就会衰老

### 朱邦復的解读：壮盛之后是衰老

朱先生将“物壮则老”解读为“事物壮大就会衰老”：

> “萬事萬物一旦到強大的階段，也就進入衰老期。”

“壮”是极盛的状态。“老”是衰老、终结。“物壮则老”是自然规律——任何事物到了顶峰就会下降。

### 从母亲经验的解读：产后急于“变强”——反而会提前“衰老”。“物壮则老”是身体的警告

“物壯即老”——在母亲的身体里，“物壮”是什么？“老”是什么？

- **她急于“变强”。** 她想要“快速恢复”——不是慢慢恢复——是“强力恢复”。她运动过度、工作过度、要求自己“回到状态”。那是“壮”——她在追求“强”的状态。
- **但“物壮即老”。** 她“壮”了——但身体“老”了。过度运动导致损伤、过度劳累导致耗竭、过度要求导致崩溃。她追求“强”——结果却是“老”（提前消耗、加速衰退）。
- **“物壮即老”的深层含义：** 不是“变老”本身是不道——是“追求壮”是不道。身体有自己的节奏——它不需要“壮”才能“活”。它需要的是“和”——不是“壮”。急于“变强”的，反而会“老”。

朱先生说“物壮则老”是壮大就会衰老。母亲的身体告诉我们：**她急于“变强”——反而提前“老”了。“物壮即老”是身体的警告——不需要“壮”，需要“和”。**

| 朱邦復的“物壮则老” | 母亲经验的“物壯即老” |
| :--- | :--- |
| 壮大就会衰老 | 她急于“变强”——结果提前“老”了。身体不需要“壮”，需要“和” |
| 第三人称：自然的规律 | 第一人称：我追求“强”——身体却说“不” |


## 九、“谓之不道，不道早已”——这不合道，不合道就会早早消亡

### 朱邦復的解读：不合道的事物会早早消亡

朱先生将“是谓不道，不道早已”解读为“强盛是不合道的，不合道的很快就消逝”：

> “強大是不合乎道的，凡不合乎道者，必然很快就會消逝。”

“不道”是偏离道。“早已”是早早结束。“物壮”导致“老”——那是“不道”。不道的，就会“早已”。

### 从母亲经验的解读：她用“意志力”强撑的恢复——“物壮”了——但那是“不道”

“不道早已”——在母亲的身体里，“不道”是什么？

- **她用“意志力”强撑——那是“不道”。** 她不顾身体的信号、忽视需要的信号、强迫自己“恢复”——那是“不道”。因为她在“违抗”身体的自然节律。
- **“早已”的后果：** 她可能“看起来”恢复了——但身体在内部“早”了。盆底肌没有恢复、腹直肌没有闭合、精力没有补充——她“壮”了，但“内部”在“老”。那不是“恢复”——是“耗”。
- **“不道早已”的深层含义：** “道”是顺应——身体怎么走，她跟着走。“不道”是命令——身体还没好，她命令它“好”。“不道”的，会“早已”——不是“死”——是“提前耗竭”。

朱先生说“不道早已”是偏离道就会早早消亡。母亲的身体告诉我们：**她用意志力强撑——“不道”。她“壮”了——但“内部”在“老”。那不是恢复——是耗竭。**

| 朱邦復的“不道早已” | 母亲经验的“不道早已” |
| :--- | :--- |
| 偏离道就会早早消亡 | 她用意志力强撑——“不道”。她“壮”了，但“内部”在“老” |
| 第三人称：不道的后果 | 第一人称：我“壮”了——但身体在说“不” |


## 结语：婴儿的“和”与母亲的“不道”——回到赤子的节律

朱邦復先生在这一章中，对“毒虫不螫、猛兽不搏”提出质疑，认为婴儿不可能真的不受动物伤害；但他保留了“骨弱筋柔而握固”、“终日号而不嗄”作为“精之至、和之至”的象征。他延续了“知和曰常，知常曰明”与“物壮则老”的逻辑，最后以“不道早已”收尾。

而母亲的身体，是这一章最完整的“赤子之喻”的演绎者——不是“象征性”的，是“字面”的：

- **“含德之厚者，比於赤子”——产后身体也像“赤子”——柔软、脆弱、需要被保护。**
- **“骨弱筋柔而握固”——产后她“弱”了——但握着孩子的手不松。那不是“肌肉”——是“精”。**
- **“未知牝牡之会而朘怒”——乳汁分泌不是靠“意识”的——身体自己知道。那是“精之至”。**
- **“终日号而不嗄”——她日夜回应——但没有“嘶哑”。那是“和之至”——因为“气顺”。**
- **“知和曰常”——产后不是在“追赶”——是在“回到和”。知道自己何时在“和”里，就是“明”。**
- **“益生曰祥”——对她来说，“益生”是休息、慢慢来、不强迫自己——那是“祥”。**
- **“心使气曰强”——她用意志力强迫自己恢复——那是“心使气”，是“强”不是“和”。**
- **“物壮即老”——她急于“变强”——结果提前“老”了。身体不需要“壮”，需要“和”。**
- **“不道早已”——她用意志力强撑——“不道”。她“壮”了，但“内部”在“老”。**

**“骨弱筋柔而握固”——产后身体是“弱”的——但母亲握着孩子的手不松。那不是“力量”的硬撑——是“精”的支撑。她不是“有力”才握住的——她“弱”了，但“精”还在。那就是“精之至”——“弱”的身体里，“精”是“固”的。**

**“终日号而不嗄”——母亲日夜回应孩子——她没有“嘶哑”。不是因为“她不累”——是因为她的“和”还在。她不是靠“意志”撑住的——是靠“和”撑住的。那就是“和之至”——气不“嗄”，因为气是“和”的。**

**“物壮即老，谓之不道，不道早已”——母亲急于“变强”——那是“壮”。但“物壮即老”——她追求“壮”，身体却“老”了。那不是“恢复”——是“耗”。那是“不道”——因为她违背了身体的自然节律。真正的“道”是“和”——不是“壮”。身体不需要“强”——它需要“和”。**

一个母亲的身体，在产后就像“赤子”一样。它需要的不是“变强”——是“被保护”。它需要的不是“快速恢复”——是“慢慢和”。它需要的不是“意志力”——是“顺应”。回到“赤子”的节律——不急、不催、不强迫。那是“和”——不是“壮”。那是“道”——不是“不道”。

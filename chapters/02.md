

## 引言：最“宇宙”的一章，最“身体”的根基

帛书本第三十九章，是《德道经》中关于“得一”与“贵贱”关系最集中的论述：

> 昔之得一者，天得一以清，地得一以寧，神得一以霝（靈），浴谷得一以盈，侯王得一而以為正。其致之也，
>
> 胃（謂）天毋已清將恐裂，胃（謂）地毋已寧將恐發，胃（謂）神毋已霝（靈）將恐歇，胃（謂）浴（谷）毋已盈將恐渴（竭），胃（謂）侯王毋已貴以高將恐蹶。
>
> 故必貴而以賤為本，必高矣而以下為基。夫是以侯王自胃（謂）曰孤寡不𥞤（穀），此其賤之本與？非也？
>
> 故致數與（譽）无與（譽）。是故不欲祿祿若玉，硌硌若石。

“昔之得一者”——以前那些得到“一”的事物：天“得一”而清明，地“得一”而安宁，神“得一”而灵验，谷“得一”而充盈，侯王“得一”而为天下正。推而言之：天若不再清明恐怕会崩裂，地若不再安宁恐怕会震动，神若不再灵验恐怕会停歇，谷若不再充盈恐怕会枯竭，侯王若不再高贵而高高在上恐怕会颠覆。

“故必贵而以贱为本”——所以真正的贵必须以贱为根本。“必高矣而以下为基”——真正的高必须以低为基础。所以侯王自称“孤、寡、不穀”——这难道不是以贱为本吗？不是吗？

“故致数誉无誉”——所以追求过多赞誉反而得不到赞誉。“是故不欲禄禄若玉，硌硌若石”——所以不要像美玉那样华丽耀眼，宁愿像石头那样质朴坚实。

朱邦復先生在《止笑譚》中，将这一章解读为 **“得一即得道、贵贱高下的辩证关系”** 。他认为“一”就是“道”——天、地、神、谷、侯王之所以能保持其本然状态，是因为它们“得一”。他特别强调了“贵以贱为本，高以下为基”——尊贵以卑贱为根本，高位以低处为基础。侯王自称“孤寡不穀”正是这个道理的体现——“自贱”是为了提醒自己不要忘本。他最后以“不欲如玉，硌硌若石”作结——不要追求华丽耀眼，宁愿像石头一样质朴坚实。

但如果我们把主语换成“母亲的身体”——那个曾经“得一”（怀孕时与胎儿浑然一体）、在产后经历“失一”、却始终以“贱”为“本”、以“下”为“基”的身体——这一章就不再是“抽象的宇宙论”，而是一份 **“关于母亲如何守住身体之‘一’、如何在‘孤寡不穀’中成就真正的‘贵’”的日常记录**：

- “昔之得一者”——曾经“得一”的，是母亲的身体在怀孕时的状态。胎儿和母亲是“一”——不分彼此、不争不抢。那是“得一”。
- “天得一以清”——母亲的身体在孕期中，因为“得一”（与胎儿一体），她“清”（清明、有方向）了。她的身体被一个统一的目的主导着。
- “地得一以宁”——她的身体“宁”了。不是因为“安静”——是因为“有了中心”。她的全部存在围绕一个生命运转。
- “神得一以灵”——她的“神”（直觉、感知）变得“灵”了。她能感知到胎儿的每一次微动、每一个信号。那是“得一”带来的“灵”。
- “谷得一以盈”——她的身体（谷）因为“得一”而“盈”（充盈）。胎儿在里面生长、羊水充满、生命越来越饱满。
- “侯王得一以为正”——她因为“得一”而“正”——她不再是“自己”——她是“孕育者”。那个身份明确、清晰、不晃动。
- “其致之也”——推而言之：如果“清”停止了，“裂”会发生；如果“宁”停止了，“发”（震动）会发生；如果“灵”停止了，“歇”会发生；如果“盈”停止了，“竭”会发生；如果“贵以高”取代了“得一”，“蹶”会发生。
- “贵以贱为本”——一个母亲的“贵”在哪里？在“贱”里。她蹲下来、弯下腰、把自己放在低处——那是“贱”。但正是那个“贱”成就了她的“贵”。她是孩子的根基。
- “高以下为基”——她“高”吗？她承载了一个生命——那是“高”。但那个“高”的根基是“低”——她的身体在低处、她的位置在低处、她蹲下去的身姿。
- “孤寡不穀”——侯王自称“孤寡”。母亲呢？她也“孤”——独自承担养育的孤独；她也“寡”——她的世界因孩子而变小；她也“不穀”——她把“谷”（生育能力）用完了，但她不以此自怜。
- “致数誉无誉”——她不需要“好妈妈”的赞誉。追求越多赞誉，越容易失去真实的连接。
- “不欲如玉，硌硌若石”——她不像玉——华丽、易碎、摆在那里被观赏。她像石头——坚实、粗糙、可以被踩在上面。


## 一、“昔之得一者”——曾经得到“一”的那些

### 朱邦復的解读：“一”就是道

朱先生将“昔之得一者”解读为“得到一的那些”：

> “所謂得一的情形是這樣的……”

“一”就是道、是整体、是未分化的本源状态。得到“一”，就是与道合一、没有被分裂。

### 从身体经验出发：曾经“得一”的是母亲在怀孕时的状态——胎儿和母亲是“一”

“昔之得一者”——在母亲的身体里，“得一”是什么时候？

- **怀孕时，她“得一”了。** 她的身体里住着另一个生命——胎儿和她不是“两个”——他们是“一个系统”。他依赖她、她承载他——那是“得一”：没有“你”和“我”的清晰边界。
- **“得一”的体验：** 她感受不到“我”和“他”的分离。她饿了，他也动；她躺下，他也安静；她呼吸，他也共享。那是“一”——不是比喻，是真实的身体状态。
- **“得一”的结束：** 分娩时，“一”被打破了。他出来了——她不再“得一”。从“一”变成了“二”。但那个“得一”的记忆，留在了她的身体里。

朱先生说“得一即得道”是万物因得一而保持本然。母亲的身体告诉我们：**她曾经“得一”——怀孕时，她和胎儿是“一”。不分你我、不分彼此。那是她生命中唯一一次“完全一体”的经验。**

| 朱邦復的“昔之得一者” | 母亲经验的“昔之得一者” |
| :--- | :--- |
| 一即道，得一则合道 | 怀孕时她“得一”——胎儿和她是一体，不分彼此 |
| 第三人称：道的整体性 | 第一人称：我曾经“一”过——那时他还在我身体里 |


## 二、“天得一以清，地得一以寧……”——万物因得一而保持本然

### 朱邦復的解读：得一才能保持本然状态

朱先生将“天得一以清，地得一以宁……”解读为“天、地、神、谷、侯王因得一而保持本然”：

> “天得一即清明澄澈，地得一则安定寧靜……”

“清、宁、灵、盈、正”都是“得一”的结果。没有“一”，它们就会失去本然状态。

### 从母亲经验的解读：怀孕时她的身体因“得一”而“清、宁、灵、盈、正”

“天得一以清”——在母亲的身体里，“得一以清”是什么？

- **她的“清”是方向明确。** 怀孕时，她的身体被一个统一的目的主导：让他活、让他长。那是“清”——不是没有疲惫，是没有“我该去哪”的迷惑。
- **“地得一以宁”——她的身体“宁”了。** 她不再是“漫无目的”的状态——她有了一个“中心”。围绕他，她的存在变得“宁”。
- **“神得一以灵”——她的直觉变“灵”了。** 她能感知胎动、能分辨他是否不舒服。不是“学习”来的——是“得一”带来的。
- **“谷得一以盈”——她的身体“盈”了。** 子宫充盈、羊水充盈、生命充盈。那是“谷”（虚空）因“得一”而“盈”（充满）。
- **“侯王得一以为正”——她因为“得一”而“正”。** 她不再是“谁”的问题——她是“孕育者”。那个身份不晃动、不分裂、不矛盾。

朱先生说“得一以清宁灵盈正”是得一才能保持本然。母亲的身体告诉我们：**怀孕时她因“得一”而清（方向明确）、宁（有中心）、灵（直觉敏锐）、盈（身体充盈）、正（身份明确）。**

| 朱邦復的“得一以清宁灵盈正” | 母亲经验的“得一以清寧霝盈正” |
| :--- | :--- |
| 得一才能保持本然状态 | 怀孕时她因“得一”而清、宁、灵、盈、正 |
| 第三人称：万物的本然 | 第一人称：那时我是“一”——我的一切都围绕一个中心 |


## 三、“其致之也……天毋已清將恐裂……”——失去“一”的后果

### 朱邦復的解读：失去一就会走向反面

朱先生将“天无以清将恐裂……”解读为“失去一就会走向反面”：

> “天若不清將有災禍，地若不寧則將崩發……”

“裂、发、歇、竭、蹶”都是“失一”的后果——失去本然状态，事物就会崩溃。

### 从母亲经验的解读：分娩后“一”被打破——“裂”发生了

“天毋已清將恐裂”——在母亲的身体里，“失一”是什么？

- **分娩时，“一”被打破了。** 胎儿离开她的身体——“一”变成了“二”。那是“裂”——她不再是他唯一的容器了。
- **“发、歇、竭、蹶”的产后版本：** 产后身体的“发”（震动、激素波动）、“歇”（疲惫停歇）、“竭”（精力枯竭）、“蹶”（身份动摇）——都是“失一”之后可能出现的结果。她不再是“孕育者”了——她需要重新找到“谁是现在的我”。
- **“失一”不是“失败”——是“分离”。** 分离是必要的——他必须出来、她必须放手。但分离意味着她失去了那个“一”的状态。

朱先生说“失一则会裂发歇竭蹶”是失去本然就会崩溃。母亲的身体告诉我们：**分娩是“裂”——一变成二了。她不再是一了。“失一”带来了产后身体的发、歇、竭、蹶——但也带来了新的开始。**

| 朱邦復的“失一则会裂发歇竭蹶” | 母亲经验的“失一會裂發歇竭蹶” |
| :--- | :--- |
| 失去本然就会崩溃 | 分娩是“裂”——一变成二。产后身体经历了发、歇、竭、蹶 |
| 第三人称：失一的后果 | 第一人称：我“裂”了——但那是他必须出来的方式 |


## 四、“故必貴而以賤為本”——真正的贵必须以贱为根本

### 朱邦復的解读：贵以贱为本

朱先生将“贵以贱为本”解读为“尊贵以卑贱为根本”：

> “尊貴是以貧賤為本源。”

真正的贵不是凭空而来的——它建立在“贱”（不起眼、卑微、低处）的基础上。没有“贱”就没有“贵”。

### 从母亲经验的解读：母亲的“贵”在“贱”里——她蹲下来、弯下腰、把自己放低

“貴而以賤為本”——在母亲的身体里，“贵”和“贱”是什么？

- **她的“贵”是：她承载了一个生命。** 那是“贵”——不是“高贵”，是“珍贵”。她的存在对一个生命来说不可或缺。
- **她的“贱”是：她蹲下来、弯下腰、把自己放低。** 她不在高处发号施令——她在低处托举。“贱”是她的位置——低、下、不显眼。
- **但“贵”以“贱”为本：** 正因为她在低处——她才能承载。如果她“高”了（站在上面、要求被服从），她就无法接住他。“贱”是“贵”的前提。

朱先生说“贵以贱为本”是真正的贵必须建立在卑贱的基础上。母亲的身体告诉我们：**她“贵”——因为她是孩子的根基。但那个“贵”的根基是“贱”——她蹲下来、在低处、在“不起眼”的位置。没有“贱”，就没有“贵”。**

| 朱邦復的“贵以贱为本” | 母亲经验的“貴而以賤為本” |
| :--- | :--- |
| 真正的贵以卑贱为根本 | 她的“贵”（承载生命）以“贱”（蹲下、弯腰、在低处）为基础 |
| 第三人称：贵贱的辩证 | 第一人称：我在低处——所以他才能被托起来 |


## 五、“高以下為基”——真正的高以低为基础

### 朱邦復的解读：高以下为基

朱先生将“高以下为基”解读为“高处建立在低处的基础上”：

> “高處係建立在低下的基礎上。”

没有“下”就没有“上”。“高”需要“低”来支撑——这是物理规律，也是人生规律。

### 从母亲经验的解读：她的身体在“下”——那是孩子可以立身的“基”

“高以下為基”——在母亲的身体里，“下”是什么？“基”是什么？

- **她的身体在“下”。** 她抱着他时，她在下面，他在上面；她哺乳时，她弯着腰，他在她怀里。她的位置永远是“下”——但那个“下”是他的“基”。
- **“基”是地基、根基。** 他能在上面、能站、能长——是因为她在下面接着。她的“下”就是他的“基”。
- **“高”的悖论：** 她看起来“低”——但她的“低”让他的“高”成为可能。她不是“不高”——她是“以低为高”。

朱先生说“高以下为基”是真正的高必须建立在低的基础上。母亲的身体告诉我们：**她在“下”——但那个“下”是他的“基”。没有她的“下”——就没有他的“高”。**

| 朱邦復的“高以下为基” | 母亲经验的“高以下為基” |
| :--- | :--- |
| 真正的高以低为基础 | 她的身体在“下”——但那个“下”是他可以站立的“基” |
| 第三人称：高低的辩证 | 第一人称：我越低——他越稳 |


## 六、“孤寡不穀”——侯王自称孤寡，母亲也是“孤寡”

### 朱邦復的解读：侯王用贱称来提醒自己不忘本

朱先生将“侯王自称孤寡不穀”解读为“侯王用贱称来提醒自己以贱为本”：

> “君王自稱‘孤、寡人、不穀’難道不是這個原因嗎？”

侯王用最卑微的称呼来称呼自己——孤独的、寡德的、不善的——以此来提醒自己不要忘记“贱”才是“贵”的根本。

### 从母亲经验的解读：母亲也“孤”（独自承担）、“寡”（世界缩小）、“不穀”（生育能力被用尽）

“孤寡不穀”——在母亲的身体里，“孤寡不穀”是什么？

- **“孤”——她独自承担。** 养育是孤独的。深夜醒来的是她、陪他度过每一次生病的是她、被耗尽的是她。她“孤”——不是没有人，是“承担”是独一份的。
- **“寡”——她的世界缩小了。** 她的社交圈变小、她的关注点变少、她的生活半径变短。她“寡”——不是因为“不够”，是因为“专注”必然带来“减少”。
- **“不穀”——她的生育能力被“用完”了。** 她把自己的“谷”（子宫、生育能力）用来孕育了一个生命。她“不穀”了——不再是一个“未被使用”的女人。但她不以此自怜。
- **“此其賤之本與？非也？”——这难道不是以贱为本吗？不是吗？** 帛书本的这个反问，恰恰是在确认：是的，这就是“以贱为本”。母亲在“孤寡不穀”中——那不是“失败”——那是“根基”。

朱先生说“孤寡不穀”是侯王用贱称来提醒自己不忘本。母亲的身体告诉我们：**她也“孤寡不穀”——独自承担、世界缩小、生育能力用尽。但那不是“失败”——那是“本”。她是“以贱为本”的活证。**

| 朱邦復的“孤寡不穀” | 母亲经验的“孤寡不穀” |
| :--- | :--- |
| 侯王用贱称提醒自己不忘本 | 她也“孤”（独自承担）、“寡”（世界缩小）、“不穀”（生育能力用尽） |
| 第三人称：身份的谦卑 | 第一人称：我不是“失败”——我是“以贱为本”的活证 |


## 七、“致數譽无譽”——追求过多赞誉反而得不到

### 朱邦復的解读：过多追求赞美反而失去

朱先生将“致数誉无誉”解读为“追求过多赞誉反而得不到”：

> “追求過多的讚譽，反而會失去讚譽。”

你越是追求“被赞美”，你越难得到真正的赞美。因为你的注意力在“得到认可”上——而不是在“做”本身。

### 从母亲经验的解读：母亲不需要“好妈妈”的赞誉——越追越空

“致數譽无譽”——在母亲的身体里，“数誉”是什么？“无誉”是什么？

- **“数誉”——她追求“好妈妈”的标签。** 她希望别人说“你真是个好妈妈”、希望孩子说“妈妈最好了”。她追了——但越追越空。
- **“无誉”——真正的赞誉不需要被追。** 当她不追“好妈妈”标签的时候——她反而“有”了。孩子不需要说“你是好妈妈”——他靠近她、信任她、依赖她——那就是她的“誉”，而它没有被“致”。
- **“致数誉无誉”的养育版本：** 当你想“我的孩子应该感谢我”时——你反而得不到感谢。当你只是做、不求感谢时——他反而会感激你。

朱先生说“致数誉无誉”是追求过多赞誉反而失去。母亲的身体告诉我们：**她不需要“好妈妈”的赞誉。越追越空。不追的时候——他靠近她、信任她——那就是她的“誉”。**

| 朱邦復的“致数誉无誉” | 母亲经验的“致數譽无譽” |
| :--- | :--- |
| 追求过多赞誉反而失去 | 她追求“好妈妈”的标签——越追越空；不追的时候，他靠近她，那就是她的“誉” |
| 第三人称：赞誉的辩证法 | 第一人称：我不需要被赞美——我需要的是他在 |


## 八、“不欲祿祿若玉，硌硌若石”——不要像玉，宁愿像石头

### 朱邦復的解读：不要像玉一样华丽，要像石头一样质朴

朱先生将“不欲禄禄若玉，硌硌若石”解读为“不要像玉一样华丽，要像石头一样质朴”：

> “像玉器般耀目的光彩，反而不如平實堅硬的石頭更近自然。”

玉是华丽的、精致的、被观赏的。石头是粗糙的、坚实的、被踩在脚下的。老子选择“石”——不要“玉”。

### 从母亲经验的解读：母亲像石头——温厚、坚实、被踩在上面也不碎

“不欲祿祿若玉，硌硌若石”——在母亲的身体里，“玉”和“石”是什么？

- **“玉”是华丽的、易碎的、需要被观赏的。** 她在“玉”的状态——精心打扮、在社交媒体上展示“好妈妈”的瞬间——那是“玉”。美，但易碎。
- **“石”是粗糙的、坚实的、被踩在上面也不碎的。** 她在“石”的状态——素颜、疲惫、身上有奶渍——但她的坚实让另一个人可以在上面站立。她是“石”——不是被观赏的，是被踩的。
- **“不欲如玉”——她不想当玉。** 她不想精致、不想被观赏、不想展示“完美”。她宁愿当“石”——可以被踩、可以不被看见、可以承载。因为“石”是真正的根基。

朱先生说“不欲如玉，硌硌若石”是要像石头一样质朴坚实。母亲的身体告诉我们：**她不像玉——华丽、易碎、被观赏。她像石头——坚实、粗糙、被踩在上面也不碎。“石”才是真正能承载的。**

## 结语：“得一”是暂时，“孤寡”是长久

朱邦復先生在这一章中，用“得一”和“贵贱”的辩证关系，解读了“天得一以清……”和“贵以贱为本”的道理。他认为“一”是万物的本然状态，失去“一”就会走向反面；“贵”以“贱”为根本，“高”以“下”为基础。他最后以“不欲如玉，硌硌若石”点明：朴实才是真正的坚实。

而母亲的身体，是这一章最完整的“得一-失一-贱本”的演绎者：

- **“昔之得一者”——怀孕时她“得一”——胎儿和她是一体。**
- **“天得一以清”——她的方向因“得一”而“清”（明确）。**
- **“地得一以宁”——她的存在因“得一”而“宁”（有中心）。**
- **“神得一以灵”——她的直觉因“得一”而“灵”（敏锐）。**
- **“谷得一以盈”——她的身体因“得一”而“盈”（充盈）。**
- **“侯王得一以为正”——她的身份因“得一”而“正”（明确）。**
- **“其致之也”——分娩是“裂”，一变成了二。**
- **“贵以贱为本”——她的“贵”（承载生命）以“贱”（蹲下、弯腰）为根本。**
- **“高以下为基”——她的“下”是他的“基”——她在低处，他才得以站立。**
- **“孤寡不穀”——她“孤”（独自承担）、“寡”（世界缩小）、“不穀”（生育能力被用尽）——但那就是“本”。**
- **“致数誉无誉”——她不需要“好妈妈”的赞誉——越追越空。**
- **“不欲如玉，硌硌若石”——她不像玉（华丽、易碎），她像石头——坚实、承载、被踩也不碎。**

**“得一”是怀孕时最完整的体验——那时她和他一体，不分彼此。“失一”是分娩——一变成二，她不再是“容器”。“贱”是她的位置——在低处、不显眼、被忽略。“贵”是她承载的生命——在“贱”中成就。“孤寡”不是失败——是“本”。“石”不是“不够好”——是“足够坚实”。**

母亲的身体从“得一”开始——怀着完整的合一；然后“失一”——他离开她的身体；然后她在“贱”中、在“孤寡”中、在“石”的状态中——继续承载。她没有“玉”的华丽，但她有“石”的坚实。那不是“遗憾”——那是“本”。

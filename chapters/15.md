

## 引言：最“本源”的一章，最“母亲”的常道

帛书本第五十二章，是《德道经》中关于“天下母”与“守母”关系最集中的论述：

> 天下有始，以為天下母。（既）得其母，以知其子，
>
> 復守其母，沒身不殆。
>
> 塞其（悶），閉其門，終身不堇（勤）。
>
> 啟其悶，濟其事，終身不棘。
>
> 見小曰明，守柔曰強。用其光，復歸其明，毋道（遺）身央（殃），是胃（謂）襲常。

“天下有始，以為天下母”——天下万物有一个开始，那就是天下的母亲。“既得其母，以知其子”——既然知道了母亲，就可以了解孩子。“复守其母，没身不殆”——回归并守住母亲，终身不会陷于危殆。

“塞其闷，闭其门”——堵塞感官的孔隙（闷=孔窍），关闭欲望的门户，“终身不堇（勤）”——终身不会劳苦困顿。“启其闷，济其事”——打开感官的孔隙，成就外在的事务，“终身不棘”——终身不可救药（棘=急，意为不可救）。

“见小曰明”——能看见细微的东西叫做“明”。“守柔曰强”——能守住柔弱叫做“强”。“用其光，复归其明”——运用它的光，回归到它的明。“毋遗身殃”——不留下自身的祸殃。“是谓袭常”——这就是承袭常道。

朱邦復先生在《止笑譚》中，将这一章解读为 **“因果认知与守道保身”** 。他认为“天下有始，以为天下母”是指道是天地万物的起源，“既得其母，以知其子”是从本源可以了解现象，“复守其母，没身不殆”是守住本源终身不虞有危。他特别强调了“塞其兑，闭其门”——关闭感官刺激的通道，不让内心受外界影响，终身无忧；“开其兑，济其事”——如果无法拒绝感官刺激，则劳心劳神，终身不可救药。他最后以“见小曰明，守柔曰强，用其光，复归其明”作结——能看到隐微的道理才是明者，能坚守柔弱的信念才是强者，利用对事物现况的认知反证事物的本源，终身不会出错，这就是承袭常道。

但如果我们把主语换成“母亲的身体”——那个在孕期与胎儿同体、产后通过“守母”来“知子”的身体——这一章就不再是“抽象的因果认知论”，而是一份 **“关于母亲如何通过守住‘母’的位置来‘知’孩子、如何通过‘见小守柔’来保护孩子”的日常记录**：

- “天下有始，以为天下母”——对每个孩子来说，天下最初的“始”就是母亲。她是他的“天下母”。不是比喻——是生理事实。他在她的身体里被孕育，从她的身体里出来，她是他最初的“天下”。
- “既得其母，以知其子”——母亲是认识孩子的起点。她不需要“研究”他才知道他——她“守”着他，就知道了。她守着怀孕的节律、守着胎动的信号、守着产检的数据——她通过“守母”（守住自己作为母体的状态）来“知子”（知道孩子的状态）。
- “复守其母，没身不殆”——母亲守住“母亲”这个位置——终身不会迷失。不是因为她“什么都知道”——是因为她“在”那个位置。她的孩子无论走多远，只要她还在“守母”的位置上，他就有一个可以回来的地方。
- “塞其闷，闭其门”——母亲在产后关闭外界干扰。她放下手机、不看社交媒体、不参加无意义的社交——她“塞”了那些“闷”（孔窍、通道）。“闭其门”是关闭那些让她分心的入口。然后她“终身不勤”——不劳苦、不困顿。
- “启其闷，济其事”——如果她打开了那些通道——刷社交媒体、看别人家的“完美育儿”、追逐“标准”——她“启”了那些闷。然后她“终身不棘”——终身不可救药地被焦虑吞噬。
- “见小曰明”——母亲能看见孩子的细微变化。他脸上一个小小的表情、他哭声里一种细微的差别、他体温上零点几度的变化。她能“见小”——那就是“明”。
- “守柔曰强”——母亲在分娩和养育中“守柔”。产道是柔的、母乳是柔的、耐心是柔的——她“守”住那些“柔”，让生命通过。那就是“强”。
- “用其光，复归其明”——她用她的“光”（对孩子的关注、爱）去照耀他。但那个“光”不是消耗品——它不断回归到她身上。她看着他——他也在看着她。她用光——光也回到她身上。
- “毋遗身殃”——她不把自己的焦虑、控制、期待“遗”在孩子身上。不让孩子替她承受她没能处理的情感。那就是“毋遗身殃”——不让自己的“殃”留在孩子身上。
- “是谓袭常”——那就是承袭常道。母亲一生在“袭”的常道——不是书本上的常道——是身体里的、世代相传的、从她母亲那里来、传给她的孩子的常道。


## 一、“天下有始，以為天下母”——天下的开始，就是天下的母亲

### 朱邦復的解读：道是万物的起源

朱先生将“天下有始，以为天下母”解读为“道是天地万物的起源”：

> “天下由無至有，‘道’即為天地萬物之起源。”

“母”在这里是比喻——道是“生”万物的那个起源。不是性别意义上的母——是“源头”的母。

### 从身体经验出发：对每个孩子来说，天下最初的“始”就是母亲

“天下有始，以為天下母”——在母亲的身体里，“天下母”是什么？

- **她就是他的“天下母”。** 不是比喻——是生理事实。他是从她身体里来的。她是他最初的“天下”——他的世界从她开始。他睁开眼睛看到的第一个人、他听到的第一个声音、他感受到的第一个温度——都是她的。她就是他的“天下母”。
- **“天下母”的另一种理解：** “天下”不是“全世界”对她来说——是“他”。她是他的天下。她孕育了他、生了他、养了他——她就是他的“天下母”。那个“母”不是“像”母——它就是母。
- **“始”的深层含义：** 她是他的“始”。他的人生开始于她的身体。没有她，就没有他的开始。那不是“比喻”——是字面意思。

朱先生说“天下有始以为天下母”是道是万物的起源。母亲的身体告诉我们：**她就是他的“天下母”——他是从她身体里来的。她是他的“始”——字面意思，不是比喻。**

| 朱邦復的“天下有始以为天下母” | 母亲经验的“天下有始以為天下母” |
| :--- | :--- |
| 道是万物的起源 | 她就是他的“天下母”——他是从她身体里来的 |
| 第三人称：宇宙的生成论 | 第一人称：我就是他的“始”——字面意思 |


## 二、“既得其母，以知其子”——知道了母亲，就能了解孩子

### 朱邦復的解读：由本源可知现象

朱先生将“既得其母，以知其子”解读为“知道了本源就知道万物”：

> “既然知道了本源，就可以知道萬事萬物發展的現象。”

“母”是本源，“子”是现象。你知道了本源——你就能“知”它的衍生。这是因果逻辑：知因则知果。

### 从身体经验出发：母亲是认识孩子的起点——她不需要“研究”他才知道，她“守”着就知道了

“既得其母，以知其子”——在母亲的身体里，“得其母”和“知其子”是什么？

- **她知道怎么认识他？——通过她自己的“母”的位置。** 她不是通过“研究”来知道孩子的——她是通过“守”着“母”的位置来知道的。她守住自己的身体节律、守住孕期的节奏、守住产后的恢复——她就“知”他了。
- **“得其母，以知其子”的另一种理解：** 她知道自己（作为母亲）的状态——就知道孩子的状态。她累了——他也累了；她平静——他也平静；她焦虑——他也焦虑。她的“母”状态，就是他的状态的指示器。
- **“知其子”不是“知道孩子是什么”——是“通过母体感知孩子”。** 她不需要“分析”他才能知道他——她“经历”他就能知道他。母是知的通道。

朱先生说“既得其母以知其子”是由本源可知现象。母亲的身体告诉我们：**她通过守住“母”的位置来“知”他。她不需要“研究”他——她“经历”他就知道了。**

| 朱邦復的“既得其母以知其子” | 母亲经验的“既得其母以知其子” |
| :--- | :--- |
| 知道了本源就能知道现象 | 她通过守住“母”的位置来“知”他——不需要“研究”，只需“经历” |
| 第三人称：因果的认知 | 第一人称：我“在”母的位置上——我就“知”他 |


## 三、“复守其母，没身不殆”——回归母亲、守住母亲，终身不危殆

### 朱邦復的解读：守住本源则终身不殆

朱先生将“既知其子，复守其母，没身不殆”解读为“守住本源终身不虞有危”：

> “等到瞭解了事物的現象，再根據此一本源來處理萬事萬物，可以終生受用不盡，不虞有危。”

“知子”之后要“守母”——不是“知道了孩子就不管母亲了”——是“通过孩子回到母亲”。守住本源——终身不危殆。

### 从母亲经验的解读：母亲守住“母”的位置——终身不会迷失

“復守其母”——在母亲的身体里，“复守”是什么？

- **她回到自己作为“母”的位置。** 孩子长大了、独立了、走远了——她不是“失去”了他——她回到自己“母”的位置。她守住那个位置——不是“等着他回来”——是“她在那里”。
- **“没身不殆”的另一种理解：** 她终身不会迷失。不是因为“她什么都知道”——是因为“她在那里”。无论孩子走多远，她守着的那个“母”的位置，就是他永远可以回来的地方。他回来了——她还在。那不是“不殆”吗？

朱先生说“复守其母没身不殆”是守住本源终身不危殆。母亲的身体告诉我们：**她守住“母”的位置——终身不会迷失。他在远方，她在那里。那就是“不殆”。**

| 朱邦復的“复守其母没身不殆” | 母亲经验的“復守其母沒身不殆” |
| :--- | :--- |
| 守住本源终身不危殆 | 她守住“母”的位置——终身不会迷失。他走远了，她还在那里 |
| 第三人称：守道的安全 | 第一人称：我不需要“抓住”他——我只需要“在那里” |


## 四、“塞其闷，闭其门，终身不勤”——关闭感官入口，终身不劳苦

### 朱邦復的解读：关闭感官刺激，不被外界干扰

朱先生将“塞其兑，闭其门”解读为“关闭感官刺激的通道”：

> “將七情六慾之感官關閉，使內心不受影響，則可終其生無憂無慮。”

“兑”是口、耳、目、鼻等感觉器官。“门”是通道。“塞”和“闭”是关闭那些可能让外界刺激进入的入口。“终身不勤”是终身不会劳苦困顿。

### 从母亲经验的解读：母亲在产后关闭外界干扰——不看社交媒体、不比别人家

“塞其闷，閉其門”——在母亲的身体里，“塞闭”是什么？

- **她放下手机。** 不刷社交媒体、不看“别人家的孩子”、不追“标准答案”——那是“塞”了那些“闷”（孔窍、通道）。她不让那些信息进入她的“门”。
- **她关闭“比较”的门。** 别人家的孩子走得早、别人家的妈妈恢复快、别人家的育儿多么“完美”——她不看了。她“闭”了那个“门”。
- **“终身不勤”的结果：** 她不劳苦、不困顿。不是因为“没有事情做”——是因为她没有“被比较”的焦虑消耗。她“塞”了那些门——她的能量没有被“勤”（不断消耗）在外面。

朱先生说“塞其兑闭其门终身不勤”是关闭感官入口，终身无忧。母亲的身体告诉我们：**她放下手机、不刷社交媒体、不比别人家——她“塞”了那些门。然后她“不勤”——不被焦虑消耗。**

| 朱邦復的“塞其兑闭其门终身不勤” | 母亲经验的“塞其悶閉其門終身不堇” |
| :--- | :--- |
| 关闭感官入口，终身无忧 | 放下手机、不比别人家——她“塞”了门，不被焦虑消耗 |
| 第三人称：感官的节制 | 第一人称：我“塞”了那些门——能量没有被“勤”在外面 |


## 五、“启其闷，济其事，终身不棘”——打开感官入口，成就外事，终身不可救药

### 朱邦復的解读：打开感官，劳心劳神，终身不可救药

朱先生将“开其兑，济其事”解读为“打开感官，劳心劳神”：

> “不能排拒外界及感官之刺激，則勞心勞神，無可救藥。”

“开”是打开。“济其事”是成就那些外在的事情。“终身不棘”是终身“不可救药”（棘=急，意为无法扭转的困境）。

### 从身体经验出发：如果她打开了那些通道——刷社交媒体、看标准、追逐“完美”——她就被焦虑吞噬了

“啟其悶，濟其事”——在母亲的身体里，“启”和“济”是什么？

- **她打开了那些“门”。** 她开始刷社交媒体——看别人家孩子的“完美成长”、看产后“神速恢复”的照片、看“你应该这样那样”的标准。她“启”了。
- **她“济”了那些事。** 她开始追逐——追逐“正确”的方法、追逐“合格”的标准、追逐“别人家的孩子”。她“济”了那些外在的事。
- **“终身不棘”的后果：** 她被焦虑吞噬了。她不是“不劳苦”了——她永远在“追赶”。打开了门——进来了不是“风”，是“比较”。那让她“终身不可救药”——不是“她没救了”——是“她的平静被门外的信息夺走了”。

朱先生说“开其兑济其事终身不救”是打开感官则不可救药。母亲的身体告诉我们：**她打开了那些门——刷社交媒体、追标准、比孩子——她就被焦虑吞噬了。“启”了的门——进来的不是“风”，是“焦虑”。**

| 朱邦復的“开其兑济其事终身不救” | 母亲经验的“啟其悶濟其事終身不棘” |
| :--- | :--- |
| 打开感官则劳心劳神不可救药 | 她刷社交媒体、追标准、比孩子——她就被焦虑吞噬了 |
| 第三人称：感官的放纵 | 第一人称：我打开了门——进来的是焦虑 |


## 六、“見小曰明”——能看见细微的叫做“明”

### 朱邦復的解读：看到隐微的道理是“明”

朱先生将“见小曰明”解读为“能看到隐微的道理才是明者”：

> “能看到隱微之道理，才是明者。”

“小”是细微的、不易察觉的。“明”是洞见、知道。不是“大的、明显的”才叫“明”——是“小的、不易看见的”才需要“明”。

### 从身体经验出发：母亲能看见孩子的细微变化——一个表情、一声哭的差异、体温零点几度的变化

“見小曰明”——在母亲的身体里，“见小”是什么？

- **她能看见他脸上一个细微的表情。** 他不是“在闹”——他的嘴角动了、他的眉毛皱了、他呼吸的节奏变了。那些“小”的变化——她看见了。那就是“明”。
- **她能听出他哭声里细微的差别。** 是饿的哭、是困的哭、是不舒服的哭——差别很小，但她听出来了。那就是“见小”——那就是“明”。
- **她能感觉到他体温零点几度的变化。** 她抱他的时候、摸他额头的时候——她“见”了那个“小”。不是“检查”出来的——是“感知”出来的。
- **“见小”的深层含义：** “见小”是“不忽略细微”。“明”不是“知道大的”——是“看见小的”。母亲最“明”的，就是她能看见那些别人看不见的“小”。

朱先生说“见小曰明”是看到隐微的道理才是明。母亲的身体告诉我们：**她看见他脸上一个细微的表情、听出他哭声里细微的差别、感觉到他体温的变化——那些“小”——她看见了。那就是“明”。**

| 朱邦復的“见小曰明” | 母亲经验的“見小曰明” |
| :--- | :--- |
| 看到隐微的道理才是明 | 她看见他脸上细微的表情、听出哭声的差别——那些“小”——她看见了 |
| 第三人称：认知的精度 | 第一人称：我看见那些别人看不见的“小”——那就是“明” |


## 七、“守柔曰强”——守住柔弱的叫做“强”

### 朱邦復的解读：坚守柔弱才是强

朱先生将“守柔曰强”解读为“坚守柔弱的信念才是强者”：

> “能堅守柔弱之信念，始為強者。”

“守柔”不是“弱”——是“选择柔弱”。真正的“强”不是“硬”——是“能柔”。

### 从身体经验出发：产道是柔的、母乳是柔的、耐心是柔的——她“守”住那些“柔”，让生命通过

“守柔曰強”——在母亲的身体里，“守柔”是什么？

- **产道是“柔”的。** 它不是“刚硬”的——它是柔软的、能扩张的。正是那个“柔”让生命可以通过。她“守”住了产道的柔——孩子出来了。
- **母乳是“柔”的。** 它是液体——没有形状、不刚硬。正是那个“柔”让婴儿可以喝到。她“守”住了母乳的柔——孩子长大了。
- **耐心是“柔”的。** 它不是“强悍”的——它是持续的、不放弃的。正是那个“柔”让孩子可以安然地成为自己。她“守”住了耐心的柔——孩子成为了他自己。
- **“守柔”的深层含义：** “守柔”不是“被动的”——是“主动选择不刚”。她不是“无力”——她是“选择了柔的方式来承载生命”。“守柔”就是“强”——因为刚的人会断，柔的人能通。

朱先生说“守柔曰强”是坚守柔弱才是强。母亲的身体告诉我们：**产道是柔的、母乳是柔的、耐心是柔的——她“守”住那些“柔”，让生命通过了。那就是“强”——不是“硬”，是“能通”。**

| 朱邦復的“守柔曰强” | 母亲经验的“守柔曰強” |
| :--- | :--- |
| 坚守柔弱才是强 | 产道是柔的、母乳是柔的、耐心是柔的——她“守”柔，让生命通过 |
| 第三人称：柔与强的辩证 | 第一人称：我不是“刚”——我是“能通” |


## 八、“用其光，复归其明”——用它的光，回归它的明

### 朱邦復的解读：运用认知，回归本源

朱先生将“用其光，复归其明”解读为“利用认知反证本源”：

> “利用對事物現況的認知，反証事物的本源。”

“光”是已经显现的、可用的认知。“明”是本源的光。“用”了“光”——然后回到“明”。不是“用了就没了”——是“用了然后回到它来的地方”。

### 从母亲经验的解读：她用她的光（关注、爱）去看他——然后那光回到她身上

“用其光，復歸其明”——在母亲的身体里，“用光”和“归明”是什么？

- **她用她的“光”去看他。** 她的关注、她的爱、她的注视——那是她的“光”。她用它去照耀他。
- **但那光“复归”了。** 她看他——他看着她的光。他回应她——他的存在就是她的“明”的回归。她用光——光也回到她身上。
- **“用光复归明”的深层含义：** 她对他的爱不是“单向消耗”的。她给他——他也给她。她看到他——他也看到她。她的“光”回到她身上。不是“她给了就没了”——是“她给了，然后被还回来了”。那是“复归”。

朱先生说“用其光复归其明”是利用认知反证本源。母亲的身体告诉我们：**她用她的“光”去看他——然后他回应她。她的光没有“消耗”——它“回归”了。她用——它也回来。**

| 朱邦復的“用其光复归其明” | 母亲经验的“用其光復歸其明” |
| :--- | :--- |
| 利用认知反证本源 | 她用她的“光”（关注、爱）去看他——然后他也回应她。光回归了 |
| 第三人称：认知的循环 | 第一人称：我给他光——他也给我光。那不是消耗——是回归 |


## 九、“毋遗身殃”——不遗留祸殃于自身

### 朱邦復的解读：不给自己留下祸害

朱先生将“无遗身殃”解读为“终身不会出问题”：

> “無遺身殃。”

“遗”是留下。“身殃”是自身的祸害。不把祸患留在自己身上。

### 从母亲经验的解读：她不把自己的焦虑、控制、期待“遗”在孩子身上——那就是“毋遗身殃”

“毋道身央”——在母亲的身体里，“毋遗身殃”是什么？

- **她不让自己的焦虑“遗”在他身上。** 她焦虑——但她不让他承受她的焦虑。她不把“我不安，所以你要让我安心”的期待放在他身上。
- **她不让自己的控制“遗”在他身上。** 她想要他成为什么——但她不强加给他。她不把“我为你牺牲了，所以你要成为我想要的样子”的期待留在他身上。
- **她不让自己的未完成“遗”在他身上。** 她有什么没实现的人生——她不通过他来“完成”。她不让她的“遗憾”成为他的负担。
- **“毋遗身殃”的深层含义：** 她做完了她的事——然后她不去“遗”给他。她不让他替她承受她没处理好的东西。那就是“毋遗身殃”——不把自己的“殃”留在孩子身上。

朱先生说“无遗身殃”是不给自己留下祸害。母亲的身体告诉我们：**她不把自己的焦虑、控制、未完成的期待“遗”在孩子身上。那就是“毋遗身殃”——不把自己的“殃”留给他。**

| 朱邦復的“无遗身殃” | 母亲经验的“毋道身央” |
| :--- | :--- |
| 不给自己留下祸害 | 她不把自己的焦虑、控制、未完成的期待“遗”在孩子身上 |
| 第三人称：自我的安全 | 第一人称：我的“殃”是我的——不“遗”给他 |


## 十、“是谓袭常”——这就是承袭常道

### 朱邦復的解读：这就是承袭常道

朱先生将“是谓袭常”解读为“这就是守道”：

> “是謂襲常。”

“袭”是承袭、沿袭。“常”是不变的规律。“袭常”是“承袭常道”——不是“自己发明”的——是“从源头接过来的”。

### 从母亲经验的解读：母亲一生在“袭”的常道——从她母亲那里来，传给她的孩子

“是胃襲常”——在母亲的身体里，“袭常”是什么？

- **她“袭”的常道——是从她母亲那里来的。** 她母亲怎么爱她、怎么抱她、怎么让她感到安全——那些“常”她“袭”了。不是“学”的——是“接”的。
- **她“袭”的常道——也会传给她的孩子。** 她怎么爱他、怎么抱他、怎么让他感到安全——那些“常”他会“袭”。不是“教”的——是“接”的。
- **“袭常”的深层含义：** 母亲做的那些事——不是她自己“发明”的。她是“承袭”的。从祖母到母亲到她到孩子——那是“袭”。不是“理论”——是“身体记忆”。她抱着孩子的方式，可能就是她母亲抱她的方式。她安抚孩子的方式，可能就是她母亲安抚她的方式。她“袭”了——然后她传下去。那就是“常”。

朱先生说“是谓袭常”是守道。母亲的身体告诉我们：**她“袭”的常道——从她母亲那里来，传给她的孩子。不是“学”的——是“接”的。那是身体记忆，是世代相传的常道。**

| 朱邦復的“是谓袭常” | 母亲经验的“是胃襲常” |
| :--- | :--- |
| 这就是守道 | 她“袭”的常道——从她母亲那里来，传给她的孩子。身体记忆 |
| 第三人称：守道的境界 | 第一人称：我没有“发明”爱——我是“接”了，然后“传” |


## 结语：母亲是“天下母”最真实的版本

朱邦復先生在这一章中，用“因果认知”和“守道保身”的框架，解读了“天下有始以为天下母”、“既得其母以知其子”、“复守其母没身不殆”以及“塞闭启济”、“见小守柔”、“用光归明”、“袭常”等概念。他认为“守母”是守住本源，“塞闭”是关闭感官，“见小守柔”是认知与力量的结合，“袭常”是承袭常道。

而母亲的身体，是这一章最完整的“天下母-守母-见小守柔-袭常”的演绎者：

- **“天下有始，以为天下母”——她就是他的“天下母”——他是从她身体里来的。**
- **“既得其母，以知其子”——她通过守住“母”的位置来“知”他——不需要“研究”，只需“经历”。**
- **“复守其母，没身不殆”——她守住“母”的位置——终身不会迷失。他在远方，她在那里。**
- **“塞其闷，闭其门”——放下手机、不比别人家——她“塞”了门，不被焦虑消耗。**
- **“启其闷，济其事”——打开了门——刷社交媒体、追标准、比孩子——她就被焦虑吞噬。**
- **“见小曰明”——她看见他脸上细微的表情、听出哭声的差别——那些“小”——她看见了。**
- **“守柔曰强”——产道是柔的、母乳是柔的、耐心是柔的——她“守”柔，让生命通过。**
- **“用其光，复归其明”——她用她的“光”去看他——然后他也回应她。光回归了。**
- **“毋遗身殃”——她不把自己的焦虑、控制、未完成的期待“遗”在孩子身上。**
- **“是谓袭常”——她“袭”的常道——从她母亲那里来，传给她的孩子。**

**“天下母”不是比喻——是母亲。** 她是他的“天下母”——他是从她身体里来的。她的“母”不是象征——是字面。

**“守母”是母亲终身的功课。** 她守住“母”的位置——不是为了“抓住”他——是为了“在那里”。他在远方，她在那里。他回来了，她还在。那就是“没身不殆”。

**“见小守柔”是母亲身体最根本的智慧。** 她看见别人看不见的“小”——那是“明”。她守住别人守不住的“柔”——那是“强”。

**“袭常”是母亲一生在做的事。** 她没有“发明”母爱——她是从她母亲那里“接”的。然后她“传”给她的孩子。那不是“学习”——那是“承袭”。身体记忆，代代相传。

一个母亲的一生，就是“天下母-守母-见小守柔-袭常”的日常版本。她不研究“道”——她就是“道”在运行的载体。她“袭”的常道不是书上的——是她身体里的——从她母亲那里来——传到她孩子那里。

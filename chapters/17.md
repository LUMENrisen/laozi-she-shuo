

## 引言：最“次第”的一章，最“身体”的传承

帛书本第五十四章，是《德道经》中关于“德性从身到天下的次第扩展”最完整的论述：

> 善建者不拔，善抱者不脫，子孫以祭祀不絕。
>
> 修之身，其德乃真。修之家，其德有餘。修之鄉，其德乃長。修之邦，其德乃豐。修之天下，其德乃溥。
>
> 以身觀身，以家觀家，以鄉觀鄉，以邦觀邦，以天下觀天下。
>
> 吾何以知天下之然哉？以此。

“善建者不拔”——善于建造的人，他所建的东西不会被拔除。“善抱者不脱”——善于抱持的人，他所抱的东西不会脱落。“子孙以祭祀不绝”——子孙因此能够世代祭祀而不中断。

“修之身，其德乃真”——在自身修养，德性就真实；“修之家，其德有餘”——在家庭修养，德性就充裕；“修之鄉，其德乃長”——在乡里修养，德性就增长；“修之邦，其德乃豐”——在国家修养，德性就丰盛；“修之天下，其德乃溥”——在天下修养，德性就普遍广大。

“以身觀身”——用自身来观察他人；“以家觀家”——用自己的家庭来观察他人家庭；“以鄉觀鄉”——用自己的乡里来观察他人乡里；“以邦觀邦”——用自己的邦国来观察他人邦国；“以天下觀天下”——用自己的天下观来观察天下的状态。

“吾何以知天下之然哉？以此”——我凭什么知道天下是这样的呢？就是凭这个（次第修证的方法）。

朱邦復先生在《止笑譚》中，将这一章解读为 **“修德的次第与以身观身的认知方法”** 。他认为“善建者不拔，善抱者不脱”是指“明理得道者”能够经得起时间的考验，其影响可泽及子孙。他特别强调“修之身→修之家→修之鄉→修之邦→修之天下”是一个从个人到全体的扩展过程——“由下而上，结构若健全，必然稳定”。而“以身观身，以家观家……”则是“见微知著”的方法——看自己就知道别人，看自己的家就知道天下。他最后以“吾何以知天下然哉？以此”收尾——我凭什么知道天下的情况呢？正是用这种方法。

但如果我们把主语换成“母亲的身体”——那个从自身开始、在家庭中扩展、最终影响整个生命世代的承载者——这一章就不再是“抽象的次第论”，而是一份 **“关于母亲如何在自身修养中让‘德’生长，并让它从自身扩展到家庭、延伸到下一代”的日常记录**：

- “善建者不拔”——母亲在孩子身上建立的“基础”——安全感、信任感、爱的能力——一旦建立就不会被拔除。无论他走到哪里，那个“基础”都在。
- “善抱者不脱”——母亲抱着孩子的方式——不是“抓紧”，是“抱持”。好的“抱”不是“执”——是“托”。“不脱”是孩子不会从她的“抱”中脱落。她抱着他，他不会掉下去。那不是“抓得紧”——是“托得稳”。
- “子孙以祭祀不绝”——母亲的影响不是“在她在的时候”——是“在她不在的时候”仍然继续。她传承的东西——不会因为她的离开而中断。那不是“基因”——是“呼吸”。她怎么爱、怎么回应、怎么承载——那些会继续。
- “修之身，其德乃真”——母亲先从自身开始。她的“德”不是“表现”给谁看的——是“真实”的。她在自己身上修——喂养时的耐心、深夜醒来的坚持、允许自己疲惫的真实。那些是“真”。
- “修之家，其德有餘”——她的德从自己“余”到家庭里。她的“德”不是“用完就没了”的——是“有余”的。她给了孩子，自己还有；她给了家庭，自己还有。那是“有余”。
- “修之鄉”——然后扩展到更大的圈子。她的影响不止于家庭——她对待邻居的方式、她对待其他孩子的方式——那是“长”（增长）。
- “修之邦”——继续扩展。她的存在方式影响更多的人。那是“丰”。
- “修之天下”——最终，她的德“溥”（普遍）。不是因为她“做了很大的事”——是因为她对待生命的方式，成为了一种普遍的“常道”。
- “以身觀身”——母亲通过自己的身体经验来理解他人的身体经验。她经历过分娩的痛——她能理解另一个母亲的痛。她经历过产后抑郁——她能看见另一个母亲的沉默。那是“以身观身”。
- “以家觀家”——母亲通过自己的家庭来理解他人的家庭。她知道“这个家是怎么运作的”——她能看见另一个家庭的节奏、张力、爱的方式。那是“以家观家”。
- “吾何以知天下之然哉？以此”——母亲为什么能理解世界？不是因为她“走遍了世界”——是因为她从自己的身体出发、从自己的家庭出发，去理解一切。那是“以此”——从“身”开始。


## 一、“善建者不拔”——善于建造的，不会被动摇

### 朱邦復的解读：真正好的建造经得起时间考验

朱先生将“善建者不拔”解读为“善于建造的人所建之物不会轻易坍塌”：

> “善建之人，其所建之物，不會輕易坍塌。”

好的建造不是“看起来坚固”——是“经得起时间”。“不拔”是“不会被拔除”——不是因为没有人“拔”它——是因为它扎得足够深。

### 从母亲经验的解读：母亲在孩子身上建立的“安全感”一旦建立，就不会被拔除

“善建者不拔”——在母亲的身体里，“建”和“不拔”是什么？

- **她在孩子身上建立的“基础”——安全感。** 她在他还不会说话的时候就已经在“建”了。每一次回应、每一次拥抱、每一次“妈妈在”——都是在打地基。那个基础不是“可见的”——但它真实存在。一旦建立，就不会被动摇。无论他走到哪里、遇到什么——那个“有人在”的感觉都在。
- **“不拔”的另一种理解：** 她建的“信任”不会被拔除。即使她偶尔犯错、即使她不是完美的——那个“信任”不会因为一次失误就被连根拔起。她建得足够深。
- **“善建者不拔”的深层含义：** 不是建“高”就厉害——是建得深才不会被拔。母亲建的“基础”——在看不见的地方——但即使狂风来了，它也不会被拔。

朱先生说“善建者不拔”是好的建造经得起时间考验。母亲的身体告诉我们：**她在孩子身上建立的“安全感”、“信任感”——一旦建立，就不会被拔除。她建得深，不是建得高。**

| 朱邦復的“善建者不拔” | 母亲经验的“善建者不拔” |
| :--- | :--- |
| 好的建造经得起时间考验 | 她建在孩子身上的“安全感”——一旦建立，就不会被拔除 |
| 第三人称：建造的稳固性 | 第一人称：我建的不是“高”——是“深” |


## 二、“善抱者不脫”——善于抱持的，不会脱落

### 朱邦復的解读：好的抱持不会脱落

朱先生将“善抱者不脱”解读为“善于抱持的人很难挣脱其怀”：

> “善抱之人，很難掙脫其懷。”

“抱”不是“抓”——是“包容”。“不脱”不是“抓紧了不放手”——是“环住了不掉”。好的“抱”是托住的，不是箍住的。

### 从母亲经验的解读：母亲抱着孩子的方式——不是“抓得紧”，是“托得稳”

“善抱者不脫”——在母亲的身体里，“抱”和“不脱”是什么？

- **她抱着他——不是“抓”着他。** 她的手是“托”着的——不是“箍”着的。她不是用“力”抱住他——是用“身体”托住他。
- **“不脱”——他不会从她的“抱”里掉下去。** 不是因为“她抓得紧”——是因为“她托得稳”。她把他的重量分到自己的手臂、肩膀、胸口——他不会滑落。那是“善抱”。
- **“善抱”的深层含义：** 不是“抓紧不放”是“善抱”——是“托住而不掉落”才是“善抱”。母亲“抱”孩子——她不是“占有”他，而是“承载”他。她抱着他，他不会掉——但他可以随时离开（当他能自己走路的时候）。那就是“抱而不脱”——不是“执而不放”。

朱先生说“善抱者不脱”是好的抱持不会脱落。母亲的身体告诉我们：**她抱着他——不是“抓”着他，是“托”着他。“不脱”不是“抓紧”——是“托稳”。**

| 朱邦復的“善抱者不脱” | 母亲经验的“善抱者不脫” |
| :--- | :--- |
| 好的抱持不会脱落 | 她抱着他——不是“抓”着，是“托”着。不脱=托得稳 |
| 第三人称：抱持的稳固性 | 第一人称：我不是“抓紧”他——我是“托住”他 |


## 三、“子孫以祭祀不絕”——子孙因此祭祀不绝

### 朱邦復的解读：泽及子孙，世代延续

朱先生将“子孙以祭祀不辍”解读为“子孙因此得以永享祭祀”：

> “明理得道者，不僅自己得益，且可澤及子孫，永享祭祀。”

“祭祀”是后人对前人的纪念和连接。“不绝”是不会中断。真正的“建”和“抱”——会让影响延续到后代。

### 从母亲经验的解读：她传承的东西——不是因为“她在”才继续——是“她不在了”也会继续

“子孫以祭祀不絕”——在母亲的身体里，“祭祀不绝”是什么？

- **她不在的时候——她的影响还在。** 她怎么爱、怎么回应、怎么承载——那些东西不会因为她不在就停止。她的孩子会带着它们继续活。那是“祭祀不绝”——不是“烧香”的祭祀——是“活在生命里”的祭祀。
- **“不绝”的另一种理解：** 她的“抱”不会因为她的离开而“脱”。她托住他的方式——他会用同样的方式去托住他的孩子。那是“不绝”——一种接力的延续。

朱先生说“子孙以祭祀不绝”是泽及子孙世代延续。母亲的身体告诉我们：**她不在的时候——她的影响还在。她的“抱”不会因为她的离开而“脱”——那是“不绝”。**

| 朱邦復的“子孙以祭祀不绝” | 母亲经验的“子孫以祭祀不絕” |
| :--- | :--- |
| 泽及子孙世代延续 | 她不在的时候——她的影响还在。她的“抱”不会因为离开而“脱” |
| 第三人称：世代的延续 | 第一人称：我会“不在”——但我给的“不会不在” |


## 四、“修之身，其德乃真”——在自身修养，德就真实

### 朱邦復的解读：德性的第一步——自身

朱先生将“修之于身，其德乃真”解读为“在自身修养，德性就真实”：

> “對個人而言，明理可使德性充實。”

“修”是从“身”开始的——不是先“修天下”。德性的第一个“道场”是自己的身。在身修，德就“真”（不是表演、不是理论——是真实的）。

### 从母亲经验的解读：母亲先从自身开始——她的“德”不是表演给谁看的，是真实的

“修之身”——在母亲的身体里，“修身”是什么？

- **她不是先“修天下”的。** 她先“修”她自己——她的身体、她的感受、她的边界。如果她不先在自己身上“修”——她的“德”就是“表演”而不是“真实”。
- **“其德乃真”的另一种理解：** 她在自己身上修的“德”——是真实的。不是“别人说她是好妈妈”才是——是她自己知道“我在”。她在自身修的那个——是“真”。

朱先生说“修之于身其德乃真”是在自身修养德就真实。母亲的身体告诉我们：**她从自己开始——她的“德”不是表演给谁看的，是真实的。在自身修的，才是“真”。**

| 朱邦復的“修之于身其德乃真” | 母亲经验的“修之身其德乃真” |
| :--- | :--- |
| 在自身修养德就真实 | 她从自己开始——她的“德”不是表演，是真实的 |
| 第三人称：次第的开始 | 第一人称：我先修自己——然后才能“真” |


## 五、“修之家，其德有餘”——在家庭修养，德就有余

### 朱邦復的解读：德性在家庭中扩展

朱先生将“修之于家，其德乃余”解读为“在家族修养，德就充裕”：

> “如擴充至家族，嘉惠更多。”

德从“身”扩展到“家”——家里的人开始感受到她的“德”。那不是“用完了”的——是“有余”的。她给了，还有。

### 从母亲经验的解读：她的德从自己“余”到家庭——她给了孩子，自己还有

“修之家”——在母亲的身体里，“修家”是什么？

- **她的德“流”出去了。** 她不只是“自己修”——她的存在方式影响了家里的其他人。孩子感受到她的耐心、伴侣感受到她的承载、家庭感受到她的稳定。那不是“她用完了”——是“有余”。
- **“有余”的另一种理解：** 她不是“把所有的爱都给了孩子然后自己没了”——她是“给了，但自己还有”。她孩子的安全感不是“从她那里拿走的”——是从她那里“溢”出来的。那才是“有余”。

朱先生说“修之于家其德乃余”是在家族修养德就充裕。母亲的身体告诉我们：**她的德不是“用完了”——是“有余”。她给了孩子——自己还有。**

| 朱邦復的“修之于家其德乃余” | 母亲经验的“修之家其德有餘” |
| :--- | :--- |
| 在家族修养德就充裕 | 她的德不是“用完了”——是“有余”。她给了，自己还有 |
| 第三人称：次第的扩展 | 第一人称：我给了——“溢”出来的，不是“耗”掉的 |


## 六、“修之鄉，其德乃長”——在乡里修养，德就增长

### 朱邦復的解读：德性在乡里中增长

朱先生将“修之于乡，其德乃长”解读为“在乡里修养德性就能流传长久”：

> “推廣至鄉里，德性能傳之長久。”

德从家扩展到乡里——它的影响力开始“长”（增长、延展）。

### 从母亲经验的解读：她的德不止于家庭——她对待邻居、其他孩子的方式——那些是“长”

“修之鄉”——在母亲的身体里，“修乡”是什么？

- **她的德“长”了。** 她不只是在家庭里——她对待邻居的方式、她对待其他孩子的方式、她在社区中的存在——那些是她的德在“长”。
- **“长”的另一种理解：** 她的德不是“只在家庭里”的——它会延伸出去。“长”是“生长”——不是“停止”的。她的影响开始覆盖更广的范围。

朱先生说“修之于乡其德乃长”是在乡里修养德性就能流传长久。母亲的身体告诉我们：**她的德不止于家庭——她对待邻居、其他孩子的方式——那是“长”。**

| :--- | :--- |
| 在乡里修养德性就能流传长久 | 她的德不止于家庭——她对待邻居、其他孩子的方式——那是“长” |
| 第三人称：次第的延展 | 第一人称：我的德从家“长”出去了 |


## 七、“修之邦，其德乃豐”——在国家修养，德就丰盛

### 朱邦復的解读：德性在国家中丰盛

朱先生将“修之于邦，其德乃丰”解读为“在国家修养德性就丰盛”：

> “推廣至一個國家，影響更為強大。”

德从乡里扩展到邦国——它的影响力“丰”（丰盛、扩大）。

### 从母亲经验的解读：她的存在方式影响更多的人——那是“丰”

“修之邦”——在母亲的身体里，“修邦”是什么？

- **她的德“丰”了。** 她的存在方式不只是影响到她的家庭和邻里——它影响到更多的人。可能是她工作的环境、她参与的社区、她所在的更广的社会圈子。
- **“丰”的另一种理解：** 她的德不是“只属于她的”——它“丰”了，成为了一种可以被更多人感受到的“常道”。她对待生命的方式——成为了别人可以参照的“丰”。

朱先生说“修之于邦其德乃丰”是在国家修养德性就丰盛。母亲的身体告诉我们：**她的存在方式影响更多的人——那是“丰”。**

| 朱邦復的“修之于邦其德乃丰” | 母亲经验的“修之邦其德乃豐” |
| :--- | :--- |
| 在国家修养德性就丰盛 | 她的存在方式影响更多的人——那是“丰” |
| 第三人称：次第的壮大 | 第一人称：我的“德”变“丰”了——不是因为“大”，是因为“多” |


## 八、“修之天下，其德乃溥”——在天下修养，德就普遍

### 朱邦復的解读：德性在天下中普遍

朱先生将“修之于天下，其德乃普”解读为“在天下修养德性就普遍周全”：

> “推廣至天下，使人人都能修德，則道德必然普及周全。”

德从邦扩展到天下——它的影响力“溥”（普遍）。

### 从母亲经验的解读：最终，她的德“溥”——她对待生命的方式，成为了一种普遍的“常道”

“修之天下”——在母亲的身体里，“修天下”是什么？

- **她的德“溥”了。** 不是因为她“做了很大的事”——是因为她对待生命的方式，成为了一种“常道”。她的爱、她的耐心、她的承载——成为了一种可以被所有人理解的“普遍状态”。那不是因为她“有名”——是因为她“在”。
- **“溥”的另一种理解：** “溥”是普遍——不是“覆盖一切”——是“可以被一切感受到”。她的德不再是“她的”了——它成为了“普遍的”。就像母亲的爱——它不属于某一个母亲——它是“普遍的”。那就是“溥”。

朱先生说“修之于天下其德乃普”是在天下修养德性就普遍周全。母亲的身体告诉我们：**她对待生命的方式——成为了一种普遍的“常道”。那就是“溥”。**

| 朱邦復的“修之于天下其德乃普” | 母亲经验的“修之天下其德乃溥” |
| :--- | :--- |
| 在天下修养德性就普遍周全 | 她对待生命的方式——成为了一种普遍的“常道” |
| 第三人称：次第的普遍化 | 第一人称：我的“德”变成了“普遍的”——不只是我的了 |


## 九、“以身觀身”——用自身观察他人

### 朱邦復的解读：由己及人

朱先生将“以身观身”解读为“以自己的身体经验理解他人”：

> “以推己及人之方法，由自己到他人。”

你不需要“研究”别人才能理解别人——你通过观察“自己”就能理解“他人”。因为人的基本经验是相通的。

### 从母亲经验的解读：她经历过分娩的痛——她能理解另一个母亲的痛。那是“以身观身”

“以身觀身”——在母亲的身体里，“以身观身”是什么？

- **她经历过——她能理解。** 她经历过分娩的痛——她能理解另一个母亲在产床上的挣扎。她不需要“问”她——“她知道”。那是“以身观身”——用自己的身体经验来理解他人的身体经验。
- **她经历过产后抑郁的沉默——她能看见另一个母亲的沉默。** 她不用别人告诉她“我不好”——她看见了。因为她经历过。那是“以身观身”。
- **“以身观身”的深层含义：** 她的身体是一个“参照系”。她用自己的身体经历来理解另一个人的身体经历。那不是“同情”——是“同在”。她知道——因为她也在过。

朱先生说“以身观身”是用自己的身体经验理解他人。母亲的身体告诉我们：**她经历过分娩的痛——她能理解另一个母亲。她知道——因为她也在过。**

| 朱邦復的“以身观身” | 母亲经验的“以身觀身” |
| :--- | :--- |
| 用自己的经验理解他人 | 她经历过分娩的痛——她能理解另一个母亲。她知道，因为她也在过 |
| 第三人称：推己及人的方法 | 第一人称：我经历过了——所以我能“看见”你 |


## 十、“以家觀家”——用自己的家庭观察他人家庭

### 朱邦復的解读：由己家及人家

朱先生将“以家观家”解读为“用自己的家庭观察他人的家庭”：

> “由自己到他人、自家到人家。”

你知道你的家是怎么运作的——你就知道别人的家是怎么运作的。模式是相通的。

### 从母亲经验的解读：她知道自己的家是怎么运作的——她能看见另一个家的节奏、张力、爱的方式

“以家觀家”——在母亲的身体里，“以家观家”是什么？

- **她知道自己的家——“呼吸”是什么样的。** 她知道什么时候是安静的、什么时候是喧闹的、什么时候需要“收”什么时候需要“放”。她能感受到一个家庭的“呼吸”——因为她知道自己的家是怎么呼吸的。
- **她能看见另一个家的节奏。** 她不需要“研究”那个家——她“感受”到了。因为家庭的“节奏”是相通的。紧张、松弛、爱的方式、沉默的方式——她知道。因为她有自己的家作为参照。

朱先生说“以家观家”是用自己的家庭观察他人家庭。母亲的身体告诉我们：**她知道自己的家是怎么运作的——她能看见另一个家的节奏、张力、爱的方式。因为模式是相通的。**

| 朱邦復的“以家观家” | 母亲经验的“以家觀家” |
| :--- | :--- |
| 用自己的家庭观察他人的家庭 | 她知道自己的家是怎么运作的——她能看见另一个家的节奏、张力 |
| 第三人称：家的参照 | 第一人称：我知道家的“呼吸”——所以我能看见你们的 |


## 十一、“吾何以知天下之然哉？以此”——我为什么知道天下是这样的？凭这个

### 朱邦復的解读：认知的根据

朱先生将“吾何以知天下然哉？以此”解读为“我凭这个（以身观身、以家观家）来认知天下”：

> “我憑什麼知道天下的情況呢，正是以這種方法。”

从“身”出发，一层层扩展——到“天下”。他用的是“以此”——从自身开始的那个方法。

### 从母亲经验的解读：母亲为什么能理解世界？不是因为她走遍了世界——是从她自己开始

“吾何以知天下之然哉？以此”——在母亲的身体里，“以此”是什么？

- **她为什么能理解世界？——从她自己开始。** 她不是“走遍天下”才知道天下的——她是“从自己的身体、自己的家庭”开始，然后一层层扩展。她理解世界的方式——不是“向外”的——是“从内向外”的。
- **“以此”的深层含义：** “以此”就是“从身开始”。她先在自己身上修——然后扩展到家、到乡、到邦、到天下。她不需要“走遍天下”才知道天下——“身”就是她的起点。

朱先生说“吾何以知天下然哉以此”是凭这个方法认知天下。母亲的身体告诉我们：**她理解世界的方式——不是走遍天下——是从自己开始的。她“以此”——从身开始。**

| 朱邦復的“吾何以知天下然哉以此” | 母亲经验的“吾何以知天下之然哉以此” |
| :--- | :--- |
| 凭这个方法认知天下 | 她理解世界不是走遍天下——是从自己开始的。她“以此”——从身开始 |
| 第三人称：认知的根据 | 第一人称：我不是“走”出去的——我是“从身”开始的 |


## 结语：从“身”开始的天下

朱邦復先生在这一章中，用“次第扩展”和“以身观身”的框架，解读了“善建不拔、善抱不脱、子孙祭祀不绝”的根基性，以及“修身→修家→修乡→修邦→修天下”的次第扩展——“由下而上，结构若健全，必然稳定”。最后以“以身观身……以天下观天下”作结——通过观察自己来观察他人，通过观察自己的家来观察天下。他问：“吾何以知天下之然哉？以此。”

而母亲的身体，是这一章最完整的“修身→修家→修天下”的演绎者：

- **“善建者不拔”——她在孩子身上建立的“安全感”——一旦建立，就不会被拔除。**
- **“善抱者不脱”——她抱着他——不是“抓”着，是“托”着。不脱=托得稳。**
- **“子孙以祭祀不绝”——她不在的时候——她的影响还在。她的“抱”不会因为离开而“脱”。**
- **“修之身，其德乃真”——她从自己开始——她的“德”不是表演，是真实的。**
- **“修之家，其德有余”——她的德不是“用完了”——是“有余”。她给了，自己还有。**
- **“修之乡，其德乃长”——她的德不止于家庭——她对待邻居的方式——那是“长”。**
- **“修之邦，其德乃丰”——她的存在方式影响更多的人——那是“丰”。**
- **“修之天下，其德乃溥”——她对待生命的方式——成为了一种普遍的“常道”。**
- **“以身观身”——她经历过分娩的痛——她能理解另一个母亲。她知道，因为她也在过。**
- **“以家观家”——她知道自己的家是怎么运作的——她能看见另一个家的节奏、张力。**
- **“吾何以知天下之然哉？以此”——她理解世界的方式——不是走遍天下——是从自己开始的。**

**“善建者不拔”——母亲建的“基础”，不在表面。它不会被拔除——因为它是从身体深处建起来的。她建的不是“高”——是“深”。**

**“善抱者不脱”——母亲的“抱”不是“箍”——是“托”。她不是用“力量”抱住他——是用“身体”托住他。他不会掉——因为她的“托”稳。那是“不脱”。**

**“子孙以祭祀不绝”——她不在的时候，她的影响还在。她的“建”、她的“抱”——不是因为“她在”才有效——是即使“她不在了”也仍然有效。**

**“修之身”——从“身”开始。母亲不是“修天下”的——她是先“修”自己的。她的“德”不是“表演”——是“真实”。从自身开始的德，不需要证明。**

**“以身观身”——母亲通过自己的身体经验来理解他人的身体经验。她不需要“问”才能知道——她“在”过就知道。那是“以此”——从“身”开始的认知方式。**

一个母亲的一生，就是“善建善抱、从身到天下”的日常版本。她建的是“深”不是“高”；她抱的是“托”不是“抓”；她的影响不因她的离开而中断——那是“祭祀不绝”。她从自己开始——然后扩展到家庭、到更广的世界。她理解世界的方式——不是走遍天下——是从自己的“身”开始的。她知道——因为她“在”过。



## 引言：最“悖论”的一章，最“身体”的日常

帛书本第四十五章，是《德道经》中关于“大成若缺、大盈若冲”等“正言若反”的集中论述：

> 大成若缺，其用不幣（敝）。大盈若𥁵（沖），其用不𡩫（宭）。
>
> 大直如詘（屈），大巧如拙，大贏如㶧。
>
> 趮（躁）勝寒，靚（靜）勝炅（熱）。請（清）靚（靜），可以為天下正。

“大成若缺”——最圆满的看起来好像有欠缺，但它的作用不会衰竭。“大盈若冲”——最充盈的看起来好像空虚，但它的作用不会穷尽。“大直如屈”——最直的看起来好像弯曲。“大巧如拙”——最巧的看起来好像笨拙。“大赢如㶧”——最多的赢取看起来好像亏损。

“躁胜寒”——躁动能战胜寒冷。“静胜热”——安静能战胜炎热。“清净”——清静的状态，“可以为天下正”——可以作为天下的准则。

朱邦復先生在《止笑譚》中，将这一章解读为 **“认知阈值与动静辩证”** 。他认为“大成若缺”是因为人的经验值越高，越难感到满足——最圆满的东西反而看起来“缺”，因为你的“感觉阀”已经提高了。“大盈若冲”是“满而不溢”的状态——看起来空的，反而用不完。他特别强调了“躁胜寒，静胜热”——躁动产生热能，但真正的根本是“静”；静能制动、寒能胜热。最后落脚在“清静为天下正”——清静是天下真正的根本。

但如果我们把主语换成“母亲的身体”——那个在产后经历了“大成若缺”（孕育了生命但身体有缺）、“大盈若冲”（乳汁充盈但乳房是空的容器）、“大直如屈”（为了抱孩子而弯曲的脊柱）、“大巧如拙”（笨拙地学习当妈妈）的身体——这一章就不再是“抽象的悖论”，而是一份 **“关于产后身体的‘圆满以缺损为形态、充盈以虚空为形态’”的日常记录**：

- “大成若缺”——她完成了一件最大的事（孕育生命），但身体是“缺”的。腹部松弛、肌肉分离、疤痕——那是“缺”。但正是那个“缺”让她的身体继续运作。如果她追求“完整如初”——她反而会“敝”（耗竭）。接受“缺”——身体才能继续“用”。
- “大盈若冲”——她的乳房充盈乳汁，但它是“冲”的（虚空）。乳房不是“装满”的容器——它是“排空”的容器。越排空，越能充盈。如果它一直“满”着——反而会堵、会痛、会“宭”（穷尽）。虚空才能持续地“盈”。
- “大直如屈”——她的脊柱为了抱孩子而“屈”（弯曲）。直是“屈”的形状。没有“屈”，她就无法抱他。真正的“直”是以“屈”为姿态的。
- “大巧如拙”——她笨拙地学习当妈妈：第一次换尿布、第一次拍嗝、第一次哄睡——每一个动作都是“拙”的。但正是那个“拙”让她成为了母亲。真正的“巧”是以“拙”为起点的。
- “大赢如㶧”——她“赢”了什么？她赢得了孩子——但她的身体“㶧”（亏损）了。她的“赢”是以“亏损”为代价的。“赢”与“亏”是一体两面——不追求“只赢不亏”的完美，就能长久。


## 一、“大成若缺”——最圆满的看起来有欠缺

### 朱邦復的解读：认知阈值：越满越觉得缺

朱先生将“大成若缺”解读为“经验值越高，越难满足”：

> “最完美的事物，看起来彷彿有所不足，但使用时不会产生弊端。”

“大成”是真正的圆满——但它看起来“缺”。不是因为真的缺——是因为你的“感觉阀”提高了，你觉得“不够”。但它的“用”不会“敝”（衰竭）。

### 从身体经验出发：她完成了一件“大成”（孕育生命），但身体是“缺”的——松弛、损伤、疤痕

“大成若缺”——在母亲的身体里，“大成”和“缺”是什么？

- **“大成”——她孕育了一个完整的生命。** 那是她身体做过的最大、最完整的事。没有比“让一个生命从无到有”更大的“成”了。
- **“缺”——她的身体是“缺”的。** 腹部松弛、腹直肌分离、剖腹产疤痕、盆底肌损伤。她的身体不再“完整”——它是“缺”的。
- **“其用不敝”——正因为有“缺”，身体才能继续运作。** 如果她执着于“回到产前”——她的“用”反而会“敝”（耗竭）。接受“缺”——身体才能继续“用”。那个“缺”不是失败——是“大成”的形态。

朱先生说“大成若缺”是真正的圆满看起来有欠缺。母亲的身体告诉我们：**她完成了一件“大成”（孕育生命），但身体是“缺”的。那个“缺”不是失败——是“大成”的形态。接受“缺”——身体才能继续“用”。**

| 朱邦復的“大成若缺” | 母亲经验的“大成若缺” |
| :--- | :--- |
| 认知阈值：越满越觉得缺 | 她完成了“大成”（孕育生命），但身体是“缺”的——接受“缺”才能继续“用” |
| 第三人称：经验的认知 | 第一人称：我“成”了，但我也“缺”了——那就是“大成”的形状 |


## 二、“大盈若沖”——最充盈的看起来像空虚

### 朱邦復的解读：满而不溢，虚而能容

朱先生将“大盈若冲”解读为“看起来空的，用起来却无穷”：

> “最充實的東西，看起來彷彿是空的，但使用時不致匱乏。”

“冲”是虚空、空虚。真正的“盈”不是“满”的形态——是“冲”的形态。虚空才能容纳、才能持续。

### 从身体经验出发：乳房充盈乳汁，但它是“冲”的——排空才能再充盈

“大盈若沖”——在母亲的身体里，“盈”和“冲”是什么？

- **“盈”——乳汁充盈。** 她的乳房充满了乳汁——那是“盈”。她为另一个生命提供了全部营养。
- **“冲”——虚空才能再充盈。** 乳房的“盈”不是“装满”的状态——是“排空”的周期。孩子吮吸后，乳房“冲”（空了），然后身体再分泌、再“盈”。如果乳房一直“满”着——反而会堵、会痛、会“穷尽”。虚空才能持续地“盈”。
- **“其用不宭”——正因为“冲”，才能持续“用”。** “冲”是“盈”能持续的前提。不接受“冲”（排空），就无法“盈”（再充盈）。

朱先生说“大盈若冲”是看起来空的用起来却无穷。母亲的身体告诉我们：**她的乳房“盈”满乳汁，但它是“冲”的——越排空，越能再充盈。“冲”是“盈”能持续的前提。**

| 朱邦復的“大盈若冲” | 母亲经验的“大盈若沖” |
| :--- | :--- |
| 看起来空，用起来无穷 | 乳房充盈乳汁——但它是“冲”的，排空才能再充盈 |
| 第三人称：虚实的辩证 | 第一人称：我的“盈”以“冲”为形态 |


## 三、“大直如屈”——最直的看起来像弯曲

### 朱邦復的解读：真正的直以屈为形态

朱先生将“大直若屈”解读为“表面屈曲，实际正直”：

> “真正正直的人，常會委曲求全。”

真正的“直”不是“硬”的——是“能屈”的。能屈才能直。

### 从身体经验出发：她的脊柱为了抱孩子而弯曲——那是“直”的形态

“大直如詘”——在母亲的身体里，“直”和“屈”是什么？

- **“屈”——她的脊柱是弯曲的。** 为了抱孩子、为了哺乳、为了弯腰牵他的手——她的身体长期处于“屈”的状态。
- **但那不是“不直”——是“直”的形态。** 没有“屈”，她就无法抱他。真正的“直”不是“僵硬”——是“能屈”。她的“屈”让她成为了“直”（能够承担）。
- **“屈”的深层含义：** 她不是“挺直”的——她是“弯曲”的。但那个弯曲让她能接住他。“直”在“屈”里。

朱先生说“大直若屈”是真正正直的人会委曲求全。母亲的身体告诉我们：**她的脊柱为了抱孩子而弯曲——那是“直”的形态。“屈”不是“不直”——是“直”的形状。**

| 朱邦復的“大直若屈” | 母亲经验的“大直如詘” |
| :--- | :--- |
| 真正正直的人会委曲求全 | 她的脊柱为了抱孩子而弯曲——那是“直”的形态 |
| 第三人称：直的辩证 | 第一人称：我“屈”了——但我因此能接住他 |


## 四、“大巧如拙”——最巧的看起来像笨拙

### 朱邦復的解读：真正的巧以拙为表

朱先生将“大巧若拙”解读为“表面平平无奇，实际精妙”：

> “技巧最精的人，表面看去平平無奇。”

真正的“巧”不张扬——它看起来像“拙”。

### 从身体经验出发：她笨拙地学习当妈妈——第一次换尿布、第一次拍嗝、第一次哄睡

“大巧如拙”——在母亲的身体里，“巧”和“拙”是什么？

- **“拙”——她第一次做那些事时笨手笨脚。** 第一次换尿布、第一次拍嗝、第一次哄睡——每一个动作都是“拙”的。不熟练、不确定、不“好看”。
- **但那不是“不巧”——那是“巧”的起点。** 那些“拙”的动作，慢慢变成了“熟练”。但真正的“巧”不是“好看”——是“有效”。孩子不哭、孩子睡了、孩子舒服了——那就是“巧”。“拙”是“巧”的入口。

朱先生说“大巧若拙”是表面平平无奇实际精妙。母亲的身体告诉我们：**她第一次换尿布时笨手笨脚——那是“拙”。但那些“拙”的动作慢慢成了“巧”。“拙”是“巧”的入口。**

| 朱邦復的“大巧若拙” | 母亲经验的“大巧如拙” |
| :--- | :--- |
| 表面平平无奇，实际精妙 | 第一次换尿布时笨手笨脚——“拙”，但那是“巧”的入口 |
| 第三人称：巧的辩证 | 第一人称：我“拙”地开始了——“巧”是从“拙”里长出来的 |


## 五、“大贏如㶧”——最大的赢取看起来像亏损

### 朱邦復的解读：真正的赢得以亏损为表

通行本无此句。“赢”是获得、胜利。“㶧”是亏损、不足。真正的“赢”看起来像“亏”——因为真正的获得不是“只赢不亏”的。

### 从身体经验出发：她“赢”得了孩子——但身体“亏损”了

“大贏如㶧”——在母亲的身体里，“赢”和“㶧”是什么？

- **“赢”——她赢得了孩子。** 他出生了、他健康了、他活着。那是她的“赢”。
- **“㶧”——她的身体“亏损”了。** 她失去了睡眠、失去了身体完整性、失去了产前的状态。那是“㶧”。
- **“赢”与“亏”是一体两面。** 她的“赢”以“亏”为代价。真正的“赢”不是“只赢不亏”——而是“赢得了一个生命，同时亏损了自己的一部分”。她能接受“亏”——才能“赢”。

朱先生说“大赢如㶧”是真正的赢得以亏损为表。母亲的身体告诉我们：**她“赢”得了孩子——但她的身体“亏损”了。她的“赢”以“亏”为代价。她接受了“亏”——才“赢”了。**

| 朱邦復的“大赢如㶧” | 母亲经验的“大贏如㶧” |
| :--- | :--- |
| 真正的赢得以亏损为表 | 她“赢”得了孩子——但身体“亏损”了。“赢”以“亏”为代价 |
| 第三人称：赢亏的辩证 | 第一人称：我“赢”了——但我也“亏”了。那就是“赢”的真实形状 |


## 六、“躁胜寒，静胜热”——躁动能胜寒，安静能胜热

### 朱邦復的解读：动静的交替与根本

朱先生将“躁胜寒，静胜热”解读为“动静交替，静为根本”：

> “行動工作，不可靜止；思考判斷，不可躁動。而思考為主，行動為輔，思考支配行動，故靜勝躁。”

躁动产生热——寒冷可以被运动克服。但真正的根本是“静”——静能制动、寒能胜热。“静”是天下真正的根本。

### 从母亲经验的解读：产后的“躁”和“静”——她在躁动中排汗，在静养中恢复

“躁勝寒，靜勝熱”——在母亲的身体里，“躁”和“静”是什么？

- **产后的“躁”——发热、出汗、激素波动。** 分娩后，身体经历剧烈的激素调整。她可能会发热、大量出汗、情绪起伏——那是“躁”。“躁”是身体在“动”——它帮助身体排出多余的热量，适应新的状态。
- **产后的“静”——静养、休息、恢复。** 身体需要“静”——静养、休息、不急着“动”。“静”不是“不动”——是“不躁”。她不急着“恢复”——她在“静”中等待身体自然恢复。
- **“躁胜寒”——分娩时身体因“躁”而热，帮助度过产后的寒冷期。**
- **“静胜热”——躁动之后，真正的恢复是“静”。** 静能制热——她需要“静”来让身体回到平衡。她不能一直“躁”——“躁”是暂时的工具，“静”是恢复的根本。

朱先生说“躁胜寒静胜热”是动静交替，静为根本。母亲的身体告诉我们：**产后她经历了“躁”（发热、出汗）——那是身体在调整。但真正的恢复在“静”——静养、休息、不急着“动”。“躁”是工具，“静”是根本。**


## 七、“清静，可以为天下正”——清静是天下之正

### 朱邦復的解读：清静是天下真正的准则

朱先生将“清静为天下正”解读为“清静是天下之本”：

> “靜及寒皆為能量低、動量小的原始狀況，是天下之本。”

清静是根本——不是“不动”，是“不躁”。它是天下真正的准则。

### 从母亲经验的解读：母亲的身体在“清静”中恢复——那是她身体的“正”

“請靜可以為天下正”——在母亲的身体里，“清静”和“正”是什么？

- **“清静”是身体的恢复状态。** 不发热、不出汗、不躁动——身体在“清静”中慢慢修复。“清静”不是“不动”——是“不躁”。她躺着、她休息、她给身体时间。
- **“正”是身体的正常秩序。** 当身体从“躁”（产后的激素波动、发热、排汗）回归“清静”——它就“正”了。不是“回到产前”——是“回到现在的正常状态”。
- **“清静”的另一种理解：** 她放下手机、关掉社交、不急着“恢复”——那是“清静”。在“清静”中，她的身体自己找到了“正”。

朱先生说“清静为天下正”是清静是天下根本。母亲的身体告诉我们：**她在“清静”中恢复——不急着“动”、不给身体施加压力。在“清静”中，身体自己回到了“正”。**


## 结语：“缺”、“冲”、“屈”、“拙”、“㶧”——母亲身体的正言若反

朱邦復先生在这一章中，用“认知阈值”和“动静辩证”解读了“大成若缺、大盈若冲……”等正言若反的表述。他认为这些“反”是认知的错觉和动静的规律——真正的圆满以“缺”为形态，真正的充盈以“冲”为形态。

而母亲的身体，是这一章最完整的“正言若反”的载体：

- **“大成若缺”——她完成了“大成”（孕育生命），但身体是“缺”的。接受“缺”才能继续“用”。**
- **“大盈若冲”——乳房充盈乳汁，但它是“冲”的——排空才能再充盈。**
- **“大直如屈”——她的脊柱为了抱孩子而弯曲——“屈”是“直”的形态。**
- **“大巧如拙”——她笨拙地学习当妈妈——“拙”是“巧”的入口。**
- **“大赢如㶧”——她“赢”得了孩子，但身体“亏损”了——“赢”以“亏”为代价。**
- **“躁胜寒”——产后的“躁”（发热、出汗）帮助度过激素调整期。**
- **“静胜热”——真正的恢复在“静”——静养、休息、不急着“动”。**
- **“清静为天下正”——她在“清静”中恢复——那是她身体的“正”。**

**“大成若缺”——你不是“完整如初”才是“成”。你“缺”了——但那正是你“成”的形状。接受“缺”，身体才能继续“用”。**

**“大盈若冲”——你不是“装满”才是“盈”。你“冲”了——但那正是你“盈”能持续的前提。接受“冲”，才能持续“盈”。**

**“大直如屈”——你不是“挺直”才是“直”。你“屈”了——但那正是你“直”的形态。接受“屈”，才能接住他。**

**“大巧如拙”——你不是“熟练”才是“巧”。你“拙”了——但那正是你“巧”的入口。接受“拙”，才能慢慢成为。**

**“大赢如㶧”——你不是“只赢不亏”才是“赢”。你“亏”了——但那正是你“赢”的真实形状。接受“亏”，才能真正“赢”。**

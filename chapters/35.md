

## 引言：最“自白”的一章，最“无声”的知

帛书本第七十一章（通行本第七十章），是《德道经》中老子对自己话语不被人理解的叹息：

> 吾言甚易知也，甚易行也；而人莫之能知也，而莫之能行也。
>
> 言有君，事有宗。夫唯无知也，是以不我知。
>
> 知我者希，則我貴矣。是以聖人被褐而褱（懷）玉。

“吾言甚易知也，甚易行也”——我说的话很容易理解，很容易实行。“而人莫之能知也，而莫之能行也”——但人们却不能理解，也不能实行。

“言有君，事有宗”——我说话有主旨，行事有根据。“夫唯无知也，是以不我知”——正是因为人们无知，所以不能了解我。“知我者希，则我贵矣”——了解我的人很少，那么了解我的人就显得珍贵了。

“是以聖人被褐而怀玉”——所以圣人穿着粗布衣服，怀里却揣着美玉。

朱邦復先生在《止笑譚》中，将这一章解读为 **“真知易行而人不行的认知悖论”**。他认为真理本来容易理解和实行，但人们把事情弄复杂了，在长时间的积非成是下很难相信有易知易行的真理。他特别强调了“言有宗，事有君”——老子的话都有根据、行事都有所本，这“宗”和“君”就是自然。他最后以“知我者希，则我者贵”和“被褐怀玉”作结——真正的知者少，所以奉行的人更珍贵；真知者只能守朴藏真，像穿着粗布衣服怀里却藏着美玉一样。

但如果我们把主语换成“母亲的身体”——那个说出“最简单的真理”却很少有人听、穿着“粗布衣服”（素颜、奶渍、疲惫）怀里却“怀玉”（抱着最珍贵的生命）的身体——这一章就不再是“知识论的叹息”，而是一份 **“关于母亲如何以‘被褐怀玉’的方式存在于世”的日常记录**：

- “吾言甚易知也，甚易行也”——母亲说的话其实很简单：“该睡了”、“吃饭了”、“妈妈在”。这些道理很容易理解、很容易做到。但人们不听。
- “人莫之能知也，莫之能行也”——但外人觉得她“没什么了不起”、觉得她“不就是在家带孩子吗”。他们不能理解她做的事，更不能“行”她做的事。
- “言有君，事有宗”——母亲的话不是随便说的——“该睡了”来自规律，“吃饭了”来自需要，“妈妈在”来自爱。她做的事都有根据——喂奶、哄睡、陪伴——都有它的道理。不是“乱来”的。
- “夫唯无知也，是以不我知”——正是因为她做的事太“简单”了——不复杂、不炫目、不被看见——所以人们“不知”她。不是因为“她没做”——是因为“人们看不见简单的价值”。
- “知我者希，则我贵矣”——真正理解母亲的人很少——但正因为少，所以那些人更珍贵。不是“孤独”的抱怨——是“珍视”的确认。
- “被褐而怀玉”——母亲穿着粗布衣服（素颜、奶渍、疲惫），怀里却“怀玉”（抱着最珍贵的生命）。她看起来“不起眼”——但她怀里的，是她生命的全部。


## 一、“吾言甚易知也，甚易行也”——我的话很容易理解，很容易实行

### 朱邦復的解读：真理简单易行

朱先生将“吾言甚易知，甚易行”解读为“真理容易理解，容易做到”：

> “我所說的話很容易瞭解，也很容易做到。”

真理本身是简单的——不是“复杂”的。老子的话不玄奥——只是人们把它想复杂了。

### 从母亲身体的经验出发：母亲的话确实简单：“该睡了”、“吃饭了”、“妈妈在”——但人们不听

“吾言甚易知也”——在母亲的身体里，“易知”的话是什么？

- **她说“该睡了”——那是真理。** 孩子需要睡眠，她说该睡了。道理简单——但人们不执行。他们让他继续玩。
- **她说“吃饭了”——那是真理。** 孩子需要进食，她说吃饭了。道理简单——但人们不配合。他们追着喂、哄着吃。
- **她说“妈妈在”——那是真理。** 孩子需要安全感，她说妈妈在。道理简单——但人们不觉得“在”有什么了不起。
- **“易知易行”的深层含义：** 母亲说的话都简单——不是“高深”的理论，是“日常”的真理。但正是因为太简单——人们不觉得那是“知识”，所以不行。

朱先生说“吾言甚易知甚易行”是真理简单易行。母亲的身体告诉我们：**她说“该睡了”——简单，但人们不听。她说“妈妈在”——简单，但人们不觉得那有什么。**

| 朱邦復的“吾言甚易知甚易行” | 母亲经验的“吾言甚易知也甚易行也” |
| :--- | :--- |
| 真理简单易行 | 她说“该睡了”、“妈妈在”——简单，但人们不听、不觉得那是“知识” |
| 第三人称：真理的简易 | 第一人称：我说的是日常真理——但太简单了，没人当回事 |


## 二、“人莫之能知也，莫之能行也”——人们不能理解，也不能实行

### 朱邦復的解读：知易行难是常态

朱先生将“天下莫能知，莫能行”解读为“人们不能了解，无法做到”：

> “天下人卻不能瞭解，更無法做到。”

不是因为“难”——是因为“人们把事情弄复杂了”。真理太简单了，简单到人们不信。

### 从母亲身体的经验出发：外人觉得她“没什么了不起”，觉得她“不就是在家带孩子吗”

“人莫之能知也”——在母亲的身体里，“莫能知”是什么？

- **外人觉得她“没什么了不起”。** “不就是在家带孩子吗”——那是“莫能知”。他们看不见她做了多少、她付出多少、她承受多少。因为那些事不“显示”。
- **外人不能“行”她的事。** 他们不知道凌晨三点醒来是什么感觉、不知道连续哄睡两小时是什么感觉、不知道身体被掏空还在继续是什么感觉。他们“莫能行”——因为没经历过。
- **“莫能知莫能行”的深层含义：** 不是她“不值得被知”——是“人们看不见简单的价值”。她的工作不复杂、不炫目、不被“知识”体系承认——所以人们不知、不行。

朱先生说“天下莫能知莫能行”是无人能知能行。母亲的身体告诉我们：**外人觉得她“没什么”——那是“莫能知”。他们不能“行”——因为没经历过凌晨三点。**

| 朱邦復的“天下莫能知莫能行” | 母亲经验的“莫之能知莫之能行” |
| :--- | :--- |
| 无人能知能行 | 外人觉得她“没什么”——不知；不能“行”——没经历过 |
| 第三人称：知行的缺失 | 第一人称：他们看不见——因为他们没经历过 |


## 三、“言有君，事有宗”——说话有主旨，行事有根据

### 朱邦復的解读：言谈有据，行事有本

朱先生将“言有宗，事有君”解读为“言谈有根据，行事有根本”：

> “我的言論都有根據，行事都有所本。這‘宗’、‘君’皆自然也。”

“宗”是本源，“君”是主宰。老子的话不是“乱说”的——来自“自然”，来自“道”。

### 从母亲身体的经验出发：她的话不是随便说的——“该睡了”来自规律，“吃饭了”来自需要，“妈妈在”来自爱

“言有君，事有宗”——在母亲的身体里，“君”和“宗”是什么？

- **她说“该睡了”——不是乱说的。** “君”是孩子身体的规律——到了该睡的时候，身体会发出信号。她只是在响应那个“君”。
- **她说“吃饭了”——不是乱说的。** “宗”是孩子身体的需要——饿了就要吃。她只是在响应那个“宗”。
- **她说“妈妈在”——不是乱说的。** “君”和“宗”是爱的本源——她在，就是回应。她的话都有根据——不是“随便说说”的。
- **“言有君事有宗”的深层含义：** 母亲说的话不复杂——但都有根据。外人不觉得“该睡了”有什么“君”——但他们不知道，那是回应自然节律的话。

朱先生说“言有宗事有君”是言谈有据、行事有本。母亲的身体告诉我们：**她说“该睡了”——那是回应身体的规律。不是“乱说”的——是有“君”的。**

| 朱邦復的“言有宗事有君” | 母亲经验的“言有君事有宗” |
| :--- | :--- |
| 言谈有据、行事有本 | 她说“该睡了”——那是回应身体规律，不是乱说的 |
| 第三人称：言行的根据 | 第一人称：我说话有根据——那是回应“他需要” |


## 四、“夫唯无知也，是以不我知”——正因为人们无知，所以不了解我

### 朱邦復的解读：无知是隔阂的原因

朱先生将“夫唯无知，是以不我知”解读为“人们无知，所以不了解我”：

> “他人不瞭解我，實是無知的緣故。”

不是因为她“不值得被知”——是因为“知”的渠道被堵塞了。人们用“复杂”来理解“简单”——所以“无知”。

### 从母亲身体的经验出发：不是她“不值得被知”——是因为人们看不见“简单”的价值

“夫唯无知也，是以不我知”——在母亲的身体里，“无知”是什么？

- **不是“笨”——是“看不见简单”。** 人们觉得“复杂”才是“有价值”的——所以当她们看见简单的喂奶、哄睡、陪伴时，觉得“那不算什么”。那是“无知”——不是“没有知识”——是“看不见简单的价值”。
- **“不我知”的另一种理解：** 母亲不被“知道”——不是因为“她没做”——是因为“她做的太日常”。日常的东西不被记录、不被看见、不被“知”。
- **“无知”的深层含义：** 人们“不知”她——是因为他们用错了“知”的尺度。他们用“复杂”的尺子量“简单”的事——量不出来，就说“没有”。

朱先生说“无知是以不我知”是无知导致不了解。母亲的身体告诉我们：**不是她“不值得被知”——是因为人们看不见“简单”的价值。他们用“复杂”的尺子量“简单”的事——量不出来。**

| 朱邦復的“无知是以不我知” | 母亲经验的“無知是以不我知” |
| :--- | :--- |
| 无知导致不了解 | 不是她“不值得被知”——是看不见“简单”的价值 |
| 第三人称：无知的原因 | 第一人称：他们用“复杂”的尺子量“简单”的事——量不出来 |


## 五、“知我者希，则我贵矣”——了解我的人少，所以更珍贵

### 朱邦復的解读：知者少，所以珍贵

朱先生将“知我者希，则我者贵”解读为“能了解我的道的人少，所以珍贵”：

> “能瞭解我的道者少之又少，能奉行不渝的人更少。”

不是因为“她特殊”——是因为“能看见的人太少”。看到的人少——所以那些人更珍贵。

### 从母亲身体的经验出发：真正理解母亲的人少——不是“孤独”的抱怨——是“珍视”的确认

“知我者希，則我貴矣”——在母亲的身体里，“知我者希”是什么？

- **不是“抱怨没人懂她”——是“懂她的人很少”。** 这不是“孤独”——这是“事实”。真正理解母亲的人确实很少——因为她的工作不被看见。
- **“则我贵矣”的另一种理解：** 正因为“知者希”，那些“知者”才珍贵。不是“她”贵——是“看见她”的人贵。那些少数看得见她的人——是“珍贵的”。
- **“知我者希”的深层含义：** 母亲不要求所有人“知”她——但她知道那些“知”她的人是珍贵的。不是“孤独”——是“珍视”。

朱先生说“知我者希则我贵”是知者少所以珍贵。母亲的身体告诉我们：**真正理解她的人少——但正是那些人“珍贵”。不是“孤独”的抱怨——是“珍视”的确认。**

| 朱邦復的“知我者希则我贵” | 母亲经验的“知我者希則我貴矣” |
| :--- | :--- |
| 知者少所以珍贵 | 真正理解她的人少——但正是那些人“珍贵”。不是孤独——是珍视 |
| 第三人称：知者的珍贵 | 第一人称：懂我的人少——但我珍视那些懂的人 |


## 六、“是以圣人被褐而怀玉”——圣人穿着粗布衣服，怀里揣着美玉

### 朱邦復的解读：外拙内秀，守朴藏真

朱先生将“圣人被褐怀玉”解读为“圣人守朴藏真”：

> “真知者只得守樸藏真。”

“被褐”是穿着粗布衣服——外表朴素、不起眼。“怀玉”是怀里揣着美玉——内在珍贵、有真价值。真知者不显“玉”——他不让人看见他怀里有玉。

### 从母亲身体的经验出发：母亲穿着粗布衣服（素颜、奶渍、疲惫），怀里却“怀玉”（抱着最珍贵的生命）

“被褐而懷玉”——在母亲的身体里，“被褐”和“怀玉”是什么？

- **“被褐”——她看起来不起眼。** 素颜、头发没洗、衣服上有奶渍和泪痕。她穿的就像“粗布衣服”——不华丽、不精致、不被注意。
- **“怀玉”——她怀里有最珍贵的东西。** 那个孩子——他活着、他在成长、他信任她——那就是她的“玉”。她抱着他——她就是“怀玉”的人。
- **“被褐怀玉”的深层含义：** 她看起来“没有价值”——但她怀里有“无价之宝”。外人看见的是“粗布衣服”——但懂她的人，看见了她怀里的“玉”。她不需要“告诉”别人她有玉——她抱着他，就是“怀玉”的证据。
- **“被褐怀玉”的另一种理解：** 她不说“我是个好妈妈”——她只是在抱他。她的“玉”不是“展示”出来的——是“怀”着的。她不说——但她在。

朱先生说“被褐怀玉”是外拙内秀、守朴藏真。母亲的身体告诉我们：**她看起来不起眼——但怀里有最珍贵的生命。外人看见粗布衣服——懂的人，看见了她怀里的玉。**

| 朱邦復的“被褐怀玉” | 母亲经验的“被褐而懷玉” |
| :--- | :--- |
| 外拙内秀、守朴藏真 | 她看起来不起眼——但怀里有最珍贵的生命。外人看见粗布，懂的人看见玉 |
| 第三人称：圣人的外朴内真 | 第一人称：我不说我有“玉”——但我在抱着他 |


## 结语：“被褐怀玉”——母亲的真相

朱邦復先生在这一章中，用“易知易行而人不行”的知识论悖论和“被褐怀玉”的守朴之喻，解读了老子对“知者少”的坦然——真理简单，但人们不认；知者少，所以更珍贵；真知者不显摆，穿着粗衣怀里却藏着美玉。

而母亲的身体，是这一章最完整的“易知易行-被褐怀玉”的演绎者：

- **“吾言甚易知也”——她说“该睡了”、“妈妈在”——简单，但那是真理。**
- **“甚易行也”——喂奶、哄睡、陪伴——简单，但那是“行”。**
- **“人莫之能知也”——外人觉得她“没什么了不起”——他们看不见。**
- **“莫之能行也”——他们不能“行”——因为没经历过凌晨三点。**
- **“言有君”——她说“该睡了”——那是回应身体规律，不是乱说。**
- **“事有宗”——她做的事都有根据——回应需要，不是“随便做”。**
- **“夫唯无知也”——不是她“不值得被知”——是看不见“简单”的价值。**
- **“是以不我知”——人们用“复杂”的尺子量“简单”的事——量不出来。**
- **“知我者希”——真正理解她的人少——但那些人珍贵。**
- **“则我贵矣”——不是“孤独”的抱怨——是“珍视”的确认。**
- **“被褐”——她看起来不起眼——素颜、奶渍、疲惫。**
- **“怀玉”——她怀里抱着最珍贵的生命——那就是她的“玉”。**

**“被褐怀玉”——母亲一生的真相。** 外人看见的是“粗布衣服”——素颜、疲惫、在家带孩子“没什么”。但懂她的人——看见她怀里的“玉”。那个孩子——是他活着、他在成长、他信任她——那就是她的“玉”。她不需要“说”自己有玉——她抱着他，就是证据。她不展示“玉”——她只是“怀”着。那是“被褐怀玉”——外表朴素，内里有真。她不求所有人“知”她——但她知道，她怀里有“玉”。

一个母亲的身体，就是“被褐怀玉”最日常的版本。她看起来不起眼——素颜、奶渍、疲惫。但她的怀里，是另一个完整的生命。那是她的“玉”——不是“展示”的，是“怀”着的。她不说“我有玉”——但她抱着他，就是“怀玉”的证据。

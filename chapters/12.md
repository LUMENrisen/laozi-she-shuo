

## 引言：最“政治”的一章，最“日常”的母心

帛书本第四十九章，是《德道经》中关于“圣人无己心、以百姓心为心”的集中论述：

> 聖人恒无心，以百姓之心為心。
>
> 善者善之，不善者亦善之，得善也。
>
> 信者信之，不信者亦信之，得信也。
>
> 聖人之在天下，𢡁𢡁焉，為天下渾心，
>
> 百姓皆屬耳目焉，聖人皆咳之。

“圣人恒无心”——圣人永远没有固定的私心。“以百姓之心为心”——以百姓的心为自己的心。

“善者善之”——善良的人，用善意对待他。“不善者亦善之”——不善良的人，也用善意对待他。“得善也”——这样就能得到“善”的结果（让善得以成就）。

“信者信之”——诚信的人，信任他。“不信者亦信之”——不诚信的人，也信任他。“得信也”——这样就能得到“信”的结果（让诚信得以建立）。

“圣人之在天下”——圣人存在于天下。“𢡁𢡁焉”——收敛、凝聚的样子。“为天下浑心”——为天下人浑合其心（把心合成一个整体，不分别对待）。

“百姓皆属耳目焉”——百姓都专注于他们的耳目（关注他们所见所闻、各自的需求）。“圣人皆孩之”——圣人都把他们当作婴儿一样对待。

朱邦復先生在《止笑譚》中，将这一章解读为 **“圣人无私、善信皆容”** 。他认为“圣人无常心”是因为圣人没有自我私心，以百姓的心为自己的心——百姓关心什么，他就关心什么。他特别强调了“善者吾善之，不善者吾亦善之”——对善良的人以善意相待，对不善良的人也以善意相待，这样社会上就不再有好坏之分；“信者吾信之，不信者吾亦信之”——信任可信任的人，也信任不可信任的人，社会就不会再有信与不信的问题。他最后落脚在“圣人皆孩之”——圣人把百姓当作婴儿一样对待，无分别、无差别、无偏见。

但如果我们把主语换成“母亲的身体”——那个在日复一日的养育中无法“挑选”孩子好坏、无法“选择”孩子是否诚信、只能全部接纳的身体——这一章就不再是“圣人的政治哲学”，而是一份 **“关于母亲如何‘无心’对待孩子、如何‘皆孩之’的日常记录”**：

- “圣人恒无心”——一个母亲对自己的孩子，没有固定的“私心”。她不是为了“证明自己是个好妈妈”才爱他——她就是爱。那个爱不是“我决定爱”的——是“她就在爱”的。她没有“我”在“执行爱”的意识。
- “以百姓之心为心”——母亲以孩子的心为自己的心。他难过，她难过；他开心，她开心；他焦虑，她焦虑。她的心不是“自己的”——她以他的心为心。
- “善者善之，不善者亦善之”——孩子今天“乖”（善），她爱他；孩子今天“不乖”（不善），她也爱他。她的爱不按“表现”来分配。无论是“善”还是“不善”——她都“善之”。这就是“得善”——真正的“善”不是“爱乖的孩子”——是“爱不乖的孩子也一样”。
- “信者信之，不信者亦信之”——孩子今天“说话算话”（信），她信任他；孩子今天“没做到”（不信），她也信任他。她不是“因为他说到做到才信任”——她先信任，再等他自己成为值得信任的人。这就是“得信”——信任不是“条件性”的——是“前提性”的。
- “圣人之在天下，歙歙焉”——母亲在孩子的生命里，是“收敛”的。她不张扬、不占领、不把他的成长当作自己的功绩。她“收缩”自己的意愿，不让孩子感受到她“希望他成为什么”的焦虑。
- “为天下浑心”——母亲不把孩子分割成“好的部分”和“坏的部分”。她不把“这孩子有时候真是天使，有时候真是恶魔”当作一种分裂的评价——她把他看作一个完整的、正在成为的人。“浑心”就是“不切割”——她不把孩子分成“可以接纳”和“不可以接纳”的两半。
- “百姓皆属耳目焉”——孩子用他的眼睛看世界、用他的耳朵听声音——母亲是他第一个“世界”。他所有关于“这是否安全”、“这是否可信”、“这是否可以”的判断，都是从她那里来的。她就是他的“属”。
- “圣人皆孩之”——母亲对待孩子，就像对待一个婴儿。她对他的爱不建立在“他能做到什么”的基础上——只建立在“他在”的基础上。婴儿不需要“表现好”才能被爱——母亲爱婴儿，因为他在。这就是“皆孩之”——不成熟的、不完全的、正在成为的——都被接纳。


## 一、“圣人恒无心”——圣人永远没有固定的私心

### 朱邦復的解读：无我无私，以百姓为心

朱先生将“圣人无常心”解读为“圣人不坚持自己的私心”：

> “聖人無自我心，把百姓之心當作自己的心。”

“无常心”不是“没有心”——是“没有固定的、私人的心”。圣人不把自己的“我想要”当作判断标准——他以百姓的“他们需要”为心。

### 从身体经验出发：母亲没有固定的“私心”——她不是为了证明自己才爱他——她就是爱

“圣人恒无心”——在母亲的身体里，“无心”是什么？

- **她不是为了“证明自己是好妈妈”才爱他。** 如果她是为了“证明”才爱——那是“有心”（有目的、有私心）。但她的爱不是“证明”驱动的——是“响应”驱动的。他在，她就爱。她没有“我”在“做”爱。
- **“无心”的另一种理解：** 她不是“按照标准”来爱——她不是“今天我做得对，所以我值得爱他；今天我做得不对，所以我不配”——她的爱不建立在自己的“表现”上。她“无心”——不计算得失、不评估自己。
- **“无心”不是“没有心”——是“心不在自己身上”。** 她的心不是“我想怎样”——是“他需要怎样”。她以他的心为心——所以她没有“自己的心”可以固执。

朱先生说“圣人无常心”是圣人不坚持自己的私心。母亲的身体告诉我们：**她不是为了证明自己才爱——她就是爱。“无心”是“心不在自己身上”——在他身上。他没有“我想”——只有“他在”。**

| 朱邦復的“圣人无常心” | 母亲经验的“圣人恒无心” |
| :--- | :--- |
| 圣人不坚持自己的私心 | 她不是为了证明自己才爱——她就是爱。心不在自己身上，在他身上 |
| 第三人称：圣人的无我 | 第一人称：我没有“我想”——我只有“他在” |


## 二、“以百姓之心為心”——以百姓的心为心

### 朱邦復的解读：把百姓的心当作自己的心

朱先生将“以百姓心为心”解读为“以百姓的需要为依归”：

> “聖人無自我心，把百姓之心當作自己的心。……以百姓心为心。”

他的逻辑是：圣人不以自己的“判断”来主导——他先“倾听”百姓的心、百姓的痛、百姓的需要。然后，他以那些需要为自己的需要。

### 从身体经验出发：母亲以孩子的心为心——他难过，她难过；他开心，她开心

“以百姓之心為心”——在母亲的身体里，“以子之心为心”是什么？

- **他难过，她难过。** 孩子摔倒了、委屈了、被拒绝了——他的“痛”直接进入她的身体。她不是“分析”他的痛——她是“感受”他的痛。他以他的痛为她的痛。
- **他开心，她开心。** 孩子笑了、跑来了、说“妈妈你看”——他的“喜”直接进入她的身体。她不是“评价”他的喜——她是“共享”他的喜。他以他的乐为她的乐。
- **“以心为心”的深层含义：** 她不是“换位思考”对他——她是“身体共振”对他。他在，她就有了“他的感觉”。她不需要“努力”去理解他——因为她以他的心为心。那是“无心”的真正结果——她无心，所以他的心就是她的心。

朱先生说“以百姓心为心”是把百姓的需要当作自己的。母亲的身体告诉我们：**他难过，她难过；他开心，她开心。她不是“换位思考”——她是“身体共振”。她无心，所以他的心就是她的心。**

| 朱邦復的“以百姓心为心” | 母亲经验的“以百姓之心為心” |
| :--- | :--- |
| 把百姓的需要当作自己的 | 他难过，她难过；他开心，她开心——她不是“换位思考”，她是“身体共振” |
| 第三人称：圣人的关怀 | 第一人称：我没有“自己的心”——他的心就是我的心 |


## 三、“善者善之，不善者亦善之”——善良的善待，不善良的也善待

### 朱邦復的解读：对善与不善都以善待

朱先生将“善者吾善之，不善者吾亦善之”解读为“对善与不善都一视同仁”：

> “在上者對善良者固然以善意相待，對不善者也沒有例外。”

“善之”是“用善意对待”。“不善者亦善之”——不因为对方“不善”就停止善意。善意不按对方的“表现”来分配——它是“无条件”的。

### 从母亲经验的解读：孩子今天“乖”她爱他，孩子今天“不乖”她也爱他——爱不按表现分配

“善者善之，不善者亦善之”——在母亲的身体里，“善之”是什么？

- **孩子今天“乖”——她爱他。** 他听话、合作、笑容满面——她的爱自然流向他。那是“善者善之”。
- **孩子今天“不乖”——她也爱他。** 他哭闹、对抗、拒绝合作——她的爱没有减少。她不因为“今天的表现”而撤回爱。那是“不善者亦善之”。
- **“得善”的深层含义：** 真正的“善”不是“爱乖的孩子”——是“爱不乖的孩子也一样”。当母亲不按“表现”来分配爱的时候——她得到了“善”的本质。那个“善”不是“他乖的时候我觉得自己好”——是“他不乖的时候我也愿意抱着他”。

朱先生说“善者善之不善者亦善之”是对善与不善都以善待。母亲的身体告诉我们：**孩子乖，她爱；孩子不乖，她也爱。她的爱不按表现分配——那就是“得善”。**

| 朱邦復的“善者善之不善者亦善之” | 母亲经验的“善者善之不善者亦善之” |
| :--- | :--- |
| 对善与不善都以善待 | 孩子乖，她爱；孩子不乖，她也爱。爱不按表现分配——那就是“得善” |
| 第三人称：无差别的善意 | 第一人称：我不是“乖的时候爱，不乖的时候不爱”——我是“都在爱” |


## 四、“信者信之，不信者亦信之”——诚信的信任，不诚信的也信任

### 朱邦復的解读：对信与不信都以信任

朱先生将“信者吾信之，不信者吾亦信之”解读为“对信与不信都一视同仁”：

> “相信可以相信的人，也相信不可相信的人，社会就不会再有信与不信的问题。”

“信之”是“信任”。“不信者亦信之”——不因为对方“曾经失信”就停止信任。信任不按对方的“历史”来分配——它先于“表现”。

### 从母亲经验的解读：孩子今天说到做到，她信任他；孩子今天没做到，她也信任他——信任是“前提”不是“奖励”

“信者信之，不信者亦信之”——在母亲的身体里，“信之”是什么？

- **孩子今天说到做到——她信任他。** 他说“我会把玩具收好”然后他真的收了——她信任他。那是“信者信之”。
- **孩子今天没做到——她也信任他。** 他说“我会自己吃饭”然后撒了一地——她仍然信任他。她不说“你骗我”——她说“下次再试”。那是“不信者亦信之”。
- **“得信”的深层含义：** 信任不是“因为他做到了才给”——是“先给了，等他自己做到”。母亲给孩子的是“前提性”的信任——她先信他，然后他慢慢成长为一个值得信任的人。如果她只在他“做到”之后才信任——他永远不会学会“信任是什么”。

朱先生说“信者信之不信者亦信之”是对信与不信都以信任。母亲的身体告诉我们：**孩子说到做到，她信任；孩子没做到，她也信任。信任不是“奖励”——是“前提”。先信，他才成为值得信的人。**

| 朱邦復的“信者信之不信者亦信之” | 母亲经验的“信者信之不信者亦信之” |
| :--- | :--- |
| 对信与不信都以信任 | 孩子做到，她信；孩子没做到，她也信。信任是“前提”，不是“奖励” |
| 第三人称：无差别的信任 | 第一人称：我先信他——他才会成为值得我信的人 |


## 五、“聖人之在天下，歙歙焉”——圣人收敛自己

### 朱邦復的解读：圣人虚纳若谷

朱先生将“圣人在天下，歙歙焉”解读为“圣人虚纳若谷”：

> “聖人居於天下，虛納若谷，服務天下，無私無欲。”

“歙”是收敛、闭合。圣人不是张扬的、不是占领的——他是“收敛”的。他不扩大自己的影响——他只以百姓的心为心。

### 从母亲经验的解读：母亲在孩子的生命里是“收敛”的——她不张扬、不占领、不把成长当成功绩

“歙歙焉”——在母亲的身体里，“歙”是什么？

- **她不把孩子的成长当“她的功绩”。** 孩子学会了走路——她不是到处说“是我教会他的”。她“收敛”了——她知道那是他自己迈出的步子。
- **她不占领孩子的空间。** 她不是“你应该这样”、“你应该那样”——她“收敛”自己的意愿，不让他感受到“她希望他成为什么”的焦虑。
- **“歙”的深层含义：** 母亲不是“站在前面”的——她是“在后面”的。她“收敛”自己，是为了让他有空间成为他自己。她的“收敛”是他的“伸展”的前提。

朱先生说“圣人在天下歙歙焉”是圣人虚纳若谷。母亲的身体告诉我们：**她不张扬、不占领——她是“收敛”的。她的“收敛”是他的“伸展”的空间。**

| 朱邦復的“圣人在天下歙歙焉” | 母亲经验的“聖人在天下歙歙焉” |
| :--- | :--- |
| 圣人虚纳若谷，收敛自己 | 她不把孩子的成长当“她的功绩”——她收敛自己，给他空间成为自己 |
| 第三人称：圣人的谦抑 | 第一人称：我不在前面——我在后面。他的路是他的 |


## 六、“為天下渾心”——为天下浑合其心

### 朱邦復的解读：使天下心合为一体

朱先生将“浑其心”解读为“无私无欲，不分别对待”：

> “聖人居於天下，虛納若谷，服務天下，無私無欲。”

“浑”是整体、不分、不切割。圣人不把天下人分成“好的”和“坏的”、“信的”和“不信的”——他把他们“浑”为一个整体。

### 从母亲经验的解读：母亲不把孩子分割成“好的部分”和“坏的部分”——她接纳他的全部

“為天下渾心”——在母亲的身体里，“浑心”是什么？

- **她不把孩子分成“好的部分”和“坏的部分”。** 不把“乖”当作“好孩子”，把“不乖”当作“坏孩子”——她接纳的是“他”这个整体。他的乖和闹都是他——她不分“可以接纳”和“不可以接纳”。
- **“浑心”的另一种理解：** 她不会因为孩子今天“不乖”就“不爱”他了。她的爱是“浑”的——不切割、不分配、不分时段。她爱的是一个完整的、在成为中的人，不是“今天合格的那部分”。
- **“浑”的深层含义：** 母亲的心是“浑”的——她没有把爱分成“他表现好时70%、表现不好时30%”。她的爱是“浑”的——全部都在，任何时候都在。

朱先生说“为天下浑其心”是使天下心合为一体。母亲的身体告诉我们：**她不把孩子分成“好”与“坏”——她接纳的是一个完整的他。她的爱是“浑”的——全部都在，不切割。**

| 朱邦復的“为天下浑其心” | 母亲经验的“為天下渾心” |
| :--- | :--- |
| 使天下心合为一体，不分别 | 她不把孩子分成“好的部分”和“坏的部分”——她接纳一个完整的他 |
| 第三人称：无分别的容纳 | 第一人称：我爱的不是一个“合格的部分”——我爱的就是他 |


## 七、“百姓皆屬耳目焉”——百姓都专注于自己的耳目

### 朱邦復的解读：百姓各有所见所闻

朱先生将“百姓皆注其耳目”解读为“百姓都专注于他们所见的”：

> “因而百姓仰賴效法聖人。”

“注”是专注。“耳目”是所见所闻。百姓都用自己的耳目去感受世界——他们需要圣人来引导。

### 从母亲经验的解读：孩子用他的眼睛看世界、用他的耳朵听声音——母亲是他第一个“世界”

“百姓皆屬耳目焉”——在母亲的身体里，“耳目”是什么？

- **孩子用他的眼睛看她。** 他还没会说话——但他已经在看了。他看她的表情、她的反应、她的“是”与“不”。他的眼睛在捕捉“世界是什么样的”——从她那里捕捉。
- **孩子用他的耳朵听她。** 他听不懂语言——但他听得出语气。他听“妈妈在”的声音、听“别怕”的声音、听“可以”的声音。他的耳朵在捕捉“声音背后的感觉”——从她那里捕捉。
- **“屬”的深层含义：** 孩子“属”于她的耳目。她是他看世界的第一双“眼睛”、他听世界的第一双“耳朵”。他的“属”不是“占有”——是“依赖”。他通过她——认识世界。

朱先生说“百姓皆注其耳目”是百姓专注于所见所闻。母亲的身体告诉我们：**孩子用眼睛看她、用耳朵听她——她是他看世界的第一双“眼睛”。他“属”于她的“耳目”——从她那里认识世界。**

| 朱邦復的“百姓皆注其耳目” | 母亲经验的“百姓皆屬耳目焉” |
| :--- | :--- |
| 百姓专注于所见所闻 | 孩子用眼睛看她、用耳朵听她——她是他认识世界的第一双“眼睛” |
| 第三人称：百姓对圣人的依赖 | 第一人称：他通过我——认识“世界” |


## 八、“聖人皆孩之”——圣人都把他们当作婴儿

### 朱邦復的解读：圣人以赤子之心对待百姓

朱先生将“圣人皆孩之”解读为“圣人爱民如子”：

> “而聖人愛護百姓，就像對赤子一般。”

“孩之”是以对待婴儿的方式对待他们——无条件、无评判、全接纳。婴儿不需要“表现好”才能被爱——他“在”就已经足够。

### 从母亲经验的解读：母亲对待孩子，就像对待一个婴儿——爱不是建立在“他能做什么”的基础上

“聖人皆咳之”——在母亲的身体里，“孩之”是什么？

- **她对待孩子，像对待婴儿。** 婴儿不需要“有出息”才能被爱、不需要“表现好”才能被接纳、不需要“证明自己”才能被拥抱。他只需要“在”就足够了。
- **“孩之”的深层含义：** 母亲的爱不是“条件性”的——不是“因为你做到了所以我才爱你”。她的爱是“前提性”的——因为你在，所以我爱。她对待他的方式，始终带着“婴儿”的底色——无论他多大、无论他走多远、无论他是否“值得”——她都用那种“婴儿式的无条件”来对待他。
- **“孩之”不是“把他当婴儿”——是“用婴儿的方式对待他”。** 婴儿不会“做”什么来赢得爱——他只是存在。母亲对孩子的爱，也同样不以“做”为基础——以“在”为基础。

朱先生说“圣人皆孩之”是圣人以赤子之心对待百姓。母亲的身体告诉我们：**她爱他不是因为“他做到了什么”——是因为他在。她对待他的方式，始终带着“婴儿”的底色——“在”就足够了。**

## 结语：母亲是“浑心”的活证

朱邦復先生在这一章中，用“无我无私”和“善信皆容”的框架，解读了“圣人无常心，以百姓心为心”的政治哲学——圣人没有私心，以百姓的需要为需要；对善与不善都以善待，对信与不信都以信任；收敛自己、浑合人心、以婴儿之心对待所有人。

而母亲的身体，是这一章最完整的“无心-浑心-孩之”的演绎者：

- **“圣人恒无心”——她不是为了证明自己才爱——她就是爱。心不在自己身上，在他身上。**
- **“以百姓之心为心”——他难过，她难过；他开心，她开心——她不是“换位思考”，是“身体共振”。**
- **“善者善之，不善者亦善之”——孩子乖，她爱；孩子不乖，她也爱。爱不按表现分配。**
- **“信者信之，不信者亦信之”——孩子做到，她信；孩子没做到，她也信。信任是“前提”，不是“奖励”。**
- **“圣人在天下，歙歙焉”——她不把孩子的成长当“她的功绩”——她收敛自己，给他空间。**
- **“为天下浑心”——她不把孩子分成“好的部分”和“坏的部分”——她接纳一个完整的他。**
- **“百姓皆属耳目”——孩子用眼睛看她、用耳朵听她——她是他认识世界的第一双“眼睛”。**
- **“圣人皆孩之”——她爱他不是因为“他做到了什么”——是因为他在。“在”就足够了。**

**“无心”——母亲不是“有目的地爱”。她不是为了“证明自己是好妈妈”才爱——她就是爱。她的“无心”让她的爱可以不附加条件、不要求回报、不计算得失。**

**“浑心”——母亲不切割孩子。她接纳一个完整的、正在成为的人——不把他的“好”和“坏”分开来爱。她的心是“浑”的——不分段、不分配、不条件化。**

**“孩之”——母亲对待孩子的方式，始终带着“婴儿”的底色。她爱他不是因为他“值得”——是因为他在。在，就足够了。**

一个母亲的一生，就是“无心-浑心-孩之”的日常版本。她不需要“成为圣人”才能做到这些——她已经在做了。她的心不在自己身上、她不切割孩子、她爱他因为他在。那不是“圣人的境界”——是“母亲的日常”。

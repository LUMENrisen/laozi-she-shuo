

## 引言：最“经济”的一章，最“母亲”的耗竭

帛书本第七十六章（通行本第七十五章），是《德道经》中关于“民饥、不治、轻死”及其根源的集中论述：

> 人之飢也，以其取食𨓚之多也，是以飢。
>
> 百姓之不治也，以其上有以為也，是以不治。
>
> 民之巠（輕）死，以其求生之厚也，是以巠（輕）死。
>
> 夫唯无以生為者，是賢貴生。

“人之飢也”——人民之所以饥饿，“以其取食税之多也”——是因为上面征收的税太多，“是以飢”——所以饥饿。

“百姓之不治也”——百姓之所以难以治理，“以其上之有以為也”——是因为上面有所作为（折腾、干预、妄为），“是以不治”——所以难以治理。

“民之轻死”——人民之所以不把生命当回事，“以其求生之厚也”——是因为上面追求享乐太甚（“生生之厚”），“是以轻死”——所以人民轻死。

“夫唯无以生為者”——只有那些不把“养生”当作刻意追求的人，“是賢貴生”——才是真正善于贵生的人。

朱邦復先生在《止笑譚》中，将这一章解读为 **“政治经济学的三重批判”** 。他认为“民之饥”是因为苛捐杂税太多；“民之难治”是因为上层有为妄作、政令繁苛；“民之轻死”是因为上层贪得无厌、奢侈腐化。人民生不如死，所以轻死。他最后以“无以生为者，是贤于贵生”作结——唯有不追求享受的人，人生才会平顺，比养尊处优更好。

但如果我们把主语换成“母亲的身体”——那个被“食税”（孩子的无尽需求、社会的期待）榨干、被“有为”（控制、焦虑、方法）弄乱、被“求生之厚”（“完美妈妈”的目标）耗尽的身体——这一章就不再是“政治经济学”，而是一份 **“关于母亲身体如何在被取食、被有为、被厚生之后说‘不’”的日常记录**：

- “人之饥也，以其取食税之多也”——母亲的身体“饥”了（疲惫、耗竭），是因为“取食税”的人太多：孩子需要她、伴侣需要她、社会要求她——“税”太重了。她“飢”了。
- “百姓之不治也，以其上有以为也”——她的身体“不治”（混乱、生病、不听使唤），是因为她“有为”太多——控制、焦虑、方法论——她“以为”了。身体被“治”得太厉害了——反而不“治”了。
- “民之轻死，以其求生之厚也”——母亲“轻死”（不在乎自己的身体、忽视自己的健康），是因为她追求“生之厚”（“完美妈妈”的目标、“为他好”的执念）。她想“让生命更好”——结果反而“轻”了生命。
- “夫唯无以生为者，是贤贵生”——只有那些不把“做一个完美妈妈”当作刻意追求的人——才是真正爱惜生命的人。


## 一、“人之饥也，以其取食税之多也”——人民饥饿，因为赋税太多

### 朱邦復的解读：苛税导致饥荒

朱先生将“民之饥，以其上食税之多，是以饥”解读为“税太多所以人民吃不饱”：

> “人民吃不飽，是因為稅繳得太多。”

“食税”是收税。“多”是太多。上层收得太多了——下层就没得吃了。

### 从母亲身体的经验出发：母亲“饥”了，因为“取食税”的人太多了——孩子、伴侣、社会——“税”太重了

“以其取食税之多也”——在母亲的身体里，“食税”是什么？

- **“税”是“被拿走”的。** 孩子从她那里拿走时间、精力、睡眠、身体空间——那是“税”。伴侣从她那里拿走关注、耐心、情绪能量——那是“税”。社会从她那里拿走“你应该”的期待——那是“税”。
- **“取食税之多”让她“饥”。** 她被拿走太多了——她“饥”了（疲惫、耗竭、空了）。不是因为“她不够”——是因为“被拿走的太多”。
- **“饥”的深层含义：** 母亲需要承认她“饥”了。不是因为“她不好”——是因为“税”太重。她需要少交一点“税”——留一点给自己。

朱先生说“民饥是因为税太多”是苛税导致饥荒。母亲的身体告诉我们：**她被拿走太多——时间、精力、身体——她“饥”了。不是因为“不够”——是因为“税”太重。**

| 朱邦復的“民饥税多” | 母亲经验的“食税之多” |
| :--- | :--- |
| 苛税导致饥荒 | 她被拿走太多——时间、精力、身体——她“饥”了 |
| 第三人称：政治经济学 | 第一人称：我被抽税太久了——我需要留一点给自己 |


## 二、“百姓之不治也，以其上有以为也”——百姓难治，因为上面有为妄作

### 朱邦復的解读：上层折腾导致难治

朱先生将“民之难治，以其上之有为，是以难治”解读为“为政者有为妄作，人民无所适从”：

> “人民之所以難治理，是因為在上者有為妄作，使得人民無所適從。”

“有为”是折腾、干预、妄作。越折腾——越难治。不是人民“难治”——是上面“太爱治”。

### 从母亲身体的经验出发：她的身体“不治”（混乱、生病），是因为她“有为”太多了——控制、焦虑、方法——身体被“治”坏了

“以其上有以為也”——在母亲的身体里，“上有为”是什么？

- **她“有为”太多。** 她控制身体（“你必须快点恢复”），她焦虑（“我是不是恢复得太慢了”），她运用方法（“用这个动作、那个工具”）。她“有为”——她在“治”身体。
- **结果——身体“不治”。** 她越是“治”身体——身体越“不治”（混乱、生病、不听使唤）。不是因为“身体不好”——是因为“治”得太多了。
- **“不治”的深层含义：** 母亲需要停止“有为”的“治”。不是“不恢复”——是“不过度恢复”。她“治”太多了——身体“不治”了。她放下“控制”和“方法”——身体反而会“自治”。

朱先生说“上有为则难治”是有为妄作则民不治。母亲的身体告诉我们：**她“治”身体太多——身体反而“不治”了。放下“治”——身体才会“自治”。**

| 朱邦復的“上有为则难治” | 母亲经验的“上有為則不治” |
| :--- | :--- |
| 有为妄作则难治 | 她“治”身体太多——身体反而“不治”了。放下“治”——才会“自治” |
| 第三人称：治理的悖论 | 第一人称：我“治”太多了——身体不“治”了 |


## 三、“民之轻死，以其求生之厚也”——人民轻死，因为上面求生太厚

### 朱邦復的解读：上层厚生则民轻死

朱先生将“民之轻死，以其上求生之厚，是以轻死”解读为“上层贪生厚养，人民轻死”：

> “人民之不怕死，是因為在上位者貪得無饜，奢侈浮華。……心必難平，平則鳴，鳴而不得，遂感生不如死。生既不如死，何以生為，無以生為，是以輕死。”

“求生之厚”是过度养生、过度追求享受。上层追求“厚生”——下层却“轻死”。因为看到上层那样“厚”——下层觉得自己的“生”不值得。

### 从母亲身体的经验出发：母亲“轻死”（忽视自己），是因为她追求“生之厚”（“完美妈妈”的目标）。她想“让生命更好”——结果反而“轻”了自己的生命

“以其求生之厚也”——在母亲的身体里，“求生之厚”是什么？“轻死”是什么？

- **“求生之厚”是“完美妈妈”的目标。** 她追求“最好”的育儿、追求“完美”的恢复、追求“无懈可击”的妈妈形象。那是“求生之厚”——她想让“生”更好。
- **结果——她“轻死”。** 她忽视自己的身体、忽视自己的需要、忽视自己的感受。她为了“厚生”（孩子的“好”）——她“轻”了自己的“生”。她不在乎自己了。
- **“轻死”的深层含义：** 母亲“轻死”不是“想死”——是“不想在乎自己了”。她觉得自己不重要了——孩子重要、家庭重要、一切都重要——只有她“轻”。那是“轻死”——不是“死”——是“把自己看轻”。

朱先生说“上层厚生则民轻死”是上层奢侈则民轻死。母亲的身体告诉我们：**她为了“完美妈妈”的目标——她“轻”了自己。不是“想死”——是“把自己看轻了”。**

| 朱邦復的“厚生则轻死” | 母亲经验的“求生之厚則輕死” |
| :--- | :--- |
| 上层厚生则民轻死 | 她为了“完美妈妈”——她“轻”了自己。不是想死——是把自己看轻了 |
| 第三人称：社会的不平等 | 第一人称：我“厚”了他——我“轻”了自己 |


## 四、“夫唯无以生为者，是贤贵生”——只有不刻意求生的人，才是真正贵生

### 朱邦復的解读：不刻意求生的才是真贵生

朱先生将“夫唯无以生为者，是贤于贵生”解读为“不追求享受才是真贵生”：

> “唯有不追求享受，人生才會平順，這樣遠比養尊處優為好。”

“无以生为”——不把“生”当作刻意追求的对象，不刻意“养生”、“厚生”。那样的人——才是真正“贵生”的人。

### 从母亲身体的经验出发：只有那些不把“做一个完美妈妈”当作刻意追求的人——才是真正爱惜生命的人

“夫唯无以生為者”——在母亲的身体里，“无以生为”是什么？“贤贵生”是什么？

- **“无以生为”是“不把‘完美妈妈’当目标”。** 她不是“刻意”做妈妈——她是“自然地”做妈妈。她不追求“最好”——她只追求“够好”。那是“无以生为”。
- **“贤贵生”——那是真正爱惜生命的人。** 当她不追求“完美妈妈”——她反而“贵”了自己的生命。她重视自己、珍惜自己、不把自己看“轻”。
- **“无以生为”的深层含义：** 母亲不需要“刻意”当妈妈。她不需要“证明”自己是好妈妈。她越“不以生为”——她越“贵生”。她不是“不够”好妈妈——她是“自然”好妈妈。

朱先生说“无以生为者贤于贵生”是不追求享受才是真贵生。母亲的身体告诉我们：**当她不追求“完美妈妈”——她反而“贵”了自己。那才是真正的“贵生”。**

| 朱邦復的“无以生为者贤于贵生” | 母亲经验的“无以生為者賢貴生” |
| :--- | :--- |
| 不刻意求生才是真贵生 | 当她不追求“完美妈妈”——她反而“贵”了自己。那才是真正的“贵生” |
| 第三人称：贵生的真谛 | 第一人称：我不刻意当“完美”妈妈——我反而“贵”了自己 |


## 结语：“无以生为”——母亲最深的回归

朱邦復先生在这一章中，用“政治经济学”的三重批判——苛税、有为、厚生——解读了“民饥、不治、轻死”的根源：税太重、治太多、享太厚。他最后以“无以生为者贤于贵生”作结——不刻意追求“生”的人，才是真正“贵生”的人。

而母亲的身体，是这一章最完整的“饥-不治-轻死-无以生为”的演绎者：

- **“人之饥”——她的身体“饥”了——疲惫、耗竭、空了。**
- **“以其取食税之多”——“税”是孩子、伴侣、社会的索取。她被拿走太多了。**
- **“百姓之不治”——她的身体“不治”了——混乱、生病、不听使唤。**
- **“以其上有以为”——她“治”身体太多——控制、焦虑、方法——身体被“治”坏了。**
- **“民之轻死”——她“轻”了自己——忽视自己、不在乎自己。**
- **“以其求生之厚”——她追求“完美妈妈”——她“厚”了目标，“轻”了自己。**
- **“夫唯无以生为者”——当她不追求“完美妈妈”——她反而“贵”了自己。**
- **“是贤贵生”——那才是真正的“贵生”。**

**“人之饥”——母亲必须承认她“饥”了。** 不是“饿”的饥——是“被掏空”的饥。她被取走太多——时间、精力、身体空间、情绪空间。那个“饥”不是她的错——是“税”太重了。她需要少交一点“税”——留一点给自己。

**“不治”——母亲必须停止“治”自己太多。** 她越控制身体——身体越不听。她越焦虑恢复——恢复越慢。那是“治”太多的结果。她需要放下“治”——让身体“自治”。不是“不管”——是“不过管”。

**“轻死”——母亲必须停止“轻”自己。** 她为了“厚”孩子——她“轻”了自己。那不是“牺牲”——是“忽视”。她需要把自己看得重一点——不是“自私”——是“自贵”。

**“无以生为”——母亲最深的回归。** 当她不再追求“完美妈妈”——她反而“贵”了。她不刻意“做”好妈妈——她自然“在”好妈妈。那才是真正的“贵生”——不是“养生”的贵——是“活着”的贵。

一个母亲的身体，就是“无以生为”最日常的版本。她停止追求“完美妈妈”——她回到“自然妈妈”。她停止“治”身体——她允许身体“自治”。她停止“轻”自己——她“贵”自己。那是她的“贤贵生”——不是“养”出来的——是“回”来的。她回到自己——不刻意、不强求、不“为之”——那个“自己”就已经够了。



## 引言：最“自然”的一章，最“母亲”的均衡

帛书本第七十八章（通行本第七十七章），是《德道经》中关于“天之道损有余补不足、人之道损不足以奉有余”的集中论述：

> 天下之道，猶張弓者也，高者印（抑）之，下者舉之，有餘者𢿃（損）之，不足者補之。
>
> 故天之道，𢿃（損）有餘而補不足；人之道則不然，𢿃（損）不足以奉有餘。
>
> 孰能有餘而有以取奉於天者乎？唯有道者乎？
>
> 是以聖人為而弗有，成功而弗居也。若此其不欲見賢也。

“天下之道，猶張弓者也”——天下的道理，就像拉弓射箭一样。“高者抑之”——高了就压低它，“下者举之”——低了就抬高它，“有餘者損之”——有余的就减少它，“不足者補之”——不足的就补充它。

“故天之道，損有餘而補不足”——所以天道是“减损有余的，补充不足的”；“人之道則不然”——人道却不是这样，“損不足以奉有餘”——减损不足的，用来供奉有余的。

“孰能有餘而有以取奉於天者乎？”——谁能在自己有余的时候，反而把多余的部分奉献给天道（补给不足者）呢？“唯有道者乎？”——大概只有有道的人吧？

“是以聖人為而弗有”——所以圣人有所作为却不占有，“成功而弗居”——成就了事情却不居功。“若此其不欲見賢也”——像这样，他是不想表现自己的贤能。

朱邦復先生在《止笑譚》中，将这一章解读为 **“天道均衡与人道失衡的根本对比”** 。他认为“天之道，其犹张弓与”是“能量的变化，系根据热力学定律‘熵’值扩散”——“有餘者損之，不足者補之”是熵的作用，也是均衡律。他特别对比了天之道与人之道：天道是“损有余而补不足”，人道却是“损不足以奉有余”——这正是“雪里送炭”与“锦上添花”的差别。他最后以“圣人为而不恃，功成而不处”作结——有恩于人而不自恃，有功于事而不居功。

但如果我们把主语换成“母亲的身体”——那个每天都像“张弓”一样在平衡“高下、损益”之间运作的身体——这一章就不再是“宇宙规律学”，而是一份 **“关于母亲如何在‘天道’与‘人道’之间选择、如何在‘损有余补不足’中守护生命”的日常记录**：

- “天下之道，犹张弓者也”——母亲的身体也像“张弓”：高了要压低（产后激素调整）、低了要抬高（情绪低谷时自我安抚）、有余要损（涨奶时喂哺）、不足要补（疲惫时休息）。
- “天之道，损有余而补不足”——母乳喂养就是“天道”最完美的例子：乳汁越多（有余）——越被“损”（排空）——不足时（排空后）——越被“补”（重新充盈）。
- “人之道则不然，损不足以奉有余”——但人间的“养育标准”却是反过来的：已经累到极限的母亲（不足）——还要继续被“损”（被要求“更多”）；已经精疲力尽的母亲——还要继续“奉”给那些“有余”的期待（“完美妈妈”的标准）。
- “孰能有馀而有以取奉於天者乎？”——谁能在自己有余的时候，反而把多余的部分补给不足者？母亲在某种意义上就是这样的“有道者”：“有余”时给（乳汁充足时喂哺），“不足”时（自己空了）——如果还能停下来、不继续“损”自己——那就是“有道”。
- “聖人為而弗有”——母亲做了所有事——但不占有孩子。她“為”了，但“弗有”。
- “成功而弗居”——孩子长大了——她“成功”了，但不“居”功。
- “不欲见贤”——她不求被看见、被标榜。她“不欲见贤”——她不需要“贤”的标签。


## 一、“天下之道，犹张弓者也”——天道像拉弓一样

### 朱邦復的解读：熵的扩散与均衡

朱先生将“天之道，其犹张弓与”解读为“能量扩散的均衡过程”：

> “能量的变化，係根據熱力學定律‘熵’值擴散……‘有餘者損之，不足者補之’，就是‘熵’的作用，亦為均衡律。”

拉弓的时候——高了就压一压，低了就抬一抬。有余就减一点，不足就补一点。那是“调”的过程——不是“一次到位”的——是不断调整、不断均衡的过程。

### 从母亲身体的经验出发：产后身体也像“张弓”——高了要压（激素调整）、低了要抬（情绪安抚）、有余要损（涨奶喂哺）、不足要补（疲惫休息）

“猶張弓者也”——在母亲的身体里，“张弓”是什么？

- **她的身体也在“张弓”。** 产后激素高了——要“抑”（压下去）；情绪低了——要“举”（托起来）；涨奶了（有余）——要“损”（排空）；疲惫了（不足）——要“补”（休息）。
- **“张弓”的深层含义：** 她的身体不是一个“固定”的状态——是一个“不断调整”的过程。高了压一压，低了抬一抬——那不是“失控”——是“调节”。她需要允许自己“调”——不要求一次到位。

朱先生说“天道犹张弓”是拉弓时的均衡调整。母亲的身体告诉我们：**她的身体也在“张弓”——高了压、低了抬、有余损、不足补——那是“调节”，不是“失控”。**

| 朱邦復的“天道犹张弓” | 母亲经验的“猶張弓者也” |
| :--- | :--- |
| 拉弓时的均衡调整 | 她的身体也在“张弓”——激素高了压、情绪低了抬、涨奶了排空、疲惫了休息 |
| 第三人称：天道的运作 | 第一人称：我的身体在“调”——不是“乱” |


## 二、“天之道，损有余而补不足”——天道减损有余、补充不足

### 朱邦復的解读：天道是自然的均衡

朱先生将“天之道，损有余而补不足”解读为“自然界的能量扩散、均衡”：

> “天道是取多餘的，補不足的。”

有余的——被“损”（减少）。不足的——被“补”（增加）。那是自然的均衡——不是人为的分配。

### 从母亲身体的经验出发：母乳喂养就是“天道”的完美例子——乳汁越多（有余）越被“损”（排空），排空后越被“补”（充盈）

“損有餘而補不足”——在母亲的身体里，“损有余补不足”是什么？

- **母乳喂养——最“天道”的例子。** 乳房涨了（有余）——孩子吃（损）——排空后（不足）——重新充盈（补）。那是“损有余而补不足”——不是“人”设计的——是身体自然在做的。
- **身体的复旧——也是“天道”。** 产后身体“有余”的（多余的羊水、血液、组织）——被“损”掉（排出）；“不足”的（气血、精力）——在恢复期被“补”回来。那是身体自己在“调”的——不是“人力”可以“加速”的。
- **“损有余补不足”的深层含义：** 母亲需要允许身体的“损”和“补”自然发生。她不能“阻止”损（排恶露是必要的），也不能“跳过”补（休息是必要的）。那是“天道”——不是“人愿”。她顺从了——身体就“调”了。她抗拒了——身体就“乱”了。

朱先生说“天之道损有余补不足”是自然的均衡。母亲的身体告诉我们：**母乳喂养就是“天道”——有余则损（排空）、损后则补（充盈）。身体自己“调”——不是“人力”能加速的。**

| 朱邦復的“天之道损有余而补不足” | 母亲经验的“損有餘而補不足” |
| :--- | :--- |
| 天道的自然均衡 | 母乳喂养——有余则损（排空）、损后则补（充盈）；身体自己“调” |
| 第三人称：自然的规律 | 第一人称：我的身体在“损”和“补”之间调——那是“天道” |


## 三、“人之道则不然，损不足以奉有余”——人道不是这样：减损不足来供奉有余

### 朱邦復的解读：人道是反均衡的

朱先生将“人之道则不然，损不足以奉有余”解读为“人道是专门剥夺不足的来奉承强大的”：

> “天之所以損有餘而補不足者，是天以均衡律為則。人損不足以奉有餘，即違反了均衡律。”

“人道”不是“所有人的道”——是“偏离道的人之道”。它不符合自然均衡——它把“不足”的拿去“奉”给“有余”的。那是“锦上添花”，不是“雪中送炭”。

### 从母亲身体的经验出发：“养育标准”就是“人道”——已经累到极限的母亲（不足）还要被要求“更多”（被损），去供奉“完美妈妈”的标准（有余）

“損不足以奉有餘”——在母亲的身体里，“人之道”是什么？

- **她已经累到极限了——但还是被要求“更多”。** 她睡眠不足（不足）——但还要继续“被损”（熬夜、早起）。那是“人道”。
- **她已经精疲力尽了——但社会还在要求她“完美”。** 她精疲力尽（不足）——但还要继续“奉”给“好妈妈”的标准（有余）。那是“人道”。
- **“人道”的深层含义：** 母亲需要识别“人道”的陷阱——那个“你还要更多”的声音。那不是“天道”的声音——是“人道”的声音。天道说“不足的要补”——人道说“不足的继续损”。她需要停下来——听哪个声音是“天道”，哪个是“人道”。

朱先生说“人道损不足以奉有余”是反均衡的。母亲的身体告诉我们：**她已经被掏空了，但还在被要求“更多”——那是“人之道”（损不足奉有余）。她需要停下来，听“天道”的声音——不足的要“补”，不要继续“损”。**

| 朱邦復的“人道损不足以奉有余” | 母亲经验的“損不足以奉有餘” |
| :--- | :--- |
| 人道反均衡 | 她已经累了——但还要继续给；已经空了——但还要继续“奉”。那是“人道” |
| 第三人称：人道的颠倒 | 第一人称：我已经空了——不能再“损”了 |


## 四、“孰能有馀而有以取奉於天者乎？唯有道者乎？”——谁能在有余时奉献给天道？只有有道者

### 朱邦復的解读：有道者才能效法天道

朱先生将“孰能有馀以奉天下，唯有道者”解读为“谁能在有余时施给不足者？唯有有道之人”：

> “有誰能把多餘的施給不足者呢？唯有有道之人。”

“有道者”不是“什么都知道”的人——是“能像天道一样运作”的人：有余的时候——不“囤”着——而是“奉”给不足的。

### 从母亲身体的经验出发：母亲在某种意义上就是“有道者”——有余时给（乳汁充足时喂哺），不足时（自己空了）——如果还能停下来、不继续“损”自己——那就是“有道”

“孰能有餘而有以取奉於天者乎？”——在母亲的身体里，“有道者”是什么？

- **“有余时”她“奉”给“不足的”（孩子）。** 她有余力、有余奶、有余耐心的时候——她给了孩子。那是“奉於天”（效法天道）。
- **“不足时”她停下来——那也是“有道”。** 当她空了、累了、被掏空了——她停下来，不继续“损”自己。那是“有道”——因为“天道”是“不足者补之”，不是“不足者继续损”。她“不足”的时候停下来、补充自己——那是“奉於天”。
- **“有道者”的深层含义：** 她有余的时候“给”（奉于不足的）；她不足的时候“停”（让不足的被补）。无论“有余”还是“不足”——她都在“天道”的节奏里。那才是“有道”——不是“永远给”——是“在有余时给、在不足时补”。

朱先生说“唯有道者能有余以奉天下”是有道者才能效法天道。母亲的身体告诉我们：**她有余时给（奉于不足者），她不足时停（让不足的被补）。无论有余不足——她都在“天道”的节奏里。那才是“有道”。**

| 朱邦復的“唯有道者能有余奉天下” | 母亲经验的“有道者” |
| :--- | :--- |
| 有道者才能效法天道 | 她有余时给（奉于不足者），不足时停（让不足被补）——她在“天道”的节奏里 |
| 第三人称：有道者的行为 | 第一人称：我有余时给——我不足时停——那是“有道” |


## 五、“圣人為而弗有”——圣人做了但不占有

### 朱邦復的解读：为而不有是圣人之德

朱先生将“圣人为而不恃”解读为“有恩于人而不自恃”：

> “聖人有恩於人而不自恃。”

“为”是做了。“弗有”是不占有。做了——但不把它当作“自己的”。

### 从母亲身体的经验出发：母亲做了所有事——但不占有孩子。她“为”了，但“弗有”

“為而弗有”——在母亲的身体里，“为”和“弗有”是什么？

- **她做了所有事。** 喂奶、哄睡、陪伴、等待——她“为”了。
- **但她不“占有”孩子。** 她不说“你是我的”——她说“你是你自己的”。她“为”了——但不“有”。那是一种“做了，然后放手的”能力。
- **“弗有”的深层含义：** 她不是“拥有”孩子的成就、不是“拥有”他的生命。她是“给予”他的——但不“占有”他。“为”是她的作为，“弗有”是她的态度。做了——但不“抓”着。

朱先生说“圣人为而不恃”是做了但不自恃。母亲的身体告诉我们：**她做了——但不占有。她“为”了，但“弗有”。那是“做了，然后放手的”能力。**

| 朱邦復的“圣人为而不恃” | 母亲经验的“為而弗有” |
| :--- | :--- |
| 做了但不自恃 | 她做了所有事——但不占有孩子。“为”了，但“弗有” |
| 第三人称：圣人的作为 | 第一人称：我做了——但不“有”他 |


## 六、“成功而弗居”——成功了但不居功

### 朱邦復的解读：功成不居

朱先生将“功成而不处”解读为“有功于事不居功”：

> “有功於事不居功。”

“成功”是完成了。“弗居”是不居功、不留在那个“成功”的位置上。完成了——但不把自己当作“成功的原因”。

### 从母亲身体的经验出发：孩子长大了——她“成功”了，但不“居”功。她不说“是我把他养大的”——她只说“他自己长的”

“成功而弗居”——在母亲的身体里，“成功”和“弗居”是什么？

- **孩子长大了——那是“成功”。** 他健康、他独立、他成了他自己——那是她的“成功”。
- **但她不“居”功。** 她不说“是我把他养大的”——她只说“他自己长的”。她“成功”了——但不“居”。不是因为“谦虚”——是因为她知道那是他自己的路。
- **“弗居”的深层含义：** 母亲不是“成功”的原因——她是“让成功发生”的。她“弗居”——所以她可以继续、可以放手、可以不“执”着那个“成功”。如果她“居”了——她就停在那里了。她“弗居”——所以她可以继续走。

朱先生说“功成而不处”是成功了但不居功。母亲的身体告诉我们：**孩子长大了——她“成功”了——但不“居”功。她知道那是他自己的路。**

| :--- | :--- |
| 成功了但不居功 | 孩子长大了——她“成功”了，但不说“是我做的”——她说“他自己长的” |
| 第三人称：圣人的功成 | 第一人称：我“成”了——但不“居” |


## 七、“若此其不欲见贤也”——像这样，他是不想表现自己的贤能

### 朱邦復的解读：不欲见贤，不自我标榜

朱先生将“其不欲见贤”解读为“无私无欲不求表现”：

> “無私無欲不求表現。”

“见贤”是表现自己有贤能。圣人“不欲见贤”——他不想要“贤”的标签，不想被看见、被标榜。不是因为“配不上”——是因为“不需要”。

### 从母亲身体的经验出发：母亲不求被看见、被标榜。“不欲见贤”——她不需要“贤”的标签

“不欲見賢”——在母亲的身体里，“不欲见贤”是什么？

- **她不需要“贤”的标签。** 她不需要别人说“你真是个伟大的妈妈”、“你太了不起了”。那些“贤”的标签——她不需要。
- **“不欲见贤”的另一种理解：** 她不展示自己的“贤”——不说“看，我多辛苦”、“我为孩子做了多少”。她知道——但不需要别人“见”。
- **“不欲见贤”的深层含义：** 母亲不是“不见贤”——她是“不欲见贤”。她不把自己的“贤”当作“被看见”的东西。她做——但不是为了“被看见”。她“为而弗有、成功而弗居、不欲见贤”——那是她的完整状态。

朱先生说“不欲见贤”是不自我标榜。母亲的身体告诉我们：**她不需要“贤”的标签——她做，但不是为了被看见。“为而弗有、成功而弗居、不欲见贤”——那是她的完整状态。**

| :--- | :--- |
| 不自我标榜 | 她不需要“贤”的标签——她做，但不是为了被看见 |
| 第三人称：圣人的谦退 | 第一人称：我做了——但我不需要你“见” |


## 结语：“张弓”与“损益”——母亲一生的平衡术

朱邦復先生在这一章中，用“天道均衡与人道失衡”的对比框架，解读了“天道犹张弓”、“损有余补不足”、“人道损不足以奉有余”、“有道者能有余奉天下”、“圣人为而不有、成功而弗居”、“不欲见贤”等原则。他认为天道是自然的均衡——有余则损、不足则补；人道是反均衡的——损不足以奉有余；只有有道者才能效法天道；圣人做了但不占有、成功了但不居功、不追求被看见。

而母亲的身体，是这一章最完整的“张弓-损益-弗有不居-不欲见贤”的演绎者：

- **“犹张弓者也”——她的身体也在“张弓”——高了压、低了抬、有余损、不足补。**
- **“天之道，损有余而补不足”——母乳喂养是“天道”——有余则损（排空），损后则补（充盈）。**
- **“人之道则不然”——她已经空了，但还在被要求“更多”——那是“人道”（损不足奉有余）。**
- **“孰能有馀而取奉於天者乎？”——她有余时给（奉于不足者），不足时停（让不足被补）——她在“天道”的节奏里。**
- **“圣人為而弗有”——她做了所有事——但不占有孩子。“为”了，但“弗有”。**
- **“成功而弗居”——孩子长大了——她“成功”了，但不说“是我做的”——她说“他自己长的”。**
- **“不欲见贤”——她不需要“贤”的标签——她做，但不是为了被看见。**

**“张弓”——母亲一生都在“调”。** 她的身体不是“固定”的——是“不断调整”的。高了压一压、低了抬一抬、有余损一损、不足补一补。那不是“乱”——那是“调”。她需要允许自己“调”——不要求“一次到位”。

**“损有余补不足”——母亲在“天道”与“人道”之间选择。** 天道说：有余的“损”，不足的“补”。人道说：不足的“损”，有余的“奉”。母亲每天都要选择——她是在听从“天道”的声音（允许自己“补”），还是“人道”的声音（继续“损”自己）？她选择“天道”——她“足”了；她选择“人道”——她“竭”了。

**“为而弗有，成功而弗居，不欲见贤”——母亲完整的状态。** 她做了所有事——但不占有孩子。她成功了——但不居功。她不需要“贤”的标签——她做，但不是为了被看见。那是她的完整——不是“自我牺牲”——是“自我完整”。她“为”了，但“弗有”；“成”了，但“弗居”；“贤”了，但“不欲见”。那是她的“道”——不是“牺牲”——是“完整”。

一个母亲的身体，就是“张弓-损益-弗有不居-不欲见贤”最日常的版本。她每天都在“调”自己——有余时给，不足时补。她不做“人道”的奴隶——她选择“天道”。她做了——但放了。她成功了——但走了。她贤了——但不需要被看见。那是她的“道”——不是“牺牲”——是“完整”。

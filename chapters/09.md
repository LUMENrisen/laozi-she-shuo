

## 引言：最“反战”的一章，最“身体”的知足

帛书本第四十六章，是《德道经》中关于“有道无道”与“知足”关系的集中论述：

> 天下有道，卻走馬以糞。天下无道，戎馬生於郊。
>
> 罪莫大於可欲，𢢸（禍）莫大於不知足，咎莫憯於欲得。
>
> 故知足之足，恒足矣。

“天下有道”——天下有道的时代，“却走马以粪”——退下战马去耕田施肥（马用于农耕生产）。“天下无道”——天下无道的时代，“戎马生于郊”——战马在郊野产仔（连怀孕的母马都要上战场）。

“罪莫大于可欲”——没有比放纵欲望更大的罪过；“祸莫大于不知足”——没有比不知满足更大的祸患；“咎莫惨于欲得”——没有比贪得无厌更惨痛的过错。

“故知足之足，恒足矣”——所以知道满足的那种满足，才是永远的满足。

朱邦復先生在《止笑譚》中，将这一章解读为 **“不知足的心理情结与知足的精神状态”** 。他认为“可欲”是欲望的刺激，“不知足”是一种心理状态——“感觉到永远得不到快乐及满足，需要不断地追求，无休无止地驱使自已”。“欲得”是“不知足”的主因——“未得时固然欲得，既得后仍不知足，继续欲得不已”。他最后以“知足之足，常足矣”作结——唯有知足的满足，才是真正的充足。

但如果我们把主语换成“母亲的身体”——那个在“天下有道”时安静耕耘、在“天下无道”时被消耗的身体——这一章就不再是“政治与欲望的批判”，而是一份 **“关于母亲身体如何在‘田’与‘郊’之间被使用、被消耗或被滋养的完整记录”**：

- “天下有道，却走马以粪”——当身体“有道”时，它是安静的、滋养的、被善待的。她像走马一样在田里耕作——不紧不慢、有节律、有产出。她的身体被“用”在创造和滋养上——不是被“耗”在战斗上。
- “天下无道，戎马生于郊”——当身体“无道”时，它被消耗、被榨干、被迫“战斗”。产后急于恢复、急于“回到状态”、急于成为“好妈妈”的标签——她的身体不是被滋养，是被“用”在边界上。“戎马生于郊”——连怀孕都要在战场上生产的母马，就是那个在“郊”（边界、前线、消耗之地）被耗尽的身体。
- “罪莫大于可欲”——对一个母亲来说，“可欲”是什么？是“更好的身材”、“更完美的人生”、“更优秀的孩子”。“可欲”让她的身体被欲望驱使，而不是被需要滋养。
- “祸莫大于不知足”——如果母亲总是不满足于孩子的现状，总觉得“还差一点”——她就会焦虑、压迫、对孩子不接纳。那不是“为了他好”——那是“祸”。不知足的焦虑会侵蚀她与孩子之间的连接。
- “咎莫惨于欲得”——“欲得”是她想要更多：孩子更听话、更优秀、更让自己“有面子”。但那个“欲得”是最惨的——因为它让她看不见孩子本身，只看见孩子“还差什么”。她想要“得”更多——却可能“失”掉了他对她的信任。
- “知足之足”——“他还好”就已经足够了。不是“比昨天更好”、“比别人更好”——是“他在、他还好”。那个“足”不需要比较——它是“恒足”。她不需要“更多”——因为她已经有了“他在”。


## 一、“天下有道，却走马以粪”——天下有道，退马耕田

### 朱邦復的解读：有道之世，生产重于战争

朱先生将“天下有道，却走马以粪”解读为“马匹是生产工具”：

> “在有道的社會中，馬匹是生產的動力。”

“却”是退下、退去。“走马”是战马。“以粪”是耕田施肥。退下战马用于农耕——生产取代了战争。马从“武器”变成了“工具”。

### 从身体经验出发：当母亲的身体“有道”时，它是安静的、滋养的、被善待的——像走马在田里

“天下有道”在母亲的身体里是什么？

- **她的身体“有道”时，是“田”不是“郊”。** 田是安稳的、有节律的、产出而不消耗的。她在田里——不急、不躁、不被催促。她的身体被用于“滋养”和“创造”——不是被用于“战斗”和“消耗”。
- **“却走马以粪”的养育版本：** 她把“战马”（焦虑、控制、急于求成）退下来。她不用身体去“战斗”——她让身体在安稳中运作。她在“田”里——安静地耕作、耐心地等待、信任身体自己的节律。那不是“无为”——那是“有道的为”。
- **“走马”的意象：** 马是力量的象征——但“有道”时，力量不被用于战斗——被用于耕作。母亲的身体力量也是如此——她不把力量用于“对抗”（急于恢复、急于证明）——她把力量用于“承载”（喂奶、抱睡、陪伴）。“走马”在田里——那才是力量该在的地方。

朱先生说“却走马以粪”是战马用于农耕。母亲的身体告诉我们：**当她“有道”时，她把力量从“战斗”（焦虑、控制）退下来——让身体在“田”里安静地运作。力量不在“郊”上——在“田”里。**

| 朱邦復的“却走马以粪” | 母亲经验的“卻走馬以糞” |
| :--- | :--- |
| 战马退下用于农耕 | 她把力量从“战斗”（急于恢复、控制）退下——用在“滋养”和“承载”上 |
| 第三人称：有道的社会 | 第一人称：我的力量不在“郊”上——在“田”里 |


## 二、“天下无道，戎马生于郊”——天下无道，战马生于郊野

### 朱邦復的解读：无道之世，连母马都要上战场

朱先生将“天下无道，戎马生于郊”解读为“乱世中连怀孕的母马都不能幸免”：

> “正常情況，馬力用作生產，反常時，生產荒廢，殃及牲畜。”

“戎马”是战马。“生”是产仔。“郊”是郊野、战场。连怀孕的母马都在战场上产仔——说明社会已经混乱到什么程度了。

### 从身体经验出发：当母亲的身体“无道”时，它被消耗、被榨干、被迫在“郊”（前线）生产

“天下无道”在母亲的身体里是什么？

- **她的身体“无道”时，是“郊”不是“田”。** 郊是边界、前线、消耗之地。她的身体不是在安稳的田里“耕作”——它是在“郊”上被耗尽、被要求、被迫“战斗”。
- **“戎马生于郊”的养育版本：** 产后急于恢复、急于回到“状态”、急于成为“好妈妈”的标签——她的身体被迫在“郊”上“战斗”。她的“戎马”（焦虑、攀比、自我要求）不是退下来——而是冲上去。她的“走马”变成了“戎马”——力量被用于对抗，而不是承载。
- **“戎马生于郊”的深层含义：** 连“怀孕”都要在前线发生——意味着身体连“休息”的权利都被剥夺了。一个母亲的产假还没结束就被要求工作、她的身体还在恢复却被催促“快点回来”——那就是“戎马生于郊”。她的身体不是在生产——是在被生产“消耗”得无法喘息。

朱先生说“戎马生于郊”是乱世连母马都不能幸免。母亲的身体告诉我们：**当她“无道”时，她的身体被要求“战斗”——急于恢复、急于证明、急于回到“战场”。她的力量不是被用来“耕作”的——是被用来“消耗”的。那不是“田”——那是“郊”。**

| 朱邦復的“戎马生于郊” | 母亲经验的“戎馬生於郊” |
| :--- | :--- |
| 乱世中连母马都在战场产仔 | 她的身体被要求“战斗”——急于恢复、急于证明。那是“郊”不是“田” |
| 第三人称：无道的社会 | 第一人称：我的身体不是在“田”里耕作——是在“郊”上被消耗 |


## 三、“罪莫大於可欲”——没有比放纵欲望更大的罪

### 朱邦復的解读：欲望是祸患的根源

朱先生将“罪莫大于可欲”解读为“欲望是最大的祸根”：

> “最大的災禍就是人之不知足；最大的過失，則來自人的貪得。”

“可欲”是“可以引发欲望的东西”。“罪”不是法律意义上的罪——是“偏离、失误、错误的根源”。“可欲”是偏离“道”的起点。

### 从母亲经验的解读：对她来说，“可欲”是“更好的身材”、“更完美的人生”、“更优秀的孩子”

“罪莫大於可欲”——在母亲的身体里，“可欲”是什么？

- **“更好的身材”是“可欲”。** 产后她应该把注意力放在身体恢复上——但当“可欲”（社交媒体上那些“产后恢复神速”的图片）出现时，她的身体被欲望驱使：她要求自己更快“回去”。那不是“自我要求”——那是“被欲望驱使”。她的身体不是在“恢复”——是在“追赶”。那是“罪”——偏离了身体真正的需要。
- **“更完美的人生”是“可欲”。** 她应该接受“现在就是生活”——但当“可欲”（别人展示的“完美育儿生活”）出现时，她开始觉得“我的生活不够好”。那不是“反思”——那是“被欲望牵着走”。
- **“更优秀的孩子”是“可欲”。** 她应该“看见”孩子——但当“可欲”（“别人家的孩子”）出现时，她开始用“标准”衡量他。那不是“爱”——那是“可欲”让她看不见真正的他。

朱先生说“罪莫大于可欲”是欲望是祸患的根源。母亲的身体告诉我们：**“更好的身材”、“更完美的人生”、“更优秀的孩子”——这些都是“可欲”。它们让她偏离了“看见当下”的能力。“可欲”是通往“郊”的路——不是通向“田”的路。**

| 朱邦復的“罪莫大于可欲” | 母亲经验的“罪莫大於可欲” |
| :--- | :--- |
| 欲望是偏离的根源 | “更好的身材”、“更完美的育儿”、“更优秀的孩子”——它们是“可欲”，让她偏离了“当下” |
| 第三人称：欲望的批判 | 第一人称：“可欲”让我看不见真正的他 |


## 四、“祸莫大於不知足”——没有比不知满足更大的祸

### 朱邦復的解读：不知足的心理情结

朱先生将“祸莫大于不知足”解读为“不知足是最大的灾祸”：

> “最大的災禍就是人之不知足……是一種心理現象，感覺到永遠得不到快樂及滿足，需要不斷地追求，無休無止地驅使自己。”

“不知足”不是“不想要”——是“永远觉得不够”。它像一个心理黑洞——永远填不满。

### 从母亲经验的解读：当母亲总是不满足于孩子的现状，总觉得“还差一点”——那是“祸”

“禍莫大於不知足”——在母亲的身体里，“不知足”是什么？

- **她总觉得“还差一点”。** 孩子还不够健康、还不够聪明、还不够独立、还不够“好”——她永远觉得“还差一点”。那不是“期望”——那是“不知足”。不知足让她看不见孩子“已经”的样子——只看见“还缺”的样子。
- **不知足的代价：** 她的焦虑传递给孩子——孩子觉得自己“还不够好”。她与孩子之间的连接被“还差一点”的裂缝割开。那不是“为了他好”——那是“禍”。
- **不知足的另一个层面：** 她对自己也不满足。她觉得自己还不够瘦、还不够好、还不够“像个好妈妈”。那个不知足——让她无法安然地“在”。“祸”不在外面——在她的“不足感”里。

朱先生说“祸莫大于不知足”是不知足是最大的祸患。母亲的身体告诉我们：**当她总是不满足于孩子的现状——那才是真正的“祸”。不知足让她看不见孩子“已经”的样子，只看见“还缺”的样子。**

| 朱邦復的“祸莫大于不知足” | 母亲经验的“禍莫大於不知足” |
| :--- | :--- |
| 不知足是最大的祸患 | 她总觉得“还差一点”——不知足让她看不见孩子“已经”的样子 |
| 第三人称：欲望的心理分析 | 第一人称：“还差一点”割开了我和他之间 |


## 五、“咎莫憯於欲得”——没有比贪得无厌更惨痛的过错

### 朱邦復的解读：欲得是最惨痛的过失

朱先生将“咎莫大于欲得”解读为“欲得是最大的过失”：

> “最大的過失，則來自人的貪得。”

“咎”是过错、灾殃。“憯”是惨痛。欲得——想要得到更多——是最惨痛的过错。因为“欲得”永远不会停止——你“得”了，还想“得”。

### 从母亲经验的解读：“欲得”是她想要孩子更听话、更优秀、更让自己“有面子”——那个“欲得”让她看不见孩子本身

“咎莫憯於欲得”——在母亲的身体里，“欲得”是什么？

- **“欲得”——她想要孩子更优秀。** 她想要他考第一、想要他“有出息”、想要他在别人面前“让她有面子”。那是“欲得”。
- **“欲得”的代价：** 她想要“得”更多——但她可能“失”了。她失了他对她的信任、失了他愿意分享的心、失了他“做自己”的能力。那个“欲得”是最惨痛的——因为它让她在“得到”的名义下失去了更重要的东西。
- **“欲得”与“知足”的区别：** “欲得”是“我想要的还不在”——它永远向外看。“知足”是“我想要的已经在了”——它看见“已有的”。母亲最难的一课——不是“给他更多”——是“看见他已经有了的”。

朱先生说“咎莫大于欲得”是贪得是最惨痛的过错。母亲的身体告诉我们：**她想要孩子更优秀——那是“欲得”。但“欲得”让她看不见孩子本身。她可能“得到”了成绩——但失去了他的信任。那才是“憯”。**

| 朱邦復的“咎莫大于欲得” | 母亲经验的“咎莫憯於欲得” |
| :--- | :--- |
| 贪得是最惨痛的过错 | 她想要孩子更优秀——那是“欲得”。但“欲得”让她看不见孩子本身 |
| 第三人称：贪欲的批判 | 第一人称：我想要“得”——却可能“失”了他 |


## 六、“故知足之足，恒足矣”——知道满足的满足，才是永恒的满足

### 朱邦復的解读：知足才能常足

朱先生将“知足之足，常足矣”解读为“知足的满足才是真正的充足”：

> “唯有知足的滿足，才是真正的充足。”

“知足”不是“不要”——是“看见已有的”。“知足之足”不是“少”——是“够”。当你知道“够”在哪里——你就永远“足”了。

### 从母亲经验的解读：“他还好”就已经足够了——那是“恒足”

“知足之足，恒足矣”——在母亲的身体里，“知足之足”是什么？

- **“他还好”——那就是“足”。** 不是“他比别人好”——是“他还好”。他活着、他平安、他在。那些“已经”的——就是“足”。当她看见“已经”的——她就“恒足”了。
- **“恒足”不是“永远满足于现状”——是“每次看见他的时候，都觉得够了”。** 她不需要“更多”的证明——因为他在、他还好。那个“足”不需要比较——它是“恒”的。
- **“恒足”的深层含义：** 她不需要“更好”的标签来确认自己是好妈妈——因为她已经“有”了他。她的“足”不在“别人说我是好妈妈”里——在“他在我身边”里。

朱先生说“知足之足常足矣”是知足才是真正的充足。母亲的身体告诉我们：**“他还好”——那就是她的“足”。她不需要更多证明——因为“他在”就是“恒足”。**

| 朱邦復的“知足之足常足矣” | 母亲经验的“知足之足恒足矣” |
| :--- | :--- |
| 知足才是真正的充足 | “他还好”——那就是她的“足”。她不需要更多证明——因为“他在”就是“恒足” |
| 第三人称：知足的境界 | 第一人称：我不需要“更好”——我只需要“他在” |


## 结语：“走马”回到“田”里——母亲身体的“知足之道”

朱邦復先生在这一章中，用“可欲-不知足-欲得”的递进关系，构建了一个关于欲望的批判框架——“可欲”是偏离的起点，“不知足”是心理黑洞，“欲得”是最惨痛的过错。他最后以“知足之足”作为解决方案——看见“已有”的，才是真正的“足”。

而母亲的身体，是这一章最完整的“走马-戎马”的演绎者：

- **“天下有道，却走马以粪”——当身体“有道”时，力量从“战斗”退下，用在“滋养”和“承载”上。那是“走马”在“田”里。**
- **“天下无道，戎马生于郊”——当身体“无道”时，力量被用于“战斗”——急于恢复、急于证明。那是“戎马”在“郊”上。**
- **“罪莫大于可欲”——“更好的身材”、“更完美的育儿”、“更优秀的孩子”——那些“可欲”让她偏离了“当下”。**
- **“祸莫大于不知足”——她总觉得“还差一点”——不知足让她看不见孩子“已经”的样子。**
- **“咎莫惨于欲得”——她想要孩子更优秀——那是“欲得”。但“欲得”让她看不见孩子本身。**
- **“知足之足”——“他还好”——那就是她的“足”。她不需要更多证明——因为“他在”就是“恒足”。**

**“走马”与“戎马”的对比：** 当母亲的身体被当作“走马”时——它在“田”里安静地耕作、滋养、承载。那是“有道”——力量用在“给”上。当她的身体被当作“戎马”时——它在“郊”上被消耗、被透支、被要求“战斗”。那是“无道”——力量用在“对抗”上。她能做的——是让“走马”回到“田”里。把力量从“战斗”退下来——放在“滋养”上。

**“知足”不是“少”——是“看见已有的”。** 母亲最大的“足”——不是“孩子比别人好”——是“他还好”。他在、他平安、他活着——那就是“恒足”。不需要比较、不需要更多证明。“知足之足”不是“不再想要”——是“已经够了”。

一个母亲的身体，可以在“田”里，也可以在“郊”上。她能选择的——是让力量从“战斗”退下来，回到“滋养”的位置上。“走马”在“田”里——那是她的“恒足之道”。



## 引言：最“反战”的一章，最“身体”的节制

帛书本第三十章，是《德道经》中关于“不以武力逞强”的集中论述：

> 以道佐人主，不以兵強於天下。其事好還，
>
> 師之所居，楚朸（棘）生之。
>
> 善者果而已矣，毋以取強焉。果而毋䮦（驕），果而勿矜，果而勿伐，
>
> 果而毋得已居，是胃（謂）果而不強。
>
> 物壯而老，是胃（謂）之不道，不道蚤（早）已。

“以道佐人主”——用道来辅佐君主的人，“不以兵强于天下”——不靠武力在天下逞强。“其事好还”——这种事（武力）会很快招致反报。

“师之所处，荆棘生焉”——军队驻扎过的地方，会长满荆棘。“善者果而已矣”——善于用兵的，达到目的就停止了，“毋以取强”——不用武力来逞强。“果而毋骄”——成功了但不骄傲；“果而勿矜”——成功了但不自大；“果而勿伐”——成功了但不夸耀；“果而毋得已居”——成功了但不自以为是。“是谓果而不强”——这就是达到目的但不逞强。

“物壮则老”——事物到了壮盛就会衰老，“是谓不道”——这就叫做“不合道”，“不道早已”——不合道的东西会很快消亡。

朱邦復先生在《止笑譚》中，将这一章解读为 **“武力会招致反作用力”** 。他认为“以道佐人主者，不以兵强天下”是“不诉诸武力”——因为武力会因果相循，你用力打别人，别人也会用力打回来。“其事好还”是“作用力与反作用力相等”——你用多大的力打出去，就会有多大的力回来。他特别强调了“善者果而已”——有识者用兵不过是为了达到目的，达到后就要停，不可继续逞强。“物壮则老”是“不道”的表现——任何事物一旦发展到极致，就会走向衰亡。

但如果我们把主语换成“母亲的身体”——那个每天都在面对一个“成长”与“衰老”同时发生的生命的身体——这一章就不再是“反战的政治哲学”，而是一份 **“关于如何不强行塑造、如何接受自然生命周期”的养育记录**：

- “以道佐人主，不以兵强于天下”——用“道”来辅助孩子的成长，而不是用“强力”来控制他。
- “其事好还”——你越是用力控制他、强迫他、要求他服从——他越会用同样的力量反抗你。你的“兵”（控制手段）会招致他的“兵”（反抗）。
- “师之所处，荆棘生之”——你使用“强力”的地方，关系会变得荒芜。你越是用“指挥”和“命令”——你们之间就越长满了“荆棘”（不信任、疏远、对抗）。
- “善者果而已”——好的辅佐者达到目的就停止了。母亲在孩子独立后，也选择“退”。你“果”了（他长大了）——你就“而已”（停）了。不再“取强”——不再控制、不再干涉。
- “果而毋骄、毋矜、毋伐”——孩子长大成人了，你成功了，但你不骄傲、不自大、不居功。这不是你的“成就”——是他的生长。你只是“让”它发生了。
- “果而毋得已居”——不把“果”当作“自己的功劳”而停留在那里。你不说“都是我做的”——你说“他自己长的”。
- “物壮则老”——孩子长大了、强壮了，你作为“主要照顾者”的角色也“老”了。那不是“不道”——那是“物壮则老”的自然节律。你不抓住不放——你承认“它结束了”，然后让它过去。

让我们逐句对照。


## 一、“以道佐人主，不以兵強於天下”——用道来辅佐人主，不靠武力逞强

### 朱邦復的解读：用道辅佐，不诉诸武力

朱先生将“以道佐人主，不以兵强天下”解读为“用道辅佐君主的人不诉诸武力”：

> “以道佐人主者，不以兵強天下。”

“佐”是辅助、辅佐。“人主”是君主。“兵”是武力、强力手段。“以道佐”就是用道的原则来辅助——而不是用“兵”（强制、威胁、控制）来“强”（逞强）。

### 从身体经验出发：用“道”来辅助孩子的成长——而不是用“强力”来控制他

“以道佐人主”——在母亲的身体里，“佐人主”是什么？

- **你是在“辅助”孩子的成长——不是“主导”他的人生。** “人主”是孩子自己——他是他生命的主人。你是“佐”（辅助）他的——不是“主”（主宰）他的。
- **“不以兵强于天下”——你不用“强力”来控制他。** 你不靠命令、威胁、惩罚、强迫来让他“听话”。你不是在用“兵”强他——你是在用“道”陪他。
- **“兵”的养育版本：** 大声吼叫、惩罚、冷暴力、控制性要求——“你怎么还不睡”、“你必须吃完”、“你再这样我就不爱你了”——这些都是“兵”。你用它们来“强”孩子。但那不是“道”。

朱先生说“以道佐人主不以兵强天下”是用道辅佐，不靠武力逞强。母亲的身体告诉我们：**你是在“辅助”他的成长——不是“主宰”他的人生。你不靠“兵”（强制、威胁、惩罚）来让他“听话”——你靠“道”（回应、陪伴、等待）。**

| 朱邦復的“以道佐人主不以兵强天下” | 母亲经验的“以道佐人主不以兵強於天下” |
| :--- | :--- |
| 用道辅佐君主，不靠武力逞强 | 你是在“辅助”孩子的成长，不是“控制”他——不用命令、威胁、惩罚来让他“听话” |
| 第三人称：辅佐的原则 | 第一人称：我不是“司令”——我是“辅佐官” |


## 二、“其事好還”——这种事会很快招致反报

### 朱邦復的解读：武力会招致反作用力

朱先生将“其事好还”解读为“武力会因果相循”：

> “武力會因果相循，無休無止。”

“好还”是“容易返还”——你用多大力打出去，就会有多大力弹回来。武力不是“单向”的——它是“往返”的。你强，别人更强；你用力，别人用更大的力。

### 从身体经验出发：你越用力控制他——他越会用同样的力量反抗你

“其事好還”——在母亲的身体里，“好还”是什么？

- **你用力控制他——他用力反抗你。** 你对他说“你必须现在睡觉”——他用更激烈的哭闹来“还”你。你对他吼“不许哭”——他哭得更凶。你用“兵”来强他——他用“兵”来强你。
- **“好还”不是“惩罚”——是“力学”。** 你给出去的力，会回到你身上。不是因为他“故意”反抗——是因为力的作用就是这样的。你推他，他退；你拉他，他靠；你用力压他，他用力顶。
- **“还”的另一个层面：** 你用心陪伴他——他也用心靠近你。你用力倾听他——他也用力向你表达。力的“好还”不只是控制的反作用——也是信任的反作用。

朱先生说“其事好还”是武力会很快招致反报。母亲的身体告诉我们：**你越用力控制他——他越用力反抗你。力是“好还”的——不是因为他坏，是因为物理就是这样。**

| 朱邦復的“其事好还” | 母亲经验的“其事好還” |
| :--- | :--- |
| 武力会招致反作用力 | 你越用力控制他——他越用力反抗你。力是“好还”的 |
| 第三人称：力的反作用 | 第一人称：我推他——他推回来；我拉他——他靠过来。用力的方式决定了“还”的方式 |


## 三、“師之所居，楚朸生之”——军队驻扎过的地方，会长满荆棘

### 朱邦復的解读：战争带来的荒芜

朱先生将“师之所处，荆棘生焉”解读为“军队所到之处，遍地荒凉”：

> “軍隊所到之處，遍地荒涼。”

战争会带来破坏——土地荒废、民生凋敝。军队走过的地方，留下的不是繁荣——是“荆棘”（荒芜、破坏、伤痕）。

### 从身体经验出发：你用“强力”管教过的地方——关系会长出“荆棘”（疏远、不信任、对抗）

“師之所居，楚朸生之”——在母亲的身体里，“师”和“荆棘”是什么？

- **“师”是你的“军队”**——命令、惩罚、威胁、冷暴力。那些你用来“强”他的手段。
- **“荆棘”是关系的荒芜**——他不再信任你、不再靠近你、不再愿意和你说话。你的“军队”走过的地方——关系就“荒”了。你越是用“军队”（控制手段）来“占领”他的领地——那个地方就越长满了“荆棘”（对抗、疏远、沉默）。
- **“荆棘”不是一夜之间长出来的**——是一次次“师之所居”累积的结果。你今天吼他一次——那里长了一根刺；明天再威胁他一次——那里又长了一根。你不知道什么时候“荆棘”已经长满了——但你知道他不再愿意亲近你了。

朱先生说“师之所处荆棘生焉”是战争带来的荒芜。母亲的身体告诉我们：**你用“强力”管教过的地方——关系会长出“荆棘”（疏远、不信任、对抗）。军队走过的地方，土地会荒；你的“军队”走过的地方，关系会荒。**

| 朱邦復的“师之所处荆棘生焉” | 母亲经验的“師之所居楚朸生之” |
| :--- | :--- |
| 军队带来的荒芜 | 你用“强力”管教过的地方——关系会长出“荆棘”（疏远、不信任、对抗） |
| 第三人称：战争的后果 | 第一人称：我的“军队”走过的地方——他不再靠近了 |


## 四、“善者果而已矣，毋以取強焉”——善于用兵的，达到目的就停止，不逞强

### 朱邦復的解读：达到目的就要停止

朱先生将“善者果而已，不敢以取强”解读为“有识者用兵不过希望达到目的而已”：

> “有識者用兵不過希望達到目的而已，不敢以此逞強。”

“果”是达到目的、完成目标。“而已”是“就这样，不再继续”。“取强”是逞强、继续用力、不满足于“果”而想要更多。善者“果”了就“已”——不继续“强”。

### 从身体经验出发：你“果”了（他长大了）——你就“已”了（停止“塑造”他）

“善者果而已矣”——在母亲的身体里，“果”和“已”是什么？

- **“果”——他长大了。** 他不再是一个需要你时刻照料的婴儿了。他已经能走路、能说话、能吃饭、能交朋友了。这就是“果”——你的“养育”达到了它的“目的”。
- **“已”——你停止了“塑造”他。** 你不继续“取强”——不继续控制他的选择、不继续决定他走哪条路、不继续“强”他成为你想要他成为的人。你“果”了——你就“已”了。
- **“毋以取強”——不要继续逞强。** 他长大了，你不需要再用“兵”（控制、命令、安排）来“强”他。你“果”了——你可以“已”了。停下来，让他自己走。

朱先生说“善者果而已不敢以取强”是达到目的就停止，不逞强。母亲的身体告诉我们：**他长大了——这就是“果”。你“果”了，就应该“已”——停止“塑造”他，不再“取强”。**

| 朱邦復的“善者果而已不敢以取强” | 母亲经验的“善者果而已矣毋以取強焉” |
| :--- | :--- |
| 达到目的就停止，不逞强 | 他长大了（果）——你就“已”（停止“塑造”他），不再“取强”（继续控制） |
| 第三人称：用兵的节制 | 第一人称：我“果”了——我应该“已”了 |


## 五、“果而毋驕”——成功了但不骄傲

### 朱邦復的解读：成功了不自大

朱先生将“果而勿矜”等解读为“达到目的也不自满、自夸、自傲”：

> “達到目的也不可自滿、自誇、自傲。”

“果”是成功——但你不能因为“果”而“骄”。因为那不是你一个人的功劳——是很多因素的共同结果。

### 从身体经验出发：孩子长大成人了——你成功了，但你不骄傲。因为那不是你的“成就”——是他的生长

“果而毋䮦”——在母亲的身体里，“毋骄”是什么？

- **孩子长大了——但你不说“看，是我把他养大的”。** 因为那不是你的“成就”——那是他的生长。你只是陪了他一段——不是“做”出了他。
- **“毋骄”的另一种理解：** 你不需要在别人面前炫耀“我的孩子如何如何”。那不是你的功绩——那是他的生命。你“骄傲”的不是“我”——而是“他”。但“骄傲”本身带着“我”的影子——“看，我养的孩子”。当你放下“我”——你就不“骄”了。

朱先生说“果而毋骄”是成功了但不骄傲。母亲的身体告诉我们：**孩子长大成人了——你成功了，但你不骄傲。因为那不是你的“成就”——是他的生长。“骄”是以为“我做的”——但你没有“做”他——你只是“让”他长。**

| 朱邦復的“果而勿矜” | 母亲经验的“果而毋䮦” |
| :--- | :--- |
| 成功了但不骄傲 | 孩子长大了——但你不说“看，是我把他养大的”——因为那不是你的成就，是他的生长 |
| 第三人称：功成的态度 | 第一人称：我没有“做”他——我只是“让”他长 |


## 六、“果而勿矜”——成功了但不自大

### 朱邦復的解读：成功了不炫耀

朱先生将“果而勿矜”解读为“成功了不自大”：

> “不自矜。”

“矜”是自大、自以为是、觉得自己了不起。善者“果”了但不“矜”——因为他知道“果”不是他一个人的。

### 从身体经验出发：你“果”了（他独立了）——但你不“矜”（不以为那是你的功劳）

“果而勿矜”——在母亲的身体里，“矜”是什么？

- **他能够独立了——但你不说“都是我教会他的”。** 你不把功劳归于自己——因为他的独立是他自己走出来的。你只是提供了他能够走出来的环境。
- **“矜”的另一个层面：** 你不在孩子面前说“你是我养大的，所以你应该听我的”。你不以“我是你妈妈”来“矜”你的权威。因为你不是“制作者”——你是“见证者”。

朱先生说“果而勿矜”是成功了但不自大。母亲的身体告诉我们：**他独立了——但你不“矜”。你不在他面前说“看，我培养出了你”——因为你不是“制作者”，你是“见证者”。**

| 朱邦復的“果而勿矜” | 母亲经验的“果而勿矜” |
| :--- | :--- |
| 成功了但不自大 | 他独立了——但你不说“都是我教会他的”——因为你是见证者，不是制作者 |
| 第三人称：功成的态度 | 第一人称：我不是“制作者”——我是“见证者” |


## 七、“果而勿伐”——成功了但不自夸

### 朱邦復的解读：成功了不炫耀

朱先生将“果而勿伐”解读为“成功了不自夸”：

> “不自伐。”

“伐”是夸耀、显示自己有功。善者“果”了但不“伐”——因为他知道“果”不是用来“展示”的，是用来“完成”的。

### 从身体经验出发：你不展示“我的孩子多优秀”——因为他不是你的“作品”

“果而勿伐”——在母亲的身体里，“伐”是什么？

- **你不在别人面前炫耀“我的孩子多优秀”。** 因为那不是你的“作品”——那是他的生命。你“伐”了——就是把他的生命当作你的“成果”。你不“伐”——因为你知道他属于他自己。
- **“伐”的另一种理解：** 你不在孩子面前说“你看，我为你做了多少”——你不把他的成长当作你的“功劳簿”。你不“伐”——因为你做那些事不是为了“被记功”——是为了让他能长大。

朱先生说“果而勿伐”是成功了但不自夸。母亲的身体告诉我们：**你不展示“我的孩子多优秀”——因为那不是你的“作品”，是他的生命。“伐”是把别人的生命当作自己的成果——你不“伐”，是因为你尊重他是独立的。**

| :--- | :--- |
| 成功了但不自夸 | 你不炫耀“我的孩子多优秀”——因为那不是你的“作品”，是他的生命 |
| 第三人称：功成的态度 | 第一人称：他不是我的“作品”——他是他自己 |


## 八、“果而毋得已居”——成功了但不自以为是

### 朱邦復的解读：不居功自傲

“果而毋得已居”——在母亲的身体里，“得已居”是什么？

- **“得已”是“自以为是”——觉得自己对了、觉得自己做得好。** “居”是停留、待在那里。你以为“我做对了”、“我是个好妈妈”——然后你“居”在那里，不再继续生长了。
- **“果而毋得已居”——你不把“果”当作“我做得对”的证据。** 你不会因为“孩子健康长大了”就说“我做得对”——因为那只是他恰好在你的陪伴下长大了，不是“你的方法”在起作用。
- **“毋得已居”的深层含义：** 你不“居”在“果”上。你不说“我做得好，所以我应该继续这样做”——因为孩子变了，你的方式也要变。你不“居”——你继续调整、继续陪伴、继续在变化中寻找新的平衡。

朱先生说“果而毋得已居”是“不把自己的功劳当作可以停留的地方”。母亲的身体告诉我们：**孩子健康长大了——但你不说“我做对了”。你不把“果”当作“我做得对”的证据——因为你还在继续学习，还没“居”在那里。**

| 朱邦復的“果而毋得已居” | 母亲经验的“果而毋得已居” |
| :--- | :--- |
| 成功后不居功自傲 | 孩子长大了——但你不说“我做对了”。你不把“果”当作“我做得对”的证据 |
| 第三人称：不居功 | 第一人称：我不“居”在“果”上——我继续学习 |


## 九、“是謂果而不強”——这就是达到目的但不逞强

### 朱邦復的解读：达到目的即是节制

朱先生将“是谓果而不强”解读为“达到目的但不逞强”：

> “達到目的也可不自滿……這才是‘果而不強’。”

不“骄”、不“矜”、不“伐”、不“得已居”——这些都是“不强”的表现。“果”是目的达成，“不强”是达成了但不继续用力。你不“果”了之后继续“强”——你就“果而不强”。

### 从母亲经验的解读：你“果”了（他长大了）——但你不“强”（不继续要求他成为你想要的）

“是胃果而不強”——在母亲的身体里，“果而不强”是什么？

- **你“果”了——他长大了。**
- **你“不強”——你不继续要求他成为你想要的。** 你不说“你长大了，所以你应该……”——你不继续“强”他。你“果”了，你就“不強”了。
- **“果而不强”的核心：** 你完成了“让他独立”的使命——你就不继续“用力”了。你不因为“我还能做”就继续“做”——你知道“果”到了，就该“已”了。

朱先生说“是谓果而不强”是达到了目的但不逞强。母亲的身体告诉我们：**他长大了——你“果”了。你“不強”——你不继续要求他成为你想要的。你完成了使命，就不再继续“用力”了。**

| 朱邦復的“是谓果而不强” | 母亲经验的“是胃果而不強” |
| :--- | :--- |
| 达到目的但不逞强 | 他长大了（果）——你不继续要求他成为你想要的（不强） |
| 第三人称：节制的完成 | 第一人称：我“果”了——我就“不強”了 |


## 十、“物壯而老，是謂不道，不道早已”——事物到了壮盛就会衰老，这叫做“不道”，不道的会很快消亡

### 朱邦復的解读：强盛之后必然是衰老

朱先生将“物壮则老，是谓不道，不道早已”解读为“事物强壮即面临衰败，这是不符合道的”：

> “萬事萬物有一定的規律，一旦強壯盛大，即面臨衰敗。希望永保壯盛是不符合‘道’的。”

“壮”是强盛、顶峰。“老”是衰落、完成。“物壮则老”是自然规律——任何事物到达顶峰后就会走向衰落。如果你不接受“老”——你就“不道”了。不道的，就会“早已”（很快消亡）。

### 从身体经验出发：孩子长大了、强壮了——你作为“主要照顾者”的角色也“老”了。那不是“不道”——那是“物壮则老”的自然节律

“物壯而老”——在母亲的身体里，“壮”和“老”是什么？

- **孩子“壮”了——他长大了、独立了、不需要你时刻的照顾了。**
- **你的角色“老”了——你不再是“主要照顾者”了。** 你的功能转变了——从“喂养”变成了“支持”，从“保护”变成了“守望”，从“中心”变成了“背景”。
- **“是謂不道”——如果你不接受“老”，你就“不道”了。** 如果你说“不，我还要继续当他的主要照顾者”——你就在违背自然节律。你不接受“角色老去”——你就会“不道”。
- **“不道早已”——不道的东西会很快消亡。** 如果你强行抓住“主要照顾者”的角色不放——你和孩子的关系就会“消亡”（疏远、对抗、断裂）。因为你不接受“壮而老”的节律。
- **但“老”不是“结束”——是“转化”。** 你的角色“老”了——但你作为母亲的存在没有“结束”。你从一个“照顾者”变成了一个“支持者”、一个“见证者”、一个“他可以回来找的人”。“老”是“转化”的开始——不是“消亡”的终点。

朱先生说“物壮则老是谓不道”是强盛之后必然衰老，不接受这个是“不道”。母亲的身体告诉我们：**孩子长大了——你的角色也“老”了。但“老”不是“结束”——是“转化”。如果你不接受角色“老去”，你就会“不道”。**

| 朱邦復的“物壮则老是谓不道” | 母亲经验的“物壯而老是胃之不道” |
| :--- | :--- |
| 强盛之后必然衰老，不接受这个是“不道” | 孩子长大了——你的主要照顾者角色也“老”了。不接受这个“老”，就是“不道” |
| 第三人称：自然衰老的规律 | 第一人称：我“老”了——但我是“转化”了，不是“结束”了 |


## 结语：“果而不强”——完成了，就不用力了

朱邦復先生在这一章中，用“反作用力”和“物壮则老”的自然规律，解读了“不以兵强天下”的政治哲学。他认为武力会招致反作用，战争的后果是荒芜，善者达到目的就停止、不继续逞强。最后，“物壮则老”是自然规律——不接受它，就是“不道”。

而母亲的身体，是这一章最完整的“实践场”：

- **“以道佐人主”——你不是孩子生命的主人——你是他的“辅佐官”。**
- **“不以兵强于天下”——你不用“强力”（命令、威胁、惩罚）来控制他。**
- **“其事好还”——你越用力控制他，他越用力反抗你。力是“好还”的。**
- **“师之所居，荆棘生之”——你用“强力”管教过的地方——关系会长出“荆棘”（疏远、不信任）。**
- **“善者果而已”——他长大了（果）——你就“已”（停止“塑造”他）。**
- **“果而毋骄”——你不骄傲——因为那不是你的“成就”，是他的生长。**
- **“果而勿矜”——你不自大——因为你不是“制作者”，你是“见证者”。**
- **“果而勿伐”——你不炫耀——因为那不是你的“作品”，是他的生命。**
- **“果而毋得已居”——你不把“果”当作“我做得对”的证据——因为“对”不是可以用来“居”的地方。**
- **“是谓果而不强”——你“果”了——但你不“强”了。**
- **“物壮而老”——孩子长大了，你的角色也“老”了。**
- **“是谓不道”——如果你不接受角色“老去”——你就“不道”。**
- **“不道早已”——不道的东西会很快消亡。**

**“果而不强”——完成了，就不用力了。** 一个母亲最深的功课不是“做到”——是“做到之后停下来”。你是“辅佐官”——不是“总司令”。你“果”了（他长大了）——你就“已”了（停止“塑造”）。你完成了——你就退下来。不是因为你“不爱了”——是因为你“完成了”。

**“物壮则老”——孩子长大了——你的角色也“老”了。** 那不是“结束”——那是“转化”。你从“照顾者”变成了“支持者”，从“中心”变成了“背景”，从“做”变成了“看”。你不抓住“壮”不放——你接受“老”。因为“老”不是“消亡”——是“转化”的开始。你“老”了——但你还在。你“转化”了——但你还在。只是不再是原来的方式了。

一个母亲的身体，就是“果而不强”最日常的版本。她完成了——她就不用力了。孩子长大了——她就退下来了。她的角色“老”了——但她的存在没有“消亡”。她转化了——不是结束了。
